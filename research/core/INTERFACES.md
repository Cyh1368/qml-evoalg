# Frozen interfaces for `research/core` and `research/search`

Written before any WP outcome was observed. Implementations must match these
signatures exactly; integration tests check cross-package use. Stack:
`module load Python/3.12.3-GCCcore-13.3.0 SciPy-bundle/2024.05-gfbf-2024a`
(numpy 1.26.4). LLM jobs additionally `module load ycrc-llm/1.0`. Stdlib +
numpy + scipy only. All randomness takes explicit `numpy.random.Generator` or
integer seeds. Every script honors `OPENBLAS_NUM_THREADS=1`.

## research/core/simulator.py

Gate entry format is the repository dict: `{"gate": G, "wire": i}` or
`{"gate": G, "wires": [a,b], "param": name}`. Supported `G`:
`RX RY RZ CRX CRY CRZ CNOT CZ RZZ H X Y S T`. Conventions match
`research/metrics/symmetry.py` for shared gates (`RX=tuple` =
`exp(-i t P/2)`; `CRZ(t)=exp[-i t (I-Z_c)Z_t/4]`; `RZZ(t)=exp(-i t Z⊗Z/2)`).
`RZZ` with a fixed angle may also appear as `{"gate":"RZZ","wires":[a,b],"angle":t}`.

- `unitary(gates, params: dict, n) -> ndarray (2**n,2**n)` — must agree with
  `metrics.symmetry.unitary` to 1e-12 on the shared gate set (unit-tested).
- `apply_gate_vectorized(gates, params, n, states0) -> psi` batched over the
  first axis of `states0 (m,2**n)`.
- `Forward` object from `compile_circuit(gates, param_names, n)`:
  `fwd.run(params_vec, states0) -> (psi, cache)` and
  `fwd.grad(params_vec, cache, dpsi_dloss) -> grads` reverse-mode gradients;
  plus `fwd.expect(params_vec, states0, observables) -> (m,len(obs))` matrix
  elements `<O_k>` and `fwd.grad_expect(...)`. Observables are sparse
  diagonal `{index_tuple: coeff}` terms, e.g. `Z_i` -> `{(i,):1.0}`,
  `Z_iZ_j` -> `{(i,j):1.0}` (index tuple = qubits acted on, bit convention
  `|q_0...q_{n-1}>` with q0 most significant, matching symmetry.py).
  Gradients must match central finite differences to 1e-6 (unit test).

## research/core/candidates.py

Candidate JSON schema (frozen):

```json
{"id": "c0007", "n_qubits": 6,
 "block": [<gate entries>], "repeats": 2, "layers": 2,
 "param_names": ["t0","t1",...],
 "hypothesis": {"generators": [[1,0,2,3,4,5], ...], "output_action": "invariant"} ,
 "notes": "free text", "source": {"arm": "...", "model": "...", "parent": "c0002"}}
```

`hypothesis` may be `null`. Generators are one-line permutations of
`range(n_qubits)`. `layers` re-applies the task feature map between blocks
(data re-uploading): full gate list = `layers x (feature_map + repeats x block)`.

- `expand(candidate, task) -> (gates, param_names)` interleaving
  `task.feature_map(x)` requires per-example expansion; provide
  `expand_example(candidate, task, x) -> (gates, param_names)` where feature
  gates carry fixed `angle` entries and only block gates carry `param`.
- `validate(candidate, task) -> list[str]` (empty = valid). Invalid proposals
  are kept in all denominators.
- `param_vector/param_dict`, `n_params(candidate)`, `count_gates(candidate)`.
- `sample_random(rng, task, max_block=24) -> candidate` and
  `mutate(candidate, rng, task) -> candidate` (point, insert, delete, reorder,
  retie-parameter mutations; always returns schema-valid or re-samples).

## research/core/tasks.py

`TaskSpec` attributes: `name`, `n_qubits`, `group_name`,
`generators` (list of permutations), `feature_map(x) -> gates`,
`observables` (list of diagonal observable dicts, frozen per family below),
`targets` (dict target key -> array), `x`, `orbit`, `splits` (train/
validation boolean masks), `label_oracle(X_rows) -> y` recomputing labels for
arbitrary input rows (for hypothesis label-preservation tests).

`load_family(name, development=True, locked=False)` reads
`research/datasets/.../npz`; `locked=True` must print a loud warning and is
forbidden in `research/search/` (enforced by a grep-able constant
`LOCKED_FORBIDDEN_IN = ("research/search",)` check in harness code).

Frozen adapters:
- `graphs_n6`: n=6; feature map `RZZ(pi/2)` on each edge (lexicographic edge
  order per manifest) whose bit is 1; observables `{Z_i}` plus all `Z_iZ_j`
  (21); group S6 adjacent transpositions; oracle = BFS connectedness
  (`connected`) and triangle existence, mapped `{-1,+1}`.
- `ring_n6`: n=6; feature map `RY(x_i)` on wire i (angle = x_i); same
  observable set (21); group D6 generated by the 6-cycle and `i -> -i mod 6`;
  targets `alpha_0 .. alpha_1` from the dataset; oracle = the analytic target
  formula recomputed on transformed rows.
- `tictactoe_n9`: n=9; feature map `RY(theta_c)` with theta in {0, pi/2, pi}
  for O/empty/X; observables `{Z_i}` plus all `Z_iZ_j` (45); group D4 acting
  on 3x3 cell indices; invariant target `winner` (+1 X-terminal, -1
  O-terminal, 0 draw; validated D4-invariant); D4-breaking counterfactual
  target `winner_designated_corner` (winner sign flipped when the winner owns
  a line through cell 0; measured violated-pair fraction 0.375). The
  originally drafted center-cell rule is itself D4-invariant (cell 4 is
  group-fixed) and is retained only as a sham control.
  Oracle recomputes the terminal classification and the corner rule on
  transformed boards.

## research/core/train.py

- `fit(candidate, task, x, y, seed, steps=200, batch=32, lr=0.05) -> Fit`
  Full-circuit readout `f = w . <O>(x) + b` with `w,b` trainable (init zeros,
  b init 0), block parameters init `Uniform(-pi,pi)` per `seed`. Adam, MSE,
  full-batch-equivalent minibatches from `seed`. No early stopping (fixed
  budget = `steps`); return final params and train loss.
- `Fit.predict(task, x) -> ndarray`; `risk(fit, task, x, y) -> float` MSE.
- Determinism: same seed + candidate + task => bitwise-identical loss history.

## research/search/

- `llmclient.py`: stdlib-urllib chat client for `OPENAI_BASE_URL`/
  `OPENAI_API_KEY` (models `ycrc-local`, `ycrc-local-think`;
  `reasoning_effort` in {`none`,`medium`}); retries with backoff; returns
  content + token usage; every call logged (id, model, prompt tokens,
  completion tokens, latency) to the run log. `mock=True` path returns
  deterministic random valid candidates for offline tests.
- `verifier_bridge.py`: `verify_candidate(candidate, task, params_samples,
  group="hypothesis"|"true") -> report` with full closure (reuse
  `research/verifier/verify.py` closure code by import), mean/max channel
  residual at the supplied parameter draws, and `label_preservation` computed
  by recomputing `task.label_oracle` on transformed training rows.
- `harness.py run --arm {random,mutation-ea,llm-fitness,llm-verify,
  llm-verify-repair} --family NAME --model M --seed S --budget B --out DIR`:
  identical initial population of 4 random candidates for a given seed across
  all arms; loop until B *valid evaluated* candidates (invalid proposals
  counted in `proposals_total`, not in B); dev risk selects the run's final
  candidate; test risk computed only from `development/` artifacts (there is
  no test key there — final locked evaluation is a separate script).
  Repair arm: if the proposal's hypothesis passes label preservation on
  training rows and candidate mean channel residual > 1e-6, wrap final
  predictions by averaging over the hypothesis group (inference-time
  Reynolds average, one predictor call per group element) and log it.
  Run log JSON: per-arm costs (tokens, evaluator calls, wall time), every
  proposal with validity, dev risk, residuals, and the dev-selected best.
- `job_*.sh` sbatch templates: `#SBATCH --partition=day`, 1 CPU, 4G,
  LLM arms `module load ycrc-llm`; array jobs allowed.

## Statistics conventions

Paired contrasts by seed; bootstrap over runs (>=10k resamples, fixed seed);
report mean paired difference, 95% CI, fraction of seeds improved. Orbit-
weighted and sample-weighted risks both reported for orbit-split families.
Multiplicity: Holm within each secondary family. Primary endpoints are the
ones named in `extension_plan.md`.
