# Structured permutation-hypothesis verifier

`verify.py` provides a small executable interface between structured LLM proposals and `../metrics/symmetry.py`. It accepts arbitrary permutation generators, computes the full finite closure with a hard size limit, and measures channel residuals for explicitly supplied parameter samples. Supported output claims are scalar invariance. The numerical pass does **not** certify all parameter values, input encoding, state preparation, readout, or task labels.

Input JSON contains `hypothesis` (`n_qubits`, `generators`, `output_action: "invariant"`), `candidate` (the repository gate-list format), and `parameter_samples` (a nonempty list of parameter dictionaries). Run `python research/verifier/verify.py INPUT.json --output REPORT.json`. Dense matrices limit this reference implementation to small systems; it is not a scalable general verifier.

Two repair functions expose established baselines: `repair_generator` applies the Reynolds projection to a Hermitian generator; its exact exponential commutes with the supplied group. It does not silently convert a circuit into an equivalent Hamiltonian or guarantee that a Trotterized gate sequence is symmetric. `invariant_prediction` group-averages predictions on arrays whose first axis represents sites, costing one predictor evaluation per group element. Graph edge arrays need an explicit induced edge action, and are not supported by that convenience function.

Discovery versus repair: an LLM may propose generators, but this module tests only their implementation in a candidate circuit. Independent label-preservation tests are necessary before accepting a task-symmetry hypothesis. Supplying the correct group and repairing the model is known-group repair, not unknown symmetry discovery. Treat verification feedback as a separate search arm and record its computational cost.

Tests: `python -m unittest discover -s research/verifier -p 'test_*.py'`. They check group closure, failure on malformed hypotheses, distinction between special-point and all-parameter claims, exact projection/idempotence, and predictive invariance.

Independent task validation is available through `validate_task_pairs` and `validate_task_oracle`. Provide scalar labels recomputed on explicitly transformed inputs using a task oracle; copying the original label would make the test circular. The oracle wrapper enumerates the generated group and records paired label MSE, largest discrepancy and fraction of violated pairs. `graph_edge_action` transforms undirected edge vectors ordered by lexicographic vertex pairs and supports arbitrary vertex permutations.

Declare probes `heldout` only when they were isolated from hypothesis design and search feedback. This declaration is caller-supplied metadata, not an audited guarantee. Reusing their feedback during search makes them development/exploratory probes; final confirmation requires fresh probes. A finite set passing the checks establishes only those tested pairs, even when the full group was enumerated. Population symmetry requires a proof or a separately justified statistical inference. Noisy labels require an explicit noise model; raw pair disagreement conflates noise and symmetry breaking.
