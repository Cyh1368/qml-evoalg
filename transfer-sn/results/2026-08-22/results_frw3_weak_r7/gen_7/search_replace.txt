<DESCRIPTION>
Replace the current mostly fully-shared single-qubit parametrization with a structure that keeps parameter efficiency high while increasing expressivity:
- Keep a shared “collective” input RY mixer (1 parameter) to retain symmetry and reduce overfitting.
- Add per-qubit RZ phase tuning before entanglement (8 parameters) to give each qubit its own adjustable phase, improving the ability to transform the feature-uploaded ZZ couplings into decision-relevant interference.
- Keep the same fixed CZ cube entangling pattern (no extra parameters).
- Use shared output mixers (2 parameters total) to map the entangled phase information into Z-measurements efficiently.
This should raise validation/test accuracy and reduce the train-test gap, while keeping the number of circuit parameters well below the “fully unshared” seed-style ansätze.
