<DESCRIPTION>
The current ansatz uses a highly parameter-efficient approach with 100% parameter sharing across all wires for each rotation layer. While this prevents overfitting and creates a smooth loss landscape, it limits the model's expressivity. Since the feature map encodes records via `IsingZZ` on specific qubit pairs with varying feature importance, the ansatz needs the ability to break symmetry. 

By making the `RY_in` parameters independent for each wire, the model can individually "weight" each qubit differently right after the feature map phase encoding. Similarly, making the `RY_out` parameters independent allows the model to align only the most predictive qubits with the Z-axis for the final measurement (which is an unweighted average of all Z expectations). We retain the collective sharing for the `RZ` and `RX_out` layers to provide regularization. This change increases the number of parameters per block from 4 to 18 (110 parameters total) which is still small enough to avoid severe overfitting but expressive enough to boost training and test accuracy.
</DESCRIPTION>
