<IMPROVE_parity_split_mixer_finisher>
<DESCRIPTION>
The current ansatz block is highly symmetric (many operations share a single parameter across all 8 qubits). That can limit expressivity for tasks where the decision boundary depends on whether features effectively “favor” even vs odd qubit positions.

This edit breaks that symmetry with parity-group parameter sharing (even wires vs odd wires) while keeping the parameter count low:
- Split the input mixer RY into two parameters: one shared on even wires {0,2,4,6} and one on odd wires {1,3,5,7}.
- Replace the single shared RZ phase (currently all wires share one param) with a parity-shared RZ phase (2 params total).
- Split the output finisher layers (RY and RX) into parity-shared versions (2 params each), instead of one fully collective param per layer.

This increases trainable expressivity modestly (still far less than per-qubit parameters), which should improve validation/test accuracy and reduce loss/gap without exploding parameter efficiency.
</DESCRIPTION>
