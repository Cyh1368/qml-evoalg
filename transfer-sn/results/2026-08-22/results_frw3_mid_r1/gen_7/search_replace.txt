<DESCRIPTION>
This edit keeps the ansatz parameter budget unchanged at 4 learned angles per block, but redistributes them into a more expressive and better-regularized structure.

Key idea:
- split the single-qubit mixers into even/odd parity groups instead of one global angle per layer;
- insert a two-stage fixed CZ scaffold: a local brickwork plus a long-range half-register bridge;
- reuse the same parity mixer parameters before and after entangling to create a deeper effective block without increasing `N_PARAMS_PER_BLOCK`.

Why this should help:
- the current model is highly symmetric and may underfit some qubit-specific structure in the encoded features;
- parity-tied mixers can break that symmetry just enough to improve accuracy;
- the extra entangling scaffold improves phase-to-amplitude conversion for the fixed ZZ feature map;
- parameter count stays at 26 total, so the efficiency metric is preserved while validation/test accuracy has room to improve.
</DESCRIPTION>

ANSATZ_SPEC = []

# Parity-tied mixer: two angles are enough to break the global symmetry of the
# mean-Z readout while keeping the block compact and trainable.
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RY", "wire": q, "param": "ry_even" if q % 2 == 0 else "ry_odd"})

# Local brickwork entangler spreads each uploaded feature phase across neighbors.
for a, b in [(0, 1), (2, 3), (4, 5), (6, 7)]:
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})
for a, b in [(1, 2), (3, 4), (5, 6), (7, 0)]:
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})

# Phase refinement on the same parity split.
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": q, "param": "rz_even" if q % 2 == 0 else "rz_odd"})

# Long-range bridge couples opposite halves of the register.
for a, b in [(0, 4), (1, 5), (2, 6), (3, 7)]:
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})

# Reuse the parity mixer again after entangling to deepen the effective block
# without increasing the parameter count.
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RY", "wire": q, "param": "ry_even" if q % 2 == 0 else "ry_odd"})
