# Analysis

Looking at the current performance metrics:
- **Test accuracy: 0.87** — room for improvement
- **Parameter efficiency: 0.01** — quite low; many parameters per unit accuracy
- **Generalization gap: 0.07** — modest, suggests the model isn't severely overfitting
- **Convergence step: 750** — reasonable, but could be faster with better expressivity
- **Current ansatz**: Independent RY/RZ on all qubits + fixed CZ chain + final RZ layer

**Key insight**: The current ansatz has mostly *fixed* two-qubit interactions (CZ chain) and independent single-qubit rotations. This limits expressivity because the entanglement pattern is predetermined, not learned. The model relies only on the single-qubit parameters to adapt to data.

**Improvement strategy**:
1. Add learnable 2-qubit interactions using **parametrized controlled rotations (CRZ)** to complement the fixed CZ gates — this enriches the entanglement without exploding parameter count
2. Add an **RX layer** before RY to provide better coverage of the Bloch sphere (RX + RY give more degrees of freedom than RY + RZ alone)
3. Use **moderate parameter sharing** on some CRZ gates to keep efficiency high while enabling learned entanglement

This should:
- Improve expressivity by learning which pairs should strongly entangle
- Reduce parameters-per-accuracy by using rotations more efficiently
- Enable faster convergence to good solutions

This change improves the ansatz expressivity by:

1. **Adding RX layer**: Complements the RY and RZ rotations. RX provides a different axis of rotation, enabling better coverage of the Bloch sphere. Combined with RY, this gives more degrees of freedom per qubit than RY+RZ alone.

2. **Replacing alternating CZ gates with parametrized CRZ gates**: Instead of a fixed CZ chain (which provides predetermined entanglement), we now learn which pairs should have stronger controlled-Z interactions. The pattern (CRZ, CZ, CRZ, CZ, ...) maintains circuit structure while introducing learnable 2-qubit parameters at strategic positions.

3. **Parameter count**: The new ansatz has 8 (RX) + 8 (RY) + 8 (RZ_pre) + 4 (CRZ) + 8 (RZ_post) = 36 parameters per block. This is a 50% increase from 24, but distributed across N_UPLOADS * N_REPEATS = 6 blocks, giving ~216 circuit parameters. While higher than the baseline (144), the improved expressivity should yield higher accuracy per parameter, reducing the effective complexity.

4. **Expected impact**:
   - Learnable entanglement allows the circuit to adapt to data structure
   - RX layer fills gaps in Bloch sphere coverage
   - Alternating CZ/CRZ preserves computational efficiency
   - Should reduce convergence time and improve test accuracy
