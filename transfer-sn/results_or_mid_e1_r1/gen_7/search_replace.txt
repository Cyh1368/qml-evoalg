<DESCRIPTION>
The current program achieves good test accuracy (0.87) but has slow convergence (750 steps) and shows some overfitting (train 0.94 vs validation 0.89). The prior program with parameter sharing achieved faster convergence (270 steps) and better generalization despite fewer parameters.

I propose to combine the benefits of both approaches:

1. **Introduce parameter sharing** in the RY and RZ layers (reuse 4 unique params across pairs of qubits). This reduces the parameter count from 32 to 12 per block, improving generalization and convergence speed.

2. **Replace the linear CZ chain with a balanced entanglement pattern** (parallel pairs + diagonal links) as in the successful prior program, which provides better connectivity.

3. **Add parametrized CRZ gates** on select qubit pairs to restore expressivity in a parameter-efficient way, targeting cross-qubit correlations that help with feature interactions.

This design should:
- Reduce overfitting by using fewer parameters
- Speed up convergence with a more efficient ansatz structure
- Maintain or improve test accuracy through parametrized controlled rotations
- Lower the generalization gap
