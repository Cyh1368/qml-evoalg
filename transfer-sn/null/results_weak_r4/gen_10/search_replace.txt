<DESCRIPTION>
Replace the per-qubit RX output layer with a cheaper RZ output layer using parameter sharing:
- Keep the 8 trainable RY “input mixing” parameters as-is.
- Replace 8 independent RX parameters with only 2 shared RZ parameters (one shared by wires {0,2,4,6} and one shared by {1,3,5,7}).

This reduces the number of circuit parameters per ansatz block (from 16 → 10), lowering total trainable parameters and depth/gate count while preserving enough expressivity via the re-uploading + CZ ring entanglement and the remaining trainable local rotations.
</DESCRIPTION>
