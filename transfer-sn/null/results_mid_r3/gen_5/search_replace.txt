<DESCRIPTION>
This edit replaces the dense per-qubit ansatz with a more compact, symmetry-biased block.

The new block uses:
- parity-shared single-qubit rotations on even/odd wires, which sharply reduces the number of trainable parameters per block and improves parameter efficiency,
- a nearest-neighbor CZ ring plus long-range CZ chords, which preserves strong mixing across the 8-qubit register,
- one shared CRZ parameter on the long-range chords, adding a small amount of learnable global phase structure without blowing up the parameter count.

Overall, this aims to keep validation/test accuracy near the current ceiling while lowering the train-test gap, reducing depth/parameter count, and improving convergence efficiency.
</DESCRIPTION>
