<DESCRIPTION>
The current fixed feature map uses a constant `FEATURE_SCALE = π/2` for all feature encodings across all data re-uploads. This restricts the network's ability to dynamically adjust the embedding strength at different stages of the circuit.

The proposed improvement makes the feature-map scale trainable per upload (one scale parameter per N_UPLOADS=3 re-upload layer). This allows the optimizer to learn optimal embedding strengths at each re-upload stage independently, which can:

1. **Improve data encoding flexibility**: Different reupload stages may benefit from different scaling factors as the quantum state evolves.
2. **Reduce train-test gap**: More adaptive embedding can better generalize to unseen data.
3. **Better parameter efficiency**: These 3 additional parameters (one per upload) provide direct gradient feedback to optimize the data encoding strength.

The implementation extracts feature scale parameters from the circuit parameter vector and passes the appropriate scale to the feature map at each upload iteration. The feature scales are initialized to π/2 (the original constant value) and then trained via backpropagation.
</DESCRIPTION>
