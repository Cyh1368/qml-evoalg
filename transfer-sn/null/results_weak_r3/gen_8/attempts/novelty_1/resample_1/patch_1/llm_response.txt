<DESCRIPTION>
Replace the current fully-local RX/RZ + sparse CRZ ansatz block with a more parameter-efficient, symmetry-aware structure:
- Share RY parameters within each qubit pair (0,1),(2,3),(4,5),(6,7): 4 params instead of 8.
- Share RZ parameters within each qubit pair: 4 params instead of 8.
- Use one parametrized CRZ per qubit pair with pair-local parameters: 4 params (same count as before for entanglers, but now aligned with the shared single-qubit structure).
- Keep a fixed CZ entangling ladder to preserve nontrivial connectivity and expressivity without adding parameters.

This reduces parameters per block (from 20 -> 12), improving parameter efficiency while maintaining (pairwise) entangling structure that works well with the fixed 2-qubit feature encoding and re-uploading.
