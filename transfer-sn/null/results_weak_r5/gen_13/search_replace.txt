<reduce_shared_phase_ringcrz>
<DESCRIPTION>
Make the ansatz more parameter-efficient and better aligned with typical expressivity patterns for ZZ/phase feature maps:

- Replace the current RX+RY-per-qubit (16 params/block) with only RY (8 params/block).
- Introduce only two *shared* global RZ calibration parameters per block (applied to all qubits), instead of many independent RZ/phase degrees of freedom.
- Keep a CZ “ring backbone” (fixed, no parameters).
- Add only two parametrized CRZ “odd/even” layers, where each layer reuses the same parameter across 4 edges (2 params/block).

This should reduce total circuit parameters substantially (better parameter efficiency) while retaining enough tunable controlled-phase structure to fit the data, improving convergence speed/validation/generalization.
</DESCRIPTION>
