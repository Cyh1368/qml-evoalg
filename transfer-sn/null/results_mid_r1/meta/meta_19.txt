# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Layered data re-uploading with minimal entangling (N_UPLOADS = 3, N_REPEATS = 2) consistently yields perfect classification. Both Gen 16 (8-Qubit Evolved Ansatz, combined_score_raw = 1.00, depth 75, 180 gates) and Gen 17 (8-Qubit ShinkaEvolve, combined_score_raw = 1.00, depth 81, 204 gates) use this layout.  
- Staggered CRX-only entanglement (even/odd control-swap pairs in Gen 16) achieves 100% accuracy with the lowest depth (75) and gate count (180) among perfect scorers.  
- Simple per-qubit RY basis rotations suffice to load trainable degrees of freedom: Gen 16 omits RZ/RX in the ansatz block yet converges to zero generalization gap.  
- Augmenting CRX with diversified two-qubit gates (distance-2 CRY plus global CZ in Gen 17) preserves perfect accuracy and speeds convergence (~270 vs. ~420 steps) but at the cost of extra depth and gates.

## Ineffective Approaches  
- Adding CRZ/CRY layers and shared RZ readout (Gen 18 “add_shared_rz_readout_layer” and Gen 19 “add_shared_final_rz_layer”): these circuits balloon to 146 parameters, depth 99, 270 gates, but test/validation loss rises (~0.11) and combined_score_raw falls to 0.98.  
- Overparameterization beyond ~100 variational angles produces no accuracy gain. Gen 18/19’s 146 parameters deliver the same 1.00 test accuracy but halve parameter efficiency to ~0.007.  
- Long-range or brickwall entanglement patterns (mixed RY–RZ layers in earlier Gens) uniformly slowed convergence and never outperformed the CRX-only pattern in combined_score_raw or resource efficiency.  

## Implementation Insights  
- Defining ansatz blocks as a validated spec (validate_ansatz_spec → PARAMETER_KEYS_PER_BLOCK) and computing key-to-index maps at runtime (apply_ansatz_block) ensures consistency and simplifies gate swaps. Gen 16’s patch “simplify_to_crx_with_control_swaps” exemplifies this.  
- Decoupling circuit parameters from gain/bias readout stabilizes training: all top programs initialize gain = 1, bias = 0 and register them separately in N_READOUT_PARAMS.  
- Uniform “for upload in N_UPLOADS: feature_map(); for repeat in N_REPEATS: apply_ansatz_block()” loops balance expressivity and resource usage—Gen 16 achieves the shallowest depth (75) by strictly limiting gates per block.  
- Automated metadata collection via qml.queuing.AnnotatedQueue ties implementation to performance tracking (depth/gate_count), guiding ansatz pruning post-evaluation.

## Performance Analysis  
- Circuits with depth ≤ 75 (Gen 16) attain combined_score_raw = 1.00, matching the best accuracy with minimal overhead. Increasing depth to 81–99 never improves combined_score_raw beyond 1.00 and often reduces raw scores (Gen 18/19: 0.98).  
- Gate counts beyond ~200 (Gen 17: 204; Gen 18/19: 270) yield marginal convergence speed gains (Gen 17 converges in ~270 steps vs. 420 for Gen 16) but sacrifice parameter efficiency (1.00/204 ≈0.005 vs. 1.00/98 ≈0.010).  
- Parameter efficiency plateaus at ~0.01 for ~100-parameter ansätze. Gen 16/17 both reach 100% test accuracy with N_PARAMS = 98, double the efficiency of 146-parameter variants.  
- Loss metrics correlate with overparameterization: low-depth CRX-only circuits achieve validation/test loss ≈0.03/0.02, while deeper CRZ-enhanced models settle at ≈0.11.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce RY-parameter symmetry across qubit pairs  
   Modify ANSATZ_SPEC so that RY gates on symmetric wires—e.g. (0,7), (1,6), (2,5), (3,4)—all share one of four keys instead of eight unique `ry0…ry7`. This halves the single-qubit parameter count (to 4) while preserving the proven RY-only expressivity, testing whether enforced symmetry maintains 100% accuracy and further uplifts parameter efficiency beyond 0.01.

2. Inject minimal CRY diversification in the second entangling layer  
   In the odd-pair layer of each block, replace two of the eight CRX gates (for instance, the middle two odd-pairs) with CRY gates but keep the same parameter names and count. Drawing on Gen 17’s faster convergence with diversified two-qubit rotations, this mutation preserves block depth (still 16 gates) and total parameters (98) while probing whether mixed CRX/CRY boosts convergence speed.

3. Append fixed (non-parametric) CZ “skip-connections” after each upload  
   After the inner `for repeat` loop of each upload, apply a CZ layer on alternating long-range pairs—e.g. wires (0,2),(2,4),(4,6),(6,0)—without introducing new parameters. This lightweight entanglement injection increases circuit connectivity akin to Gen 17’s global CZ but at zero parameter cost, testing expressivity gains under the ≤75-depth constraint.

4. Vary N_REPEATS non-uniformly across uploads  
   Replace the constant `N_REPEATS=2` with a schedule like `[1,2,3]` so upload 0 uses one block, upload 1 uses two, upload 2 uses three—totaling six blocks as before. Holding total depth and parameter count fixed, this re-allocates ansatz effort to later uploads, probing whether concentrated entanglement in deeper layers sharpens feature encoding.

5. Add a per-block shared RZ phase rotation  
   In each ANSATZ_SPEC block, insert one RZ on qubit 0 with a new key `"rz_block"` immediately after the RY layer. This adds six RZ gates and six parameters overall (one per block), capitalizing on the success of solo single-qubit rotations to fine-tune mid-circuit phases with minimal depth impact (~+1 per block) and assess gains in validation loss.
