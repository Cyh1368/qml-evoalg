Following the expert recommendation, I propose adding a final shared-parameter RZ phase layer after all ansatz blocks. This adds only 1 new parameter but 8 gates to fine-tune the measurement basis globally. This approach:

1. Addresses the measurement calibration bottleneck with minimal parameter overhead
2. Leverages the success of simple single-qubit rotations observed in prior programs
3. Maintains the current block structure while enhancing the final readout rotation
4. Should improve convergence speed by allowing the network to globally adjust the measurement axis
5. Adds negligible computational complexity (8 RZ gates) with only 1 shared parameter

The shared parameter `"rz_end"` is reused across all 8 qubits, making it an efficient fine-tuning knob for the measurement basis. This is similar to how gain/bias calibration works in the readout, but embedded within the quantum circuit.
