# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- Parameter sharing across qubits dramatically boosts efficiency without sacrificing accuracy.  
  • Program 11 (“8-Qubit Re-uploading Ansatz Classifier”) reuses only five unique rotation keys per block (“ry_a”, “ry_b”, “rz_0/1/2”), yielding N_PARAMS=32 and achieving combined_score_raw=1.00 (train/val/test=1.00/1.00/1.00).  
  • This shared-param layout outperformed fully distinct per-qubit parameterizations in Programs 7 and 8 (N_PARAMS=122–164, raw=0.97, efficiency≈0.01).

- Linear CZ-chain entanglement in each ansatz block maximizes expressivity per gate.  
  • All top performers (Programs 6 and 11) used a chain of CZ couplers and reached raw ≥ 0.97, whereas ring-CNOT (Program 1) plateaued at 0.96.  

- Three fixed IsingZZ feature-map uploads with two ansatz repeats (N_UPLOADS=3, N_REPEATS=2) consistently delivered full separability on the 28-feature task.  
  • Programs 2, 6, and 11—all using this 3×2 pattern—achieved the highest raw scores (0.94→0.97→1.00).

- A simple two-parameter gain/bias calibration on the mean Pauli-Z output remains crucial for tightening decision boundaries.  
  • Featured in all top circuits, it reduced validation/test loss to zero in Program 11 and capped generalization gaps at ≤ 0.01 in prior bests.

## Ineffective Approaches

- Adding long-range parametric two-qubit rotations (CRZ “skip” links) inflated resources but did not improve accuracy.  
  • Program 4 increased N_PARAMS to 164 and depth to 109, yet combined_score_raw stalled at 0.96 and convergence slowed (~240 steps vs. ~180).

- Over-parameterized per-qubit rotations (distinct RY/RZ on every wire) yielded low parameter efficiency without boosting final score.  
  • Programs 7 and 8 used 122–164 parameters for raw=0.97, efficiency≈0.01, versus Program 11’s 32 params at raw=1.00, efficiency=0.03.

- Ring-topology CNOT entanglers converged quickly but lacked the expressivity of linear CZ chains.  
  • Program 1 reached raw=0.96 in ~120 steps, vs. >0.97 for CZ-chain designs.

- Excessive depth/gate counts (≥120 depth, ≥252 gates) marginally lowered training burden per epoch but gave no accuracy gain over shallower (~93–99 depth) circuits.

## Implementation Insights

- Defining the ansatz as a flat ANSATZ_SPEC and mapping parameter-keys → positions enables bulk parameter sharing.  
  • Program 11’s five-key spec supports six blocks (N_PARAMS_PER_BLOCK=5) and scales to 30 circuit parameters plus two readout, simplifying indexing and optimization.

- Modular loops over uploads and repeats (`for upload_index in range(N_UPLOADS): feature_map… for repeat_index in range(N_REPEATS): apply_ansatz_block`) let you sweep depth vs. param density systematically.  

- Using PennyLane’s backprop QNode with `pnp.array(..., requires_grad=True)` and the built-in Adam optimizer yields stable gradient computation even with heavy parameter sharing.  

- Early stopping on validation loss (min_delta=1e–4, patience=75) with best-weight restoration was key to achieving zero generalization gap in the current best and capping it at 0.01 in earlier models.

## Performance Analysis

- Raw combined_score_raw rose from 0.96 (Program 1, ring-CNOT)→0.97 (Programs 7/8, larger CZ-chain)→1.00 (Program 11) by trimming parameters (from 146 → 32) and depth (109 → 93).  

- Parameter efficiency (test_accuracy/N_PARAMS) doubled—from ~0.01 in over-parametrized designs to 0.03 in Program 11—demonstrating that leaner circuits can outperform bulky ones.  

- Depth/gate_count sweet-spot around 90–100 depth and ~220 gates consistently yields top accuracy; adding more layers or gates yields diminishing returns.  

- Training convergence slowed (480 steps in Program 11 vs. ~180 in the 146-param model) but the trade-off paid off in perfect accuracy and maximal efficiency.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce per-feature trainable scaling in the feature map.  
   – Add a vector `feature_scale_params` of length `N_FEATURES` and replace each fixed coupling  
     ```python
     qml.IsingZZ(FEATURE_SCALE * records[..., k], wires=[a,b])
     ```  
     with  
     ```python
     qml.IsingZZ(FEATURE_SCALE * feature_scale_params[k] * records[..., k], wires=[a,b])
     ```  
   – This adds only 28 parameters, lets the model learn the embedding strength of each feature, and builds on the proven benefits of the fixed IsingZZ uploads in Programs 2, 6, and 11.

2. Alternate CZ-chain direction between ansatz repeats.  
   – Define two CZ patterns in `ANSATZ_SPEC` (forward 0–1–…–7 and backward 7–6–…–0) and apply them in alternating repeats within each upload:  
     ```python
     pattern = forward_cz if (repeat_index % 2 == 0) else backward_cz
     for wires in pattern: qml.CZ(wires=wires)
     ```  
   – This preserves the linear-chain entanglement that yielded ≥0.97 accuracy while enriching expressivity without adding gates.

3. Share the same ansatz-block parameters across uploads.  
   – In `apply_ansatz_block`, compute  
     ```python
     shared_block = block_index % N_REPEATS
     offset = shared_block * N_PARAMS_PER_BLOCK
     ```  
     instead of allocating unique parameters per upload.  
   – By tying the 5-parameter block across all three uploads, you cut `N_CIRCUIT_PARAMS` from 30 to 10, doubling parameter efficiency while keeping the 3×2 upload structure that converged in ~180 steps.

4. Upgrade global readout to per-qubit gain and bias.  
   – Replace the two scalars with vectors `gain_vec`, `bias_vec` of length `N_QUBITS`, then compute:  
     ```python
     z = pnp.stack(circuit_z_expectations(...))  # (N_Q, B)
     calibrated = gain_vec * (z - bias_vec[:, None])  # (N_Q, B)
     predictions = pnp.mean(calibrated, axis=0)
     ```  
   – Adding 16 readout parameters gives each qubit its own calibration, further tightening decision boundaries as seen in Program 11’s global calibration.

5. Inject a shared sparse CRZ on top-correlated feature pairs.  
   – Identify the 2–3 highest-mutual-information feature pairs, and in each block append  
     ```python
     qml.CRZ(crz_shared, wires=[a,b])
     ```  
     where `crz_shared` is one additional trainable parameter.  
   – This introduces controlled long-range entanglement in a parameter-efficient way, leveraging the CRZ motif without the over-parameterization that hindered Program 4.
