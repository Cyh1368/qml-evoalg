<DESCRIPTION>
This edit replaces the current high-parameter block with a more regular, symmetry-aware ansatz that is better matched to the fixed 8-qubit readout.

Key ideas:
- Compress local rotations into four shared RY parameters on adjacent qubit pairs, which keeps the block expressive but reduces overfitting.
- Add a fixed CZ chain to propagate correlations without adding trainable parameters.
- Use long-range controlled rotations (CRX) across opposite qubits to capture nonlocal feature interactions induced by the dataset’s two-qubit ZZ feature map.
- End the block with shared RX rotations instead of trailing phase-only gates, so the last repeated block still affects the final Z measurements.

Overall this lowers the parameter count per block from 23 to 10, improving parameter efficiency and generalization while retaining enough nonlinearity for the classifier.
</DESCRIPTION>
