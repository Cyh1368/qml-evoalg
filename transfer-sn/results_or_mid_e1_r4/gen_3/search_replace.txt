<DESCRIPTION>
This edit replaces the dense per-qubit RY/RZ stack with a more parameter-efficient, symmetry-regularized block that is better matched to the fixed feature-map structure.

Key changes:
- Reduce each block from 24 trainable circuit parameters to 12 by sharing parameters across opposite qubit pairs.
- Add a two-scale entangling pattern:
  - long-range CNOTs on opposite pairs to rapidly mix information across the register,
  - cross CZs to reintroduce phase correlations between neighboring pair groups,
  - a final local CNOT layer to improve information flow before the next upload.
- Keep only supported gates and maintain the same block interface, so the fixed training loop remains unchanged.

This should improve validation/test generalization, reduce the train-test gap, and increase parameter efficiency while preserving enough expressivity for the six repeated blocks.
</DESCRIPTION>
