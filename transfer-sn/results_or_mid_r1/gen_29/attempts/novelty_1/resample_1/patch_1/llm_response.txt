<DESCRIPTION>
This edit replaces the over-parameterized seed block with a more compact mirrored ansatz that keeps the successful low-parameter structure from the stronger prior program, but adds block-dependent long-range entanglement diversity.

Key ideas:
- Reduce the circuit parameter count from 98 to 74 by using shared mirrored single-qubit parameters.
- Keep local CZ entanglers unchanged for stable short-range mixing.
- Alternate the long-range CZ mesh on odd blocks to expose the model to two complementary correlation patterns without increasing depth.
- Add a small controlled-rotation core to improve nonlinearity and reduce train/validation gap.
- Preserve full compatibility with the fixed training loop and schema validation by using only supported gate types; the alternate wires are selected inside apply_ansatz_block based on block_index.

This should improve generalization and convergence speed while also raising parameter efficiency.

def apply_ansatz_block(params, block_index: int) -> None:
    """Apply one candidate ansatz block from the formal ANSATZ_SPEC."""
    if SPEC_ERRORS:
        raise ValueError("; ".join(SPEC_ERRORS))

    offset = block_index * N_PARAMS_PER_BLOCK
    key_to_position = {key: i for i, key in enumerate(PARAMETER_KEYS_PER_BLOCK)}
    for item in ANSATZ_SPEC:
        gate = str(item["gate"]).upper()
        if gate in ALLOWED_SINGLE_QUBIT_GATES:
            angle = params[offset + key_to_position[item["param"]]]
            wire = int(item["wire"])
            if gate == "RX":
                qml.RX(angle, wires=wire)
            elif gate == "RY":
                qml.RY(angle, wires=wire)
            elif gate == "RZ":
                qml.RZ(angle, wires=wire)
        elif gate in ALLOWED_TWO_QUBIT_GATES:
            if gate == "CZ" and block_index % 2 == 1 and "alt_wires" in item:
                wires = [int(w) for w in item["alt_wires"]]
            else:
                wires = [int(w) for w in item["wires"]]
            if gate == "CNOT":
                qml.CNOT(wires=wires)
            elif gate == "CZ":
                qml.CZ(wires=wires)
        elif gate in ALLOWED_PARAM_TWO_QUBIT_GATES:
