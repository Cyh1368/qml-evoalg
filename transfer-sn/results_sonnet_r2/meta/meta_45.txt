# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Three data re-uploads interleaved with two ansatz repeats  
  • Consistently appears in top circuits:  
    – Gen42 (Reuploading CRZ-based 8-Qubit Classifier): combined 0.91, test 0.92  
    – Gen44 (8-Qubit Ring CRZ Reupload): combined 0.90  
    – Gen45 (Dual-ring Shared Ansatz w/ Zero-Cost RY Mixing): test 0.91  
  • The current best (Gen42) uses 3× uploads × 2 repeats to stabilize training and reach 0.92 test accuracy.  

- Paired shared single-qubit rotations  
  • All leading models share RY/RZ angles across qubit pairs (4 keys each for pre- and post-rotations), halving unique parameters without loss of expressivity.  
  • Gen39 (Mirrored Shared-Pair, combined 0.90) and Gen42 (0.91) both maintain ≥0.91 test accuracy with only 68–98 trainable angles.  

- Dual-ring alternating CRZ entanglement  
  • Adding a distance-2 ring (crz_c/crz_d) atop the nearest-neighbor ring yields a marginal +0.01 absolute gain:  
    – Single‐ring Gen38 test 0.91 → Gen42 dual‐ring test 0.92.  
  • Alternating shared parameters (a/b on ring-1, c/d on ring-2) maximizes entanglement expressivity per parameter.  

- Lightweight readout calibration & early stopping  
  • All high-scoring circuits append global gain/bias and employ L2-loss early stopping (patience 75, Δmin 1e-4).  
  • Gen42 exhibits a small generalization gap (0.05) and converges within ~390 steps, mirroring earlier best practices from Gen41.  

## Ineffective Approaches  
- Zero-cost mixing via parameter reuse  
  • Gen45 reused pre-rotation RY angles for post-entangling mixers to inject phase information at no extra parameters.  
  • Although convergence sped up (~270 steps), final test accuracy plateaued at 0.91, below Gen42’s 0.92.  

- High gate count without new expressivity  
  • Gen44’s 372 gates (vs 324 in Gen42) and identical 98 parameters achieved only combined 0.90.  
  • Depth/gate increases unaccompanied by novel entangling structures did not yield accuracy improvements.  

- Over-parameterized ansätze (>120 parameters)  
  • Past models (e.g., Gen35) with >120 trainable angles stalled at combined ~0.88 and required >600 steps to converge.  

- Mixing CZ with parametric CRZ  
  • Earlier hybrid CZ/CRZ designs delivered test accuracies ≤0.86 with larger generalization gaps (0.07), underperforming pure-CRZ dual-ring layouts.  

## Implementation Insights  
- Automated parameter‐key mapping  
  • The `validate_ansatz_spec`→ `PARAMETER_KEYS_PER_BLOCK` → `key_to_position` pattern (as in Gen42) keeps ANSATZ_SPEC concise and ensures reproducible gate counts (324) and depth (142).  

- Declarative ANSATZ_SPEC structure  
  • Defining each gate as a dict (`gate`, `wires`/`wire`, `param`) allows easy insertion of alternating rings (crz_a/b and crz_c/d loops) without manual index arithmetic.  

- Pure-CRZ loops + Adam optimizer  
  • Using only CRZ entanglers with `qml.AdamOptimizer(lr=0.03)` consistently converges in ~390 steps for Gen42—~3× faster than mixed-entangler variants.  

- Phase alignment via separate pre/post rotations  
  • Framing dual-ring CRZ blocks between shared RY and independent RZ layers (8 pre, 8 post parameters) boosts expressivity and phase control without expanding the parameter budget.  

## Performance Analysis  
- Combined score uplift from single to dual ring  
  • Gen39 (mirrored single-ring) combined 0.90 → Gen42 (dual-ring reupload) combined 0.91, a +0.01 gain for +18% more gates and +30 parameters.  

- Depth vs. expressivity trade-off  
  • Increasing depth from 124 (Gen39) to 142 (Gen42) yields a measurable accuracy boost (0.90→0.92 test) with only a slight increase in the generalization gap (0.04→0.05).  

- Parameter-efficiency considerations  
  • Gen39’s 68 params achieves efficiency 0.0134, while Gen42’s 98 params gives 0.0094. The highest absolute test accuracy (0.92) in Gen42 balances performance over raw efficiency.  

- Convergence dynamics  
  • Gen45’s zero-cost mixers reached threshold faster (~270 steps) but capped at 0.91 test. Gen42 showed that a moderate convergence time (~390 steps) with dual-ring CRZ nets the highest final accuracy.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Specialize pre- and post-rotation parameters per feature-map upload  
   In ANSATZ_SPEC, replace each shared “ry_p{0–3}” and “rz_post_p{0–3}” with upload-indexed keys like “ry_p{i}_u{u}” and “rz_post_p{i}_u{u}” for upload u∈{0,1,2}. This increases the circuit parameters from 98 to 106 but lets each of the three data-reupload cycles independently tune its local mixers, testing whether modest per-upload adaptation can push accuracy past 0.92 while remaining in the sweet spot of ~100–110 total parameters.  

2. Append a lightweight distance-3 CRZ entanglement ring  
   After the existing distance-2 loops, add CRZ gates on qubit pairs at graph-distance 3—e.g. (0,3), (1,4), (2,5), (3,6), (4,7), (5,0), (6,1), (7,2)—alternating two shared keys (e.g. “crz_e”/“crz_f”) or reusing “crz_a”∕“crz_b” by key-cycling. This pure-CRZ third ring explores longer-range correlations with minimal gate count increase and no more than 2–4 extra parameters, leveraging the dual-ring’s +0.01 accuracy uplift.  

3. Cycle CRZ parameter assignments across ansatz blocks  
   In apply_ansatz_block, implement key-cycling by selecting the CRZ parameter for the i-th gate as key_sequence[(i + block_index) % len(key_sequence)] from [“crz_a”, “crz_b”, “crz_c”, “crz_d”]. This zero-cost structural variation diversifies entangling strengths per block—akin to an alternating dual-ring—but reuses the existing CRZ keys, potentially improving expressivity without increasing the parameter budget.  

4. Introduce entanglement “dropout” during training  
   Wrap each distance-1 and distance-2 CRZ ring application in a Bernoulli mask p_keep≈0.9 sampled per block (or per epoch): if mask=False, skip that ring entirely during that training pass, but always apply all rings at evaluation. This regularizes entanglement patterns, may reduce overfitting (narrow the generalization gap), and builds on the effective dual-ring CRZ architecture without changing gate count or core parameters.  

5. Upgrade readout calibration to per-qubit-pair gain and bias  
   Replace the single global gain/bias with distinct gain_p{i}, bias_p{i} for each of the four qubit-pairs defined by the shared pre-rotation scheme. Adding these 8 readout parameters (raising N_PARAMS from 98 to 106) captures pair-specific measurement offsets, refining the global calibration layer that all top models—especially Gen42—have shown is critical for closing the residual generalization gap.
