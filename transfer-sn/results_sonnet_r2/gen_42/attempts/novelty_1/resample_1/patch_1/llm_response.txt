dual_ring_shared_ansatz

<DESCRIPTION>
The current program's ANSATZ_SPEC uses fully independent RY/RZ parameters per qubit and only a single nearest-neighbor CRZ ring, giving 110 params but weaker generalization (val_acc 0.88, gap 0.06) compared to the previously best-performing "dual-ring shared" design (val_acc 0.94, gap 0.05, 98 params) that used paired/shared single-qubit rotation angles plus both a nearest-neighbor and next-nearest-neighbor CRZ ring. That design achieved a better combined score (0.91) by improving parameter efficiency (fewer independent single-qubit angles reduces overfitting risk) while adding richer entanglement (two interleaved CRZ rings instead of one), which better captures correlations among the 28 pairwise features spread across 8 qubits. I am reinstating and slightly extending that superior architecture: shared paired RY/RZ pre-rotation (4 unique angles each instead of 8), a nearest-neighbor CRZ ring (crz_a/crz_b alternating), a next-nearest-neighbor CRZ ring (crz_c/crz_d alternating) for longer-range coupling, and a shared post-rotation RZ layer. This reduces per-block parameter count relative to the current fully-independent-parameter spec while adding better entangling structure, which should improve validation/test accuracy and reduce the generalization gap.
