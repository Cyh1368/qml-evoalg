per_qubit_readout_calibration

<DESCRIPTION>
Extending the readout calibration from a single scalar gain/bias to per-qubit gains and biases gives the model more flexibility to weight each qubit's contribution individually before averaging, which can improve accuracy and reduce the train/validation/test gap. This requires: (1) increasing N_READOUT_PARAMS from 2 to 16 (8 gains + 8 biases), (2) updating predict_batch to slice out the per-qubit gain/bias vectors and apply them elementwise to the per-qubit Z expectations before averaging, and (3) updating the parameter initialization in run_experiment so gains start at 1 and biases start at 0 for all 8 qubits. This directly implements the recommended per-qubit calibration approach, keeping circuit structure unchanged so the extra capacity is purely in the classical readout, which is cheap and differentiable.

def predict_batch(params, x_batch: np.ndarray):
    """Scalar prediction per record: calibrated mean of per-qubit Z expectations."""
    circuit_params = params[:N_CIRCUIT_PARAMS]
    gains = params[N_CIRCUIT_PARAMS : N_CIRCUIT_PARAMS + N_QUBITS]
    biases = params[N_CIRCUIT_PARAMS + N_QUBITS : N_CIRCUIT_PARAMS + 2 * N_QUBITS]
    records = pnp.array(np.asarray(x_batch, dtype=float), requires_grad=False)
    z = pnp.stack(circuit_z_expectations(records, circuit_params))  # (N_QUBITS, B)
    calibrated = gains[:, pnp.newaxis] * (z - biases[:, pnp.newaxis])  # (N_QUBITS, B)
    return pnp.mean(calibrated, axis=0)
