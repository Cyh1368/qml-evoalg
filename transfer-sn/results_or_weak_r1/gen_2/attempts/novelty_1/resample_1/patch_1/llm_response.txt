<idea>
ry_rz_alternating_with_entanglement
</idea>

<DESCRIPTION>
The current ansatz uses a simple RY-RZ pattern with linear CZ entanglement, which may not provide sufficient expressivity for the 8-qubit system with 28 binary features.

This modification:
1. Alternates RY and RZ layers to create more complex single-qubit rotations
2. Adds full connectivity entanglement through CRZ gates between all qubit pairs
3. Uses parameter sharing to maintain efficiency while increasing expressivity
4. Maintains the data re-uploading structure but with more powerful blocks

This should improve the model's ability to learn complex patterns in the feature space while keeping parameter count reasonable.
</DESCRIPTION>
