<DESCRIPTION>
Improve the ansatz by implementing an elegant 3-parameter-per-block single-qubit mixer design that avoids parameter redundancy while maintaining full SU(2) expressivity between entangling layers. 

In previous iterations, having both `RY_in` and `RX_in` alongside `RZ_out` and `RX_out` created a 4-rotation cascade (`RZ -> RX -> RY -> RX`) between subsequent blocks, which is overparameterized since only 3 rotations are needed for any SU(2) gate. Overparameterization creates flat directions in the loss landscape, slowing Adam's convergence.

By using `RY` at the input and `RZ`, `RX` at the output, the inter-block cascade perfectly forms an `RZ -> RX -> RY` universal Euler sequence. This achieves maximum expressivity with exactly 3 parameters per block, maximizing parameter efficiency and test accuracy while eliminating redundancy. The perfect matchings of K8 are preserved to maintain strict S8 permutation equivariance, complementing the fixed feature map interactions.
</DESCRIPTION>
