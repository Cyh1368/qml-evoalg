The current program achieves 0.89 combined score with only 8 parameters and excellent parameter efficiency (0.11), but test accuracy lags slightly at 0.89. The recommendation to add variational readout rotations is well-motivated:

**Analysis of prior programs:**
- First program (score 0.89): 50 params, test accuracy 0.90
- Second program (score 0.90): 44 params, test accuracy 0.90
- Current program (score 0.89): 8 params, test accuracy 0.89

The current program has achieved extreme parameter efficiency by using full sharing (single "theta" parameter across all 8 qubits in each block), resulting in only 6 circuit params + 2 readout params = 8 total. However, this minimal ansatz sacrifices representational capacity.

**Proposed solution:**
Add a compact variational readout layer with two new shared parameters (`ry_read` and `rz_read`) applied to all 8 qubits immediately before measurement. This adds only 4 parameters (2 per block × 2 uploads × N_REPEATS), bringing the total to 12 params while maintaining excellent parameter efficiency.

**Why this works:**
1. The fixed gain-bias readout calibration has already reduced noise/variance in the measurement
2. A compact phase-rotation layer can capture residual systematic offsets that the minimal ansatz cannot express
3. The rotations are applied at the measurement stage where they directly influence Z-expectation values
4. This is a minimal architectural extension that doesn't disrupt the existing parameter-sharing structure
5. Brings params from 8 → 12 while potentially lifting test accuracy from 0.89 → 0.91+, improving the combined score

This targets the exact gap identified: the current circuit is too restricted. By adding these final rotations with strong parameter sharing, we gain expressiveness without significant overhead.
