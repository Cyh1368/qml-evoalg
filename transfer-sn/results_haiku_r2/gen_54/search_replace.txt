The current design (score 0.90) achieves 91% test accuracy with 4 parameters per block, but shows room for improvement compared to prior programs (score 0.91) that maintained similar accuracy with richer entanglement structures.

**Key observation:** The prior high-performing program (second example) used both nearest-neighbor CRY and next-nearest-neighbor CRY with full parameter sharing, achieving test accuracy 0.93 while keeping n_params at 26. The current design has replaced fixed CZ layers with parametrized CRZ but lost the next-nearest-neighbor connectivity that provided expressivity.

**Proposed improvement:** Add a next-nearest-neighbor CRZ layer to inject long-range entanglement. By reusing the same `crz_diag` parameter (which already exists), we add 8 gates with **zero additional parameters**. This mirrors the successful pattern from the prior program while maintaining parameter efficiency.

**Why this works:**
- Long-range entanglement (diagonal interactions 2 qubits apart) is known to improve trainability and expressivity in quantum circuits
- Parameter sharing keeps overhead minimal (N_PARAMS_PER_BLOCK stays at 4)
- The next-nearest-neighbor structure complements the nearest-neighbor CRZ by creating a denser interaction graph
- Convergence should remain fast due to low parameter count
- This addresses the 2% gap in test accuracy (0.91 → 0.93 in prior work)

**Expected gains:**
- Improved test accuracy (+1-2%)
- Maintained or improved generalization (richer feature maps often reduce overfitting when properly regularized)
- No increase in parameter count or significant depth overhead
- Faster convergence due to well-structured entanglement pattern
