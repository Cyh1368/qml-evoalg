The two prior seed variants that reached the best score (0.87) both used an RY encoding layer followed by a nearest-neighbor CRZ ring with shared alternating parameters, then an entangling/rotation combo (RX + skip/diameter CRZ layers). The current candidate (CZ-only entangler with unshared RY/RZ pre/post layers) underperforms (0.83) and has more parameters (194) than needed.

I revert to the higher-scoring architecture (RY -> CRZ ring with shared even/odd params -> symmetric-tied RX -> shared skip-2 CRZ -> shared diameter CRZ), and then duplicate that entire block a second time while reusing exactly the same parameter names. This doubles the effective circuit depth (more entangling layers -> higher expressivity) without increasing the parameter count at all, testing whether extra tied-parameter depth improves accuracy/generalization further, consistent with the recommendation to stack a shared-parameter "sandwich".
