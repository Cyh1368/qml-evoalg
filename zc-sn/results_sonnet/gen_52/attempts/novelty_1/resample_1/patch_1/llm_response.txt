<DESCRIPTION>
This candidate crosses over the two strongest seeds (the "ring + single-shared-skip" variant that reached test-accuracy 0.91 with only 116 parameters, and the "ring + mixed skip/diamond" variant that reached 122 parameters but lower test accuracy) with the long-range "diamond" connectivity idea from the current program.

Rationale:
- The RY→ring-CRZ (alternating shared even/odd)→RX→skip-2-CRZ (single shared parameter) backbone from the best-performing seed is kept unchanged, since it already gives the best test accuracy/generalization gap trade-off among the seeds.
- We add one extra, *maximally shared* long-range entangling layer (distance-4 "diamond" connections using CRX, a different rotation axis than the CRZ layers already present) with a *single* shared parameter, rather than the two separate parameters used in the lower-scoring seed. This keeps the parameter-efficiency advantage of strong sharing while adding the extra long-range expressivity that the current (176-param, lower-score) program tried to exploit but diluted with too many independent RZ/diamond parameters.
- The whole block is still duplicated (same parameter names) to double effective circuit depth without any extra parameter cost, exactly as in the two best-performing seeds.
- Net effect: same backbone that reached 0.89 score / 0.91 test accuracy, plus one cheap (+1 parameter per repetition) long-range mixing layer that should help capture correlations beyond distance-2 without hurting the train/test gap, since it is a single, heavily shared parameter.

This keeps the parameter count modest (20 unique params per outer repetition instead of 19 or 29), while combining the strongest structural elements of all provided programs.
