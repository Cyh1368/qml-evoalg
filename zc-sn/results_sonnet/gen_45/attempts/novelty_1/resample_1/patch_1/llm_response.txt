add_antipodal_diameter_entangler

<DESCRIPTION>
The current ansatz entangles nearest neighbors (distance 1, "ring") and distance-2 ("skip") pairs, but never connects qubits that are maximally separated on the 8-qubit ring (distance 4, "diameter": pairs (0,4),(1,5),(2,6),(3,7)). Adding these long-range links lets information mix across the whole register in a single layer, which is known to improve expressivity and trainability of shallow hardware-efficient ansätze without a large parameter cost. Following the recommendation, we split the diameter entangler into two shared parameters based on even/odd starting qubit ("crz_diam_even" for [0,4] and [2,6], "crz_diam_odd" for [1,5] and [3,7]") rather than one single parameter, giving the circuit a bit more flexibility to learn different global-mixing angles for the two interleaved antipodal pairs while only adding 2 parameters total (162 -> 164... actually current has crz_skip as 1 shared param, so we add 2 new params: 164+2=166). This keeps parameter count low and efficient while adding a new topological feature (full-diameter connectivity) that the current spec lacks, which should help close the generalization gap and improve validation/test accuracy by allowing richer global correlations to be captured.
</DESCRIPTION>
