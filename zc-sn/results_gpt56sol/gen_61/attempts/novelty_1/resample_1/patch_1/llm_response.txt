<DESCRIPTION>
This design retains the strongest prior program’s multi-scale CZ connectivity while applying substantially stronger parameter regularization. Instead of assigning independent phase parameters to each entangling stage, every stage reuses one parity-shared pre-phase pair and one parity-shared post-phase pair. This directly tests whether the useful behavior comes from the repeated phase-entanglement pattern rather than stage-specific angles.

The circuit combines even-bond, shifted-bond, and full-chain entanglers so information can propagate across the ring, but uses only 14 independent parameters per ansatz block: eight local RY angles, four globally shared phase angles, and two parity-shared final RX angles. The final noncommuting RX layer converts accumulated phase correlations into measurable population differences. Compared with the best prior phase-sandwich circuit, this preserves its connectivity and depth profile while sharply reducing parameter count, which should improve parameter efficiency and constrain overfitting.
