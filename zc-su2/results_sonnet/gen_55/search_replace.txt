<DESCRIPTION>
Replace the single global "theta" parameter with four axis-specific shared parameters: "theta_rx" for the RX pre-rotation layer, "theta_ry" for the RY pre-rotation layer, "theta_rz" for the RZ post-rotation layer, and "theta_e" for the parametrized XX entangler in the ring. This breaks the single-scalar bottleneck (which forces RX, RY, RZ and the entangler to move together) while still using aggressive parameter sharing (only 4 unique names per block instead of one per gate). The extra tunability along each axis should allow the optimizer to find sharper decision boundaries, potentially reducing validation/test loss and convergence steps, while keeping the parameter count low and preserving the dense ring + skip-2 + antipodal connectivity backbone that achieved the best combined score so far (0.80).
