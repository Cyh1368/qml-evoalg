skip2_cry_shared_theta_e

<DESCRIPTION>
Building on the highest-scoring prior design (single shared "theta" parameter driving RX/RY/RZ layers plus an alternating XX/CZ nearest-neighbor ring, which achieved combined score 0.80 with fast 30-step convergence), I replace the current 20-parameter, group-of-8 RY/RZ design (score 0.68) with that stronger topology, and additionally enrich the lightweight skip-2 sub-ring by replacing its zero-parameter CZ gates with parametrized CRY gates that all reuse a single new shared parameter "theta_e". This keeps the total trainable-parameter count at just 2 (theta, theta_e) — far fewer than the current 20 — while adding genuine tunable expressivity to the skip-2 connections instead of fixed CZ, which should help maintain full train/val/test accuracy with even better parameter economy and comparable or better convergence speed, since the skip-2 interactions can now be optimized rather than fixed.

ANSATZ_SPEC = []

# 0. Pre-entanglement rotation layer, axis RX: ALL 8 qubits share the SAME
#    single trainable parameter "theta".
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RX", "wire": wire, "param": "theta"})

# 1. Pre-entanglement rotation layer, axis RY, reusing the SAME "theta".
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": wire, "param": "theta"})

# 2a. Nearest-neighbor ring, alternating between a fixed CZ and a
#     parametrized XX interaction that REUSES the shared "theta"
#     parameter, injecting a non-commuting tunable entangler without new
#     trainable names.
for i in range(N_QUBITS):
    a, b = i, (i + 1) % N_QUBITS
    if i % 2 == 0:
        ANSATZ_SPEC.append({"gate": "XX", "wires": [a, b], "param": "theta"})
    else:
        ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})

# 2b. Skip-2 sub-ring linking every other qubit (0-2, 2-4, 4-6, 6-0), now
#     using a parametrized CRY gate that shares a single new parameter
#     "theta_e" across all four links, boosting local expressivity in
#     this lightweight topology while adding only one extra trainable
#     parameter overall.
for i in range(0, N_QUBITS, 2):
    ANSATZ_SPEC.append(
        {"gate": "CRY", "wires": [i, (i + 2) % N_QUBITS], "param": "theta_e"}
    )

# 2c. Fixed, zero-parameter antipodal shortcuts (distance-4 on the
#     8-cycle) for long-range connectivity.
for i in range(N_QUBITS // 2):
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [i, i + N_QUBITS // 2]})

# 3. Post-entanglement rotation layer, axis RZ, reusing the SAME "theta"
#    parameter, keeping the total unique parameter count per block at
#    exactly 2 (theta, theta_e).

    ANSATZ_SPEC.append({"gate": "RZ", "wire": wire, "param": "theta"})
