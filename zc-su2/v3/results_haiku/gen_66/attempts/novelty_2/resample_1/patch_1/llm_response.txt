The current approach uses static parameter sharing based on qubit parity (even/odd), which limits expressiveness and fails to capture problem-specific structure. The fundamental issue is that uniform parameter sharing across all qubits in a category may not align with the actual data geometry.

This new approach uses a **layered adaptive rotation and targeted entanglement strategy**:

1. **Diverse single-qubit rotations**: Instead of just even/odd sharing, we use RX, RY, and RZ gates to create richer single-qubit state space that can better capture input features and intermediate correlations.

2. **Minimal, strategic entanglement**: We focus on proven high-impact two-qubit interactions:
   - Nearest-neighbor links (0-1, 2-3, 4-5, 6-7) for local correlation
   - Long-range links (0-3, 2-7) as recommended to capture non-local dependencies
   - Controlled gates (CRX, CRY) on key links for directional information flow

3. **Reduced parameter count**: By mixing gate types and being selective about where parameters appear, we reduce the distinct parameter count below the current 11, improving parameter efficiency while maintaining expressiveness.

4. **Better convergence structure**: The rotation-before-entanglement-before-rotation pattern with diverse Pauli axes should converge faster and achieve better worst-group margins by creating more orthogonal feature spaces for hard-to-separate samples.

This replaces the parity-based uniform RY rotations with a heterogeneous approach that balances depth, parameter economy, and expressiveness.
