2. **Poor worst_group_margin (0.03)**: The circuit is failing to robustly separate hard samples, which is the main optimization criterion.
3. **Too many parameters (24 distinct)**: Parameter efficiency directly impacts scoring - each parameter hurts the score.
4. **Poor validation margin (0.03)**: The decision boundary is weak on validation data.

The current ansatz is a simple linear structure:
- 8 single RY rotations (shared parameters across all samples)
- 8 independent RZ pre-rotations
- Linear chain of CZ gates
- 8 independent RZ post-rotations

This lacks:
1. **Parameter sharing** - The RZ gates should be shared across qubits to reduce parameter count
2. **Non-linear entanglement** - A linear chain CZ connectivity doesn't create complex enough entanglement patterns for robust separation
3. **Adaptable feature maps** - Individual RZ rotations per qubit don't help generalization when parameters aren't shared

My strategy:
1. **Reduce parameters dramatically** by sharing RZ gates across all qubits (use same param name)
2. **Add stronger entanglement** with a more connected pattern to create robust separations
3. **Simplify the structure** to rely on the shared parameters working together rather than individual parameters per qubit
