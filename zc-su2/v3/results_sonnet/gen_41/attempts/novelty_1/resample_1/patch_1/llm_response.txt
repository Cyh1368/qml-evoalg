front_loaded_zz_shared_ry_entangler

<DESCRIPTION>
Builds on the best-performing prior seed (RX/RY/CNOT-ring/RZ/CRZ/CNOT/RY, 5 distinct params) by prepending a long-range ZZ Ising layer on opposite-qubit pairs ([0,4],[1,5],[2,6],[3,7]) that REUSES the existing "a" parameter (the one driving the first RX layer) instead of introducing a new trainable name. This follows the recommendation that front-loaded long-range entanglement before the first global rotation layer sharpens the decision boundary, while keeping the total distinct-parameter count unchanged at 5 (since "a" is shared). The ZZ pairs are mutually disjoint so they execute in one parallel layer, adding only ~1 unit of circuit depth rather than a full extra layer, preserving the ~42-gate depth band while giving the classifier an early global entangling cue that the previous ansatz lacked. All subsequent structure (RX(a), RY(b), fixed CNOT ring, RZ(c), shared CRZ(d) entangler on disjoint pairs, offset fixed CNOT ring, final shared RY(e)) is kept intact since it already produced the best generalization gap (0.03) among tested variants.

"""Seed program. Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved.

Everything else about the task, that is how inputs are encoded, how the circuit
is measured, how training works and how metrics are computed, is fixed and lives
in a module that is not reproduced here. No information about the data is
available in this file.
"""

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}
ALLOWED_ISING_GATES = {"XX", "YY", "ZZ"}


# EVOLVE-BLOCK-START
ANSATZ_SPEC = []

# Layer 0: front-loaded long-range ZZ entangling layer on opposite-qubit
# pairs. These four pairs are mutually disjoint, so they execute in a
# single parallel depth-layer. Crucially, this layer REUSES the "a"
# parameter (shared with the very next RX layer) rather than introducing
# a new trainable name, so the distinct-parameter count stays unchanged
# while the classifier gets an early global entangling cue before any
# single-qubit rotation has been applied.
for _i in range(4):
    ANSATZ_SPEC.append({"gate": "ZZ", "wires": [_i, _i + 4], "param": "a"})

# Layer 1: global shared rotation RX(a) on every qubit (same "a" as above).
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RX", "wire": _i, "param": "a"})

# Layer 2: global shared rotation RY(b) on every qubit.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": _i, "param": "b"})

# Fixed entangling ring 1 (no parameters), nearest-neighbor connectivity.
for _i in range(N_QUBITS - 1):
    ANSATZ_SPEC.append({"gate": "CNOT", "wires": [_i, _i + 1]})
ANSATZ_SPEC.append({"gate": "CNOT", "wires": [N_QUBITS - 1, 0]})

# Layer 3: global shared rotation RZ(c) on every qubit.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": _i, "param": "c"})

# Cheap parametrized entangling structure: CRZ(d) shared across disjoint
# pairs, giving controlled correlation without extra parameter cost.
for _i in range(0, N_QUBITS, 2):
    ANSATZ_SPEC.append({"gate": "CRZ", "wires": [_i, _i + 1], "param": "d"})

# Fixed entangling ring 2, offset to spread information further without
# adding trainable parameters.
for _i in range(1, N_QUBITS, 2):
    _j = (_i + 1) % N_QUBITS
    ANSATZ_SPEC.append({"gate": "CNOT", "wires": [_i, _j]})

# Final global shared rotation RY(e) on every qubit, giving the readout a
# flexible final basis.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": _i, "param": "e"})
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
