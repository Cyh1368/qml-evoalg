<DESCRIPTION>
Invert the alternating rotation-axis assignment so even wires use RX and odd wires use RY. This tests whether the encoded features and fixed readout align better with the opposite parity-axis distribution while preserving the same single shared parameter, gate count, depth, and entanglement topology. The prior inverted-axis result showed slightly better validation loss than the current arrangement, making this a parameter-neutral probe for improved held-out separation.
</DESCRIPTION>
