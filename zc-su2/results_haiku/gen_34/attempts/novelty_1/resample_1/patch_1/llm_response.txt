<DESCRIPTION>
The current program uses global parameter sharing (`rx_shared`, `rz_shared`) across a single ansatz block. This creates a bottleneck: all qubits must rotate by the same angle, limiting expressivity without increasing parameter count.

The new architecture splits the ansatz into two specialized blocks, each with its own rotation parameters (`rx_1`, `rz_1` for block 1 and `rx_2`, `rz_2` for block 2). This doubles the parameter count from 2 to 4 (still very economical), but allows each block to learn independent rotation angles while maintaining the same CZ chain structure.

Key improvements:
1. **Better expressivity**: Each block can specialize to different aspects of the problem
2. **Faster convergence**: Independent parameters reduce optimization landscape flatness
3. **Maintained economy**: Only 4 parameters—still very parameter efficient
4. **Preserved structure**: Linear CZ chains remain, proven to work well
5. **Clear modularity**: Two distinct transformation layers make the circuit architecture more interpretable

This directly addresses the recommendation to give each sandwich block its own rotation pair, enabling specialization while staying within a tight parameter budget.
