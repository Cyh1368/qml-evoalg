# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- Two-Block CZ-Sandwich with Global Sharing  
  • Seed program (“two-block CZ-sandwich”) repeats [shared-RY → shared-RZ → CZ-chain → shared-RZ] twice, using only ry_shared and rz_shared. This yields the top combined score 0.72 with 14 parameters (depth 65, 372 gates, convergence in ~90 steps).  
  • Repeating identical CZ blocks at fixed parameter count boosted expressivity by +0.04 versus single-block XX/CZ designs (e.g., Gen 19/22, score 0.68, 20 params, depth 35).  

- Aggressive Global Parameter Reuse  
  • Collapsing all 16 RY and 32 RZ rotations into two scalars (ry_shared, rz_shared) maximizes parameter efficiency (0.07) and achieves perfect generalization.  
  • Global sharing alone (Gen 25 “parametrized_entangling_ladder” with CRZ) reached 0.68 but the two-block CZ variant doubles depth to recover the full +0.04 score boost.  

- Linear CZ Chain Outperforms Alternative Entanglers  
  • Linear nearest-neighbor CZ chains consistently hit 1.00/1.00/1.00 accuracy with zero gap; ring-CZ (Gen 24/30) and CRZ-based ladders (Gen 25) also generalize but plateau at 0.68.  
  • Linear CZ facilitates faster convergence (~90 steps) compared to ring entanglement (~150 steps in Gen 24), indicating a smoother optimization landscape.  

## Ineffective Approaches

- Overparameterized Per-Wire Rotations  
  • Ansätze with 20 (Gen 26/27/30) or 26 parameters (Gen 29) achieved perfect accuracy but only 0.68–0.66 combined score and parameter efficiencies of 0.05–0.04, showing diminishing returns past ~14 shared parameters.  

- Substituting CZ with CRZ or XX  
  • Shared-Parameter RY-RZ-CRZ Ansatz (Gen 25) scored 0.68—no improvement over CZ-chain—even though it converged faster (~60 steps).  
  • Shared RY-RZ-XX chains (Gen 19/22) also plateau at 0.68, confirming CZ is the more expressive two-qubit gate for this classification.  

- Minimal-Parameter Single-Block Designs  
  • Circuits with only two global rotation parameters (Gen 16) entirely failed (score 0.00), demonstrating underparameterization cannot cover the required hypothesis space.  

## Implementation Insights

- Block Replication Multiplies Expressivity  
  • The seed’s EVOLVE-BLOCK uses 64 RY and 64 RZ gates (across two blocks) all tied to ry_shared/rz_shared. This gate-count inflation at fixed parameters (372 gates) delivers the highest score.  

- Parameter-Gate Ratio Matters  
  • Seed: 14 params over 372 gates → PE 0.07; Gen 26/27/30: 20 params over ~192 gates → PE 0.05; Gen 29: 26 params over 186 gates → PE 0.04. Higher gate counts per parameter correlate with better combined score.  

- CZ-Chain Topology Simplifies Optimization  
  • Linear CZ chains in both blocks of the seed program drove convergence in ~90 steps. In contrast, ring CZ (Gen 24/30) required ~150/90 steps without score gains, suggesting that introducing long-range loops can complicate the loss landscape.  

- Shared-Parameter Sandwich Template  
  • The core template—RY(ry_shared) × N → RZ(rz_shared) × N → CZ-chain → RZ(rz_shared) × N—is a highly reusable motif. Doubling its depth rather than diversifying parameters proved key to maximizing expressivity.  

## Performance Analysis

- Combined Score vs. Parameter Count  
  • 14 parameters (Seed) → 0.72; 20 parameters (Gen 25–27,30) → 0.68; 26 parameters (Gen 29) → 0.66. Fewer, globally shared parameters plus deeper blocks outperform higher parameter counts.  

- Gate Count Trade-Off  
  • Seed’s deep circuit (372 gates) yields +0.04 score over shallow designs (186–192 gates). Doubling gate count at constant params is a worthwhile cost for improved expressivity.  

- Convergence Speed vs. Entanglement Style  
  • CRZ-based Gen 25 converged fastest (~60 steps) but scored 0.68; seed’s linear CZ design strikes the best balance—90 steps for the top score.  

- Parameter Efficiency Correlates with Score  
  • PE: 0.07 (Seed, 0.72) > 0.05 (Gen 25/27/30, 0.68) > 0.04 (Gen 29, 0.66). Higher gate-per-parameter ratios align with both better generalization and combined score.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Replace each CZ with a shared-parameter CRZ gate across both blocks. Define a new global parameter `phi_shared` and swap every `{"gate":"CZ"}` for `{"gate":"CRZ","param":"phi_shared"}`. This preserves the linear entangling ladder while giving the optimizer direct control over entangling angles, capitalizing on CRZ’s faster convergence.

2. Split the sandwich’s Z rotations into pre- and post-entanglement phases. Introduce two scalars `rz_pre` and `rz_post` (replacing all instances of `rz_shared` before the CZ chain with `rz_pre` and those after with `rz_post` in both blocks). This raises the parameter count from 2→3 and grants independent tuning of phase insertion timing without increasing gate depth.

3. Give each CZ-sandwich block its own RY/RZ pair. Replace all `ry_shared`/`rz_shared` in block 1 with `ry_1`/`rz_1` and in block 2 with `ry_2`/`rz_2`, bringing n_params to 4. Block-specific sharing retains parameter economy within each layer but lets the two deep sandwiches specialize to potentially capture different features.

4. Stack a third RY→RZ→CZ-chain→RZ block reusing `ry_shared` and `rz_shared`. Append an identical sandwich to the end of the existing two, keeping n_params=2 while boosting depth to ≈100 and gate count to ≈560. Given that doubling depth at fixed parameters yielded +0.04 score, a triple stack tests whether further depth inflation can exceed the 0.72 ceiling.

5. Prepend a shared RX layer across all qubits. Insert eight `{"gate":"RX","wire":i,"param":"rx_shared"}` gates before the first RY stage, introducing a third global parameter. This cross-axis augmentation explores whether an initial X-rotation enhances state-space coverage while preserving the proven Y/Z sandwich plus linear CZ backbone.
