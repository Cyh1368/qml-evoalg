# Analysis

Looking at the current program and prior attempts, I notice:

1. **Current performance**: Combined score 0.65 with 8 distinct parameters, worst_group_margin 0.35
2. **Best prior**: Combined score 0.66 with 7 distinct parameters, worst_group_margin 0.35
3. **Key bottleneck**: The worst_group_margin is stuck at 0.35 across all attempts, suggesting we need better expressivity for hard samples

The recommendation to replace ZZ gates with CRZ gates is sound because:
- CRZ provides **tunable phase control** per gate, vs ZZ which only has a shared parameter
- Current code uses 5 ZZ gates with 1 shared parameter (`ent_lr`) - replacing with CRZ gates and 1 shared parameter would maintain efficiency while increasing expressivity
- CRZ is a parametrized two-qubit gate that's in ALLOWED_PARAM_TWO_QUBIT_GATES
- This allows fine-grained control over two-qubit entanglement to better separate difficult samples

Additionally, I'll reduce `rz_mid` to fewer qubits (targeting even indices only, matching the pattern of other blocks) to reduce the gate count and parameter overhead while maintaining structure.
