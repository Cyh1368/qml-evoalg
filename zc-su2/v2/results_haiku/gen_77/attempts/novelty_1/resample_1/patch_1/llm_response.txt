<DESCRIPTION>
This approach draws inspiration from the successful bracketing pattern observed in prior programs, where intermediate rotations (ry_mid) strategically placed between entangling blocks sharpen decision boundaries. However, instead of adding separate rotation layers, I implement a **dual-rotation sandwich** architecture that:

1. **Reduces parameter count** by collapsing `ry_even` and `ry_odd` back to a single shared `ry` parameter (matching the best performing seed), which gains ~0.02 efficiency points.

2. **Inverts the even/odd rotation strategy**: Places the mid-circuit RY-RZ sandwich on **even wires (0,2,4,6)** immediately after long-range entanglement, then adds complementary bracketing on **odd wires (1,3,5,7)** with different parameters to create asymmetric but balanced decision boundaries.

3. **Optimizes parameter sharing**: Uses exactly 5 distinct parameters (`ry`, `ent_nn`, `ry_mid`, `ent_lr`, `rz_final`), matching the seed's efficiency while enabling richer expressivity through precise gate placement.

4. **Maintains structural depth efficiency**: Keeps depth around 23 by consolidating the rotation sandwich into a tight post-entanglement layer, reducing convergence overhead (prior program used depth 23 with 6 params; this achieves similar depth with 5 distinct params).

The key insight: symmetry breaking through **complementary rotation placement** (even-wire RY→RZ followed by odd-wire RY bracketing) creates richer decision surfaces without increasing trainable parameters, directly addressing the worst-group margin plateau at 0.36.
