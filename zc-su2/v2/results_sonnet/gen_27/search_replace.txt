add_xx_ring_after_zz

<DESCRIPTION>
Insert a shared-parameter XX ring immediately after the existing ZZ ring (before the backward CNOT ladder). The ZZ ring currently only mixes phase information; adding an orthogonal Ising XX coupling on the same ring topology lets the circuit build entanglement in a complementary basis, which empirically improves worst-group margin without increasing the distinct parameter count beyond +1 (single shared "xx_ring" parameter). This should help robustness on harder validation groups while keeping parameter economy strong (5 distinct params vs current 4), a small trade-off for a potentially larger margin gain as suggested by the recommendation.
</DESCRIPTION>
