merge_rzp_zzring_into_theta

<DESCRIPTION>
The two prior seeds show that fewer distinct trainable parameters strongly improve the combined score: the 2-distinct-parameter variant (ry_a, theta) scored 0.73, beating the 3-distinct-parameter variant (ry_a, rz_p, zz_ring) which scored only 0.71, despite the latter having strictly richer connectivity (extra skip-2 ZZ shell, XX ring, etc.). This strongly suggests parameter economy dominates over marginal connectivity gains here.

This edit merges the "rz_p" (global phase) and "zz_ring" (all entangling ZZ/XX couplings) parameter names into a single shared parameter "theta", cutting n_distinct_params from 3 to 2 while keeping the exact same gate structure (same depth, same connectivity, same gate count). This should combine the parameter-economy benefit of the 0.73 seed with the richer connectivity (skip-2 ZZ shell + XX ring) of the current 0.71 seed, hopefully pushing the score above both.
</DESCRIPTION>
