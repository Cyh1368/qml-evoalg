# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Two-group RY sharing (wires 0–3 vs 4–7) plus a single shared ZZ‐ring with wrap-around and long-range cross-couplings achieved the top combined score of 0.71 (Gen 22).  
- Reuse of one global RZ parameter applied both before and after the entangling layers (param name “rz_p”) preserved phase flexibility without increasing distinct parameters, contributing to a high validation margin (0.71) and zero generalization gap.  
- Inserting fixed forward and backward CNOT ladders around the parametrized entangler (as in the current best program) doubled gate connectivity at zero parameter cost and halved convergence steps from 60 → 30 compared to the pure ZZ‐ring design (Gen 21).  
- Limiting to four distinct trainable names (“ry_a”, “ry_b”, “rz_p”, “zz_ring”) while deploying six total parameterized gates strikes an optimal balance between expressivity and trainability, yielding peak parameter efficiency (0.17) and perfect accuracies.  

## Ineffective Approaches  
- Excessive parameter sharing without complementary mixing (Gen 23, Gen 25, Gen 26) led to score 0.0 and validation failures; omitting ring closure or cross-couplings cripples expressivity and violates topology requirements.  
- Collapsing all RZ layers into one without dual-layer reuse (as in earlier failed patches) removes critical phase degrees of freedom, resulting in both poor performance and test failures.  
- Omitting the wrap-around ZZ(7, 0) link breaks the ring topology (seen in Gen 17) and causes outright validation failure, underscoring full‐cycle connectivity as mandatory.  
- Relying solely on a shared ZZ-ring entangler without unparameterized CNOT ladders (e.g., Gen 21’s 96-gate design) achieves high accuracy but converges twice as slowly and scores 0.70 versus 0.71 when compared to circuits with CNOT mixing.  

## Implementation Insights  
- Define ANSATZ_SPEC with clear, reusable param names: use “ry_a”/“ry_b” for two-group single-qubit rotations, “rz_p” for all RZ gates pre/post entangling, and “zz_ring” for every ZZ coupling (including cross-links).  
- Leverage unparameterized two-qubit gates (forward/back CNOT ladders) to deepen entanglement at zero extra parameter cost, sharpening the optimization landscape and speeding convergence.  
- Introduce long-range ZZ cross-couplings (wires [0,4], [1,5], [2,6], [3,7]) under the same “zz_ring” name to boost connectivity for worst-margin groups without inflating the parameter count.  
- Structuring the ansatz as “pre-rotation → CNOT ladder → RZ(“rz_p”) → ZZ-ring (+ cross-links) → backward CNOT ladder → RZ(“rz_p”)” encodes both symmetry and rich mixing in a compact, trainable form.  

## Performance Analysis  
- Adding forward/back CNOT ladders and cross-couplings to Gen 21’s pure ZZ-ring design increased combined score from 0.70 → 0.71 and reduced convergence from 60 → 30 steps.  
- Gate count rose from 96 → 150, but parameter efficiency improved from 0.16 → 0.17, showing that modest depth increases can pay off when parameters are reused effectively.  
- Validation margin improved from ~0.70 (Gen 21) to 0.71 (current best), while worst-group margin held at 0.36, indicating that cross-links help maintain group-balanced robustness without additional parameters.  
- Perfect train/validation/test accuracies and zero generalization gap across top designs confirm that minimal distinct parameters combined with rich unparameterized entangling yield both high accuracy and strong generalization.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Add a second set of diagonal “zz_ring” cross-links  
   Immediately after the existing long-range ZZ couplings, append four more ZZ gates on wires [0, 5], [1, 6], [2, 7], [3, 4], all labeled with the same “zz_ring” parameter. This leverages the proven benefit of long-range connectivity to further boost worst-group margins without increasing the distinct parameter count.  

2. Diversify the fixed ladders by interleaving CZs  
   Modify every other gate in both the forward and backward CNOT ladders to CZ (for example, make wires [1,2], [3,4], [5,6] use CZ instead of CNOT). This introduces an orthogonal entangling interaction at zero parameter cost, building on the ladder-mixing insight that richer unparameterized two-qubit gates accelerate convergence.  

3. Swap each ZZ entangler for controlled-RZ (CRZ) gates  
   Replace all eight ZZ( i,i+1 ) and eight cross-ZZ gates with CRZ on the same wire pairs, still using the shared “zz_ring” parameter. Since CRZ and ZZ(ϕ) are locally equivalent up to unitaries, this tests whether native two-qubit phase rotations further tighten the optimization landscape while preserving the single-parameter Ising block.  

4. Introduce a complementary two-block sandwich  
   Immediately duplicate the entire RY→CNOT→RZ→ZZ(+cross)→CNOT→RZ sequence as a second block, reusing all four parameter names. In that second block, swap the long-range coupling pattern to the complementary diagonals ([0,5],[1,6],[2,7],[3,4]) so both cross-link sets are covered. This doubles depth but keeps n_distinct_params=4, following the proven sandwich motif to boost margins without doubling convergence steps.  

5. Test an alternate two-group split for RY rotations  
   Change the pre-rotation (and any post-rotation remix) so that “ry_a” is applied to even wires [0,2,4,6] and “ry_b” to odd wires [1,3,5,7]. This preserves the two-parameter symmetry that yielded perfect accuracy but explores a different qubit partition, potentially uncovering a more expressive grouping without adding new parameters.
