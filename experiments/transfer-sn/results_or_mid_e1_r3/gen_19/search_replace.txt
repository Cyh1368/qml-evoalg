<DESCRIPTION>
This edit replaces the current higher-variance CRY/RX-heavy block with a phase-centric, low-parameter ansatz that better matches the fixed IsingZZ feature map.

Why this should help:
- Uses only 5 unique trainable parameters per block instead of 6, improving parameter efficiency and reducing overfitting.
- Keeps all mixing operations in the phase domain with RY/RZ + CRZ, which is well aligned with the ZZ feature encoding.
- Preserves two complementary entangling patterns: disjoint pairs and shifted ring pairs, which helps correlation propagation across the 8-qubit register.
- The shared-parameter structure should converge faster under Adam and typically improves validation/test stability on this task.
</DESCRIPTION>
