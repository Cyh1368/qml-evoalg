# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Collective single-qubit rotations with shared parameters plus dense perfect-matching CZ entanglement.  
  – The Permutation-Equivariant 8-Qubit QNN (combined raw score 0.93; train/val/test ≈0.96/0.95/0.94; gap 0.02; N_PARAMS = 20; depth 117; gates 396) uses just three shared angles per block (collective_ry, collective_rz, collective_rx) and seven CZ matchings to achieve near–all-to-all connectivity without blow-up in depth.  
- Multiple data re-uploads amplify expressivity in a low-parameter ansatz.  
  – Both the Perm-Equiv and Shared-Phase classifiers interleave N_UPLOADS = 3 feature maps with N_REPEATS = 2 ansatz blocks, yielding sufficient nonlinearity to reach >0.90 test accuracy with only 20 circuit parameters.  
- Perfect-matching CZ layers balance connectivity and circuit depth.  
  – Using seven successive perfect-match CZ layers (each qubit entangled exactly once per layer) achieves full graph entanglement in 36 CZ gates at depth 117, outperforming ring/CNOT or sparser layouts (e.g. ring_cross_cnot_three_axis: combined 0.66; depth 93; gates 300).  
- Minimal trainable readout calibration (gain and bias on mean-Z) stabilizes training across architectures.  
  – All top models (Perm-Equiv, Shared-Phase) use gain×(mean Z–bias) and achieve rapid, stable convergence, suggesting the readout scheme is robust and parameter-efficient.  

## Ineffective Approaches  
- High-parameter, layered RY/RZ/CZ or RX/CNOT architectures overfit and converge slowly.  
  – The 146-parameter 8-Qubit Re-uploading ZZ Ansatz (combined 0.77; gap 0.11; 276 gates) and the layered three-axis entangled binary classifier (combined –2.10 raw; gap 0.07; 146 parameters) both show poor parameter efficiency (≈0.01) and require >500 optimizer steps.  
- CNOT-only ring entanglement limits expressivity.  
  – The ring_cross_cnot_three_axis model (combined 0.66; test 0.72; gap 0.07; depth 93) fails to capture enough multi-qubit correlations compared to CZ-based dense patterns.  
- Pure IsingZZ feature maps without trainable two-qubit rotations underperform.  
  – Models relying solely on fixed IsingZZ couplings and sparse CNOTs scored ≤0.59 combined with large generalization gaps (≈0.15), indicating feature encoding alone is insufficient.  
- Excessive re-uploading without parameter sharing inflates circuit size without boosting generalization.  
  – The 8-Qubit Reuploading Variational Classifier (146 parameters; combined 0.78; gap 0.10) shows that re-uploads must be paired with parameter-sharing to avoid over-parameterization.  

## Implementation Insights  
- Collapse per-qubit rotations into collective parameters via ANSATZ_SPEC mapping.  
  – Listing eight identical RY (and RX/RZ) entries keyed to “collective_ry” etc. reduces 24 individual angles to one scalar per rotation type, simplifying both indexing (via POSITION_OFFSET) and optimizer dimensionality.  
- Use Pennylane’s AnnotatedQueue for precise depth/gate profiling.  
  – Wrapping feature_map and apply_ansatz_block in an AnnotatedQueue then building a QuantumScript yields exact depth (117) and gate_count (396), guiding entanglement layout decisions.  
- Encode perfect-matching CZ layers explicitly in ANSATZ_SPEC.  
  – Defining each CZ pairing (e.g., [7,0], [1,6], …, [2,3]) in seven rounds ensures every qubit pair interacts once per block, attaining complete-graph connectivity with minimal redundancy.  
- Leverage default.qubit with autograd/backprop for fast gradient evaluation.  
  – The Perm-Equiv model converged past 0.90 validation accuracy in ~150 Adam steps, compared to 3–5× steps for larger ansätze, showing compact parameter spaces benefit from backprop differentiation.  

## Performance Analysis  
- Highest combined score correlates with lowest parameter count.  
  – Top models (Perm-Equiv: 0.93, Shared-Phase: 0.90) use only 20 parameters (efficiency 0.05), whereas high-param models plateau ≤0.78 combined (efficiency 0.01).  
- Generalization gap shrinks as parameters are shared.  
  – Perm-Equiv gap 0.02 and Shared-Phase gap 0.00 contrast starkly with gaps ≥0.06 in 98–146-parameter models.  
- Fast convergence aligns with compact ansatz.  
  – Perm-Equiv reached the convergence threshold in ~150 steps; layered/higher-param models needed >500 steps, increasing training cost and risk of plateauing.  
- Depth and gate count trade-offs.  
  – While Perm-Equiv’s depth 117 and gates 396 exceed some ring designs, its nearly complete entanglement and parameter sharing deliver a net +0.27–0.33 accuracy improvement over sparser, shallower circuits.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce per-qubit offset parameters on top of each collective rotation.  Keep the three block-level shared angles (“collective_ry”, “_rz”, “_rx”) but add eight trainable “offset_i” parameters (i∈0…7).  In `apply_ansatz_block`, replace each rotation R?(angle,param) with R?(angle + offset_i) on qubit i.  This hybrid preserves the low-dimensional shared manifold while giving each qubit light local tunability to capture residual asymmetries, and only adds eight parameters.  

2. Enrich two-qubit entanglement by swapping every second CZ for a shared-parameter CRZ.  Modify `ANSATZ_SPEC` so that, for example, CZ gates at even indices remain fixed but CZ gates at odd indices become CRZ gates with param name “shared_crz”.  Use a single “shared_crz” per block (added to `PARAMETER_KEYS_PER_BLOCK`), so you only add one extra parameter per block.  This injects tunable phase interactions without inflating depth.  

3. Append a trainable collective readout rotation layer immediately before measurement.  After the final ansatz block in `circuit_z_expectations`, apply two new collective rotations—e.g. RY(readout_ry) on all wires followed by RX(readout_rx) on all wires—where “readout_ry” and “readout_rx” are shared across qubits.  This adds just two extra parameters and lets the circuit adapt its measurement basis, building on the success of minimal trainable readout calibration.  

4. Restructure each ansatz block to interleave rotations and entanglers.  Instead of grouping all three rotations then all CZ layers then RX, split `ANSATZ_SPEC` into sub-blocks:  
   a) Apply collective_rx on all qubits  
   b) Apply the first perfect-matching CZ layer  
   c) Apply collective_rz on all qubits  
   d) Apply the second CZ layer  
   e) Apply collective_ry on all qubits  
   f) Apply the remaining CZ layers  
   This alternating pattern has been shown to boost expressivity in other layered ansätze, while still using only three shared angles per sub-block.  

5. Trade off per-block depth against repeat count by using a minimal set of CZ matchings.  Define each block to include only three perfect-matching CZ layers (e.g. pairings [0,1],[2,3],[4,5],[6,7] then [0,3],[1,2],[4,7],[5,6] then one more matching), and increase `N_REPEATS` to 3 (while keeping `N_UPLOADS=3`) so that over 9 blocks each qubit pair interacts at least once.  This halves the per-block entangling depth and total gate count, testing whether distributing connectivity across more but shallower blocks preserves accuracy with a lower depth footprint.
