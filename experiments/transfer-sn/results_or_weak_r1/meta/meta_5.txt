# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Parameter sharing across qubit pairs consistently boosted generalization and raw score:  
  • Generation 3 (Parameter-Shared RY/RZ Ansatz) used shared RY and RZ parameters over four qubit-pairs, achieving the top combined_score_raw = 0.89 (vs. 0.85 in G0) and shrinking the generalization gap to 0.03.  
- Dual-ring CZ entanglement maintained expressivity with fewer parameters:  
  • The interleaved two-ring CZ scaffold in Generation 3 matched the depth (99) and gate count (276) of G0 but halved the parameter count (74 vs. 146), preserving accuracy.  
- Readout calibration (trainable gain & bias) and early stopping stabilized training:  
  • All top-performing classifiers (G0, G3) used a two-parameter readout layer plus L2‐loss early stopping, yielding negligible variance (std = 0.00) and converging within ~270 steps.  
- Three feature-uploads with two ansatz repeats struck the right balance between depth and feature re‐uploading:  
  • The current best program (G3) retained N_UPLOADS = 3 and N_REPEATS = 2, matching high-accuracy configurations in G0 and avoiding the overfitting seen when adding extra parametric entanglers in G4/G5.  

## Ineffective Approaches  
- Overparameterized entangler layers led to plateaued validation accuracy and larger generalization gaps:  
  • Generation 1 (enhanced entanglement + parameterization) and Generation 4 (enhanced rotation layers) both exceeded 120 parameters and incurred combined scores ≤ 0.81 with gen gaps ≥ 0.11.  
- Heavy use of parameterized two-qubit gates without sharing caused overfitting:  
  • G1 and G4 employed CRZ/CRX layers in each block (122–212 parameters), yet test accuracy never surpassed ~0.85, indicating diminishing returns.  
- Depth increases beyond ~100 layers did not improve performance:  
  • Generation 4 (depth = 126) and Generation 5 (depth = 117) added circuit layers but saw raw scores drop to 0.79–0.81, confirming that simply deepening the ansatz hurts generalization.  
- Removing structured entanglement or pruning repeats degraded parameter efficiency without accuracy gains:  
  • The pure “reuploading” design in Generation 2 (IsingZZ + CNOT chain, 122 parameters) reached only 0.78 combined score despite maintaining moderate depth (91), highlighting the need for an expressive, shared-parameter entangler pattern.  

## Implementation Insights  
- Light‐weight, shared‐parameter blocks enforce regularization by construction:  
  • In Generation 3’s ANSATZ_SPEC, mapping four shared “ry_i” and “rz_pre_i”/“rz_post_i” parameters to eight wires reduces free parameters to 74 while preserving rotational freedom.  
- Two‐ring CZ layout provides full qubit connectivity in 8-qubit architectures:  
  • The interleaved rings [(0–2–4–6–0) and (1–3–5–7–1)] deliver global entanglement within minimal two-qubit gate overhead (16 CZs per block), matching expressive power of linear chains or dense CRZ meshes.  
- Centralized parameter‐to‐index mapping simplifies spec changes:  
  • The validate_ansatz_spec → PARAMETER_KEYS_PER_BLOCK pipeline allows rapid iteration on gate lists without manual index bookkeeping, facilitating experiments like pruning or swapping gates.  
- Consistent hyperparameter recipe underpins reproducibility:  
  • All top variants used Adam (stepsize ≈ 0.03), L2 loss, batch_size = 15, N_EPOCHS = 1000 with early stopping (patience = 75), demonstrating that ansatz design—more than optimizer tuning—drove performance differences.  

## Performance Analysis  
- Evolution of combined_score_raw over generations:  
  • G0 (0.85) → G1 (0.78) → G2 (0.81) → G3 (0.89) → G4 (0.81) → G5 (0.79), peaking at G3 with parameter sharing.  
- Parameter count vs. test accuracy correlation:  
  • High-param models (146–212 params) topped train accuracy (~0.97) but suffered test accuracy (0.85–0.87) and gen gaps ≥ 0.07.  
  • Mid-param models (~74–122 params) struck a sweet spot—G3 at 74 params delivered 0.90 test accuracy and gen gap = 0.03, while G2 at 122 params hit only 0.84 test.  
- Depth and gate count held steady (~99 layers, ~270 gates) across top performers:  
  • Neither reducing depth (G2: 91) nor increasing depth (G4: 126) improved the combined score, indicating an optimal depth corridor around 95–105 layers.  
- Parameter efficiency remained uniformly low (~0.01), signaling that even the best programs are under‐parameterized relative to classical models—but sharing patterns boosted effective expressivity without bloating the parameter count.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Tie rotation parameters across all blocks. In ANSATZ_SPEC, replace per-block parameters `ry_i`, `rz_pre_i`, and `rz_post_i` with a single global set of those keys and reuse them in every upload/repeat. This mutation slashes N_CIRCUIT_PARAMS from 72 to 12, enforcing stronger regularization to test if deeper parameter sharing can maintain the 0.89 combined_score_raw.

2. Add a shared RX pre-rotation layer. Prepend each block in ANSATZ_SPEC with `{"gate": "RX", "wire": j, "param": "rx_shared"}` for every qubit j, and declare one trainable key `"rx_shared"`. This injects an extra global basis-change parameter per block, enriching expressivity along an orthogonal axis with minimal parameter overhead.

3. Hybridize one CZ ring into shared CRZ. In each block, replace the second interleaved CZ ring gates with `{"gate": "CRZ", "wires": [a,b], "param": "phi_ring"}` and use a single `"phi_ring"` key for all those four two-qubit operations. This adds one tunable entanglement phase per block while preserving dual-ring connectivity, probing whether small phase parameters boost entanglement utility.

4. Coarse-grain rotation sharing over half-circuits. Group qubits [0–3] and [4–7] instead of pairs: in ANSATZ_SPEC use only two `ry_h`, two `rz_pre_h`, and two `rz_post_h` keys (one per half) to drive RY/RZ on the respective four qubits. This aggressive sharing reduces rotation parameters by 50% relative to the current best, evaluating if larger-block regularization retains performance.

5. Interleave a directional CNOT cycle. Between the two CZ rings in each block, insert four unparameterized CNOTs on wires `[(0,2),(2,4),(4,6),(6,0)]`. By mixing control-direction entanglement with the existing CZ scaffold, you diversify correlation pathways without altering the trainable parameter budget.
