# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- Parameter sharing over qubit pairs consistently drove the highest raw scores and zero generalization gap.  
  • In the current best (Shared-Parameter CZ Ansatz, Gen 11) 74 parameters shared across (0,1),(2,3),(4,5),(6,7) yielded combined_score_raw = 0.89, test = 0.91, gen_gap = 0.00.  
  • Earlier Parameter-Shared RY/RZ Ansatz (Gen 3) also halved parameters (74) and achieved combined_score_raw = 0.85 with gen_gap = 0.03.  

- Dual-ring CZ entanglement with added “chord” connections preserved expressivity at low parameter counts.  
  • Gen 11’s two interleaved rings plus chords (0–4,1–5,2–6,3–7) and no extra trainable two-qubit gates produced depth 105, gate_count 300, yet top raw score.  
  • Gen 3 used a similar interleaved two-ring CZ scaffold to match G0’s depth/gate_count at half the parameters.  

- Fixed-readout calibration (gain & bias) and L2-loss early stopping stabilized training across seeds.  
  • All top performers (Gen 3, Gen 11) used a two-parameter gain/bias and early stopping (patience = 75), yielding std = 0.00 in accuracies and rapid convergence (~150–270 steps).  

- Three feature-uploads with two ansatz repeats remains the sweet spot.  
  • Gen 11: N_UPLOADS = 3, N_REPEATS = 2 → depth 105 and strong test accuracy.  
  • Attempts to add extra parametric entanglers or repeats (G1, G4, G5) increased depth beyond ~120 and hurt generalization.  

## Ineffective Approaches

- Dense, fully parameterized CRZ entanglement layers increased depth/parameter cost without boosting test accuracy.  
  • All-to-All CRZ (Gen 2) had 482 params, depth 226 → combined_score_raw = 0.74, gen_gap = 0.11.  
  • Ring-CRZ Ansatz (Gen 6) with 146 params, depth 114 → combined_score_raw = 0.79, gen_gap = 0.09.  

- Rich rotation-entanglement patterns with >120 parameters plateaued validation performance and widened generalization gaps.  
  • Enhanced Ansatz (Gen 7) used 218 params, depth ? → raw_score = 0.77, gen_gap = 0.09.  
  • Pairwise-Sharing CRZ (Gen 8) achieved raw_score = 0.84 but only modest efficiency and gen_gap = 0.09.  

- Increasing circuit depth beyond ~105 layers did not improve scores.  
  • Gen 4 (depth 126) and Gen 5 (depth 117) saw raw scores drop to 0.79–0.81.  

- Heavy use of parameterized two-qubit gates (CRX/CRZ) without sharing led to overfitting.  
  • G1 and G4 overparameterized each block and failed to surpass test ~0.85 despite rich entanglement.  

## Implementation Insights

- Centralized spec-to-index mapping simplifies ansatz modifications and ensures consistency.  
  • The `validate_ansatz_spec` → `PARAMETER_KEYS_PER_BLOCK` pipeline in Gen 11 automatically indexes shared parameters, easing gate-list tweaks.  

- Shared-parameter single-qubit rotations enforce architectural regularization by construction.  
  • Gen 11’s mapping of “ry_i,” “rz_pre_i,” and “rz_post_i” to pairs reduced free parameters to 12 per block while preserving per-pair flexibility.  

- Dual-ring CZ plus fixed chords maximizes global connectivity with minimal parameter overhead.  
  • By adding four cross-ring CZs, Gen 11 achieved expressivity comparable to all-to-all CRZ but at one-sixth the parameter count.  

- Consistent hyperparameter recipe isolates ansatz design as the main performance driver.  
  • All top variants use Adam(0.03), L2 loss, batch_size = 15, early stopping (patience = 75), confirming ansatz structure—rather than optimizer tuning—dictates outcomes.  

## Performance Analysis

- Parameter count vs. raw score:  
  • Mid-param models (~74 params) peaked at raw_score = 0.89 (Gen 11) and test = 0.91.  
  • High-param models (146–482 params) never exceeded raw_score = 0.84 and had gen_gaps ≥ 0.09.  

- Depth corridor ~95–105 layers remains optimal:  
  • Gen 3 (depth 99) and Gen 11 (depth 105) both delivered raw scores ≥ 0.85.  
  • Depth < 95 (Gen 2: 91) or > 115 (Gen 4/5) underperformed.  

- Gate count ~270–300 sufficient for global entanglement:  
  • Gen 3 used ~276 gates; Gen 11 used 300 gates. Further increases yielded no gains.  

- Parameter efficiency uniformly low (~0.01), but shared-parameter patterns maximize effective expressivity per parameter.  
  • Despite low efficiency, Gen 11’s shared-parameter design achieved the best test accuracy and zero generalization gap, underscoring the value of structural regularization.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Replace the four fixed CZ “chord” gates in each block with shared-parameter CRZs. In the EVOLVE-BLOCK, change  
   `{"gate": "CZ", "wires": [a,b]}` for each chord to  
   `{"gate": "CRZ", "wires": [a,b], "param": "phi_chord"}`  
   and declare one `"phi_chord"` key. This adds a single tunable entanglement phase per block (vs. zero) and tests whether a small learned phase on the cross-ring chords boosts expressivity without blowing up the parameter count. Evidence: hybrid entanglers in Gen 8 achieved respectable raw scores with minimal parameters.  

2. Prepend a shared-parameter CRX layer on qubit pairs before the first CZ ring. In ANSATZ_SPEC, insert before the existing CZs:  
   ```
   {"gate": "CRX", "wires": [0,1], "param": "theta_pair"},
   {"gate": "CRX", "wires": [2,3], "param": "theta_pair"},
   {"gate": "CRX", "wires": [4,5], "param": "theta_pair"},
   {"gate": "CRX", "wires": [6,7], "param": "theta_pair"},
   ```  
   reusing the single `"theta_pair"` key. This introduces an early, tunable two-qubit interaction within each pair on top of shared RY rotations, probing whether initial entanglement accelerates convergence. Success in Gen 3’s interleaved shared ansatz suggests such lightweight entanglers can improve raw scores.  

3. Hierarchically share rotation parameters across upload domains instead of per block. Define two sets of rotation keys—one for blocks in upload 0–1 and one for blocks in upload 2—and assign the same four `"ry_i"`, `"rz_pre_i"`, `"rz_post_i"` keys to all blocks in each domain. This reduces N_PARAMS by roughly 25% while preserving the dual-ring+chord connectivity, testing if higher-level sharing retains the zero generalization gap of Gen 11. Gen 3’s success with aggressive sharing hints that some across-block parameter tying may be tolerable.  

4. Rebalance the feature-upload vs. ansatz-repeat schedule to N_UPLOADS=2, N_REPEATS=3. Keep the total of six blocks (2×3=6) so depth stays near 105 but shift toward deeper variational processing per data injection. This mutation explores the trade-off between encoding frequency and circuit expressivity, leveraging the insight that optimal depth is around 95–105 layers. Maintaining gate_count~300 ensures fair comparison to the current best.  

5. Append a single shared RZ rotation on every qubit at the end of each block. In ANSATZ_SPEC, after the existing post-RZs add:  
   ```
   {"gate": "RZ", "wire": 0, "param": "global_z"},
   …  
   {"gate": "RZ", "wire": 7, "param": "global_z"}
   ```  
   with one `"global_z"` key. This introduces a minimal global phase-tuning parameter per block, providing fine-grained control over the final state without increasing model complexity. Similar small additions of global rotations have stablilized training in other top variants.
