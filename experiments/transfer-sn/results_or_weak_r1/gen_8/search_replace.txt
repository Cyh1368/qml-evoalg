<DESCRIPTION>
Replace the final post single-qubit RZ layer with an adaptive, parameterized entangling layer using CRZ gates.
We keep the current parameter budget per block (12 unique parameters) by:
- Keeping the pairwise-shared RY parameters (4 params).
- Keeping the pairwise-shared pre-RZ parameters (4 params).
- Adding 4 new pairwise-shared CRZ parameters (4 params).
- Removing the 4 pairwise-shared post-RZ parameters (8 RZ gates).
This increases expressivity (adaptive phase entanglement) while maintaining the same number of circuit parameters, which should improve validation/test accuracy and reduce the train-test gap.
</DESCRIPTION>
