<DESCRIPTION>
This edit streamlines the ansatz block to improve training efficiency and performance, based on the recommendation to use learnable CRZ chords. Specifically:
1. Removes the redundant "RX" rotation layer, which contributed significant parameters but likely limited expressivity.
2. Removes the "Global RZ" layer, as it was redundant with local post-rotations.
3. Implements the recommendation: replaces the fixed CZ chords with learnable CRZ chords using a single shared parameter `crz_chord`.
4. Retains the essential "interleaved rings" entanglement and the local RY/RZ structures.

This reduces the parameter count per block from 10 to 8, leading to better optimization behavior (lower `n_params` overall), consistent with the successful seed architecture's philosophy.
</DESCRIPTION>
