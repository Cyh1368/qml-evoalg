<DESCRIPTION>
A brick-wall entangling ansatz with ring topology. Key differences from the seed:
1. Two staggered CNOT layers per block (even pairs 0-1,2-3,4-5,6-7 then odd pairs 1-2,3-4,5-6,7-0) instead of a single linear CZ chain. This creates much faster entanglement spreading across all qubits.
2. Ring closure (7→0 CNOT) ensures periodic boundary, preventing edge qubits from being under-entangled.
3. CNOT instead of CZ gates - these create asymmetric entanglement (control vs target) which can be more expressive for classification.
4. Three rotation layers (RY+RZ, RY, RZ) interleaved with entangling layers, using all rotation axes for richer single-qubit expressibility.
5. Moderate parameter count (32 per block) balances expressibility against overfitting risk.
</DESCRIPTION>
