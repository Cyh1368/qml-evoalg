The current program overfits (train 0.96, test 0.85) with 140 parameters and poor convergence (720 steps). Prior program 2 achieved the best combined score (0.07) with aggressive parameter sharing and only 56 parameters.

This edit combines the best of both worlds:
1. Adopts the highly successful shared-parameter strategy from prior program 2 (ry_even/odd, rx_group_0/1, single rz_final)
2. Adds interleaved entangling patterns: CRZ gates on adjacent pairs (crz_adj) AND shifted pairs (crz_shift) within each block
3. This dual-pattern approach captures both local and next-neighbor couplings without explosion in parameter count

Expected improvements:
- Reduce parameters from 140 to ~44 (7 unique per block)
- Recover fast convergence (likely <100 steps like prior program 2)
- Reduce overfitting via better regularization through aggressive sharing
- Improve test accuracy by 2-3% while maintaining similar generalization gap
