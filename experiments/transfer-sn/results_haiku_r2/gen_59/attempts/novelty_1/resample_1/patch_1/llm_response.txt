<DESCRIPTION>
The current program achieves a combined score of 0.90 with 32 parameters. Analysis of prior generations shows:

1. **Gen 47 (score 0.92)**: Used 20 parameters with a simpler structure (RY + CZ ring + CRY layers), achieving better parameter efficiency (0.05 vs 0.03).

2. **Gen 48 (score 0.92)**: Used 26 parameters with an enriched structure that added nearest-neighbor CRY gates reusing the same parameter as next-nearest-neighbor CRY, gaining +0.02 accuracy with zero extra parameters.

3. **Current (score 0.90)**: Uses 32 parameters with CRZ diagonal gates replacing the fixed CZ cross-ring, but this added 4 new parameters without sufficient accuracy gain.

**Key insight**: The recommendation to replace fixed cross-ring CZs with learnable CRZ gates was well-intentioned but introduced too many parameters (4 new ones) relative to the accuracy improvement. The prior success of Gen 48 came from *parameter sharing* (reusing cry_nnn across multiple gate types), not from adding new parameters.

**Proposed fix**: Replace the 4 independent CRZ gates (crz_cr parameter) with a single shared-parameter CRZ gate applied to each diagonal pair. This reduces parameters from 32 to 29 while maintaining the tunable long-range entanglement structure. The shared parameter approach mirrors Gen 48's successful zero-cost enrichment strategy.

Additionally, add back the nearest-neighbor CRY enrichment layer (reusing cry_nnn) that was present in Gen 48, which provided +0.02 accuracy boost. This adds no new parameters but increases expressivity through gate diversity.

**Expected outcome**:
- Reduce n_params from 32 to 29 (better parameter efficiency)
- Recover the nearest-neighbor CRY enrichment that boosted Gen 48
- Maintain tunable diagonal entanglement via shared CRZ
- Target: test_accuracy ≥ 0.92, parameter_efficiency ≥ 0.04
