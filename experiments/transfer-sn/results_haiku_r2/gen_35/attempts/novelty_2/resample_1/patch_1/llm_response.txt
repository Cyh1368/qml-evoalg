<DESCRIPTION>
The current implementation uses a fixed FEATURE_SCALE (π/2) for encoding all 28 binary features via IsingZZ gates. This is a critical hyperparameter that controls the amplitude of feature injection into the quantum circuit.

**Rationale for improvement:**
1. **Data-dependent encoding strength**: Different datasets and feature distributions may benefit from different encoding amplitudes. A trainable scale parameter allows the circuit to learn the optimal feature injection strength during training.

2. **Separation of concerns**: The feature map and variational ansatz are already separated (data re-uploading architecture). Adding a trainable global scale factor leverages this structure—it acts as a learned "gain" on the feature encoding, complementary to the existing output calibration (gain/bias on readout).

3. **Minimal parameter overhead**: Adding just one trainable parameter (phi_scale) is highly efficient and unlikely to cause overfitting, especially given the current parameter efficiency metric of 0.04.

4. **Gradient flow improvement**: A trainable scale can help balance the gradient magnitudes from the feature map and variational layers, potentially improving convergence speed and final accuracy.

5. **Prior performance context**: The second prior program achieved 0.93 test accuracy with 26 parameters. Adding one parameter (27 total) is negligible and could unlock better feature encoding.

**Implementation:**
- Replace the fixed `FEATURE_SCALE = np.pi / 2` constant with a trainable parameter `phi_scale`.
- Modify the `feature_map()` function to use `phi_scale * records[..., k]` instead of `FEATURE_SCALE * records[..., k]`.
- Initialize `phi_scale` to `np.pi / 2` (the current fixed value) so the circuit starts in a known good state.
- Include `phi_scale` in the parameter vector passed to the optimizer.
- Update `N_READOUT_PARAMS` to account for the new parameter.

This change is orthogonal to the ansatz structure and should improve both accuracy and parameter efficiency by allowing the circuit to adapt the feature encoding strength to the data.
</DESCRIPTION>
