<DESCRIPTION>
The recommendation suggests implementing **full block parameter recycling**: instead of creating independent parameter copies for each of the N_UPLOADS × N_REPEATS block instances, we reuse a single set of parameters across all repeats and uploads. 

**Motivation:**
1. The prior programs show success with parameter sharing (e.g., the second program achieved 0.85 test accuracy with only 68 params vs. 146 in the seed). This proves that sharing reduces overfitting and improves parameter efficiency.
2. The current program uses 110 parameters (spread across 3 uploads × 2 repeats = 6 block instances). The vast majority are circuit parameters; reducing them further should improve generalization.
3. The fixed IsingZZ feature map backbone is already re-applied at each upload—it provides strong signal injection. The ansatz block's role is to process and rotate this signal; the block structure itself (gates and connectivity) already encodes the expressivity. Reusing parameters means the block will learn more general, transferable transformations.
4. Convergence can improve because: (a) fewer parameters = simpler optimization landscape, (b) the block sees the same gradient signals 6 times (once per upload-repeat cycle), effectively amplifying learning signal, (c) regularization through parameter sharing reduces overfitting.

**Implementation:**
Modify `apply_ansatz_block()` to always use `block_index = 0` (i.e., ignore the `block_index` argument and always read from offset 0). This makes all 6 block instances share the same parameter set. The circuit will still have 6 block applications, preserving depth and expressivity, but only N_PARAMS_PER_BLOCK unique circuit parameters instead of 6 × N_PARAMS_PER_BLOCK.

**Expected outcome:**
- Reduction in N_CIRCUIT_PARAMS from 110 – 2 = 108 to ~18 (single block's 16 + 2 readout).
- Improved parameter efficiency and likely better test accuracy.
- Faster convergence due to stronger gradient signal per parameter and simpler landscape.
- Reduced overfitting (smaller generalization gap).
