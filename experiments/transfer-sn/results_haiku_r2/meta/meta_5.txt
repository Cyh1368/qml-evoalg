# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- Dense single-qubit rotations interleaved with simple CZ chains.  
  • The 8-Qubit Evolved Ansatz (Generation 0) uses RY→RZ→linear CZ→RZ per block, reaching test 0.87, gap 0.07 (score 0.85).  
- Parity-based parameter sharing.  
  • The Parity-Shared Layered Ansatz (Generation 4) halved rotation parameters yet matched 0.87 test accuracy and 0.07 gap (score 0.85).  
- Triple feature re-uploads with two ansatz repeats (N_UPLOADS=3, N_REPEATS=2).  
  • Both top programs (Gen 0, Gen 4) leverage three fixed IsingZZ uploads, underpinning expressivity.  
- Early-stopping with best-weights restoration.  
  • Convergence in ~540–750 steps prevented overfitting, maintaining low validation loss across runs.  

## Ineffective Approaches
- Over-parameterized CRZ/CRY entanglement.  
  • Generation 1 (IsingZZ-Phase) and Generation 3 (CZ-CRY) pushed train acc to 0.95–0.96 but widened gap to 0.10, dragging combined scores to 0.84 and 0.80.  
- Excessive depth reduction.  
  • Generation 5’s lower depth (81) and 222 gates cut validation accuracy to 0.85 and combined score to 0.78, indicating too shallow for stable generalization.  

## Implementation Insights
- Favor CZ chains over parametrized two-qubit gates for generalization.  
  • The current best (Gen 0) omits CRZ/CRY, balancing expressivity and gap.  
- Block structure—RY, pre-RZ, CZ network, post-RZ—drives stable convergence.  
  • This ordering in Gen 0 attains consistent 0.89 validation accuracy.  
- Parameter sharing reduces model size without accuracy loss.  
  • Parity-sharing in Gen 4 cuts per-block params from 18 to ~9, holding test acc at 0.87.  
- Fixed IsingZZ feature map uploads are a robust encoding backbone.  
  • All high-scoring models (scores ≥0.84) use three IsingZZ uploads.  

## Performance Analysis
- Generalization gap tracks combined score.  
  • Programs with gap 0.07 (Gen 0, Gen 4) score 0.85; gap 0.10 (Gen 1, Gen 3) score ≤0.84.  
- Depth ≥90 and gate count ≈270–300 correlate with best test performance.  
  • Shallow variants (depth 81) underperform despite fewer gates.  
- Parameter count vs efficiency.  
  • Gen 4 (110 params) ties Gen 0 (146 params) in score, but both have low efficiency (~0.01), highlighting redundancy in rotations.  
- Validation accuracy stability.  
  • Top programs maintain validation std 0.00, suggesting their ansatz patterns yield consistent convergence.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce parity‐based sharing for the RY rotations in each block. Replace the eight distinct “ry_0”–“ry_7” parameters with just two keys, e.g. “ry_even” and “ry_odd”, and apply them to even- and odd-indexed qubits respectively. This mirrors the Generation 4 parity sharing that halved rotation parameters without degrading test accuracy, and will cut per-block params from 16 to 2, improving parameter efficiency.  

2. Tie each qubit’s pre-RZ and post-RZ angles together by using a single parameter per wire (e.g. “rz_k” in place of “rz_pre_k” and “rz_post_k”). This halves the 16 Z-rotation params per block to 8, testing whether symmetric Z corrections before and after the CZ chain suffice to maintain the 0.87 test accuracy and 0.07 gap currently observed.  

3. Share the entire block’s parameter set across all repeats (full block recycling). Rather than having N_PARAMS_PER_BLOCK×N_UPLOADS×N_REPEATS unique parameters, define one block’s worth of params and reuse it for every upload and repeat. This drastic reduction echoes the success of the fixed IsingZZ uploads backbone and will probe how much expressivity is inherent in the block structure alone.  

4. Experiment with increasing the ansatz depth via a third repeat per upload (N_REPEATS=3, N_UPLOADS=3). Keeping the same RY→RZ→linear CZ→RZ block order, this modification boosts depth from ~99 to ~135 and gate count from ~270 to ~405. Given that depths ≥90 correlated with top performance, this tests whether additional blocks can further raise test accuracy without widening the generalization gap.  

5. Enrich entanglement connectivity by alternating two simple CZ‐chain patterns between successive blocks. For example, in odd-indexed blocks connect qubits (0,1),(2,3),(4,5),(6,7) and in even-indexed blocks connect (1,2),(3,4),(5,6). This maintains the proven generalizability of CZ gates but broadens qubit coupling pathways, potentially boosting expressivity without introducing parameterized two-qubit rotations.
