The prior programs show strong performance (0.91–0.92 combined scores) but there is opportunity to improve validation accuracy and reduce the train-test gap further. The recommendation to introduce per-upload amplitude scalars (lambda parameters) is theoretically well-motivated: each feature-map/upload cycle encodes increasingly refined information from data re-uploading, yet currently all variational blocks apply uniform parameter magnitudes across uploads.

By introducing three learnable scalars (lambda_0, lambda_1, lambda_2)—one per upload—that multiplicatively scale all block parameters within each upload cycle, we enable the optimizer to dynamically weight early vs. late blocks. Early uploads may benefit from smaller amplitudes to avoid rapid saturation, while later uploads can apply stronger corrections. This is a lightweight mechanism (only 3 extra parameters) that preserves the ansatz structure and leverages the natural phase structure of data re-uploading.

Implementation strategy:
1. Add three global scalar parameters: lambda_0, lambda_1, lambda_2 (initialized to 1.0 each).
2. Modify apply_ansatz_block to accept an upload_index and scale all rotation angles by the corresponding lambda before applying gates.
3. Include lambda parameters in the parameter vector for training.
4. Update circuit_z_expectations to pass upload_index when calling apply_ansatz_block.
5. Adjust N_PARAMS accounting to include the 3 lambda scalars.

This approach is non-invasive (preserves ANSATZ_SPEC structure), parameter-efficient (only +3 params vs. current 32), and aligns with proven algorithmic insights from block-level scaling in prior searches.

def apply_ansatz_block(params, block_index: int, upload_index: int = 0) -> None:
    """Apply one candidate ansatz block from the formal ANSATZ_SPEC.
    
    Optionally scale rotation angles by a per-upload amplitude scalar lambda.
    """
    if SPEC_ERRORS:
        raise ValueError("; ".join(SPEC_ERRORS))

    offset = block_index * N_PARAMS_PER_BLOCK
    lambda_scale = params[N_CIRCUIT_PARAMS + upload_index] if upload_index < N_UPLOADS else 1.0
    key_to_position = {key: i for i, key in enumerate(PARAMETER_KEYS_PER_BLOCK)}
