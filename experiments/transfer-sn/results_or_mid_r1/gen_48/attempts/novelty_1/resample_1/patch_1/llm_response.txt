<DESCRIPTION>
Implementation of the parameter-tying recommendation to reduce overfitting and improve generalization.

**Rationale:**
The current program has 74 parameters (12 per block × 6 block instances + 2 readout). The two repeats per upload (repeat_index 0 and 1) use independent parameters, which may introduce redundancy and lead to overfitting (validation_accuracy dropped from 0.91 to 0.88 in current vs. prior programs).

By tying ansatz parameters across both repeats within each upload, we reduce the effective parameter count from 6 blocks to 3 blocks:
- N_CIRCUIT_PARAMS: 72 → 36 (both repeats per upload share one parameter set)
- N_PARAMS: 74 → 38 total (including 2 readout params)

**Expected benefits:**
1. Reduced overfitting via parameter reduction
2. Improved validation accuracy and smaller validation-test gap
3. More structured, regularized learning
4. Faster convergence
5. Better parameter efficiency score

**Implementation:**
Modify circuit_z_expectations, apply_ansatz_block, circuit_metadata, and N_CIRCUIT_PARAMS to compute parameter offsets using upload_index instead of block_index (which combines upload_index and repeat_index).
</DESCRIPTION>
