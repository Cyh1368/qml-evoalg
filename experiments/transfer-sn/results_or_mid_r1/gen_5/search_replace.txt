<DESCRIPTION>
This edit targets two weaknesses in the seed block.

First, the original final RZ layer is effectively measurement-invariant for the Z readout, so it adds parameters without improving the classifier signal. I replace that terminal RZ layer with an RX layer, which directly changes the measured Z expectations and gives the last stage real predictive power.

Second, the original entanglement is only a nearest-neighbor chain. Since the fixed feature map already uses arbitrary qubit pairs, the ansatz should also be able to mix distant qubits efficiently. I replace the line of CZ gates with a butterfly-style all-to-all mixing pattern over long, medium, and short-range pairs. This should better capture cross-feature correlations, improve validation/test accuracy, and reduce overfitting without increasing parameter count.

The parameter budget stays the same: 24 trainable parameters per block, but the block is more expressive where it matters.
</DESCRIPTION>
