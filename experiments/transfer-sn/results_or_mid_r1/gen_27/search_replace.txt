<DESCRIPTION>
This edit implements a more parameter-efficient and expressive ansatz by following two strategies:
1. Replacing the four fixed long-range CZ gates with mirror-shared CRZ rotations (2 parameters per block). This tunable entanglement allows the circuit to better adapt to the IsingZZ feature map's correlations.
2. Applying mirror symmetry to the input RY layer, reducing the per-block input parameter count from 8 to 4.

These changes reduce the total parameter count from 98 to 86 while increasing the expressive power of the entangling layer, which is expected to improve the combined score by enhancing parameter efficiency and potentially improving validation accuracy.
</DESCRIPTION>
