<DESCRIPTION>
The current program (0.07 combined score) uses aggressive parameter sharing (74 params) which reduces expressiveness. The second prior program (0.23 combined score) achieved better performance with 98 params using strategic per-qubit inputs combined with symmetric parameter sharing in middle and output layers.

This proposal balances expressiveness and efficiency by:
1. Using per-qubit RY input gates (8 independent params) for better initial encoding
2. Keeping strong entanglement via CZ ring connectivity
3. Adding parametrized CRX gates with strategic sharing (4 params shared in pairs)
4. Using final RZ with 4-way parameter sharing

This should yield ~90 total params (better than current 74, more efficient than prior 98) while improving the expressive power and validation accuracy.
