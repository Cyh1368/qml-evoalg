# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- Three re-uploads interleaved with two repeats of a linear CZ-chain ansatz block (per-qubit RY → per-qubit RZ → CZ chain → per-qubit RY) yielded the top combined score of 0.86 in the Current Best Program (train/val/test 0.94/0.89/0.88, gap 0.06, depth 99, 270 gates).  
- Fixed two-qubit IsingZZ feature maps across all 28 inputs conserved parameter budget for the variational layers, as in both the Current Best Program and Gen17 (“Re-uploading CZ-Entangled 8-Qubit Classifier,” combined 0.85).  
- Trainable output calibration (gain initialized to 1, bias to 0) consistently stabilized convergence and nudged up test accuracy (Current Best Program vs earlier uncalibrated variants).  
- Limiting ansatz repeats to two per upload balanced expressivity and circuit depth—surpassing deeper six-block designs in both performance (0.86 vs 0.85 combined) and convergence speed (~390 steps to reach 0.90 validation).

## Ineffective Approaches

- Dense ring-CZ entanglement (Gen17 “Re-uploading CZ-Entangled,” 276 gates, depth ∼120) plateaued at a combined 0.85 and incurred moderate depth, offering no net gain over the linear chain pattern.  
- Over-parameterized SU2-style brickwork (Gen18 “Layered ZZ Feature Map,” combined 0.79, gap 0.08) and directional CNOT chains (Gen19 “Layered RY-RZ Entangler,” combined 0.76, gap 0.11) exhibited low parameter efficiency (∼0.01) and moderate overfitting.  
- Adding extra two-qubit rotations (CRX/CRY/CRZ) without structural focus (e.g., Gen21 “Reuploading RY-RZ-CZ,” combined 0.75) worsened generalization and offered no accuracy advantage.  
- Simply trimming parameter count (e.g., moving from 146 to 98 trainable params in Gen21) did not salvage performance when ansatz topology remained suboptimal.

## Implementation Insights

- Defining ansatz blocks via a reusable ANSATZ_SPEC list with explicit gate dictionaries and a key-to-position mapping (as in the Current Best Program) ensures correct parameter indexing and simplifies variant exploration.  
- Employing qml.IsingZZ(FEATURE_SCALE·x) for fixed feature encoding embeds all 28 binary inputs without trainable overhead, reserving capacity for expressive variational layers.  
- Extracting circuit depth and gate count via qml.queuing.AnnotatedQueue and QuantumScript metadata provided a reliable complexity fingerprint (Current Best: depth 99, gate_count 270) to correlate structure with performance.  
- Initializing readout gain to 1 and bias to 0 before optimization accelerated convergence (~390 steps to hit 0.90 validation) and prevented train-test calibration drift.

## Performance Analysis

- Transitioning from ring entanglement (Gen17, combined 0.85) to a linear CZ chain (Current Best, combined 0.86) cut depth by ∼20 ops and lifted test accuracy by ~0.01.  
- Circuits exceeding depth ∼120 uniformly underperformed; targeting depth ≈99 (Current Best) maximized generalization (test 0.88) while maintaining expressivity.  
- All high-score models sustained parameter efficiency ~0.01; further efficiency gains must come from ansatz topology refinements rather than raw parameter reduction.  
- Consistent patterns: three uploads + two repeats yields optimal training stability and generalization gap (~0.06), outperforming both shallower (N_REPEATS=1) and deeper (N_REPEATS>2) variants.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Replace each per-qubit pre-rotation RY–RZ pair with a full Euler block RZ(α)–RY(β)–RZ(γ) before the CZ chain, while pruning the post‐entangler RY on every second qubit (e.g., qubits 1,3,5,7) to keep the total parameter count and depth constant.  Richer SU(2) expressivity around entanglers has lifted accuracy in earlier gens (e.g. Gen13) without pushing depth beyond ~99.

2. Alternate your entanglement pattern between repeats: in the first repeat of each upload use the standard linear CZ chain, and in the second repeat connect next‐nearest neighbors (0–2, 1–3, …, 6–7) with CZs.  This “two‐tier” CZ schedule fits seven two-qubit gates per block, augments qubit mixing, and leverages the cyclic‐shift insight without increasing gate count.

3. Share the variational parameters of ANSATZ_SPEC across the three uploads, so that the same pre-rotation, post-rotation, and CZ parameters are reused upload-to-upload.  This parameter tying regularizes the model (reducing unique circuit params by ≈2∕3), freeing budget to introduce a single trainable CRZ on the middle CZ link of each block for adaptive two-qubit coupling.

4. Make the feature map’s global scale trainable by replacing the fixed FEATURE_SCALE = π/2 with a learnable scalar φ initialized to π/2, applied to all qml.IsingZZ gates.  Data-adaptive embedding strength can help the variational layers focus on the most informative binary inputs without adding gates.

5. Extend output calibration from a single global gain/bias to per-qubit affine parameters (gain_i, bias_i for i=0…7), initialized at (1, 0).  Use parameters freed by tying post-RY rotations across repeats; qubit-level calibration has the potential to correct readout imbalances and further stabilize convergence.
