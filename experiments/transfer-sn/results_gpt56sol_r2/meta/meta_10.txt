# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Three feature‐map re-uploads combined with two repeats of a linear CZ-chain ansatz block interleaving per-qubit RY/RZ pre- and post-rotations (8-Qubit Ansatz Binary Classifier, Gen13) yielded the top combined score of 0.86 (train 0.94, validation 0.89, test 0.88) and converged in ~390 steps—surpassing earlier 0.85-scoring models.  
- Trainable output calibration (gain initialized to 1, bias to 0) atop the mean-Z readout consistently stabilized training and nudged test accuracy upward (Gen0 test 0.87 → Gen13 test 0.88).  
- Replacing dense ring entanglement (depth 120, gate 276) with a linear CZ chain reduced depth (99 vs 120) and gate count (270 vs 276) while improving performance by ~0.01 in combined score (Gen13 0.86 vs Gen10/11 0.85).  
- Retaining the fixed two-qubit IsingZZ feature map across all top performers embedded 28 binary features without extra trainable overhead, preserving parameter budget for expressive variational layers.  

## Ineffective Approaches  
- Dense ring-CZ layouts (close_entangling_ring patches, Gen10 & Gen11) incurred depth 120/gate 276 yet plateaued at test 0.87 and parameter efficiency 0.01, offering no accuracy gain over linear chains.  
- Butterfly-style mixers with shared CRY entanglers (Gen2) reached only test 0.85—and despite slightly lower generalization gaps—failed to hit the 0.90 validation threshold, showing that more complex two-qubit patterns did not boost expressivity effectively.  
- Over-parameterized closed-ring CZ-RY layering (Gen5) delivered a low combined score of 0.77 (test 0.81) and a large generalization gap (0.11), confirming that adding entanglement density without structural focus degrades generalization.  
- Trimming parameter count alone (e.g., Gen2’s 134 vs 146 parameters) did not improve accuracy, highlighting that ansatz topology, not mere parameter reduction, governs performance.  

## Implementation Insights  
- Defining the ansatz via a reusable ANSATZ_SPEC list with explicit gate dictionaries and a key-to-position mapping streamlines variant exploration and guarantees correct parameter indexing, as in the current best program.  
- Utilizing qml.IsingZZ(FEATURE_SCALE·x) for fixed two-qubit feature encoding maps all 28 inputs without trainable parameters, isolating variational capacity in the ansatz.  
- Extracting circuit depth and gate count via a qml.queuing.AnnotatedQueue and QuantumScript metadata offers a reproducible way to correlate structural complexity with model performance across generations.  
- Initializing readout gain to 1 and bias to 0 before optimization (as in run_experiment) sets a stable baseline, contributing to faster convergence (≈390 steps) in the best‐performing program.  

## Performance Analysis  
- The best combined score rose from 0.85 (Gen0/Gen2/Gen11) to 0.86 (Gen13) when adopting the linear CZ-chain ansatz with three reuploads and two repeats, confirming a measurable +1 ppt gain without increasing parameter count.  
- Validation/test accuracies improved from 0.87 to 0.89/0.88 alongside a training accuracy of 0.94, yielding a moderate generalization gap (0.06)—the smallest among high-score models—underscoring the balance of expressivity and regularization in the linear-chain design.  
- Circuits with depth >120 uniformly underperform; reducing depth to ~99 operations in Gen13 correlated with the highest test accuracy, highlighting a negative correlation between excessive depth and generalization.  
- Parameter efficiency (test_accuracy / n_params) remains ~0.01 across all 146-parameter ansätze, indicating that further efficiency gains will likely stem from novel ansatz topologies rather than mere parameter tuning.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Expand local SU(2) expressivity around the linear‐CZ chain by replacing each qubit’s RY–RZ pre‐rotation pair with a full Euler block RZ(α)–RY(β)–RZ(γ).  To preserve the 146‐parameter budget, remove the post‐RY on every second qubit (e.g. qubits 1,3,5,7) in each block.  Evidence: richer single‐qubit gates around entanglers boost local expressivity without adding depth, building on Gen13’s success with interleaved RY/RZ layers.  

2. Introduce selective trainable entanglement by swapping one fixed CZ per block (e.g. the middle link on [(3,4)]) with a CRZ(θ) gate, dropping the corresponding post‐RY on qubit 3 to keep parameters constant.  This injects just one tunable two‐qubit coupling per block, leveraging data‐adaptive entanglement while maintaining the low‐depth linear chain that drove the +0.01 gain in Gen13.  

3. Rebalance feature uploads versus variational depth by setting N_UPLOADS=2 and N_REPEATS=3 (six total ansatz blocks).  This preserves overall circuit depth and gate count but concentrates more variational mixing between re‐uploads, testing whether deeper ansatz layers per feature upload outperforms the 3–2 split that yielded 0.86.  

4. Enrich entanglement diversity by cyclically shifting the linear CZ chain in each block: for block b use wires [(b mod 8, (b+1) mod 8), ((b+1) mod 8, (b+2) mod 8), …].  This keeps seven CZs per block and depth≈99 but rotates which qubit‐pairs interact over the full circuit, promoting more uniform mixing without extra gates.  

5. Tie parameters across repeats to free budget for per‐qubit calibration: reuse the same post‐RY parameter names in both repeats of each upload (halving unique post-rotation params), then use the 16 freed slots to implement per-qubit gains and biases (gain_i, bias_i for i=0…7), initialized at 1/0.  Evidence: parameter sharing regularizes the variational block and per-qubit calibration extends the proven stabilizing effect of global gain/bias in Gen13.
