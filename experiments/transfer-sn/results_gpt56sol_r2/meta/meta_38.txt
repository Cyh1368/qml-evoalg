# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- Full-graph CZ entanglement combined with a single, centrally placed CRZ phase gate delivers the top combined score (0.94) with minimal parameters  
  • Seen in Gen 43 “symmetric_complete_crz” and Gen 50 “phase_aligned_center”: train/val/test ≃ 0.96/0.96/0.95, generalization gap 0.02, N_PARAMS = 26, depth = 141, gate_count = 402.  
- Permutation-symmetric shared rotations before and after entanglement layers strongly regularize the model, concentrating expressivity into the CZ+CRZ block  
  • Both best programs use only four unique parameter keys per block (“ry_pre”, “rz_pre”, “crz_center”, “ry_post”) repeated over 3 uploads×2 repeats.  
- Three data-reuploads interleaved with exactly two variational blocks per upload consistently hit the sweet spot of expressivity vs. depth  
  • All 0.94-scoring designs settle at depth ≈ 141 and gate_count ≈ 402.  
- Trainable gain & bias calibration on the mean-Z readout accelerates convergence (~450 steps to validation accuracy ≥ 0.90) and adds ~0.01–0.02 to final test accuracy  

## Ineffective Approaches
- Swapping the central CRZ for a CRY (Gen 45 “shared_complete_graph_cry”) lowered the combined score to 0.93 and widened the gap to 0.03  
- Introducing extra adaptive two-qubit gates (Gen 48 “symmetric_crz_bridge”) increased N_PARAMS to 32 and depth/gate_count to 147/450 but only reached 0.93 combined, showing diminishing returns  
- Removing the trainable CRZ entirely (Gen 49 “symmetric_complete_graph_bridge”) dropped the combined score to 0.92 despite identical depth/gate_count, underlining the marginal expressivity gain from a single CRZ  

## Implementation Insights
- A declarative ANSATZ_SPEC with four parameter keys per block yields N_PARAMS_PER_BLOCK = 4, clean key-to-index mapping, and total N_PARAMS = 4×6 blocks+2 readout = 26, simplifying both specification and optimization  
- Shared “ry_pre”/“rz_pre” and “ry_post” keys across all qubits focus the trainable budget on the CZ+CRZ entanglement pattern, boosting parameter efficiency (0.04)  
- Validation of ANSATZ_SPEC via validate_ansatz_spec and dynamic key-lookup in apply_ansatz_block prevents spec-to-circuit mismatches and runtime errors  
- Leveraging Pennylane’s AnnotatedQueue for on-the-fly depth and gate_count extraction allows immediate resource-use feedback, essential for keeping circuits within near-term hardware limits  

## Performance Analysis
- Only the complete-graph CZ + central CRZ designs (Gen 43 & 50) achieve the 0.94 combined-score threshold at N_PARAMS = 26, depth = 141, gate_count = 402  
- Circuits with fewer parameters (e.g., previous Gen 33/35/38 at N_PARAMS = 20, depth = 135) also hit 0.94 combined but enjoy slightly better parameter efficiency (0.05 vs. 0.04) and a narrower generalization gap (≤ 0.01) when omitting CRZ  
- Increasing depth or parameter count beyond the 141-gate/26-param regime (e.g., Gen 48’s 147/32) fails to surpass 0.93 combined, demonstrating a plateau in expressivity gains  
- Structured full-graph entanglement layouts consistently cap generalization gap at ~0.02, whereas ad-hoc or SU2-heavy insertions correlate with gaps ≥ 0.05 and lower combined scores

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Insert a second CRZ on a high‐centrality edge in each block (for example between qubits [2,5]) but reuse the existing “crz_center” parameter key. Because the single centrally placed CRZ in the best program delivered a measurable expressivity boost with minimal cost, doubling its application on another key edge—without adding new parameters—tests whether richer two-qubit phase control can lift accuracy further.

2. Promote the fixed FEATURE_SCALE (π/2) to a single learnable scalar φ by replacing FEATURE_SCALE with a new circuit parameter “feature_scale” (initialized to π/2) in the feature_map. Prior runs (Gen25/27) showed that tuning embedding strength accelerates convergence by ~200 steps and adds ~0.01–0.02 test accuracy without increasing circuit depth or gate count.

3. Upgrade the readout calibration from a single global gain + bias to per-qubit affine corrections: introduce gain_0…gain_7 and bias_0…bias_7 applied to each ⟨Z⟩ before mean pooling. Although this adds 16 readout parameters, finer-grained calibration has been shown to tighten generalization gaps by capturing individual qubit biases, complementing the proven benefits of trainable readout in the current best program.

4. Tie the ansatz parameters across the two repeats within each upload so that each upload uses a single shared parameter block instead of two independent blocks. This four-key block sharing retains the full-graph CZ + CRZ expressivity at depth = 141 but halves the unique circuit parameters per upload from 8 to 4, freeing parameter budget that can be reinvested in, for example, additional shared CRZ insertions or learnable feature scales.

5. Diversify entanglement schedules across uploads by cycling CZ patterns: keep the full complete graph in uploads 1 and 3, but in upload 2 apply a structured skip-chain (edges [0,2],[1,3],…,[7,1]) using the same CZ gates. This “multi-tier” mixing preserves gate_count ≃ 402 and depth ≃ 141 while enriching qubit interaction patterns, leveraging pattern variation as a low-cost route to improved expressivity and generalization.
