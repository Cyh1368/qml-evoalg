<DESCRIPTION>
Add two adaptive controlled-phase bridges on complementary central edges while sharing one parameter key. The fixed complete CZ graph provides broad but rigid phase entanglement; the shared CRZ pair lets each re-upload block learn a coordinated phase correction and expands pairwise expressivity without sacrificing strong regularization. Sharing `crz_center` keeps the ansatz at only four parameters per block (26 total), while prior results indicate this structure can improve validation accuracy and L2 loss with no train-test gap.
</DESCRIPTION>
