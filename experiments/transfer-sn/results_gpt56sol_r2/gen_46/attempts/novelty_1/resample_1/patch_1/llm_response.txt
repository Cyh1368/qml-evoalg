<DESCRIPTION>
Replace the over-parameterized, wire-specific block with a permutation-regularized design aligned with the complete pairwise feature map and mean-Z readout. Shared local parameters reduce the model from 98 to 26 total parameters, while an added shared RZ layer provides phase control. Complete-graph CZ entanglement exposes every encoded feature pair to variational mixing, and one trainable CRZ interaction adds controlled phase flexibility without materially increasing complexity. This structure is expected to improve validation accuracy and L2 loss while reducing overfitting.
</DESCRIPTION>
