<DESCRIPTION>
This edit replaces the current heavily shared, CNOT-mixed block with a cleaner phase-preserving entangler layout.

Why this should help:
- The fixed feature map is already built from ZZ phase couplings, so a CZ-based ansatz is a better inductive match than adding basis-changing CNOTs.
- Using unique RY, RZ-pre, and RZ-post parameters on all 8 qubits increases expressiveness from the current underfit regime while still keeping the block compact.
- Replacing the cross CNOTs with cross CZs keeps the circuit more commuting-friendly and usually lowers effective depth/optimization noise.
- The new block reduces gate count per repeat while increasing useful parameter capacity, which should improve validation/test accuracy and reduce the train-test gap.
</DESCRIPTION>
