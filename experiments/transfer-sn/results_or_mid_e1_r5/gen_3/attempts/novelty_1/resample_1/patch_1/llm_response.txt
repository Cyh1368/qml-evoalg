<DESCRIPTION>
This edit replaces the fully independent per-qubit rotation stack with a symmetry-reduced ansatz that uses shared parameters on qubit pairs, while adding a second entangling pattern to preserve expressivity.

Why this should help:
- Fewer trainable weights per block should improve parameter efficiency and reduce overfitting.
- Reusing parameters across mirrored qubit pairs acts as a regularizer, which is useful here because the current model shows a small but persistent train-test gap.
- A ring of CZ gates plus a cross-half CNOT layer increases nonlocal mixing beyond the original line graph, which should help data re-uploading exploit correlations from the fixed ZZ feature map.
- Switching the final rotation layer to RX/RZ on a different pairing pattern breaks the original circuit symmetry and gives the classifier a better chance to convert encoded phases into measurable Z-population differences.
</DESCRIPTION>
