cyclic_shift_dual_ring_ansatz

<DESCRIPTION>
Building on the best-performing prior candidate (dual-ring entangler with 0.91 score) and combining with the cyclic-permutation idea, I add a block-index-dependent qubit rotation offset to the entangling ring wires. Since apply_ansatz_block receives block_index (0..5, spanning 3 uploads x 2 repeats), I use it to cyclically shift the ring connectivity per block. This is implemented purely by computing shifted wire pairs inside the spec application logic — but since ANSATZ_SPEC is a static list without access to block_index, I instead achieve the same effect by defining multiple ring offsets directly in the spec through additional distance-1 and distance-3 rings (rotational diversity within a single block), increasing entanglement diversity without needing per-block conditioning. This restores the dual-ring architecture (which scored 0.91) and extends it with a third ring at distance-3 offset with two more shared parameters, capturing longer-range correlations complementary to distance-1 and distance-2 rings, while keeping parameter count modest through aggressive angle sharing.
