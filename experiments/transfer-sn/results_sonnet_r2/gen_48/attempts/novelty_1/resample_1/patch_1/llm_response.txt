per_pair_readout_calibration

<DESCRIPTION>
The current readout uses a single global gain/bias applied to the mean of all 8 qubit Z expectations. This discards potentially useful information about how different qubit groups (paired by the ansatz's shared-parameter structure) contribute to the classification signal. I propose upgrading the readout to use per-pair gain and bias: instead of averaging all 8 qubits into one scalar then applying one gain/bias, we first average each of the 4 qubit-pairs (0,1),(2,3),(4,5),(6,7) separately (matching the shared-parameter grouping already used throughout the ansatz), apply an independent gain/bias to each pair's mean, then average the 4 calibrated values into the final prediction. This adds 6 extra readout parameters (going from 2 to 8: gain_u0..gain_u3, bias_u0..bias_u3), letting the model learn different scaling/offset corrections for each qubit-pair channel — which should better match the block-diagonal structure induced by the shared angles in the ansatz (ry_p0..p3, rz_pre_p0..p3, etc.), improving calibration fidelity and thus accuracy/loss without touching the core entangling structure.

def predict_batch(params, x_batch: np.ndarray):
    """Scalar prediction per record: per-pair calibrated mean of qubit Z expectations."""
    circuit_params = params[:N_CIRCUIT_PARAMS]
    gains = params[N_CIRCUIT_PARAMS : N_CIRCUIT_PARAMS + 4]
    biases = params[N_CIRCUIT_PARAMS + 4 : N_CIRCUIT_PARAMS + 8]
    records = pnp.array(np.asarray(x_batch, dtype=float), requires_grad=False)
    z = pnp.stack(circuit_z_expectations(records, circuit_params))  # (N_QUBITS, B)
    pair_means = pnp.stack([
        pnp.mean(z[0:2], axis=0),
        pnp.mean(z[2:4], axis=0),
        pnp.mean(z[4:6], axis=0),
        pnp.mean(z[6:8], axis=0),
    ])  # (4, B)
    calibrated = pnp.stack([
        gains[i] * (pair_means[i] - biases[i]) for i in range(4)
    ])  # (4, B)
    return pnp.mean(calibrated, axis=0)
