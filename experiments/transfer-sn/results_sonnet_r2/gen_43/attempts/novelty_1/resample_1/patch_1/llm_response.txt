per_upload_crz_specialization

<DESCRIPTION>
Specialize the long-range (distance-2) CRZ coupling angles per data re-upload cycle by making the block index visible to the ansatz's parameter key generation for those specific gates. Since the fixed training loop calls `apply_ansatz_block(circuit_params, block_index)` with `block_index = upload_index * N_REPEATS + repeat_index`, and each upload's two repeats (blocks 0-1, 2-3, 4-5) currently share entangling structure but already have independent parameter copies per block (since `N_CIRCUIT_PARAMS = N_PARAMS_PER_BLOCK * N_UPLOADS * N_REPEATS` and parameters are offset by `block_index * N_PARAMS_PER_BLOCK`), the existing per-block independence already differentiates blocks. However all blocks currently use the *same* ANSATZ_SPEC structure with generic key names, so the pattern of sharing (crz_a/b/c/d) is identical across blocks — only the numeric values differ after training. This edit doesn't change that mechanism (which is already true), but instead increases expressivity for the distance-2 ring specifically by giving it 4 independent angles per block instead of the shared alternating 2 (crz_c/crz_d applied 4 times each), while keeping the distance-1 ring shared for parameter efficiency. This targeted increase (adding 2 more distinct parameter names for the second half of the distance-2 ring) tests whether relaxing the crz_c/crz_d symmetry within a single block (not across uploads, since that's already independent) improves fit without exploding parameter count, moving from 98 to 102 total parameters.
