<DESCRIPTION>
Since only the ANSATZ_SPEC block can be edited, I focus improvements there. The current spec uses a ring of CRZ gates plus a single RZ layer. To improve expressivity and mixing while keeping parameter count reasonable, I add an RX layer before the RY layer (giving each qubit a full single-qubit rotation basis RX-RY before entangling), keep the CRZ ring for entanglement, and add a second ring of CRX gates on alternating pairs (skip-1 connectivity) to increase entanglement structure and help the model capture higher-order feature interactions, followed by the final RZ layer. This is inspired by hardware-efficient ansatz designs that alternate rotation gates with different entangling generators (ZZ-like CRZ and XX-like CRX) to enrich the accessible unitary group, which should help reduce the train/test gap and improve validation accuracy without excessive depth increase.
