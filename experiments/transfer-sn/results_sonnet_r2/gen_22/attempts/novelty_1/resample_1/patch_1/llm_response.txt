sparse_end_to_end_cz_odd_blocks

<DESCRIPTION>
The current best-performing candidate (score 0.85) uses a simple linear CZ chain with a final wraparound CZ(7,0)/CZ(0,7) closing the ring every block. The reversed-direction variant with CRZ scored slightly lower (0.84) with a higher generalization gap trend under-fitting. Building on the higher-scoring linear-chain topology (first prior program, score 0.85), I add a periodic long-range CZ link only in odd-indexed blocks (block_index % 2 == 1), which happens for half of the 6 total blocks (3 uploads x 2 repeats). This introduces sparse global connectivity that alternates with purely local chain connectivity, allowing the network to build up local correlations first (block 0 of each upload, even index) then integrate long-range correlations (block 1 of each upload, odd index) without adding any new trainable parameters. This should help capture cross-feature interactions between distant qubits (e.g., qubit 0 and 7 pairs that are otherwise only 1 hop apart via the existing ring closure) while keeping the low overfitting behavior of the CZ-only backbone. Since apply_ansatz_block already receives block_index, I can conditionally add the extra CZ gate directly in that function without modifying ANSATZ_SPEC's declarative structure, keeping the diff minimal and safe.
