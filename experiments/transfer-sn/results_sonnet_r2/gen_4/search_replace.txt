add_ring_entanglement_and_crz_couplings

<DESCRIPTION>
The current ansatz block uses only a linear chain of fixed CZ gates plus RY/RZ rotations, which limits the entangling power and expressivity per block (146 params, ~0.87 test accuracy with a 0.07 train-test gap). I propose:

1. Close the entangling chain into a ring by adding a CZ(7,0) gate, giving full-loop connectivity instead of a linear chain — this improves information mixing across all qubits with no additional parameters.
2. Replace the fixed CZ entangling layer with parametrized CRZ gates that share parameters in a structured way (each CRZ parameter tied to a neighbor pair), which adds trainable entangling strength without exploding the parameter count. This gives the ansatz the ability to learn how strongly qubits should be entangled at each block/upload, which should improve accuracy and reduce generalization gap since the model can adapt entanglement strength to the data rather than using a fixed maximal entangler.
3. Keep the same RY+RZ single-qubit structure for consistency, but move an RY layer after the entangling layer too (sandwich structure) to give the block more capacity to rotate into the eigenbasis it needs after entanglement.

This adds 8 more parameters (one per CRZ gate) per block, totaling 154 params overall (28 params/block × 6 blocks + 2 readout), well within reasonable limits, and should improve expressivity while maintaining reasonable depth.
