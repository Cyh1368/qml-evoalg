crx_extra_entangling_layer

<DESCRIPTION>
Since only the ANSATZ_SPEC block is editable, I focus the improvement there. The current spec has a single ring of CRZ/CZ entanglers. To increase expressivity while keeping parameter count modest, I add a second entangling ring using CRX gates on the "odd" pairing offset by one qubit, which creates a richer entanglement pattern (two different rotation axes across two different connectivity patterns) without significantly increasing depth. This should help the model separate classes better, potentially improving validation/test accuracy and reducing the train-test gap by giving the ansatz better expressiveness within the same block-repetition budget.
