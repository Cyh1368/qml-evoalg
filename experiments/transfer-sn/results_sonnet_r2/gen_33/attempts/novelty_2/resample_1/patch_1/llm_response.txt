<DESCRIPTION>
The current ANSATZ_SPEC uses global "crz_a"/"crz_b" keys for the entangling ring, meaning the ring-entanglement strengths are shared across all 3 uploads (since parameter sharing only happens within a block, but the ring pattern is structurally identical across uploads with independently-trained per-block params already - wait, actually since block_index provides an offset, each upload*repeat already gets independent copies). Looking more carefully, the current train/test gap (0.12) suggests overfitting with 158 params. To reduce the gap while keeping expressivity, I propose sharing the pre/post RZ rotations within adjacent pairs (reducing single-qubit rotation redundancy) similar to the first seed's compression strategy, cutting parameter count and helping generalization. This combines the higher-capacity CRZ ring structure (crz_a/crz_b alternating) with the parameter-efficient paired RZ compression from the best-generalizing seed, aiming to keep strong training accuracy while narrowing the generalization gap and improving test performance beyond the current 0.86.
