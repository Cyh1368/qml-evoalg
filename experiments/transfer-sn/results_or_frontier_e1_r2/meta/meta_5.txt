# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Extensive single-qubit rotations interleaved with pre- and post-RZ layers drove the top score.  
  - The current best program (“8-Qubit Variational Binary Classifier”) uses per-qubit RY plus pre/post-RZ around a linear CZ chain in each of six blocks and achieves combined_score_raw = 0.85 (test = 0.87).  
  - By contrast, simpler RY–RZ blocks alone (“8-Qubit Repeating RY-RZ Ansatz Classifier”) only reached 0.65, showing the benefit of richer single-qubit phase structure.  
- Multiple data re-uploads enhanced expressivity without exacerbating over-fitting.  
  - Both the best program (3 uploads × 2 repeats) and the 0.83‐scorer (“8-Qubit Re-Uploading Ansatz Classifier”) used three IsingZZ feature‐map uploads and saw train accuracies ≥ 0.93 with generalization gaps of 0.07–0.10.  
  - Programs with a single upload or fewer rotations plateaued on validation (e.g., 0.65 score, gap = 0.12).  
- Linear nearest-neighbor CZ entanglement provided sufficient qubit coupling with controlled depth.  
  - The best design’s linear CZ chain (7 CZs per block) achieved depth = 99 and gate_count = 270 while maintaining a generalization gap of only 0.07.  
  - More complex brickwork or long-range schemes (“8-Qubit Brickwork Reupload Classifier”, score = 0.76) added gates (depth = 93, 300 gates) without commensurate accuracy gains.  
- Trainable gain/bias readout stabilized calibration.  
  - All top programs included two readout parameters and used mean Z expectation; this consistency likely aided convergence to test accuracies ≥ 0.82 across variants.  

## Ineffective Approaches  
- Overly sparse entanglement or missing phase diversity limited expressivity.  
  - The pure RY–RZ–CNOT ansatz (“8-Qubit RY-CNOT Ansatz Binary Classifier”) plateaued at combined_score_raw = 0.65, showing that single-axis rotations and CNOT alone were insufficient.  
- Brickwork patterns with fixed two-axis layers introduced too many gates for modest gains.  
  - The brickwork reupload circuit (300 gates, 146 params) achieved only 0.76, indicating that parameter-heavy entanglement patterns can hurt parameter efficiency (0.01) without boosting accuracy.  
- Flat ansatz repeats without pre/post RZ splits increased over-parameterization.  
  - Programs that stacked RY+RZ blocks twice per upload but omitted additional phase layers suffered generalization gaps of 0.12 (test = 0.68 vs train = 0.80).  

## Implementation Insights  
- Parameter-ordering via a fixed `PARAMETER_KEYS_PER_BLOCK` map simplifies block indexing and supports easy Evolve-Block mutations.  
  - The best program defines 24 param keys/block (8 RY + 16 RZ) in a clear pre→CZ→post layout, yielding N_PARAMS_PER_BLOCK = 24×1 + 0 = 24 and N_PARAMS = 146.  
- Using `qml.IsingZZ` feature maps with FEATURE_SCALE = π/2 across three uploads yields rich non-linear embeddings.  
  - All high-scoring designs used this pattern; the best combined it with heavy single-qubit phase rotations to fully exploit the encoded features.  
- Early stopping on validation loss with best-weight restoration reliably controlled over-fitting.  
  - The best program’s training loop uses patience = 75, min_delta = 1e-4; convergence at step = 750 and an eventual stop reason “early_stopping” or “max_epochs” produced stable test accuracy of 0.87.  
- Linear CZ connectivity minimizes unnecessary two-qubit gates while enabling global state correlations.  
  - The best design’s CZ chain per block (wires [0–1], [1–2],…, [6–7]) strikes a balance between entangling power and circuit depth (99), outperforming both sparse CNOT-only and dense brickwork patterns.  

## Performance Analysis  
- Score progression tracks ansatz complexity and phase-layer richness:  
  - Basic RY-RZ repeats → combined_score_raw = 0.65 (depth = 81, gap = 0.12)  
  - Brickwork entanglement adds complexity → 0.76 (depth = 93, gap = 0.07)  
  - Full six-block RY+pre/post-RZ + linear CZ → 0.85 (depth = 99, gap = 0.07)  
- Generalization gaps narrow as pre/post phase layers are introduced:  
  - Removing pre/post RZ raises gap to 0.12; including them reduces gap to 0.07 without hurting depth substantially.  
- Parameter efficiency remains low (~0.01) across deep ansätze, indicating diminishing returns per parameter.  
  - Even the best program with 146 learnable params yields just 0.87 test accuracy; this underscores the importance of structural choices (phase layers + entanglement) over mere parameter count.  
- Convergence speed correlates with ansatz expressivity:  
  - The best design hit convergence around global_step = 750, while heavier brickwork designs needed similar or more steps for lower accuracy, highlighting efficient learning in the six-block phase-CZ pattern.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Replace a subset of fixed CZ gates with parameterized CRZ rotations in each ansatz block. For example, mutate every third CZ in the linear chain to a CRZ with its own trainable angle. This leverages the success of phase-rich single-qubit layers by extending tunability to two-qubit interactions without dramatically increasing depth.

2. Experiment with increasing the number of data re-uploads to N_UPLOADS=4 while reducing N_REPEATS per upload from 2 to 1 (total still six blocks). Prior results show three uploads boost expressivity; shifting to four smaller blocks may pack more non-linear embeddings into the circuit at similar overall depth.

3. Augment the current pre-RZ layer with an additional RX layer on all qubits (i.e., RX→RZ_pre→CZ chain→RZ_post). Adding a different rotation axis before phase encoding builds on the beneficial phase diversity of pre/post-RZ and can enrich the local state space.

4. Introduce sparse long-range CZ couplings every two blocks—for instance, add CZ(wires=[0,4]) and CZ(wires=[3,7]) after block 2 and block 4. Global insights suggest linear NN entanglement is sufficient, but occasional long-range links could capture higher-order correlations with minimal gate overhead.

5. Alternate entangling direction across blocks by reversing the linear CZ chain in odd-numbered blocks (i.e., [7–6], [6–5], … [1–0]). This simple topology mutation maintains gate count and depth while diversifying the entanglement pattern, potentially improving parameter efficiency.
