# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Dense CZ entanglement with minimal trainable rotations drove the top score. The 8-Qubit Repeated CZ-RX-RY Classifier (Gen 11, “collective_cz_mixer”) uses a global RX layer, a dense all-to-all CZ block, then a global RY layer in each repeat (14 params total) to achieve combined_score_raw = 0.95, test ≈ 0.97, and gap = 0.01.  
- Shared, coarse-grained single-qubit parameters (one “global_rx” and one “global_ry” per block) yield high expressivity per parameter. By contrast, per-wire parameters increased count without proportional accuracy gains (e.g., Three-Layer 8-Qubit classifier’s 194 params for raw 0.73).  
- Three re-upload stages × two repeats interleaving feature maps and ansatz blocks consistently boosts nonlinearity. Both the current best (0.95) and Hypercube-Structured classifier (Gen 12, raw 0.91) exploit 3×2 layouts to stabilize learning.  
- Eliminating parametric two-qubit gates in favor of fixed CZs simplifies gradients and reduces overhead, maintaining robustness (generalization gap ≈ 0.01) while avoiding the extra parameters of CRX/CRY/CRZ blocks.  

## Ineffective Approaches  
- Over-deep, over-entangled brickwork hindered efficiency: the Three-Layer 8-Qubit Quantum Classifier used 348 two-qubit gates and depth 132 for raw 0.73 and efficiency ≈ 0.005, showing unstructured entanglement leads to redundancy.  
- Sparse, loosely connected CNOT layouts with tied phases (e.g., 8-Qubit sparse_multiscale_decoder, raw 0.88, eff 0.03) limited expressivity and failed to match denser CZ designs despite comparable depth.  
- Hypercube partitions with per-wire rotations but without coarse parameter tying (Gen 14, 50 params) reached only test 0.90 (raw 0.88) and eff 0.02—illustrating that added phase layers must be balanced by parameter reuse.  
- Pure global rotations without trainable entanglers plateaued at ~0.87 accuracy (low depth 65), confirming two-qubit couplings aligned to data-upload maps are essential for top performance.  

## Implementation Insights  
- Key-to-position mapping of a small set of parameters (“global_rx”, “global_ry”) per block allows reusing the same angles across all qubits, slashing N_PARAMS from ∼50→14 in the best model.  
- Specifying dense CZ entanglers as a single block of wire pairs simplifies ANSATZ_SPEC and avoids custom loops for cross-CNOTs, reducing code complexity while retaining full connectivity.  
- A uniform apply_ansatz_block abstraction in a for-loop over (upload, repeat) decouples gate sequencing from parameter management, facilitating rapid prototyping of new patterns.  
- Omitting parametric two-qubit gates (CRX/CRY/CRZ) in favor of fewer, unparametrized CZs cuts gradient computation overhead, speeding convergence (convergence_step ≈ 120 vs. ≈540 for hypercube).  

## Performance Analysis  
- The Gen 11 classifier’s combined_score_raw = 0.95 outperforms the previous hypercube best (Gen 12 raw 0.91) by +0.04 and the deep brick model by +0.22, establishing dense CZ+global mixers as a superior pattern.  
- Parameter efficiency peaks at 0.07 for the best model—over three times the hypercube’s efficiency (~0.02), demonstrating that careful parameter tying can outrank raw parameter count.  
- Depth (111) and gate count (348) for the top model are similar to less effective designs (e.g., three-layer brick), showing that structured entanglement, not minimal depth, governs expressivity.  
- All top CZ-based designs share tiny generalization gaps (0.01–0.02), whereas unstructured or under-entangled circuits show larger gaps (0.05–0.07), underlining the overfitting mitigation from problem-inspired entanglement geometry.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Insert a global RZ mixer after the existing global RY in each ansatz block. In the ANSATZ_SPEC, append for every wire an RZ with a single new parameter key (e.g. “global_rz”), so each block has RX→CZ→RY→RZ. This adds only one extra parameter per block, leverages coarse-grained tying, and enriches axis mixing without blowing up N_PARAMS.

2. Replace a small, fixed subset of CZs in the dense entangler block with trainable CRZs—e.g. swap CZ([0,1]), CZ([2,3]), CZ([4,5]), CZ([6,7]) for CRZ gates parameterized by one “crz” per block. This introduces fine-grained two-qubit phase flexibility grounded in the success of phase-rich couplings, while limiting the parameter overhead to just one extra angle per block.

3. Make the FEATURE_SCALE in the IsingZZ data upload trainable per upload stage: replace the constant π/2 with three new parameters scale_0, scale_1, scale_2 used in the first, second, and third feature_map calls. This lets the circuit learn the optimal embedding strength at each re-upload, building on reported gains from adaptive feature scaling.

4. Experiment with three repeats per upload (N_REPEATS = 3) while reusing the same global_rx/global_ry parameters across all repeats. The current 3×2 layout’s stability suggests a 3×3 design could further boost nonlinearity; shared parameters keep N_PARAMS_per_block unchanged, preserving efficiency.

5. After every second ansatz block, insert two fixed long-range CZ edges—e.g. CZ(wires=[0,4]) and CZ(wires=[1,5]). These occasional shortcuts capture higher-order correlations beyond the core all-to-all entangler, adding no new parameters or trainable gates but complementing the existing dense geometry.
