<DESCRIPTION>
This edit replaces the current purely local RX/RY + CZ pattern with a mirrored hybrid block that is better matched to the fixed phase-encoding data map.

Key ideas:
- Keep the circuit parameter budget moderate by using mirrored parameter sharing across qubits 0↔4, 1↔5, 2↔6, 3↔7.
- Add long-range CRY couplings to turn the fixed IsingZZ feature phases into trainable amplitude interactions, which usually improves optimization on Z-readout classifiers.
- Retain a CZ ring backbone for stable entanglement and avoid overfitting through excessive depth.
- Use a final RX layer to ensure the learned phases are converted into measurable Z-basis signal.

Overall, this should improve convergence speed and validation/test performance while preserving parameter efficiency.
</DESCRIPTION>
