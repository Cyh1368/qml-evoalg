<DESCRIPTION>
This edit cuts the circuit parameter count sharply while keeping the classifier expressive enough for the re-uploading schedule.

Key ideas:
- Use shared even/odd parameters for RX and RY layers, which reduces the per-block trainable degrees of freedom from the current pairwise scheme.
- Keep a full CZ ring for local propagation.
- Add a long-range CZ cross pattern to improve global mixing across the 8-qubit register.

This should improve combined score by lowering model size and depth pressure without removing the entangling structure needed for the binary feature task.
</DESCRIPTION>
