# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Re-uploading interleaved with minimal rotation–entanglement blocks achieves top score (0.85):  
  • Current Best (“Seed”/Gen 0 spec, also 8-Qubit Feature-Reupload Ansatz, Gen 7) uses 3 feature-map uploads × 2 repeats of an RY→pre-RZ→CZ-chain→post-RZ block (24 params/block), depth 99, 270 gates → combined_score_raw 0.85 (train 94%, test 87%).  
- Linear CZ chain with two-stage single-qubit rotations provides high expressivity per parameter:  
  • No need for RX layers or parameterized two-qubit gates—models with only RY+RZ+CZ match or beat more complex blocks while staying under 100 depth.  
- Fixed IsingZZ feature map + trainable gain/bias readout ensures stable convergence:  
  • All top performers (Gen 0, Gen 7) embed FEATURE_SCALE·IsingZZ encodings and two readout params, yielding consistent calibration and rapid convergence by step 750 on average.  

## Ineffective Approaches  
- Over-parameterized or symmetry-tied ansätze increased depth/gates without score gain:  
  • Mirror-Symmetric Ansatz (Gen 5) tied mirrored RY/RZ, added local/global mixers → depth 105, 372 gates → combined 0.78, generalization gap 0.10.  
- Circular/CNOT ring entanglement under-performed:  
  • Repeating Ring Ansatz (Gen 6) with CNOT rings and 146 params → depth 99, 324 gates → combined 0.67, gap 0.12.  
- Parameterized two-qubit gates (CRX/CRY/CRZ) and skip-layer bridges added overhead:  
  • Enhanced Entanglement (Gen 2) using CRZ saw depth 126, 300 gates → combined 0.81;  
  • Symmetric Skip CRZ Block (Gen 10) depth 111, gates 270 → combined 0.80.  

## Implementation Insights  
- Spec-driven ansatz definition decouples design and indexing:  
  • `validate_ansatz_spec` extracts a stable ordered `PARAMETER_KEYS_PER_BLOCK`, enabling clean offset-based parameter lookup in `apply_ansatz_block`.  
- AnnotatedQueue + `tape.graph.get_depth()` yields accurate depth/gate counts reflecting actual QNode execution.  
- Autograd-enabled Pennylane QNode with Adam+early stopping and best-weights restore ensures robust training across architectures.  
- The current best’s concise ANSATZ_SPEC (24 params/block) balances expressivity and resource cost, yielding the highest combined score at minimal depth.  

## Performance Analysis  
- Depth vs. combined_score_raw shows a strong inverse trend:  
  • Depth 99 → score 0.85 (current best) vs. depths 111–132 → scores 0.79–0.81.  
- Gate count beyond ~300 offers no net gain:  
  • Best models cluster at ~270 gates; raising to 300+ (Gen 2, Gen 5) lowered or matched lower scores.  
- Moderate generalization gap (~0.07) aligns with top performance:  
  • Current best gap 0.07 vs. lowest gap 0.04 (Gen 8) didn’t translate to top combined score.  
- Parameter efficiency remains uniformly low (~0.01); optimizing depth/gates per parameter is key to further gains.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Implement intra-upload weight tying for rotation layers. Modify the ANSATZ_SPEC and parameter‐indexing so that within each feature‐reupload, the two repeated RY→RZ–CZ–RZ blocks share the same set of single‐qubit angles. This halves the unique circuit parameters (from 146 to ~74) while preserving the successful block structure, and should boost parameter efficiency without increasing depth.  

2. Add sparse next‐nearest‐neighbor CZ gates on alternating blocks. Following the linear nearest‐neighbor CZ chain, append CZ(a, a+2) for even a on every other ansatz block (e.g. block_index % 2 == 1). This injects longer‐range entanglement seen in the “sparse coupling” recommendation with minimal gate overhead (~4 extra CZs per block) and may capture higher‐order feature correlations.  

3. Experiment with an extra feature‐map upload (N_UPLOADS=4) while keeping two repeats per upload. Based on the strong expressivity per parameter in the 3×2 layout, a 4×2 configuration should enrich nonlinearity for only ~50 additional gates. Track combined_score_raw vs. depth/gate_count to find whether this deeper reuploading outperforms the 3×2 baseline.  

4. Alternate CZ‐chain direction between blocks. Define two entangler patterns—one wiring qubits [0→1→…→7] and the reverse [7→6→…→0]—and apply them on odd vs. even block_index. This bidirectional mixing enhances information propagation across the line topology without adding gates, leveraging the success of linear CZ chains in boosting expressivity.  

5. Group per‐qubit phase rotations into half‐register shared parameters. Replace the eight independent rz_pre_i (and likewise rz_post_i) with two shared rz_pre_{0–3}, rz_pre_{4–7} (and rz_post_{0–3}, rz_post_{4–7}), cutting four parameters per layer. This tests whether coarse global phase shifts maintain the current block’s expressivity while raising parameter efficiency, in line with insights that expressivity arises from entanglement structure rather than per‐qubit phases.
