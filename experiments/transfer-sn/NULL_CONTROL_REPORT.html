Negative control · Sn transfer task

Does the discovery criterion survive a task with nothing to discover?

Three frontier-ensemble runs on a dataset built to have no permutation symmetry, testing whether the structural criterion in VALIDATION_CRITERIA.md correctly returns “nothing here” instead of manufacturing agreement.

Runs 3 × 15 generations Jobs 22546135–37 Completed 2026-08-18 Ensemble gpt-5.6-sol · opus-4.6 · gemini-3.1-pro
Result against the pre-registered readout

0 of 3 null runs produced a fully tied parameter family, against 3 of 3 on the real task. That falls in the branch the launch script pre-registered as “the criterion discriminates.”

Fisher exact on 3/3 versus 0/3 gives p = 0.10, which the pre-registration itself labelled suggestive rather than significant. The result is consistent with the hypothesis and is not on its own strong evidence for it.

00

Definitions

Every term used later in this page is defined here. Nothing below introduces new vocabulary.

The task

Ansatz
A fixed template of quantum gates with adjustable rotation angles. Training fits the angles; evolution changes the template itself.
Qubit / wire
One of the 8 quantum bits in the circuit. “Wire” is the horizontal line each qubit traces in a circuit diagram. Used interchangeably here.
ANSATZ_SPEC
The only part of the program the evolution loop is allowed to edit: a list of gate entries, each naming a gate type, the wire(s) it acts on, and (for rotations) the name of the parameter driving it.
Single-qubit rotationRX, RY, RZ
A gate that rotates one qubit by a trainable angle about the x, y, or z axis.
Two-qubit gateCZ, CNOT, CRX/CRY/CRZ
A gate acting on a pair of qubits, entangling them. The CR-prefixed forms carry a trainable angle; CZ and CNOT do not.
Parameter
One trainable angle, referenced by name. Two gates written with the same parameter name are driven by a single shared number.
Seed program
The starting circuit every run begins from, identical across all runs and both conditions. It has 24 distinct parameters per block and 146 trainable parameters in total.

The symmetry

S8 permutation symmetry
The group of all 8! relabellings of the 8 vertices. A rule is invariant under S8 if renaming the vertices never changes its answer.
Real tasklabel rule
Label = +1 if and only if the graph is connected. Connectivity does not care what the vertices are called, so this rule is S8-invariant.
Null tasklabel rule
Label = +1 if and only if deg(v*) ≥ 2, the degree of one fixed vertex. Relabelling moves v*, so this rule is not S8-invariant. The best circuit here must single out one qubit, which is the opposite of tying parameters together.
Parameter tying
Reusing one parameter name across several gates so they share a single angle. This is how a circuit expresses “these wires are interchangeable.”
Fully tied familythe motif
One parameter driving the same single-qubit rotation on all 8 wires. This is the structural fingerprint of S8 invariance and the thing the criterion looks for. Counted by symmetry_analysis.py as fully_tied_single_families.
Equivariance
The behavioural version of the same idea: permute the inputs, and the model’s output is unchanged. Measurable directly, with no fingerprint to choose. Not run for this report; every structural claim here is structural only.

The search

ShinkaEvolve
The evolutionary loop under test. Each generation it asks language models to propose an edited program, evaluates the result, and keeps a population of the survivors.
Generation
One propose-and-evaluate cycle. These runs were given 15 generations each.
Proposal / program
One candidate circuit produced by a model in one generation, together with the model’s own patch name and description of what it changed.
Ensemble / arm
The set of models allowed to propose. Frontier is gpt-5.6-sol + opus-4.6 + gemini-3.1-pro; mid and weak are cheaper sets used in earlier experiments.
Run / replicate
One complete execution of the loop. Replicates here use byte-identical configs; all variation is the pipeline’s own nondeterminism.
Orchestrator / eval job
The orchestrator is the long-lived cluster job driving the loop; it launches a separate short eval job per candidate to train and score it.

The measurements

Raw combined scorecombined_score_raw
A weighted blend of validation accuracy, train accuracy, generalization gap, loss, parameter efficiency, and convergence speed. Bounded above by 1.0.
Rescaled scorethe displayed number
The raw score mapped through a fixed affine transform so that 0.0 = the real task’s seed (raw 0.8546) and 1.0 = the best symmetric solution ever found on the real task (raw 0.9483). These two anchors are hardcoded and were not re-measured for the null task, which is why null numbers exceed 1.0.
Motif recurrence, across runscriterion 5
How many independent runs have the motif in their best program. Rated WORKS in VALIDATION_CRITERIA.md and the pre-registered readout for this experiment.
Motif recurrence, within a runcriterion 6
What fraction of all proposals in a single run contain the motif. Also rated WORKS; the cheapest signal, since it needs only one run.
Parameter-count collapsecriterion 8
Whether the best program uses far fewer distinct parameters than the seed’s 24. Rated only PARTIAL: good precision, but it misses true positives, so it is a screen and not the test.
Say-versus-buildcriterion 2
Whether a proposal that uses symmetry language in its patch notes actually builds a tied family. Rated FAILS as a criterion: on the real task mid-tier models say it as often as frontier models and build it far less.
Linear probe
Least-squares fit of the label directly from the 28 raw input features, with no circuit. A high score means the task is nearly solvable without any quantum structure at all.
Ceiling effect
When the starting point already scores near the maximum, leaving little room for improvement, so gains compress and are hard to compare across tasks.
Fisher exact test
A significance test for small 2×2 count tables. Reported here for 3/3 versus 0/3.
01

What was hypothesized, before any results

The broader programme asks whether ShinkaEvolve can be turned into a benchmark for scientific discovery, and whether a researcher with no answer key could tell a genuine discovery from a confabulated one. VALIDATION_CRITERIA.md tested nine candidate criteria against 18 runs on a task that does contain a symmetry, and found that the reliable signals were all recurrence measures: the motif showing up across independent runs (3/3 frontier, 1/5 mid, 2/10 weak) and repeatedly within a single run.

That leaves an obvious hole, stated in make_dataset_null.py: every test so far was on a task that has the structure. A criterion that fires on a symmetric task and also fires when there is no symmetry is detecting “frontier models like tying parameters,” not “the problem has a symmetry.” This experiment is the missing negative control.

The design holds everything constant except the one thing under test. Inputs are distributionally identical between conditions: same 8 vertices, same 28 adjacency bits, same scrambled qubit relabelling, same edge-density sampling, same random seed and call sequence, so the feature-pair table matches the real dataset exactly. I verified this independently: feature_pairs is byte-identical across the two files. Only the label rule changes, from connectivity to deg(v*) ≥ 2.

The pre-registered decision rule

Recorded in transfer-sn/launch_null.sh before the runs were submitted, in terms of how many of the three runs end with the motif in their best program:

3/3 or 2/3

The criterion false-positives. It fires with no symmetry present, so it is measuring a model habit rather than a property of the problem, and the hypothesis fails.

0/3 or 1/3

The criterion discriminates. Explicitly annotated in advance with “Fisher p = 0.10 at n = 3, so suggestive rather than significant.” ← this branch fired

Two design choices matter for reading the results. The readout is the structural motif rate, never the score, so score comparisons across conditions were never part of the test. And the budget was set at 15 generations on the stated grounds that the frontier signal saturates by generation 9–14 on the real task.

03

Interpretation

The primary readout matches the hypothesis

The criterion returned “nothing here.” Zero of three null runs ended with a fully tied family, against three of three on the real task, and the separation is categorical rather than marginal: null best programs carry 16, 24, and 20 distinct parameters, essentially the seed’s 24, while real best programs collapse to 4, 2, and 5. The criterion is not simply detecting a frontier-model habit of tying parameters.

This is what the null task’s design predicts. Because the label depends on one distinguished vertex, the optimal circuit must single out a qubit, so tying all eight wires together is not merely unhelpful, it is the wrong shape. The search behaved accordingly.

The 15-generation budget is not what produced the null

The obvious objection is that the null runs simply had less time: 15 generations against 20 and 50. The data answers it. On the real task the motif is first built at generation 3 in all three runs, well inside the null budget. The null runs also had ample opportunity in a second sense: they did produce tied circuits, first at generations 2, 1, and 5. The structure was proposed early in every condition. Only on the real task did it survive.

Selection rejected the motif, rather than the models failing to propose it

This is the sharpest thing in the results. In null r1 the most heavily tied proposal scored −1.222 with 3 parameters, and in null r2, −1.174 with 2 parameters. Negative on this axis means worse than the real task’s seed, and both are far below their own run’s seed at 1.249. The models reached for the symmetry hypothesis, built it, and were punished for it by the fitness function.

The say-versus-build numbers point the same way. Frontier models used symmetry language in 16.7% of null proposals versus 36.0% of real ones, so the language did not vanish. What changed is what happened next: 96.8% of real proposals that said it also built it, against 43% in the null condition. The discrimination is being performed by evaluation and selection, not by the models declining to entertain the idea.

This sits alongside, rather than overturning, the earlier say-versus-build finding. That result was about models differing from each other on a fixed task, where mid and frontier talk at the same rate and build at 22% versus 97%. This one is about a fixed ensemble across differing tasks. Both say the verbal claim is unreliable evidence.

The scores cannot carry any of this argument

The score gap looks decisive and is not. Two independent problems compound. First, the displayed score is affinely anchored to the real task’s seed and best solution, and those constants were never re-measured for the null dataset, so the null seed alone reads 1.249 — above the best solution ever found on the real task. Second, the null task is far easier: a linear probe on the raw features reaches 97.3% against 87.3% on the real task, which follows directly from the label rule, since deg(v*) ≥ 2 is a threshold on a sum of seven incident edge bits and is therefore nearly a linear function of the inputs.

The consequence is a ceiling. Measured as a fraction of the headroom remaining to raw 1.0, the null arm captures 60.1% and the real arm 60.4% and 67.3% — indistinguishable. So the raw-score gap is mostly the ceiling, not the condition. This is why the pre-registration used the structural motif and not the score, and that choice looks well made in hindsight.

What this does not establish

  • Significance. Fisher exact on 3/3 versus 0/3 gives p = 0.10. The pre-registration said so in advance. Three runs per condition cannot do better, and the honest reading is “consistent with the hypothesis,” not “demonstrated.”
  • Behaviour. Every claim here is structural. The equivariance check, which measures the invariance directly and has no fingerprint to choose, was not run. symmetry_analysis.py wrote a best_program_local.py for each null run, so it is available cheaply.
  • The fingerprint problem. VALIDATION_CRITERIA.md flags this as the protocol’s weakest point: the strict motif definition was chosen knowing the answer, and a looser one degrades the criterion badly. This control tests the strict fingerprint against a negative task, which is a real strengthening, but it does not resolve the underlying circularity.
  • Generality. One task, one symmetry, one ensemble. The null arm was run only at the frontier tier, so nothing here says how mid or weak arms behave without a symmetry to find.

Two discrepancies I did not chase

My first-hand measurement of within-run motif recurrence on the real frontier runs gives 63%, 42%, and 83%, a mean of 62.9%. VALIDATION_CRITERIA.md reports 69.7% for the same arm. Similarly I measure built-given-said as 30/31 where that document reports 32/33. Both gaps are small and most likely come from a different count of parseable proposals, but I did not track them down; the numbers on this page are the ones I measured.

Methodological note on the first attempt

An earlier submission of these same three runs (jobs 22465035–37) returned 0 of 15 correct programs in about nine minutes each and is void. The task directory was missing its activate_eval_cluster.sh, so eval jobs never activated the conda environment and died at import numpy. The loop did not stall; the models spent all 15 generations writing patches about the infrastructure error, with names like env_error_bypass. Those results are archived, not deleted. The rerun added the activate script with its data and log paths pointed at the null directory, leaving the evaluation protocol otherwise byte-identical between conditions.

What would settle it

The cheapest strengthening is more null replicates. At roughly $5.50 and ninety minutes per run, taking the null arm from 3 to 10 would bring the comparison to the same n as the weak arm and, if the motif rate stays at 0, move Fisher well below 0.05. Running the behavioural equivariance check on the six best programs already extracted would remove the dependence on the structural fingerprint entirely. Adding mid and weak null arms would show whether the criterion’s discrimination holds for the cheaper ensembles, where the real-task motif rates were 1/5 and 2/10 and there is much less signal to lose.
