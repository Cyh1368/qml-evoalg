<DESCRIPTION>
This edit replaces the dense per-qubit parameterization with a more efficient, symmetry-aware block.

The fixed feature map already injects rich pairwise ZZ structure, so the ansatz can be smaller without losing much expressivity. I use:
- parity-shared single-qubit mixing layers on all qubits,
- a closed CZ ring for local entanglement propagation,
- a second parity-shared RX layer to convert phases into measurable population changes,
- and a short set of long-range CZ links to couple the two halves of the register.

This cuts the number of circuit parameters per block from 24 to 6 while keeping a meaningful entangling backbone, which should improve parameter efficiency and reduce overfitting while preserving accuracy under repeated re-uploading.
</DESCRIPTION>
