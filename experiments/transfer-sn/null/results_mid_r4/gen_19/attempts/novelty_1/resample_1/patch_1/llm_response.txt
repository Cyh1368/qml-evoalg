<DESCRIPTION>
This edit replaces the current high-parameter mixed-axis block with a more structured and parameter-efficient ansatz.

Key changes:
- Preserve per-qubit input expressivity with one RY on each qubit.
- Replace the heavier CRX/CRY/CRZ stack with a cleaner CRZ entangling scaffold.
- Add a sparse long-range skip link, `CRZ(0,4)`, to help the circuit capture non-local correlations without much overhead.
- Replace the final per-qubit RY layer with a single shared RY mixer applied to all qubits, which keeps the output layer trainable while reducing parameter count and helping regularization.

This should improve optimization stability, lower the train-test gap, and reduce L2 loss while using parameters more efficiently.
</DESCRIPTION>
