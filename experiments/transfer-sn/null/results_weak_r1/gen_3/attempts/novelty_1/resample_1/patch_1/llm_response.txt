<REDUCE_shared_z_entangling_block>
<DESCRIPTION>
Reduce parameter count per ansatz block by introducing shared trainable Z/X rotation parameters across all qubits, while increasing fixed entangling connectivity. This should improve `parameter_efficiency` (fewer trainable circuit parameters) and help maintain high accuracy by keeping the circuit expressive via re-uploading + strong fixed CZ connectivity.
Key changes:
- Replace per-qubit RZ layers (16 params total) with a single shared RZ parameter used on all qubits for pre- and post-entangling layers (2 params total).
- Add a shared RX parameter used on all qubits (1 param).
- Keep per-qubit RY parameters (8 params) and enrich the fixed CZ pattern (no extra parameters).
Resulting `N_PARAMS_PER_BLOCK` drops from 24 to 11, lowering overall `n_params` from 146 to 68 (readout params unchanged).
</DESCRIPTION>
