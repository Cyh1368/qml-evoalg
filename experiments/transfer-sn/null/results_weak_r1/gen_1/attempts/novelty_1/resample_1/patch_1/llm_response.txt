To improve the performance of the 8-qubit binary classifier, I am proposing an evolution of the `ANSATZ_SPEC`. The current ansatz is a simple, somewhat linear structure (RY, RZ, linear CZ chain, RZ). We can improve expressivity and convergence by introducing more entanglement and a more flexible rotation structure that allows for better optimization landscapes without inflating the parameter count too drastically.

Specifically, I am moving to a structure that uses `CRZ` gates (parametric entanglement) and adds more cross-layer entanglement. This is generally more robust for classifiers than fixed `CZ` gates, as it allows the optimizer to tune the strength of the entanglement between qubits during training.
