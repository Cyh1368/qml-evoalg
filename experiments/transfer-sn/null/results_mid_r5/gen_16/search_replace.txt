<DESCRIPTION>
The current program has 122 parameters, leading to overfitting and poor accuracy (0.99 test vs 1.00 in prior programs). Program 2 achieved perfect accuracy with only 32 parameters by using aggressive parameter sharing and a linear CNOT chain.

The key improvements:
1. **Reduce RX layer**: Use only 2 shared parameters (alternating even/odd qubits) instead of 8 independent ones
2. **Reduce RY layer**: Use only 2 shared parameters (alternating even/odd qubits) instead of 8 independent ones
3. **Reduce RZ layer**: Use only 3 shared parameters instead of 4
4. **Simplify entanglement**: Replace the complex two-stage CNOT pattern with a linear chain [0-1, 1-2, 2-3, 4-5, 5-6, 6-7, 7-0], which is known to be more efficient

This reduces parameters from 20 per block → 7 per block, leading to 42 circuit parameters + 2 readout = 44 total (vs 122 currently). This should:
- Reduce overfitting and improve validation accuracy
- Lower test loss while maintaining or improving test accuracy
- Improve parameter efficiency (acc/params)
- Enable faster convergence
- Better match the successful design of Program 2
