<DESCRIPTION>
This edit replaces the over-parameterized local stack with a lower-rank, symmetry-tied block that is closer to the previously best-performing structure, while still injecting the requested sparse long-range controlled-phase motif.

Key ideas:
- Share parameters across even/odd qubits for the initial RY layer to cut redundant degrees of freedom.
- Keep a shallow CZ backbone to preserve fast entanglement spread.
- Use a compact 3-way shared RZ pattern for phase refinement instead of per-qubit phase freedom.
- Add a single shared CRZ parameter on three cross-register pairs to capture nonlocal correlations efficiently.

This should reduce train-test gap and validation loss, improve parameter efficiency, and likely converge faster than the current 164-parameter block.
</DESCRIPTION>
