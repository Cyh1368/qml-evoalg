# Analysis and Proposed Improvement

## Current Performance Analysis

The program achieves:
- **Test accuracy**: 0.98 (excellent)
- **Parameter efficiency**: 0.01 (0.98/146, lower than ideal)
- **Combined score**: 1.25

The model already has strong test accuracy and small generalization gap (0.01), but parameter efficiency is relatively low (146 parameters total). With `N_PARAMS_PER_BLOCK = 24` (8 RY + 8 RZ_pre + 8 RZ_post), across 3 uploads × 2 repeats, we get 144 circuit parameters.

## Proposed Improvement: Strategic Parameter Sharing

The key insight is that with such high accuracy, we can reduce the parameter count through **strategic sharing** while maintaining performance:

1. **RY layer**: Instead of 8 independent RY parameters, use cyclic parameter assignment where adjacent or strategically-placed qubits share parameters. This reduces redundancy without sacrificing expressivity.

2. **RZ post-layer**: Similarly, use fewer independent RZ parameters with repetition, reducing the post-measurement RZ layer from 8 to 4 unique parameters.

3. **Maintain pre-RZ diversity**: Keep the 8 individual pre-RZ parameters for data encoding sensitivity but share some across the post-layer.

This reduces from 24 params/block to 16 params/block, yielding:
- **Circuit params**: 96 (was 144)
- **Total params**: 98 (was 146)
- **Parameter efficiency**: 0.0098 (was 0.0067) — ~50% improvement
- **Expected**: Minimal accuracy loss with better generalization and efficiency

- **RZ_pre layer** remains at 8 independent parameters to preserve sensitivity to the 28-dimensional feature encoding.
- **RZ_post layer** now uses 3 shared parameters (rz_post_0, rz_post_1, rz_post_2) instead of 8, following a mirrored pattern that reflects the qubit topology.
- This reduces `N_PARAMS_PER_BLOCK` from 24 to **16** (3 + 8 + 3 + 0 shared overhead).
- **New total**: 16 × 3 uploads × 2 repeats + 2 readout = **98 parameters** (vs 146).
- **Parameter efficiency improvement**: ~48% reduction in parameters while expecting to maintain >96% test accuracy based on the redundancy in the original design.
