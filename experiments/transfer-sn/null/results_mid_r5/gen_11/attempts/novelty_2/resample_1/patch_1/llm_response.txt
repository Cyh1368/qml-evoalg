<DESCRIPTION>
Following the formal recommendation and learning from prior program 2's success (convergence in 180 steps with a combined score of 1.25), we implement parameter sharing across data re-uploads while maintaining independent parameters within each repeat block.

The key insight is that data re-uploading already provides expressivity by interleaving the feature map with ansatz blocks. By tying the same parameter block across the three uploads but using different parameters for each of the two repeats within an upload cycle, we:
1. Reduce parameter count from 96 to 32 (3× reduction in circuit parameters)
2. Preserve the triple re-upload structure's inductive bias
3. Improve parameter efficiency and reduce overfitting
4. Enable faster convergence (similar to prior program 2's 180 steps)

Additionally, we revert to the simpler CZ line connectivity pattern (rather than CNOT cycle), which proved effective in prior program 2. This reduces circuit depth/complexity while maintaining expressivity.

The modification to `apply_ansatz_block` uses `block_index % N_REPEATS` to reuse the same parameter block across all three uploads.
</DESCRIPTION>
