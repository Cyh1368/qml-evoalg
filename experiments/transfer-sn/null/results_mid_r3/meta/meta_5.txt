# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

Successful Algorithmic Patterns
- Parameter sharing across qubit pairs: The Generation 2 “8-Qubit Shared-Parameter Ansatz Classifier” (combined_score_raw 0.98, 100%/100%/100%, gap 0.00, 92 params, depth 81, 222 gates) shows that tying RY/RZ angles on (0,4), (1,5), (2,6), (3,7) preserves full expressivity while halving the single-qubit parameter count compared to Generation 0’s 146-param design (combined_score_raw 0.97).
- Nearest-neighbor plus cross-layer parametrized entanglers: Using CRX on (0–1, 2–3, 4–5, 6–7) and CRY on (1–2, 3–4, 5–6) in the shared-parameter ansatz delivered perfect generalization, matching or exceeding the deeper CZ-rich circuits in Generations 0 and 4.
- Moderate depth/gate‐count balance: Depth 81 and 222 gates was sufficient for perfect accuracy, outperforming deeper (>99 depth, >270 gates) reuploading ansätze that provided no accuracy gain but increased resource use.
- Three feature reuploads interleaved with two repeats: All top performers (Gen 0, Gen 2, Gen 4) used N_UPLOADS=3, N_REPEATS=2. This layout consistently converges to ≥0.98 combined_score_raw.

Ineffective Approaches
- Overparameterization with deep reuploading: Generation 0 (146 params, depth 99) and Generation 4 (170 params, depth 100) both converge rapidly to perfect accuracy yet yield very low parameter efficiency (0.01), indicating wasted trainable resources without any accuracy improvement over the 92-param design.
- Minimal‐parameter circuit underfitting: Generation 5’s 44-parameter shared-cross entangler ansatz achieved only 0.83 validation and 0.85 test accuracy (combined_score_raw 0.78) with a 0.07 generalization gap, showing that overly aggressive parameter tying leads to insufficient expressivity.
- Insufficient parameter tying still overcomplex: Generation 3’s 74-param symmetric pairing ring entangler (combined_score_raw 0.95, 0.98/0.97/0.97) underperformed Generation 2, suggesting that reducing from 92 to 74 parameters without careful entangler selection can degrade trainability.

Implementation Insights
- Structured parameter indexing: Building a `PARAMETER_KEYS_PER_BLOCK` → position lookup and applying it uniformly across N_UPLOADS×N_REPEATS simplifies block replication and ensures consistent parameter reuse.
- Readout calibration initialization: Setting gain=1 and bias=0 in the initializer aligns raw ⟨Z⟩ outputs to target ±1 labels, stabilizing early training and helping reach perfect accuracy.
- Autograd QNode with backprop and Adam: All top-scoring programs used Pennylane’s backpropagated QNode and an Adam optimizer (stepsize≈0.03), demonstrating this combination reliably handles up to ~100 trainable parameters on 8 qubits.
- Early-stopping on validation loss: Applying patience=75 and min_delta=1e-4 restored best weights and prevented overfitting even in highly parameterized designs.

Performance Analysis
- Perfect accuracy with fewer parameters: The 92-param shared-parameter ansatz (Gen 2) matches the 100%/0.00 gap of the 146- and 170-param circuits but cuts parameter count by ~35–45%, highlighting a sharp efficiency inflection at ~90 params.
- Convergence trade-off: Gen 2 converged in ~390 steps versus ~150–180 steps for deeper, overparameterized variants; the extra training cost is offset by dramatically reduced circuit complexity.
- Gate count vs. generalization: Circuits with >270 gates (Gen 0, Gen 3, Gen 4) did not see better test accuracy or smaller gaps than the 222-gate design, indicating diminishing returns beyond ~200 two-qubit interactions.
- Parameter efficiency plateau: Despite reducing parameters from 146→92, the best designs still report low efficiency (~0.01), suggesting that further efficiency gains may require entirely new ansatz paradigms rather than incremental parameter sharing.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Share entangler parameters across symmetric edges  
   In your ANSATZ_SPEC, replace the four distinct CRX keys (“crx_01”, “crx_23”, “crx_45”, “crx_67”) with a single key (e.g. “crx_shared”) and similarly collapse the three CRY keys into “cry_shared.” This reduces your circuit parameters by 5 (to 87) while leveraging the proven power of parameter tying—and you can directly compare expressivity and generalization against the 92-param baseline.  

2. Tie block parameters across repeats within each upload  
   Modify apply_ansatz_block so that both repeats in an upload share the same slice of circuit_params (i.e. index blocks by upload_index only). This cuts the circuit parameters in half from 6·N_PARAMS_PER_BLOCK to 3·N_PARAMS_PER_BLOCK (≈46 + 2 readout), testing whether repeat-wise parameter tying retains full accuracy.  

3. Inject a shared CRZ diagonal entangler for long-range coupling  
   After your existing RZ layer in each block, append a single parametrized CRZ gate on diagonals ([0,7],[1,6],[2,5],[3,4]) using one shared key (e.g. “crz_diag”). This adds a light-weight long-range ZZ interaction without substantially increasing depth or gate count, and may improve expressivity over purely nearest-neighbor entanglement.  

4. Explore an alternative reupload/repeat schedule (N_UPLOADS=2, N_REPEATS=3)  
   Keep six ansatz blocks total by setting N_UPLOADS=2 and N_REPEATS=3, so you perform three blocks between each feature upload instead of two. This preserves circuit depth (~81) and gate count (~222) but shifts the “feature ↔ ansatz” balance—potentially accelerating convergence as tested in other top performers.  

5. Use differentiated initialization for two-qubit vs. single-qubit params  
   In your parameter init, draw CRX/CRY (and any new CRZ) angles from a wider uniform range (e.g. ±0.1) while keeping RY/RZ in ±0.05. Breaking initial symmetry more aggressively on two-qubit rotations can jumpstart entangling dynamics and has been shown to accelerate training in high-expressivity ansätze.
