# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Ring‐topology CZ entanglement sandwiched between single‐qubit rotations drove the top score.  
  • The current best program (Seed with RY-CZ ring-RX) and Generation 7 (“ry_cz_rx_efficient”) both achieved combined_score_raw 0.99 with perfect 1.00/1.00/1.00 accuracies, zero gap, N_params = 98, depth 81, gate_count 228, and converged by ~150 steps.  
- Moderate circuit depth (≈80) and gate count (~230) outperformed deeper circuits.  
  • Reducing from depth 93 (Gen 10, 104 params) and depth 99 (Gen 14, 170 params) to depth 81 (98 params) maintained perfect accuracy while improving parameter efficiency.  
- Three feature re-uploads × two ansatz blocks remained essential.  
  • All top performers (Gen 10, current best) used N_UPLOADS = 3 and N_REPEATS = 2, consistently yielding zero generalization gap.  
- Simple per-qubit RY→CZ→RX blocks outperformed denser multi-gate blocks.  
  • Replacing complex CRX/CZ mixtures (Gen 10 “shared_bridge_crx”) with only CZ entanglers (current best) cut parameters from 104 to 98 without loss in accuracy.

## Ineffective Approaches  
- Over-parameterized dense couplings failed to improve scores.  
  • Generation 11’s dense CZ connectivity and extra RX layers (194 params, depth 93) plateaued at combined_score_raw 0.97 and converged in 180 steps, despite zero gap.  
  • Generation 14’s multi-gate phase-coupled ansatz (170 params, depth 99) also stalled at 0.98 combined score.  
- Simple CNOT-ladder or ring-CNOT designs underperformed CZ‐based rings.  
  • Generation 12 (“cnot_ring_ry_rx”) used RY–CNOT–RX in a ring (98 params, depth 114) but only reached combined_score_raw 0.98 and 0.99 accuracies; CZ lowered depth and boosted accuracy.  
- Brick-wall patterns added gates without accuracy gains.  
  • Generation 13’s brick-wall RY–CNOT–RZ–CNOT–RY (146 params, depth 87) hit 0.98 combined score but suffered a 0.01 gap and lower parameter efficiency.

## Implementation Insights  
- Formal ANSATZ_SPEC with validate_ansatz_spec ensures parameter–gate alignment.  
  • All high‐performers, including the current best, used an explicit parameter key ordering (e.g., ["ry_0",…,"ry_7","rx_0",…,"rx_7"]) to avoid indexing errors.  
- Vectorized batch predictions via pnp.stack of qml.expval outputs accelerates both forward and backward passes.  
  • The seed program’s predict_batch stacks per‐wire Z‐expectations and computes a calibrated mean (gain/bias), mirroring earlier efficient designs.  
- AnnotatedQueue + QuantumScript metadata extraction ties structural changes to depth/gate_count.  
  • Comparing depth 81 vs 93 directly informed the pruning of extraneous two‐qubit gates in the best program.  
- Minimal readout calibration (one gain, one bias) sufficed for perfect separation.  
  • All top circuits used only 2 readout parameters, stabilizing convergence without extra trainable layers.

## Performance Analysis  
- Combined_score_raw climbed from 0.97 → 0.98 → 0.99 as parameter count was tuned, not simply increased.  
  • 194 params (Gen 11) → 170 (Gen 14) → 146 (Gen 13) all stalled at ≤0.98, while 98 params (current best) hit 0.99.  
- Depth reduction correlated with faster convergence and higher scores.  
  • Depth 99 (Gen 14) and 93 (Gen 10) converged by ~150–180 steps; depth 81 (current best) also converged by ~150 steps but with higher accuracy consistency (std 0.00).  
- Zero generalization gap was achievable across all high‐scoring designs, but only the lean RY–CZ–RX ring reached perfect 1.00/1.00/1.00 accuracies.  
- Parameter efficiency (test_accuracy/N_params) peaked at ~0.0102 in the current best program, surpassing heavier circuits (≤0.007 in Gen 10–14).

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Insert parameterized RZ rotations around each CZ gate. In your ANSATZ_SPEC, wrap every CZ entangler with single-qubit RZpre_i→CZ→RZpost_i on both wires, adding two new parameters per CZ. This leverages insights from Generations 5/9 that commuting Z-layers boost phase flexibility without overfitting, and should preserve the lean RY–CZ–RX block’s moderate depth.

2. Alternate local and nonlocal CZ rings across blocks. Keep the standard nearest-neighbor ring on even-indexed blocks, but in odd-indexed blocks replace the entangling sequence with a “skip-2” ring (wires [0,2],[1,3],[2,4],…,[7,1]). This interleaves short- and medium-range correlations without increasing block count, potentially improving expressivity as demonstrated by mixed topology strategies in earlier gens.

3. Sparsely inject trainable CRZ gates after select CZs. In each block, follow every second CZ (for example, those on pairs (1,2),(5,6)) with a CRZ(angle, wires) using a unique parameter. This adds only ~4 parameters per block and builds on the hypothesis that adding tunable two-qubit phases can reduce the number of blocks needed for peak accuracy.

4. Make the feature-map scales trainable per feature dimension. Replace the fixed FEATURE_SCALE with a parameter vector feat_scale of length N_FEATURES, and use qml.IsingZZ(feat_scale[k]·records[...,k], wires=[a,b]). By learning individual feature weights at encoding time, the circuit can adaptively prioritize high-impact inputs, mirroring the success of minimal readout calibration upstream.

5. Calibrate readout with per-qubit biases. Instead of one global bias, append an 8-element bias vector b_i and compute raw_i = expval(Z_i) – b_i before averaging. This per-qubit calibration (plus the existing global gain) can correct wire-specific shifts, refining the decision boundary and potentially lowering the validation/test loss further.
