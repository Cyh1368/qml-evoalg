An issue with the current program is that it uses an unentangled, collective-parameter ansatz, which drastically reduces expressiveness and hurts accuracy. We can fix this by introducing independent parameterized single-qubit rotations and entangling gates. 

Following the recommendation, we will replace the `collective_y` and `collective_x` layers with individual `RY` and `RX` rotations per qubit. To efficiently create entanglement without excessive depth and gate overhead, we insert a "zig-zag" (or staggered ladder) pattern of `CZ` gates between the rotation layers. This pattern groups the commuting `CZ` gates into exactly two parallel depth slices (e.g. `(0,1), (2,3), (4,5), (6,7)` then `(1,2), (3,4), (5,6)`).

This structural change restores the necessary expressivity required to achieve high accuracy on the validation and test datasets while keeping the gate count slightly lower than an overparameterized ring topology.
