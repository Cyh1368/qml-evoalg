# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Ring-CZ entanglement with minimal local rotations  
  • Both the Generation 5 ring-CZ RY–RZ ansatz (98 params, depth 81, gate 228) and the current best RY–CZ-ring–RX design achieved perfect train/validation/test accuracy and zero generalization gap. The latter boosted the combined raw score from 0.98→0.99 by replacing RZ output layers with RX, while keeping depth/gate count constant.  
- Three re-uploads × two repeats layout  
  • Every top-performer (Gen 0/1/5/7) uses N_UPLOADS=3 and N_REPEATS=2. This multi-upload structure consistently delivers negligible overfitting (~0.00–0.01 gap) and rapid convergence (≈120–210 steps).  
- Parameter-efficient per-qubit rotations  
  • Moving from full SU(2) blocks (146 params, Gen 6, score 0.97) to single-axis RY+RX or RY+RZ per qubit (16 params/block) maintained or improved accuracy, halving parameter count while boosting combined score to ≥0.99.  
- Nearest-neighbour CZ only  
  • Restricting two-qubit gates to staggered CZ rings (even+odd bonds) minimized circuit depth and gate count, preserving expressivity and maximizing parameter efficiency (~0.01 for N_params=98).  

## Ineffective Approaches  
- Over-parameterized SU(2) rotation layers  
  • Generation 6’s full RX, RY, RZ on each qubit (146 params, depth 99, gate 270) plateaued at a 0.97 combined score with a 0.01 generalization gap, showing diminishing returns.  
- Insertion of parameterized two-qubit rotations  
  • Adding CRZ/CRY/CRX layers (e.g., Gen 4) inflated depth to 126 and gate count without score gains (0.97), indicating these extra entanglers muddle optimization.  
- Long-range CNOT entanglers  
  • Hybrid CZ+CNOT layouts (Gen 3) increased gate count to 306 and depth to 111, slowed convergence (~390 steps), and dropped combined score to 0.94.  
- Shared-parameter collapse of all rotations  
  • Aggressive parameter sharing (Gen 8, 50 params) yielded only 0.73 combined score, showing that over-sharing can undercut the expressivity needed for perfect classification.  

## Implementation Insights  
- Modular ANSATZ_SPEC with validate_ansatz_spec  
  • Defining the ansatz as a list of gate dictionaries and auto-extracting PARAMETER_KEYS_PER_BLOCK enforces a consistent param ordering and simplifies swaps between RZ and RX output rotations.  
- key_to_position + offset indexing  
  • The mapping from parameter keys to block-local indices, combined with block_index·N_PARAMS_PER_BLOCK offsets, cleanly applies identical blocks across uploads/repeats.  
- factorized feature_map vs. apply_ansatz_block  
  • Separating fixed IsingZZ feature encoding from trainable ansatz blocks eases experimentation with entanglement patterns—critical in arriving at the ring-CZ design.  
- Automated metadata via AnnotatedQueue  
  • Using qml.queuing.AnnotatedQueue to compute depth/gate_count ensures any change in ANSATZ_SPEC immediately reflects in resource metrics, guiding the choice of the 2-layer CZ ring approach.  

## Performance Analysis  
- Parameter count vs. combined score  
  • Reducing from 146 params (Gen 6, score 0.97)→98 params (Gen 5, score 0.98)→98 params with RX outputs (current best, score 0.99) shows a clear inverse correlation: fewer, targeted rotations improve both optimization and final accuracy.  
- Depth/gate count sweet spot at 81/228  
  • All top-scoring circuits (Gen 5, current) share depth 81 and gate 228. Designs above this threshold added complexity without score gains.  
- Convergence behavior  
  • The current best circuit converges in ~150 steps—faster than over-complex layouts (~390) and slightly slower than the earliest SU(2) designs (~120), striking a balance between expressivity and trainability.  
- Parameter efficiency maximized at ~0.01  
  • With test accuracy = 1.00 and N_params = 98, the current design achieves a parameter efficiency of ~0.01, the highest among all evaluated programs.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce per-upload trainable feature-map scaling.  Instead of using the fixed FEATURE_SCALE for all three uploads, add one learnable scalar αₖ per upload (k=0,1,2) that multiplies FEATURE_SCALE inside the feature_map.  This injects only three extra parameters but lets the model adapt the encoding strength of each re-upload—leveraging the proven multi-upload structure to potentially boost expressivity without touching the ansatz depth or CZ pattern.  

2. Mix rotation axes in the input layer.  Replace half of the block’s RY rotations with RZ on alternating qubits (e.g. qubits 0,2,4,6 remain RY; qubits 1,3,5,7 become RZ), keeping one angle per qubit.  By diversifying the input-axis pool while holding total parameters (8) constant, you build on the parameter-efficient single-axis insight and explore whether mixed axes better capture feature correlations.  

3. Alternate two block types to enrich expressivity.  Define block A as the current RY–CZ–RX pattern and block B as RX–CZ–RY (swapping the order of input/output axes), then interleave them across the 3×2 layout (A,B,A,B,A,B).  This preserves the ring-CZ entangling structure and parameter count (16 per block) but tests if cycling the rotation-order per block yields a smoother loss landscape or faster convergence.  

4. Add a single global CRZ at circuit end.  After all ansatz blocks and before measurement, append one CRZ gate on a representative bond (e.g. wires [0,1]) with its own trainable angle.  This one extra depth and parameter injects minimal two-qubit parametrization—drawing on the idea that a light, global entangler might nudge expressivity without the overhead that sunk Gen 4’s performance.  

5. Move from uniform averaging to qubit-weighted readout.  Replace the scalar mean over all eight Z-expectations with a trainable weighted sum z̄=∑ᵢwᵢ·⟨Zᵢ⟩ (plus the existing global bias and gain), adding eight qubit-specific weights wᵢ.  This fine-grained calibration builds on the successful output-shaping strategy, allowing the circuit to learn which qubits carry stronger signals and potentially improving both convergence and noise robustness.
