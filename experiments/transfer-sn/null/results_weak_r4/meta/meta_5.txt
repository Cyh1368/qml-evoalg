# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- CZ-ring entanglement with only RY input and RZ output rotations  
  • 8-qubit CZ-ring quantum classifier (Generation 5) used two staggered CZ-ring layers per block (16 trainable params) and achieved the top combined raw score of 0.98 with perfect validation/test accuracy.  
- Parameter reduction via shared phase dressings  
  • Collapsing pre- and post-RZ rotations into shared RZ parameters cut the circuit from 146 params (Gen 0/1) to 98 params (Gen 3/5) without sacrificing accuracy; Gen 5 even improved to 1.00 test accuracy.  
- Multi-upload re-uploading layout  
  • All top performers (Gen 0/1/5) used three feature-upload rounds interleaved with two ansatz repeats, consistently delivering negligible generalization gaps (~0.01) and rapid convergence.  
- Focusing entanglement on nearest-neighbour CZs  
  • Limiting two-qubit gates to a CZ ring (Gen 5) rather than inserting long-range CNOT or CRZ layers preserved expressivity while reducing depth (81) and gate count (228), boosting parameter efficiency to 0.01.  

## Ineffective Approaches  
- Over-parameterized two-qubit rotations  
  • Adding CRZ layers in Generation 4 swelled parameters to 218 and depth to 126 but only matched a 0.97 combined score, indicating diminishing returns from extra entanglers.  
- Inserting long-range CNOT entanglers  
  • Generation 3’s hybrid CZ + CNOT layout increased gate count to 306 and depth to 111 yet dropped the combined raw score to 0.94 and slowed convergence (~390 steps).  
- Large parameter counts with marginal gains  
  • The 146-param circuits in Generations 0/1 converged in ~120–180 steps for a 0.97 score, but their parameter efficiency remained low (~0.01), offering no advantage over the streamlined 98-param design.  

## Implementation Insights  
- Modular ansatz specification  
  • Defining ANSATZ_SPEC as a list of gate dictionaries (16 params/block) and deriving PARAMETER_KEYS_PER_BLOCK via validate_ansatz_spec ensures consistent parameter ordering across N_UPLOADS×N_REPEATS.  
- Clear separation of feature map and ansatz  
  • factorizing feature_map(records) and apply_ansatz_block(params, idx) supports rapid prototyping of different entanglement patterns (chain CZ, ring CZ, CRZ) with minimal code changes.  
- Automated circuit metadata extraction  
  • Leveraging qml.queuing.AnnotatedQueue to compute depth and gate_count enables quantitative evaluation of how structural changes (e.g., Gen 5’s ring CZ) impact resource metrics.  
- Backpropagation optimizer synergy  
  • Using PennyLane’s backpropagation with Adam on default.qubit yields stable and fast convergence (~210 steps in Gen 5), even for circuits with multiple re-uploads and 98 trainable parameters.  

## Performance Analysis  
- Parameter count vs. score  
  • Reducing from 146 params (Gen 0/1, score 0.97) to 98 params (Gen 5) increased combined raw score to 0.98 and achieved 1.00 test accuracy.  
- Depth/gate trade-offs  
  • Gen 3 and Gen 4 expanded depth (111/126) and gates (306/–) without outperforming Gen 5’s shallower (81) and leaner (228) circuit, demonstrating that lower depth correlates with higher parameter efficiency and accuracy.  
- Convergence behavior  
  • The simplest high-performing layout (Gen 1) converged fastest (~120 steps) but plateaued at 0.97; the Gen 5 ring CZ model converged by ~210 steps to 1.00 accuracy, whereas over-complex layouts (Gen 3) required ~390 steps.  
- Generalization gap consistency  
  • All multi-upload circuits maintained a tiny generalization gap (0.01), confirming that expressivity delivered by repeated feature re-uploads is robust to ansatz simplification.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Implement parameter sharing for single-qubit rotations across blocks. Instead of defining distinct `ry_i` and `rz_i` for every block, reuse the same eight `ry_0…ry_7` (and similarly eight `rz_0…rz_7`) keys in each block. Update `validate_ansatz_spec` and `apply_ansatz_block` to map these shared keys across all `N_UPLOADS×N_REPEATS` blocks, cutting `N_PARAMS_PER_BLOCK` from 16 to 8 and halving the total trainable parameters while preserving the proven RY–CZ–RZ structure.

2. Explore a 4-upload, 1-repeat layout to amplify multi-upload expressivity with minimal depth. Change `N_UPLOADS=4` and `N_REPEATS=1` (keeping four total ansatz blocks) so the feature map is applied more often, but each ansatz block is lighter. This builds on the negligible generalization gaps seen in three-upload circuits and may accelerate convergence even further.

3. Augment each ansatz block with a single shared-parameter CRZ gate. After the two staggered CZ layers, insert one `CRZ` on a representative ring bond (e.g., wires `[0,1]`) using a new block-specific key like `phi_block_k`. This introduces a minimal trainable two-qubit rotation per block—testing whether a small CRZ supplement can boost expressivity without inflating depth or gate count.

4. Replace the output RZ rotations with RX rotations to probe different rotation axes. In the `ANSATZ_SPEC`, change the eight `RZ` gates at the end of each block to `RX` (same wire indices and keys). This swaps the output axis while keeping parameter count constant, leveraging the two-axis input/output strategy but exploring whether RX outputs yield smoother optimization landscapes or faster convergence.

5. Thin out entanglement in alternating blocks to reduce depth. Redefine `ANSATZ_SPEC` so odd-indexed blocks maintain the full two-layer staggered CZ ring, but even-indexed blocks apply only the first (even-bond) CZ layer. This alternation cuts the average gate count and circuit depth by ~25%, testing if interleaving lighter-entangler blocks holds onto the high accuracy of the full ring CZ design.
