<DESCRIPTION>
Reduce parameter count per ansatz block by sharing the same trainable RZ parameter for both the “pre” and “post” RZ layers (i.e., the same `rz_i` is used twice in the block). This cuts `N_PARAMS` from 146 to 122 without changing the fixed upload/repeat/feature map pipeline.
Also improve expressivity by adding an extra CNOT entangling pattern (on non-nearest-neighbor pairs) while keeping parameter count unchanged (since CNOT is non-parametrized in this search language).
This should maintain (or improve) accuracy via richer entanglement while improving parameter efficiency and reducing train-test gap risk.
</DESCRIPTION>
