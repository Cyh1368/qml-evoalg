<DESCRIPTION>
This edit replaces the line-based, 8-parameter-per-layer pattern with a more compact ring-entangling block.

Why this should help:
- The previous final RZ layer was mostly diagonal and therefore weakly effective against the fixed ZZ feature map and Z-basis readout.
- A full CZ ring gives each qubit direct global mixing in one layer, which is a better fit for the re-uploaded feature map.
- Parity-shared RY/RX layers keep the block expressive while cutting the number of trainable circuit parameters per block from 8 to 4.
- Fewer parameters should improve parameter efficiency and reduce overfitting, while keeping enough non-diagonal basis changes to preserve accuracy.

Overall, this keeps the architecture lightweight, more symmetric, and better aligned with the fixed phase-encoding data pipeline.
</DESCRIPTION>
