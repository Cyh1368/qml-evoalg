<DESCRIPTION>
Share each pre/post RZ parameter on the same qubit. The intervening CZ gates commute with every RZ, so the original block depends only on the sum of each pre/post pair; their independent difference is an unobservable flat optimization direction. Using the same parameter twice preserves the full reachable effective-angle family while retaining strong gradient sensitivity. This reduces parameters per block from 24 to 16 and total parameters from 146 to 98 without reducing expressivity, improving parameter efficiency and potentially accelerating Adam by removing redundant directions.
</DESCRIPTION>
