# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Multi-upload (N_UPLOADS = 3) interleaved with modest repeats (N_REPEATS = 2) consistently yields perfect accuracy and zero generalization gap.  
  • Verified by the current best 86-param ansatz (depth 138, gates 336, conv. in ~210 steps, combined_raw 0.99) and earlier high-performers (Gen 1/5/6).  
- Sparse, targeted two-qubit entanglers plus fixed CZ backbone deliver expressivity with few parameters.  
  • The current best uses only four CRZ angles per block plus two CZ layers to “densify” correlations, matching the 100% test accuracy of heavier designs (e.g. Gen 9’s 170-param ansatz) at 86 params.  
- Shared-parameter global RZ phases before and after entanglement sharply reduce tunable parameters without accuracy loss.  
  • Both the current best (1 shared pre-RZ, 1 shared post-RZ) and Gen 5 achieved combined_raw 0.99 with ~14 params per block vs. 28+ in naive designs.  
- Trainable readout calibration (gain + bias) remains essential for stable convergence and zero generalization gap.  
  • Every top model—including the 86-param variant—relies on two scalar output parameters to drop test loss to ~0.06 and lock in 1.00 accuracy.  

## Ineffective Approaches  
- Overparameterized entanglement layers without sharing led to slower training and lower efficiency.  
  • Gen 9’s “enhanced_entanglement_ansatz” (170 params, depth 87) hit combined_raw 0.99 but had parameter efficiency 0.01 and trained ~300 steps.  
- Fully independent CRZ couplings increased parameters with no accuracy gain.  
  • Gen 11’s CRX/CRZ shared-parameter variant (104 params) matched 1.00 accuracy but still low efficiency and depth 81 vs. current best depth 138 at fewer params.  
- Excessive pruning of entanglers collapsed capacity below a threshold.  
  • Gen 13/15’s 74-param designs dropped to combined_raw 0.98/0.97 and test accuracy 0.99, indicating a lower bound ~86 params for full expressivity.  
- Deep staircase or repeated two-qubit-gate patterns without sharing bloat gate count.  
  • Gen 12’s RY–CZ–CRZ repeater (86 params but 120 depth, 252 gates) matched accuracy but added needless gates relative to the 336-gate shared-spec model.  

## Implementation Insights  
- Centralized ANSATZ_SPEC + validate_ansatz_spec/enforced key ordering simplifies block prototyping and parameter deduplication.  
  • The current best uses dict.fromkeys on parameter_keys to collapse eight shared-RZ entries into one key, shrinking per-block params from 16→14.  
- Generic apply_ansatz_block with key‐to‐position mapping allows rapid swaps between shared vs. independent gates.  
  • Swapping a handful of “param” entries in ANSATZ_SPEC produced the current 86-param block vs. the 170-param predecessor with minimal code changes.  
- Explicit second CZ layer (“densify correlations”) enhances entanglement depth cheaply, trading extra fixed gates for reduced trainable angles.  
  • This pattern achieves the same test accuracy as two independent CRZ layers (Gen 9) but at half the parameter cost.  
- Automated metadata extraction via AnnotatedQueue + QuantumScript drives transparent depth/gate comparisons across variants.  
  • The current best’s reported depth 138/gates 336 vs. Gen 11’s 81/222 and Gen 12’s 120/252 directly guided the consolidation of shared-parameter strategies.  

## Performance Analysis  
- Peak combined_raw score of 0.99 is achieved at ~86–110 params; higher counts (170, 104) show no accuracy gain.  
  • Current best (86 params) vs. Gen 9 (170 params) and Gen 11 (104 params) all hit 1.00 test accuracy, exposing overparameterization.  
- Parameter efficiency maximizes around 0.011–0.012 at 86 params, dropping below 0.009 at 110+ params and falling off past 170.  
  • Current best yields ≈0.012, outpacing Gen 9’s ≈0.006 and Gen 11’s ≈0.009.  
- Deeper circuits with shared parameters (depth 138) outperform shallower, heavily parameterized ones in efficiency—without slowing convergence (~210 steps).  
  • Convergence steps cluster tightly at ~210 for all shared-param models, whereas overparameterized (Gen 9) required ≈300.  
- Accuracy plateau at combined_raw 0.99 aligns with a parameter “sweet spot” of 86–110; fewer than 86 causes accuracy drop (0.98–0.97).

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Replace the single “rz_shared_pre” key with three upload-specific pre-phase keys (“rz_pre_u0”, “rz_pre_u1”, “rz_pre_u2”) so that before each of the three data uploads you apply a distinct global RZ on all eight wires. This leverages the proven benefit of multi-upload interleaving by giving each re-injection its own phase degree of freedom, adding only two extra parameters but potentially unlocking new expressivity without bloat.  

2. In the second repeat of each upload, swap the four parametrized CRZ gates for two shared CRX (“crx_shared”) on wires [0,1] and [4,5] and two shared CRY (“cry_shared”) on wires [2,3] and [6,7]. This mixed-axis sparse entangler pattern builds on the current best’s four-CRZ block by diversifying control-rotation axes—adding just two parameters while improving gradient flow and expressivity as seen in Gen 5.

3. After the existing second CZ backbone, append a sparse diagonal CRZ layer on pairs [(1,2), (3,4), (5,6), (7,0)] all sharing a new key “crz_diag.” This single extra parameter extends long-range coupling in the same lightweight, shared-parameter style that densified correlations in the best 86-param ansatz, with minimal depth increase and proven expressivity gains.

4. Between upload 1 and upload 2, interleave a fixed IsingXX feature-map layer mirroring the existing ZZ encoding: call qml.IsingXX(FEATURE_SCALE * records[..., k], wires=FEATURE_PAIRS[k]) for each feature k. This costs zero trainable parameters, enriches nonlinear data interactions across uploads, and exploits the finding that additional coupling axes can boost expressivity more effectively than extra variational angles.

5. Experiment with a 4×1 upload-repeat layout (set N_UPLOADS=4, N_REPEATS=1) while keeping the total of six ansatz blocks constant. By increasing the cadence of data re-injection and reducing repeats per block, you directly test whether more frequent feature uploads can match or surpass the current convergence in ~210 steps—extending the multi-upload insight to a new upload-heavy regime.
