<DESCRIPTION>
Replace the current ansatz block (which uses independent RX and RY on every qubit, creating 16 single-qubit parameters plus 8 CRZ parameters per block) with a more parameter-efficient but still expressive structure:

- Use only one trainable single-qubit rotation type per qubit (RY) to reduce redundant degrees of freedom while retaining universality with re-uploading.
- Add shared (parameter-reused) global RZ layers to capture per-qubit phase offsets without increasing the parameter count linearly with qubits.
- Keep a CZ “ring backbone” plus an additional fixed CZ layer to ensure strong connectivity/correlation capacity at low parameter cost.
- Use sparse, disjoint CRZ controlled-phase parameters to add nontrivial entangling expressivity, but with far fewer parameters than the current dense staircase.

This targets higher combined score primarily via improved parameter efficiency (lower n_params) while maintaining (or improving) validation/test accuracy and keeping generalization gap low.
</DESCRIPTION>
