# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- Circular CZ topology with minimal parametric layers  
  – The current best, “8-Qubit Repeated CZ-RY Ansatz Classifier” (combined_score_raw = 0.99, depth 81, gate_count 228), interleaves two CZ patterns ([0–1,2–3,…6–7] then [1–2,3–4,…7–0]) per block. This balanced, local+wrap-around entanglement outperforms the purely linear CZ chain of Generation 0 (combined_score_raw = 0.97, depth 99, gate_count 270).  

- Simple single-qubit parameterization  
  – Restricting trainable gates to RY rotations (16 params per block) plus fixed CZs delivered perfect accuracies and zero generalization gap. In contrast, ansätze using parameterized two-qubit gates (CRX/CRY/CRZ in Generation 5, combined_score_raw = 0.97) did not improve performance despite higher expressivity.  

- Moderate depth with multiple feature re-uploads  
  – Maintaining N_UPLOADS = 3 and N_REPEATS = 2 provided sufficient expressivity. The best program’s depth of 81 strikes an optimal balance between expressivity and trainability, whereas deeper circuits (depth ≥ 91 in Generations 2 & 7) showed no score gains.  

- Early stopping with loss-based restoration  
  – Employing Adam plus validation-loss early stopping stabilized training and ensured zero generalization gap. The best converged at step ≈390 with no overfitting, unlike overparameterized counterparts that required greater patience without accuracy gains.  

## Ineffective Approaches

- Overly deep CZ-chain ansätze  
  – Generation 2’s “Layered RY–Shared RZ CZ Chain” (combined_score_raw = 0.98, depth 99, gate_count 270) added shared-parameter RZs but still underperformed versus the simpler circular CZ design, indicating diminishing returns from extending chain length.  

- Heavy use of parameterized two-qubit gates  
  – The mirror-bridge ansatz (Generation 5) and hierarchical ladder (Generation 7) incorporated CRY, CRZ, CNOT layers and cascaded couplings, boosting gate counts to 300 and 252 yet yielding lower raw scores (0.97 and 0.96). The complexity did not translate into better generalization.  

- Aggressive parameter sharing without topology tuning  
  – Although Generation 2 reduced parameters to 74 via key-based sharing, its performance plateaued (0.98). Sharing alone cannot substitute for an appropriately connected entanglement pattern.  

## Implementation Insights

- ANSATZ_SPEC-driven block instantiation  
  – Defining each block as a list of dicts (gates, wires, param keys) and using `validate_ansatz_spec` plus a `key_to_position` map in `apply_ansatz_block` yields clear, extensible code where adding/removing gates is trivial and validated automatically.  

- Separation of circuit vs. readout parameters  
  – Splitting N_CIRCUIT_PARAMS from the two readout parameters (gain, bias) simplifies both the QNode signature and calibration step, facilitating stable convergence and easy monitoring of end-to-end gradient flow.  

- Modular feature re-upload loop  
  – The fixed outer loop over `N_UPLOADS` calling a standalone `feature_map` ensures consistent encoding of all 28 binary features. Coupling this with repeats over ansatz blocks ensures that expressivity scales linearly with re-uploads.  

- Efficient batching with wrap-around indexing  
  – The `_batch_indices` function’s modulo logic guarantees uniform mini-batches and avoids complex edge-case handling, contributing to stable Adam updates across all programs.  

## Performance Analysis

- Depth and gate count tradeoff  
  – The current best (depth 81, gate_count 228) vs. deeper designs (depth ≥ 91, gate_count ≥ 252) shows a clear correlation: lowering circuit depth while preserving full qubit connectivity yields higher combined_score_raw (0.99 vs. ≤ 0.98).  

- Parameter efficiency parity among 98-param designs  
  – Both the best program and mirror_bridge_ansatz (Gen 5) use 98 total params and achieve parameter_efficiency ≈ 0.01. However, only the circular CZ-RY pattern reached perfect test accuracy and zero gap, indicating that connectivity design, not param count alone, governs efficiency.  

- Convergence step vs. accuracy  
  – Although Generation 0 converged faster (≈ 180 steps) with slightly lower raw score (0.97), the best required ≈ 390 steps to attain perfect generalization. This suggests that modest additional training on a well-structured ansatz yields superior accuracy and robustness.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Interleave a “skip-1” CZ pattern with the existing nearest-neighbor CZs across uploads. For example, modify ANSATZ_SPEC so that upload 1 uses CZs on [(0,1),(2,3),(4,5),(6,7)] and upload 2 uses CZs on [(0,2),(1,3),(2,4),(3,5),(4,6),(5,7),(6,0),(7,1)] (or the 4 distinct skip-1 pairs). This preserves the simple RY-only parameterization and depth budget (~81) while testing whether richer second-neighbor connectivity boosts expressivity without raising param count.  

2. Diversify single-qubit rotations by alternating RX and RY gates in every other block. Concretely, in blocks with odd block_index replace RY on qubits [1,3,5,7] with RX (keeping the same param keys), so each block still has 8 trainable angles. This small change stays within the single-qubit rotation family that proved effective and may capture features along orthogonal axes without increasing total parameters.  

3. Rebalance the feature re-upload vs. ansatz repeat ratio to probe expressivity trade-offs: switch to N_UPLOADS=2 and N_REPEATS=3 while maintaining total circuit depth ≈81. Adjust the training loop and N_PARAMS so that you have two feature_map calls and three ansatz blocks per upload, keeping N_PARAMS_per_block the same. This explores whether deeper local processing per encoding outperforms more frequent uploads at fixed depth and param budget.  

4. Apply block-level parameter tying across repeats to reduce redundancy: in your ANSATZ_SPEC, rename the param keys in the second repeat of each upload to exactly match the first repeat’s keys (e.g. “ry_a0” → “ry_a0” instead of “ry_b0”). This halves the unique parameter count per upload (from 16→8), testing if weight sharing combined with the circular CZ topology retains perfect generalization while boosting parameter efficiency.  

5. Insert a lightweight shared RZ phase layer after each two-CZ segment within a block. For instance, after the first pair of CZs in each block append eight RZ gates on wires 0–7 all tied to a single parameter key “rz_shared.” This adds only one extra trainable parameter per block and may enrich global phase flexibility, leveraging the success of simple single-qubit rotations without the overhead of full two-qubit parametrization.
