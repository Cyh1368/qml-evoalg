<DESCRIPTION>
Replace the seed block (which uses 24 distinct trainable parameters per block: RY + RZ(pre) + RZ(post) on all 8 qubits) with a leaner but more expressive block:
- Keep full local expressivity using an RX layer (8 params) + a RZ layer (8 params).
- Add a small number of parametrized controlled-phase gates (4 CRZ params) to create trainable, feature-dependent correlations.
- Keep additional fixed CZ entangling across non-adjacent pairs to increase interaction pathways without increasing parameter count.

This reduces total parameters from 146 to 122 while adding trainable multi-qubit structure, which typically improves validation/test accuracy and lowers the train–test gap under re-uploading.
</DESCRIPTION>
