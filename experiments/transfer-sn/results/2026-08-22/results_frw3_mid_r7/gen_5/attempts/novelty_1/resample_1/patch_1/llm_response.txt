<DESCRIPTION>
This edit keeps the ansatz at the same parameter budget as the current winner, but makes it more expressive by breaking the global qubit symmetry into even/odd sublattices and by replacing the purely diagonal entangling scaffold with a mixed CZ/CNOT pattern.

Why this should help:
- The current block uses the same angle on all 8 qubits, which is very parameter-efficient but can underfit subtle class structure.
- Even/odd parameter sharing adds just enough asymmetry to capture localized correlations without inflating the model.
- Interleaving CNOT with CZ gives both phase entanglement and amplitude mixing, which is often beneficial when the data map is phase-based and the readout is in the Z basis.
- The gate count stays compact and the number of trainable parameters per block remains 4, so the model should preserve the strong generalization and optimization behavior while improving fit.

ANSATZ_SPEC = []

# Parity-resolved input mixer: keep the model compact, but break the fully
# global symmetry so even/odd sublattices can specialize.
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RY", "wire": q, "param": f"ry_in_{q % 2}"})

# Mixed entangling scaffold: alternating phase and amplitude mixing on a
# cube-like 8-qubit topology. The disjoint matchings preserve shallow depth.
for a, b in [(0, 1), (2, 3), (4, 5), (6, 7)]:
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})

for a, b in [(1, 2), (3, 4), (5, 6), (7, 0)]:
    ANSATZ_SPEC.append({"gate": "CNOT", "wires": [a, b]})

for a, b in [(0, 4), (1, 5), (2, 6), (3, 7)]:
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})

# Output mixer: parity-specific RX layers improve readout expressivity while
# keeping parameter count low.
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RX", "wire": q, "param": f"rx_out_{q % 2}"})
