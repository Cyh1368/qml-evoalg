<DESCRIPTION>
The current design uses fully shared (collective) parameters for all rotations, giving only 4 unique params per block. While this provides excellent regularization, it limits expressivity since different qubits encode different features via IsingZZ. 

The key change: replace the collective RZ with per-qubit independent RZ rotations, and add per-qubit RY rotations after the entangling layer. This allows each qubit to independently adjust its phase response to its specific feature encodings while keeping shared input/output RY layers for regularization. The parameter count grows modestly (4→14 per block, 26→86 total), preserving good generalization while boosting accuracy.
</DESCRIPTION>

ANSATZ_SPEC = []

# Collective input RY mixer — shared for regularization
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RY", "wire": q, "param": "collective_ry_in"})

# Per-qubit RZ: each qubit tunes its phase response to its own IsingZZ features
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": q, "param": f"rz_{q}"})

# Hypercube entangler — three disjoint perfect matchings
for a, b in [(0,1),(2,3),(4,5),(6,7)]:
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})
for a, b in [(0,2),(1,3),(4,6),(5,7)]:
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})
for a, b in [(0,4),(1,5),(2,6),(3,7)]:
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})

# Per-qubit RY after entangling: breaks symmetry per qubit
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RY", "wire": q, "param": f"ry_mid_{q}"})

# Collective output RY + RX — shared to regularize readout
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RY", "wire": q, "param": "collective_ry_out"})
for q in range(8):
    ANSATZ_SPEC.append({"gate": "RX", "wire": q, "param": "collective_rx_out"})
