<DESCRIPTION>
This update replaces the fully uniform block with a parity-aware “checkerboard” mixer that is lighter but more expressive in the right places.

Key ideas:
- Keep parameter sharing strong to preserve generalization and parameter efficiency.
- Split the input and output mixers into even/odd wire groups so the circuit can learn asymmetric structure without exploding the parameter count.
- Replace the all-CZ entangling scaffold with a CZ + CNOT ladder, which is better suited for converting the fixed ZZ feature-map phases into measurable Z-basis signal.
- Remove redundant full-width single-qubit layers and reduce gate count per block substantially, which should help the combined score while keeping the ansatz trainable.

This keeps the fixed architecture intact and only changes ANSATZ_SPEC, as required.
</DESCRIPTION>
