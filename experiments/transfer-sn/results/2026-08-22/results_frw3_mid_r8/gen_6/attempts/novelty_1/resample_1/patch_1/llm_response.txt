<DESCRIPTION>
The current program achieves excellent results with only 26 parameters and a tiny generalization gap (0.01). To improve further, I'll increase expressive capacity while maintaining parameter efficiency through shared parameterization.

The key insight is that the current collective parameter sharing acts as a strong regularizer. By adding a layer of parametrized controlled rotations (CRZ) with shared parameters applied strategically in the entangling region, we can:

1. Increase expressivity to handle more complex feature interactions
2. Maintain the regularization benefit of parameter sharing
3. Keep the total parameter count reasonable (26 → ~32 parameters)
4. Preserve the small generalization gap

The new block structure:
- Collective RY input mixing
- Collective RZ phase adjustment  
- New: CRZ parametrized entanglement with shared parameter (breaks the fixed CZ-only layer)
- Original CZ cube structure
- Second collective RZ layer (additional refinement)
- Collective RY/RX output mixing

This adds two new unique parameters per block (collective_crz, collective_rz_mid) while keeping most of the parameter sharing that prevents overfitting.
</DESCRIPTION>
