<DESCRIPTION>
The current ansatz uses globally collective parameters (4 per block), which highly restricts the model's capacity and forces it to treat all features and qubits identically. The model achieves good generalization but underfits slightly (0.90 accuracy). 

To increase representational capacity without causing overfitting, we assign **independent parameters** for the input `RY` layer (`ry_in_0` to `ry_in_7`). This breaks spatial symmetry immediately after the feature map, allowing the model to uniquely weight the signal encoded on each qubit. 

For the deeper rotation layers (`RZ`, `RY_out`, `RX_out`), we introduce a **bipartite parameter sharing scheme**. The 8-qubit hypercube entangler perfectly forms a bipartite graph with two sets: A = {0, 3, 5, 6} and B = {1, 2, 4, 7}. Every `CZ` gate exactly connects a qubit from Set A to a qubit from Set B. By assigning shared parameters `*_A` and `*_B` based on this topological coloring, we gracefully maintain the hypercube's symmetry while doubling the expressivity of the deeper layers. This balanced approach raises the parameters from 26 to 86, allowing the model to fit better while avoiding the severe overfitting seen in previous ~150+ parameter variants.
</DESCRIPTION>
