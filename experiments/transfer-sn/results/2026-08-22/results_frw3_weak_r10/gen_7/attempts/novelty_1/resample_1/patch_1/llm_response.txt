<DESCRIPTION>
The current ansatz block is extremely parameter-efficient (only 4 shared rotation parameters per block), which yields low train-test gap but caps expressivity. To improve accuracy without exploding parameter count, this rewrite increases parameter diversity in a structured way:
- Replace fully collective rotations with **grouped** single-qubit rotations (4 groups → shared parameters within each group).
- Keep the entangling structure **fixed** using a cube/brickwork-like CZ pattern for efficient mixing.
- Add a small number of **parametrized entanglers** using CRZ on disjoint edges (to make pairwise correlations trainable while limiting parameters).
- Use a final grouped RZ to add phase fine-tuning before measurement.

This targets better validation/test accuracy and lower L2 by giving the optimizer additional controlled degrees of freedom, while maintaining moderate parameter efficiency (far below the large-parameter seed baselines).
</DESCRIPTION>
