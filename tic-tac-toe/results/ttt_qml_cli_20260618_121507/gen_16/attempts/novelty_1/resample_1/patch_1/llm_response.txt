<DESCRIPTION>
The current ansatz shares a single parameter across all 8 perimeter CRY gates, all 4 center-aggregator CRY gates, and all 4 center-broadcast CRY gates. While symmetry-inspired, this over-sharing severely limits expressivity (train accuracy is only 0.43, indicating underfitting). The key insight from the prior programs is that distinguishing the perimeter segments by *direction* (endpoint→mid vs mid→endpoint) and adding a pre-entanglement phase layer raised expressivity.

This edit:
1. Splits the single perimeter `cry_pair_to_edge` into two directional families (endpoint→mid and mid→endpoint), giving bidirectional coupling along winning-line segments — the strongest motif from prior top circuits.
2. Adds a lightweight orbit-shared RZ pre-entanglement phase layer (only 3 params) so each qubit has a 2-axis frame before the CRY mixers, which does not commute through them (unlike a terminal RZ near a Z readout).

This adds only ~5 params per block (72 → ~102 total), keeping us within the gate budget while substantially raising expressivity to close the underfitting gap.
</DESCRIPTION>
