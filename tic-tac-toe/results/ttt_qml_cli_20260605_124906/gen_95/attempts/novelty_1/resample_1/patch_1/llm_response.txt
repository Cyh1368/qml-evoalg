</NAME>

<DESCRIPTION>
Split hub entanglement into per-edge parameters to increase expressivity. Previously, center-to-edge CRX/CRY gates used shared parameters across opposite edges (edges 1 with 5, edges 3 with 7). This change assigns separate parameters hub_crx_1, hub_crx_5, hub_cry_3, hub_cry_7 for the four center-edge gates, enabling more flexible entangling patterns while still respecting adjacency constraints. This increases per-block parameter count slightly but can improve fits and generalization by providing more nuanced hub coupling patterns.
</DESCRIPTION>

</NAME>

<DESCRIPTION>
Further increase expressivity by assigning distinct parameters to each center-to-edge hub gate. This decouples the CRX gate on CENTER-1 from CENTER-5 and the CRY gate on CENTER-3 from CENTER-7, enabling edge-pair-specific entangling strengths while preserving adjacency constraints. This change increases the per-block parameter count and depth modestly but offers potential gains in validation/test performance and generalization.
</DESCRIPTION>
