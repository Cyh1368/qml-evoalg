2. **Evidence from prior runs**: The second prior program (score 0.60) used CRX on the ring and CRY on the hub, achieving +0.03 improvement over the first (score 0.57). This suggests that axis diversity in two-qubit gates helps. The current program (score 0.57) uses CRY on ring and CRX on hub—a reversal. Adding CRZ on the ring after CRX hub should provide similar synergistic benefits.

3. **Parameter efficiency**: By sharing a single "crz_ring" parameter across all 8 ring edges, we add only 1 parameter per block (6 total with 3 uploads × 2 repeats), maintaining a lean parameter budget while enriching the expressivity.

5. **Placement**: CRZ is placed immediately after the CRX hub layer (Layer 4.5), before the post-entanglement RZ rotations. This preserves the symmetry structure and allows the phase correlations to interact with the final single-qubit rotations.
