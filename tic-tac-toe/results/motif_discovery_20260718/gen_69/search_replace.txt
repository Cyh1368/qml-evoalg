<DESCRIPTION>
Replace the original CRZ-heavy entangling layer with fixed CZ entanglement across the grid edges and concentrate the trainable multi-qubit motif on the actual winning lines. Rationale:

- Fixed CZs provide stronger, parameter-free entangling connectivity across the board so feature information can propagate without increasing parameter count; this often improves generalization by reducing overfitting to entangling-phase parameters.
- Replacing the ring/shared CRZs with fixed CZs frees up capacity in the parameter budget. I reallocate that capacity by placing a single shared CCRZ parameter across all eight winning lines, letting the ansatz directly condition multi-qubit rotations on the canonical tic-tac-toe lines (controls on the outer cells, target the middle cell of each line). This focuses trainable nonlocal interactions on the geometry relevant to the task.
- Keep the lightweight symmetry-grouped single-qubit rotations upfront and the symmetry-grouped post-RZ rotations for phase flexibility.
- Keep ZZZ motifs grouped by geometric category (rows/cols/diagonals) so collective Z rotations still capture parity-like features of lines.
- Overall this lowers the per-block parameter count (reducing overfitting risk) while increasing entangling expressivity targeted at winning lines, which should improve test accuracy and reduce train-test gap.

All gates remain within the allowed vocabulary and two-qubit gates only use adjacent grid edges.
</DESCRIPTION>
