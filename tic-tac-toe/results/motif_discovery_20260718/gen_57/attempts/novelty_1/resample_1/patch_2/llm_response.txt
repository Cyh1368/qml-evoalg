<DESCRIPTION>
Modest, targeted changes to the ansatz to improve expressivity where it helps and reduce redundant trainable entangling parameters:

- Add symmetry-grouped RX rotations (rx_corner, rx_edge, rx_center) after the existing RY rotations. This provides an extra rotation axis per symmetry class with only three extra parameter keys per block, improving local expressivity and trainability.
- Replace the parametrized outer-ring CRZ entanglers with fixed CZ gates to preserve entangling connectivity but remove a repeated shared trainable parameter (crz_ring) that can add optimization noise across many repeated edges.
- Split the single shared zzz_row parameter into three per-row parameters (zzz_row_0/1/2) so each physical row can specialize to its local winning motif, while keeping columns and diagonals grouped to limit parameter growth.
- Keep center-edge CRZs, CCRZ triples, and post-RZ symmetry-grouped rotations unchanged.

Rationale: the RX additions increase local rotation freedom (helpful for classification) with minimal parameter cost; fixed CZs maintain entanglement while reducing optimizer burden; splitting the row ZZZs allows targeted motif specialization likely beneficial for tic-tac-toe structure without drastically increasing parameter count.
