<DESCRIPTION>
Replace the original ansatz block with a motif-aware, parameter-efficient block that:
- Keeps symmetry-grouped single-qubit rotations (RY and post RZ) to reduce parameter count and encourage translation symmetry.
- Replaces the fixed CZ backbone with trainable CRZ couplings on the ring and separate trainable CRZs to the center. This lets the optimizer tune entangling strength rather than fixing it.
- Splits three-qubit ZZZ motifs into row/column/diagonal shared parameters so the circuit can detect line-like patterns with fewer parameters.
- Splits doubly-controlled RZ (CCRZ) center-involving triples into two parameter types: ccrz_edge_center (edge–edge–center triples) and ccrz_diag_center (corner–corner–center triples). This follows the suggested motif split and tests different geometry-dependent line weights without blowing up parameter count.

The block intentionally removes the pre-RZ layer (keeping only post-RZ) to reduce parameters. The resulting block uses 13 unique parameter keys -> 13 * N_UPLOADS(3) * N_REPEATS(2) = 78 total parameters, matching a well-performing prior variant while adding targeted motif structure (row/col/diag ZZZ + split CCRZ). This balances expressivity, motif specificity, and parameter efficiency to improve validation/test accuracy and reduce generalization gap.
</DESCRIPTION>
