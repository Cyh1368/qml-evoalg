<DESCRIPTION>
The current program uses a fixed FEATURE_SCALE (2π/3) for all qubits during feature encoding. The recommendation proposes introducing learnable feature-scaling parameters per symmetry orbit (corners, edges, center) to allow the circuit to adaptively control how strongly input information is injected into each region of the grid.

**Rationale:**
1. **Adaptive information injection**: Different board regions (corners, edges, center) may benefit from different feature-encoding strengths. Corners and edges encode player moves, while the center qubit is used for the draw classification. Learnable per-orbit scaling lets the circuit discover optimal encoding strengths.

2. **Parameter efficiency**: Instead of adding 9 independent parameters (one per qubit), we add only 3 (one per orbit), keeping the per-block parameter budget at 13 (matching the current 78 total params across 6 blocks).

3. **Symmetry-aware design**: The scaling parameters respect the grid's 4-fold rotational symmetry, aligning with the existing parameter-sharing strategy.

4. **Early correlation buildup**: Adaptive feature scaling can accelerate the formation of useful correlations in early layers by allowing the optimizer to tune how much input signal reaches each qubit type.

**Implementation:**
- Add three new trainable parameters: `feat_corner`, `feat_edge`, `feat_center` to PARAMETER_KEYS_PER_BLOCK.
- Modify `feature_map()` to apply these learned scales: `qml.RX(feat_zone * FEATURE_SCALE * board[..., wire], wires=wire)` for each orbit.
- To maintain 13 params/block, merge the final rotation keys: collapse `rot_edges` and `rot_center` into `rot_others` (already done in current code, so no change needed there).
- The feature-scaling parameters are initialized uniformly in [-0.05, 0.05] like other parameters, allowing the optimizer to learn optimal scales during training.

This change is minimal, non-invasive, and directly addresses the recommendation to improve early-stage learning dynamics and parameter efficiency.
</DESCRIPTION>

def feature_map(board: np.ndarray, feature_scales: dict | None = None) -> None:
    """Encode cell values -1, 0, +1 as equidistant Pauli-X rotations.

    Accepts either a single board (shape (N_QUBITS,)) or a batch of boards
    (shape (B, N_QUBITS)); ``board[..., wire]`` broadcasts over the leading
    batch dimension so the whole batch executes as one statevector op.
    
    If feature_scales is provided, applies learned per-orbit scaling factors.
    Otherwise uses the fixed FEATURE_SCALE for all qubits.
    """
    # Default to uniform scaling if not provided
    if feature_scales is None:
        feature_scales = {
            FEATURE_SCALE_CORNERS: 1.0,
            FEATURE_SCALE_EDGES: 1.0,
            FEATURE_SCALE_CENTER: 1.0,
        }
    
    for wire in range(N_QUBITS):
        if wire in CORNERS:
            scale = feature_scales.get(FEATURE_SCALE_CORNERS, 1.0)
        elif wire in EDGES:
            scale = feature_scales.get(FEATURE_SCALE_EDGES, 1.0)
        else:  # CENTER
            scale = feature_scales.get(FEATURE_SCALE_CENTER, 1.0)
        qml.RX(scale * FEATURE_SCALE * board[..., wire], wires=wire)
