<DESCRIPTION>
Introduce modest, targeted architectural enhancements to improve expressivity while keeping parameter growth controlled.

Key changes:
- Replace fixed CZ entangling edges with parametrized CRX entangling rotations separated into two shared parameters: crx_ring (for the ring edges) and crx_hub (for the hub edges). This gives the optimizer tunable entanglement strength for ring vs center couplings, helping separate draw vs win patterns.
- Add a lightweight RX layer (shared by symmetry classes) before entangling to enrich single-qubit rotations (more expressive single-qubit Bloch coverage) without exploding parameter count.
- Replace multiple per-wire pre-RZs with a single shared rz_global applied to all wires to add a global phase flexibility with minimal parameters (regularizing).
- Use symmetry-aware split final mixing: a periphery pair (ry_out_periphery, rz_out_periphery) and a center pair (ry_out_center, rz_out_center), as recommended, to allow the center qubit to be tuned separately for draw-vs-win discrimination.
- Maintain class-sharing for corner/edge/center groups to keep parameter efficiency and exploit board symmetries.

This produces a moderate parameter increase (to 13 params per block -> 78 total for N_UPLOADS=3, N_REPEATS=2) while providing tunable entanglement and richer local rotations. The design emphasizes symmetry-aware sharing to reduce overfitting risk and improve generalization.
</DESCRIPTION>
