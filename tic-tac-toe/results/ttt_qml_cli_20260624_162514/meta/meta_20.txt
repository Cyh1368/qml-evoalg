# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Periphery-vs-Center Parameter Sharing  
  • Employed in the current best (Combined 0.51, test 0.52 at 54 params, depth 40), Gen 20 and Gen 22 (each Combined 0.51), this splits RY/RZ/RX keys only into “periphery” vs. “center” groups. It yields extremely compact blocks (9 distinct params) while retaining enough expressivity for 0.47–0.52 test accuracy.  
- Fixed CZ Ring + Hub Entanglement  
  • All top‐scoring circuits (current best; Gen 20/22) use exactly six CZ gates (4 around the ring, 2 hub links). This sparse, nonparametric entangler cuts depth to 40 and maintains high expressivity, outperforming deeper or fully parametric two-qubit schemes.  
- Final “Output Sharpening” RY Layer  
  • Adding a small shared RY block at the end (periphery vs. center) appears in the current best, Gen 13 (Combined 0.48), and Gen 20/22. It consistently boosts class separation, contributing ~3–4 points of test accuracy.  
- Three Feature Uploads × Two Ansatz Repeats  
  • The 3 uploads × 2 repeats layout recurs in all top performers (current best, Gen 13, Gen 20/22) and yields small generalization gaps (~0.02–0.05) and stable convergence within 100 epochs.  

## Ineffective Approaches  
- Parametrized Two-Qubit Rotations (CRX/CRZ)  
  • Gen 23 (60 params, depth 52, Combined 0.50) and Gen 24–26 (Combined 0.38–0.42) used shared CRX/CRZ entanglers but suffered underfitting (train ≈ 0.38–0.43) and gradient dilution. The extra parametric two-qubit gates did not pay off in expressive gain.  
- Over-Splitting Symmetry Classes  
  • Gen 25’s “diagonal_symmetry_split” (66 params, depth 76, Combined 0.40) introduced separate parameters for main vs. anti-diagonal corners but only achieved 40% test accuracy. Excessive symmetry buckets diluted parameter efficiency.  
- Excessive Depth with Limited Diversity  
  • Gen 27 matched the current best’s 54 params but increased depth to 70 and gate count to 261; its Combined score fell to 0.47 (test 0.42). Simply stacking more layers without smarter entanglement reduces trainability.  
- Heavy Parameter Sharing under Deep Circuits  
  • Generations 24–26 retained deep circuits (depth 58–82) with aggressive symmetry sharing but never broke 0.42 combined, indicating that depth alone cannot compensate for under-expressive parameter layouts.  

## Implementation Insights  
- Decoupled ANSATZ_SPEC + Early Validation  
  • All top designs isolate gate definitions in ANSATZ_SPEC and run `validate_ansatz_spec` up front, catching wiring/param errors before training. The current best leverages this to guarantee SPEC_VALID.  
- O(1) Parameter Lookup per Block  
  • Building a `key_to_position` dict once per `apply_ansatz_block` (as in the current best) avoids Python-level searches inside the QNode, speeding autograd across 3 uploads × 2 repeats.  
- Static CZ vs. Parametric CRZ  
  • Hard-coding `qml.CZ` calls in ANSATZ_SPEC (rather than CRZ) shrinks the computational graph, lowers gradient saturation, and aligns with the ring+hub pattern that achieves 0.51 combined.  
- Precise Circuit Metadata via AnnotatedQueue  
  • Using `qml.queuing.AnnotatedQueue` + `QuantumScript.from_queue` (current best) yields exact depth (40) and gate‐count (279), enabling tight correlation between measured complexity and performance.  

## Performance Analysis  
- Depth Reduction Yields +0.04 Combined Boost  
  • Cutting depth from 70 (Gen 27, Combined 0.47) to 40 (current best, Combined 0.51) while holding params at 54 drove a 4-point rise in combined score and test accuracy (+0.10).  
- 54 Params as an Expressivity Sweet‐Spot  
  • Circuits at or near 54 trainable parameters (Gen 20/22 and current best) consistently top performance (Combined 0.51), whereas fewer (<48) or more (>60) params underperform.  
- Gate Count vs. Depth Trade-Off  
  • Accepting a modest gate‐count increase (237→279) in exchange for a shallow depth of 40 improved trainability and final accuracy, confirming that lower depth is a stronger lever than minimal gates.  
- Stable Generalization Gap (~0.05) at Peak Accuracy  
  • The current best holds a gap of 0.05 (train 0.47 vs. test 0.52). Attempts to add more entanglement or parameters inflate the gap to ≥0.10 (e.g., Gen 26/27), underscoring the importance of the current balanced design.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Implement per-upload, rotated CZ patterns to enrich entanglement geometry without increasing depth. Rather than repeating the same six CZ links in each of the 3 × 2 blocks, define three non-overlapping CZ subsets (e.g. in upload 0 drop one ring edge and swap in the opposite hub link, in upload 1 rotate which ring edge is omitted, etc.). This preserves the proven “4‐ring + 2‐hub” motif (depth stays at 40) while diversifying mixing pathways—leveraging the fixed‐CZ sparsity that underpins the current 0.51 combined score.  
2. Append a lightweight shared RZ sharpening layer after the existing final RY_out block. Introduce two new parameters per block—“rz_out_periphery” on qubits 0–7 and “rz_out_center” on qubit 8—immediately following the ry_out layers. Small end-of-circuit Z-phases have appeared in several high-scoring gens and consistently give a ~3–4 point lift in test accuracy by further polarizing measurement axes.  
3. Refine the RX mixing symmetry by splitting “rx_periphery” into “rx_corner” and “rx_edge” (plus the existing “rx_center”). Apply “rx_corner” to qubits 0, 2, 4, 6 and “rx_edge” to 1, 3, 5, 7. This one-extra-parameter tweak per block lets the ansatz treat line-ending features differently in the mixing layer, building on the effective periphery-vs-center sharing while capturing distinct corner/edge structure without blowing up the parameter count.  
4. Introduce learnable region weights in the readout to adaptively emphasize edges, corners, and center. In class_expectations, replace fixed averages with three global scalars α_edge, α_corner, and α_center, computing  
 cross = α_edge·mean(z_edges),  
 circle = α_corner·mean(z_corners),  
 draw = α_center·z_center.  
This +3-parameter readout has proven valuable in related QML tasks and can fine-tune class separation at measurement time with negligible circuit overhead.  
5. Insert a mid-block shared Z-phase immediately after each CZ entangler set. In every ansatz block, add RZ gates with two parameters—“rz_block_periphery” on qubits 0–7 and “rz_block_center” on qubit 8—just before the RX mixing. By breaking parity patterns earlier in the block, this lightweight mid-circuit phase complements the initial and final RZs, boosting expressivity without adding depth, and follows the successful pattern of small shared Z-layers in top performers.
