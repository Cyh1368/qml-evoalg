<DESCRIPTION>
This design preserves the proven 12-edge interaction graph while replacing only the two peripheral CZ links [1,8] and [4,8] with independently trainable CRZ gates. Unlike the earlier phase-sharing approach, it retains independent RZ parameters so each qubit can learn its own phase response. Regularization is instead applied selectively to the RY layer by sharing amplitudes across graph-related wire pairs (1,4), (2,3), and (5,6). This reduces the parameter count relative to the current program while retaining independent rotations on the structurally distinct hub wires 0, 7, and 8. The result combines controlled peripheral adaptivity with axis-selective parameter sharing, aiming to reduce overfitting without sacrificing phase expressivity.
</DESCRIPTION>
