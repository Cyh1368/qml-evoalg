The current ansatz is parameter-efficient (6 params/block, 38 total) and shallow, achieving perfect accuracy with fast convergence. However, the recommendation suggests that **alternating shared-parameter entanglers can inject richer two-qubit interactions and potentially improve convergence speed further**.

**Proposed improvement: Alternate entanglement strategy across repeats**

The key insight from the recommendation is that:
1. In **odd-indexed repeats** (1, 3, 5), keep fixed CZ chain for stability
2. In **even-indexed repeats** (0, 2, 4), replace CZ gates with parametrized IsingXX gates using shared parameters

This approach:
- Maintains the proven 6-parameter budget per block (ry_even, rz_odd, xx_even, xx_odd, zz_01, zz_23)
- Introduces richer, more flexible two-qubit interactions in even repeats
- Provides natural alternation between fixed (CZ) and learned (XX) entanglers
- Can improve convergence by giving the optimizer more diverse interaction types
- Should reduce convergence steps by offering better gradient flow through varied entanglement

The modification aligns with the observation that IsingXX gates (proved in prior generations) can speed up convergence when mixed with fixed connectivity patterns.

def apply_ansatz_block(params, block_index: int) -> None:
    """Apply one candidate ansatz block from the formal ANSATZ_SPEC.
    
    For even repeats, apply parametrized XX entanglers; for odd repeats,
    apply fixed CZ chain instead to allow learning of XX parameters.
    """
    if SPEC_ERRORS:
        raise ValueError("; ".join(SPEC_ERRORS))

    offset = block_index * N_PARAMS_PER_BLOCK
    key_to_position = {key: i for i, key in enumerate(PARAMETER_KEYS_PER_BLOCK)}
    is_even_repeat = (block_index % 2 == 0)
    
    for item in ANSATZ_SPEC:
        gate = str(item["gate"]).upper()
        if gate in ALLOWED_SINGLE_QUBIT_GATES:
            angle = params[offset + key_to_position[item["param"]]]
            wire = int(item["wire"])
            if gate == "RX":
                qml.RX(angle, wires=wire)
            elif gate == "RY":
                qml.RY(angle, wires=wire)
            elif gate == "RZ":
                qml.RZ(angle, wires=wire)
        elif gate in ALLOWED_TWO_QUBIT_GATES:
            wires = [int(w) for w in item["wires"]]
            if gate == "CNOT":
                qml.CNOT(wires=wires)
            elif gate == "CZ":
                qml.CZ(wires=wires)
        elif gate in ALLOWED_PARAM_TWO_QUBIT_GATES:
            # For XX gates in ANSATZ_SPEC: apply in even repeats, use CZ in odd repeats
            if gate == "XX":
                if is_even_repeat:
                    angle = params[offset + key_to_position[item["param"]]]
                    wires = [int(w) for w in item["wires"]]
                    qml.IsingXX(angle, wires=wires)
                else:
                    # Odd repeats: use fixed CZ chain instead
                    wires = [int(w) for w in item["wires"]]
                    qml.CZ(wires=wires)
            else:
                angle = params[offset + key_to_position[item["param"]]]
                wires = [int(w) for w in item["wires"]]
                if gate == "CRX":
                    qml.CRX(angle, wires=wires)
                elif gate == "CRY":
                    qml.CRY(angle, wires=wires)
                elif gate == "CRZ":
                    qml.CRZ(angle, wires=wires)
                elif gate == "YY":
                    qml.IsingYY(angle, wires=wires)
                elif gate == "ZZ":
                    qml.IsingZZ(angle, wires=wires)
