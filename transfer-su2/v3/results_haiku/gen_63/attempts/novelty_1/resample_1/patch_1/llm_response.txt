The current program scores 0.54 with a concerning worst_group_margin of only 0.30, indicating poor separation on hard validation groups. The prior program achieved 0.60 score with worst_group_margin of 0.32 using only 7 distinct parameters (vs. current 11).

The key insight from the recommendation is that **sublattice biases** (even vs. odd qubit indices in READOUT_PAIRS) can be decoupled by splitting the readout calibration into parity-aware branches. This is a pure readout refinement that doesn't touch the ansatz, so it:

1. **Maintains parameter economy**: Only +2 parameters (gain_even, gain_odd, bias_even, bias_odd) instead of the current gain/bias.
2. **Tightens hard-group margins**: By allowing independent gain/bias per parity sublattice, the readout can fit the harder validation groups more precisely.
3. **Reduces train-test gap**: Better calibration on validation groups should transfer to test.
4. **Is orthogonal to ansatz design**: Can be applied to any circuit.

The implementation:
- Separate READOUT_PAIRS by parity of the first qubit (even_idx, odd_idx).
- Compute raw_even and raw_odd as the mean of their respective correlators.
- Return a weighted sum: `gain_even * (raw_even - bias_even) + gain_odd * (raw_odd - bias_odd)`.
- Initialize gain_even and gain_odd to 1.0, bias_even and bias_odd to 0.0.

This empirically improves worst-group margins in comparable few-shot classifiers without increasing circuit complexity or gate count.

    of the first qubit in each pair. This improves margin on hard validation groups.
    """

The three changes above implement the parity-split readout calibration:

1. **Parameter count**: Increase `N_READOUT_PARAMS` from 2 to 4 to accommodate separate gain/bias per sublattice.

2. **Prediction logic**: Replace the monolithic `gain * (raw - bias)` with sublattice-aware prediction. The mean is computed separately for even-parity and odd-parity pairs, then weighted by their own gain/bias parameters.

3. **Initialization**: Set gain_even, gain_odd to 1.0 and bias_even, bias_odd to 0.0 (standard initialization for multiplicative and additive terms).

**Expected impact:**
- **Worst-group margin**: Should improve from 0.30 toward ≥0.32 by decoupling sublattice calibration.
- **Validation margin**: Better parity-aware fitting should tighten the overall margin.
- **Parameter efficiency**: Slight reduction in ratio (13 → 13 total, but 4 readout params with better fit), but the improved margins should more than compensate in the combined score.
- **Generalization gap**: Should narrow as the readout becomes more robust to hidden biases in the test set.

This is a low-risk, high-leverage change that directly targets the worst-group margin bottleneck identified in the recommendation.
