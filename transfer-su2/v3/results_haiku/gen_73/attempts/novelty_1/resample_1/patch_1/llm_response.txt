<DESCRIPTION>
The current readout uses a single global gain and bias applied to the mean of all two-qubit correlators. However, the two-qubit observable may exhibit different behavior on even- vs. odd-indexed pairs, or on pairs with even vs. odd qubit indices. By introducing separate calibration parameters for even and odd parity groups of correlators, we can better capture parity-specific structure in the measurement outcomes.

This is a +2-parameter tweak (N_READOUT_PARAMS: 2 → 4) that provides fine-grained calibration without modifying the ansatz core. The empirical evidence from the recommendation and prior work suggests this can lift worst-group margins significantly, particularly on harder samples, which is exactly what the scoring metric prioritizes (worst-group margin is the dominant term).

Implementation:
1. Increase N_READOUT_PARAMS to 4 and define parity-specific names: gain_even, bias_even, gain_odd, bias_odd.
2. Modify predict_batch to compute separate means for even- and odd-indexed correlators and blend them with their respective calibrations.
3. Adjust initialization in run_experiment to set the four readout parameters appropriately.

This maintains parameter economy in the ansatz while improving measurement fidelity on heterogeneous data.
</DESCRIPTION>

def predict_batch(params, x_batch: np.ndarray):
    """Scalar prediction per state: parity-aware calibrated mean of the fixed correlators."""
    circuit_params = params[:N_CIRCUIT_PARAMS]
    gain_even = params[N_CIRCUIT_PARAMS]
    bias_even = params[N_CIRCUIT_PARAMS + 1]
    gain_odd = params[N_CIRCUIT_PARAMS + 2]
    bias_odd = params[N_CIRCUIT_PARAMS + 3]
    states = pnp.array(np.asarray(x_batch, dtype=complex), requires_grad=False)
    z = pnp.stack(circuit_pair_expectations(states, circuit_params))  # (n_pairs, B)
    # Separate even and odd indexed correlators
    z_even = z[::2, :]  # even indices: 0, 2, 4, ...
    z_odd = z[1::2, :]  # odd indices: 1, 3, 5, ...
    raw_even = pnp.mean(z_even, axis=0) if z_even.shape[0] > 0 else 0.0
    raw_odd = pnp.mean(z_odd, axis=0) if z_odd.shape[0] > 0 else 0.0
    return gain_even * (raw_even - bias_even) + gain_odd * (raw_odd - bias_odd)
