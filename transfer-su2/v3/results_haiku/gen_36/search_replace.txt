## Rationale

This approach encodes all three block variants directly into ANSATZ_SPEC within the EVOLVE-BLOCK. Since `apply_ansatz_block` is called 3 times and applies the entire ANSATZ_SPEC each time, we now have:

1. **First repetition (block_index=0):** Applies rotation_layer + entanglement(offset=0) + phase_layer
2. **Second repetition (block_index=1):** Applies rotation_layer + entanglement(offset=1) + phase_layer
3. **Third repetition (block_index=2):** Applies rotation_layer + entanglement(offset=2) + phase_layer

**Benefits:**
- **No parameter increase:** Still uses 7 distinct parameters (ry_even, ry_odd, xx_near, yy_diag, zz_diag, rz_even, rz_odd)
- **Breaks 3× symmetry:** Each repetition has different two-qubit connectivity while sharing single-qubit gates and parameters
- **Improves worst-case margin:** Cyclic pattern diversity acts as regularization, forcing robustness to different entanglement topologies
- **Better generalization:** Hard samples are separated more reliably when features must work across diverse connectivity patterns
- **Compatible:** No changes needed to the fixed training loop or apply_ansatz_block function
