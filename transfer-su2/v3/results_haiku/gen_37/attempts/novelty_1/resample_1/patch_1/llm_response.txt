Looking at the performance metrics:

**Prior programs (better performing):**
- Program 1: score 0.60, validation_accuracy 0.97, test_accuracy 0.96, n_params 9, n_distinct_params 7
- Program 2: score 0.56, validation_accuracy 0.93, test_accuracy 0.87, n_params 10, n_distinct_params 8

**Current program (underperforming):**
- score 0.43, validation_accuracy 0.80, test_accuracy 0.77, n_params 11, n_distinct_params 9
- High generalization gap (0.23), large validation_loss (0.57), worst_group_margin only 0.30

**Key observations:**

1. The current program has MORE parameters (11 vs 9) but WORSE performance - parameter count is clearly hurting the score
2. The second prior program achieved better scores with 7 distinct parameters by using aggressive parameter sharing
3. The current program over-parameterized the ZZ layer (zz_04, zz_26, zz_15) instead of sharing, which increased complexity without benefit
4. The validation accuracy dropped from 0.97 to 0.80 - the extra parameters are overfitting on the tiny training set
5. The worst_group_margin is stuck at 0.30, indicating poor separation of hard samples

**Recommendation:**

Implement **layer-wise cyclic rotation of two-qubit gates** (as suggested in the prompt), combined with **maximal parameter sharing**. This breaks the 3× repetition symmetry while keeping parameter count LOW. The three block variants will apply the same gate types but with wiring rotated by +1 qubit modulo 8 across layers, providing diversity without extra parameters.

This approach:
- Reduces distinct parameters by consolidating the split ZZ gates back to shared parameters
- Introduces entangler-pattern diversity across the 3 repetitions (evidence-backed regularizer)
- Maintains shallow depth while improving generalization
- Should reduce worst_group_margin overfitting through structured diversity

All single-qubit rotations (RY, RZ) remain unrotated with even/odd sharing. This introduces layer diversity (a proven regularizer) while keeping ALL parameters shared across the three blocks, reducing total distinct parameters from 9 to 6.

The key insight: varying entangler connectivity across layers helps the circuit learn robust feature representations that generalize from few examples, directly addressing the generalization gap (0.23 → target ~0.04).

def _build_block_variant(rotation: int) -> list[dict]:
    """Build an ansatz block with two-qubit gates rotated by (rotation) mod 8.
    
    rotation=0: base wiring
    rotation=1: YY and ZZ wires shifted by +1 mod 8
    rotation=2: YY and ZZ wires shifted by +2 mod 8
    
    Single-qubit gates (RY, RZ) are always applied to all qubits (no rotation).
    """
    def rotate_wire(w: int, shift: int) -> int:
        return (w + shift) % 8
    
    def rotate_pair(pair: tuple, shift: int) -> list:
        return [rotate_wire(pair[0], shift), rotate_wire(pair[1], shift)]
    
    block = []
    
    # Initial RY rotation layer (no rotation applied)
    block.extend([
        {"gate": "RY", "wire": 0, "param": "ry_even"},
        {"gate": "RY", "wire": 1, "param": "ry_odd"},
        {"gate": "RY", "wire": 2, "param": "ry_even"},
        {"gate": "RY", "wire": 3, "param": "ry_odd"},
        {"gate": "RY", "wire": 4, "param": "ry_even"},
        {"gate": "RY", "wire": 5, "param": "ry_odd"},
        {"gate": "RY", "wire": 6, "param": "ry_even"},
        {"gate": "RY", "wire": 7, "param": "ry_odd"},
    ])
    
    # Nearest-neighbor XX gates (no rotation applied)
    block.extend([
        {"gate": "XX", "wires": [0, 1], "param": "xx_near"},
        {"gate": "XX", "wires": [2, 3], "param": "xx_near"},
        {"gate": "XX", "wires": [4, 5], "param": "xx_near"},
        {"gate": "XX", "wires": [6, 7], "param": "xx_near"},
    ])
    
    # Cross-layer YY with cyclic rotation
    yy_base_pairs = [[0, 2], [1, 3], [4, 6], [5, 7]]
    for pair in yy_base_pairs:
        rotated = rotate_pair(tuple(pair), rotation)
        block.append({"gate": "YY", "wires": rotated, "param": "yy_cross"})
    
    # Long-range ZZ with cyclic rotation
    zz_base_pairs = [[0, 4], [2, 6]]
    for pair in zz_base_pairs:
        rotated = rotate_pair(tuple(pair), rotation)
        block.append({"gate": "ZZ", "wires": rotated, "param": "zz_diag"})
    
    # Final RZ rotation layer (no rotation applied)
    block.extend([
        {"gate": "RZ", "wire": 0, "param": "rz_even"},
        {"gate": "RZ", "wire": 1, "param": "rz_odd"},
        {"gate": "RZ", "wire": 2, "param": "rz_even"},
        {"gate": "RZ", "wire": 3, "param": "rz_odd"},
        {"gate": "RZ", "wire": 4, "param": "rz_even"},
        {"gate": "RZ", "wire": 5, "param": "rz_odd"},
        {"gate": "RZ", "wire": 6, "param": "rz_even"},
        {"gate": "RZ", "wire": 7, "param": "rz_odd"},
    ])
    
    return block
