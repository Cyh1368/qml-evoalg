This heterogeneity across repeats mirrors Gen 3's improved generalization from broken symmetry, without requiring a redesign of the entire apply_ansatz_block machinery.

Core idea:

- Block B uses ZZ on pairs (1,4) and (5,2) with parameter "zz_diag_b" (swapped diagonals)
- Apply sequence A–B–A across the 3 repeats
- This introduces heterogeneity while keeping ~10 distinct parameters (similar to current), but leverages the block_index parameter already passed to apply_ansatz_block to enable variant selection
- The staggered diagonal patterns break symmetry and force the optimizer to learn richer correlations across repetitions, improving separation on hard validation groups

The approach is parameter-economical (only adds 1 new parameter vs. full redesign) and preserves the overall gate structure. The diversity in entanglement patterns across repeats should improve generalization and margin robustness.

    Implements alternating A–B–A pattern for the 3 repetitions:
    - block_index 0: use ANSATZ_SPEC_A
    - block_index 1: use ANSATZ_SPEC_B
    - block_index 2: use ANSATZ_SPEC_A
    
    This breaks repetition symmetry to improve generalization.
    Parameters are shared within each variant across its usage.
    """
    if SPEC_ERRORS:
        raise ValueError("; ".join(SPEC_ERRORS))

    # Select variant based on block index: A-B-A pattern
    if block_index % 2 == 0:
        spec = ANSATZ_SPEC_A

        spec = ANSATZ_SPEC_B
