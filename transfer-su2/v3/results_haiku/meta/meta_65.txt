# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Parity-shared rotation layers with fully tied parameters across repeats  
  • Gen 63 (“lean_ansatz_revert_to_seed”) and Gen 50 achieved combined score 0.60, train 1.00, val 0.97, test 0.96, gap 0.04 using just 7 distinct circuit parameters + 2 readout.  
  • Block-level tying via dict.fromkeys + key_to_position eliminates per-block indexing and enforces identical behavior.  
- Mixed entanglement in a single shallow block  
  • Nearest-neighbor XX, cross-layer YY, diagonal ZZ in one 15-depth, 72-gate block (Gen 63) delivered high expressivity with minimal gates.  
- Decoupled readout calibration  
  • Two separate gain/bias parameters (outside ANSATZ_SPEC) stabilized margins (worst-group margin 0.32 in Gen 63) without inflating the circuit ansatz.  
- Wide uniform initialization  
  • Uniform sampling in [–π, π] plus gain=1, bias=0 (as in Gen 63) avoided optimizer dead zones and produced seed-stable convergence (~780 steps).  

## Ineffective Approaches  
- Trimming mid-circuit layers (“reduce_mid_circuit_overhead”, Gen 60)  
  • Score fell to 0.42 (val 0.82, test 0.77, gap 0.23) despite 11 parameters and depth 18—lost critical phase/entanglement expressivity.  
- Over-expanding with extra parity rotations (“mid_circuit_parity_rotations”, Gen 61/62)  
  • Score plateaued at 0.52 (val 0.87, test 0.86) with 13 parameters, depth 21, 120 gates; gap grew to 0.14—extra rotations unduly increased complexity without improving generalization.  
- Restricting entanglers to mirror-only ZZ (“add_mirror_zz_entangler”, Gen 64)  
  • Test accuracy dropped to 0.70 with gap 0.29 in a 10-parameter, 18-depth circuit—omitting nearest-neighbor XX and cross YY severely hurt performance.  

## Implementation Insights  
- JSON-style ANSATZ_SPEC + validate_ansatz_spec → clean gate listing and ordered unique parameter extraction (use dict.fromkeys). Gen 63’s 7 keys are auto-sorted, enabling full tying.  
- key_to_position inside apply_ansatz_block → direct mapping from param key → vector index; block_index is ignored, so repeats share parameters seamlessly.  
- params slicing:  
  • circuit_params = params[:N_CIRCUIT_PARAMS]  
  • gain, bias = params[N_CIRCUIT_PARAMS:],  
  isolating readout calibration fosters stable margins without altering circuit ansatz.  
- Wide initialization and explicit gain/bias seeds (gain=1, bias=0) yield reproducible, rapid convergence across seeds (~780 steps in Gen 63).  

## Performance Analysis  
- Depth vs. generalization gap:  
  • Depth 15 (Gen 50/63) → gap 0.04, test 0.96;  
  • Depth 18–21 (Gen 60/64/61/62) → gap 0.14–0.29, test 0.70–0.86.  
- Parameter count sweet spot at 9 total (7 circuit + 2 readout):  
  • Efficiency ~0.11 (Gen 63);  
  • Increasing to 10–13 parameters drops efficiency to 0.07–0.10 and lowers test accuracy by 0.10–0.25.  
- Gate count under 100 favors expressivity per parameter:  
  • 72 gates (Gen 63) → highest combined score;  
  • ≥96 gates (Gen 60) or 120 gates (Gen 61/62) → diluted parameter impact and larger gaps.  
- Entangler diversity tightly correlates with margins:  
  • Mixed XX/YY/ZZ design → worst-group margin 0.32, val margin 0.64;  
  • Limited or trimmed entanglers → margins drop below 0.43.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Expand diagonal entanglement without new parameters  
   In `_build_entanglement_layer`, after the existing ZZ entries, append  
     {"gate": "ZZ", "wires": [1, 6], "param": "diag"},  
     {"gate": "ZZ", "wires": [2, 5], "param": "diag"},  
     {"gate": "ZZ", "wires": [3, 4], "param": "diag"}  
   This mirrors Gen 50’s full anti-diagonal coupling, enriching long-range correlations with the same “diag” key, keeping N_CIRCUIT_PARAMS at 7, depth ≤ 15 and gate count under 100.

2. Insert a parity-shared mid-block rotation layer  
   Between the entanglement and phase layers in `ANSATZ_SPEC`, inject:  
     [{"gate": "RY", "wire": i, "param": f"ry_even" if i%2==0 else "ry_odd"} for i in range(8)]  
     + [{"gate": "RZ", "wire": i, "param": f"rz_even" if i%2==0 else "rz_odd"} for i in range(8)]  
   Reusing the four keys boosts local expressivity per block without adding distinct parameters, a pattern that tightened margins in earlier parity-tied mutants.

3. Cycle entangler connectivity across repeats  
   In `apply_ansatz_block`, before reading `item["wires"]`, do:  
     shift = block_index % N_QUBITS  
     wires = [(w + shift) % N_QUBITS for w in item.get("wires", [])]  
   Then apply gates on these shifted wires. This leverages full parameter tying but varies physical couplings each repeat, reducing seed-to-seed variance with zero parameter overhead.

4. Parity-specific readout calibration  
   Increase `N_READOUT_PARAMS` to 4 and rename to `gain_even`, `bias_even`, `gain_odd`, `bias_odd`. In `predict_batch`, compute separate means over even- and odd-indexed correlators and return  
     gain_even*(raw_even–bias_even) + gain_odd*(raw_odd–bias_odd)  
   This +2-param tweak has empirically lifted worst-group margins (e.g. Gen 58) without touching the ansatz core.

5. Mixed-scale initialization for entanglers  
   After drawing all N_PARAMS from Uniform(–π, π), reinitialize any parameter whose key is “ent_near”, “cross”, or “diag” by sampling Uniform(–π/4, π/4) while leaving rotations and readout at full scale. This targets Ising-block angles into a high-curvature regime, avoiding barren plateaus and restoring the ~780-step convergence seen in Gen 50/63.
