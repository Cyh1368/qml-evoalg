<DESCRIPTION>
The recommendation is to introduce deterministic "entangler dropout" in `apply_ansatz_block`. This lightweight per-repeat variation will selectively skip one two-qubit entangling gate per repetition (cycling through them), regularizing the circuit structure without adding any trainable parameters.

**Rationale:**
- The current program shows good train accuracy (1.00) but poor worst-group margin (0.22), indicating the classifier overfits to easy samples and fails on hard ones.
- Gen 9's shallow-varied blocks and the second prior program both achieved better worst-group margins (0.31, 0.33) with fewer distinct parameters and faster convergence.
- By skipping one entangler per repeat in a deterministic pattern, we:
  1. **Reduce redundancy**: Each full repetition is now slightly different, preventing the fixed three-pass from being identical.
  2. **Preserve parameter economy**: No new trainable parameters are introduced—only structural variation.
  3. **Regularize the circuit**: The circuit becomes a learnable ensemble of related sub-circuits, sharpening margin on held-out data.
  4. **Converge faster**: Fewer active gates per repeat reduce training overhead.

**Implementation:**
- Identify all two-qubit parametrized gates (XX, YY, ZZ) in `ANSATZ_SPEC` at specification time.
- In `apply_ansatz_block`, use `skip = block_index % n_entanglers` to deterministically choose which entangler to omit on each repeat.
- This creates three distinct circuit "flavours" across the three repetitions, improving generalization on hard validation groups.

def _collect_entangler_indices(spec: list[dict]) -> list[int]:
    """Collect indices of all two-qubit parametrized gates (entanglers) in ANSATZ_SPEC."""
    entanglers = []
    for idx, item in enumerate(spec):
        gate = str(item.get("gate", "")).upper()
        if gate in ALLOWED_PARAM_TWO_QUBIT_GATES:
            entanglers.append(idx)
    return entanglers


_ENTANGLER_INDICES = _collect_entangler_indices(ANSATZ_SPEC)
