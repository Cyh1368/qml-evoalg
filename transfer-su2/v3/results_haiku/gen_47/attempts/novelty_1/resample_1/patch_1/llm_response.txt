Following the recommendation, I propose introducing sublattice-specific readout calibration: separate gain/bias pairs for even-indexed and odd-indexed qubits in the readout pairs. This minimal 2-parameter extension (gain_even, bias_even, gain_odd, bias_odd) allows the model to correct systematic sublattice biases without increasing circuit complexity. This addresses the worst_group_margin gap directly by letting the readout adapt to the structure of the measurement pairs.

The change requires:
1. Expand N_READOUT_PARAMS from 2 to 4
2. Modify predict_batch to compute separate means for even/odd starting indices in READOUT_PAIRS
3. Apply sublattice-specific calibration before combining

This is orthogonal to the ansatz and can improve robustness on hard samples without additional circuit depth or gate count penalties.

def predict_batch(params, x_batch: np.ndarray):
    """Scalar prediction per state: sublattice-calibrated mean of the fixed correlators."""
    circuit_params = params[:N_CIRCUIT_PARAMS]
    gain_even = params[N_CIRCUIT_PARAMS]
    bias_even = params[N_CIRCUIT_PARAMS + 1]
    gain_odd = params[N_CIRCUIT_PARAMS + 2]
    bias_odd = params[N_CIRCUIT_PARAMS + 3]
    states = pnp.array(np.asarray(x_batch, dtype=complex), requires_grad=False)
    z = pnp.stack(circuit_pair_expectations(states, circuit_params))  # (n_pairs, B)
    
    # Separate correlators by sublattice: even if first qubit in pair is even, odd otherwise
    even_indices = [i for i, (a, b) in enumerate(READOUT_PAIRS) if a % 2 == 0]
    odd_indices = [i for i, (a, b) in enumerate(READOUT_PAIRS) if a % 2 == 1]
    
    if len(even_indices) > 0:
        raw_even = pnp.mean(z[even_indices, :], axis=0)
    else:
        raw_even = pnp.array(0.0)
    
    if len(odd_indices) > 0:
        raw_odd = pnp.mean(z[odd_indices, :], axis=0)
    else:
        raw_odd = pnp.array(0.0)
    
    # Combine sublattice predictions
    weight_even = pnp.array(len(even_indices) / max(len(READOUT_PAIRS), 1))
    weight_odd = pnp.array(len(odd_indices) / max(len(READOUT_PAIRS), 1))
    
    return (weight_even * gain_even * (raw_even - bias_even) + 
            weight_odd * gain_odd * (raw_odd - bias_odd))
