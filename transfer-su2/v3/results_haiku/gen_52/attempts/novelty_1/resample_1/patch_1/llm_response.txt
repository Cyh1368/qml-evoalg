The current program shows significant degradation compared to the seed (0.51 vs 0.60 combined score), with notably worse worst_group_margin (0.36 vs 0.32 is actually slightly better, but the test accuracy drops from 0.96 to 0.85). The key issue is overfitting to the training set (1.00 train accuracy vs 0.85 test) and poor generalization to hard samples.

The seed program uses parameter sharing across repetitions with fixed gate connectivity, which allows tied parameters to build invariant representations. However, the current program has expanded entanglement (more gates, more parameters) without the key regularization mechanism.

I propose implementing **circular shift regularization** as recommended: before applying each two-qubit gate during each repetition, cyclically shift the physical qubit indices by an amount dependent on the repeat index. This breaks layer symmetry without adding parameters—the same tied parameter acts on different qubit pairs across repetitions, forcing the optimizer to learn robust features that don't overfit to specific qubit couplings.

Mathematically, for gate wires `[a, b]` and repeat index `r`, apply to wires `[(a + r) % N_QUBITS, (b + r) % N_QUBITS]`. This:
1. Reduces overfitting by regularizing learned representations
2. Improves worst-group margin by forcing the circuit to learn more balanced decision boundaries
3. Maintains parameter economy (no new parameters)
4. Converges faster (fewer steps needed to find robust solutions)

The implementation modifies `apply_ansatz_block()` to apply the shift only to two-qubit gates, preserving single-qubit gates on fixed wires for clarity.

    Parameters are shared across repetitions: every application of the block
    reads the same values. For two-qubit gates, apply circular shift regularization:
    cyclically shift wire indices by block_index to break layer symmetry and reduce
    overfitting without adding parameters.
    """

        raise ValueError("; ".join(SPEC_ERRORS))

    key_to_position = {key: i for i, key in enumerate(PARAMETER_KEYS_PER_BLOCK)}
    for item in ANSATZ_SPEC:
        gate = str(item["gate"]).upper()
        if gate in ALLOWED_SINGLE_QUBIT_GATES:
            angle = params[key_to_position[item["param"]]]
            wire = int(item["wire"])
            if gate == "RX":
                qml.RX(angle, wires=wire)
            elif gate == "RY":
                qml.RY(angle, wires=wire)
            elif gate == "RZ":
                qml.RZ(angle, wires=wire)
        elif gate in ALLOWED_TWO_QUBIT_GATES:

            # qubit connectivity across repetitions without adding parameters
