<DESCRIPTION>
Revert to the higher-scoring 3-shell shared-CRZ backbone (nearest-neighbor, skip, antipodal rings, all keyed to theta_z, plus a shared theta_ry local layer) that previously achieved combined score 0.61, dropping the final-RY-mixer variant that regressed to 0.55. On top of that proven backbone, apply the targeted axis-mixing recommendation: in Shell 3 (the four antipodal, distance-4 pairs) swap CRZ for CRY while still reusing the same shared "theta_z" parameter name (so the parameter count stays at 2 distinct circuit parameters). Rationale: CRZ commutes with the RZ single-qubit layer and with the CRZ gates in shells 1/2, so all Z-generated rotations only ever dephase relative phases and never rotate Bloch vectors out of the Z-eigenbasis structure imposed by the local RZ layer -- this leaves a residual symmetry (global relative-phase invariance) that a state's Z-basis populations alone cannot break. Introducing a Y-axis controlled rotation only on the long-range antipodal links forces those particular qubit pairs to develop entanglement that is not diagonal in the same basis as the rest of the circuit, which should let the read-out observable pick up a genuinely different (non-commuting) correlation structure specifically from the hardest, most long-range-correlated validation examples, without adding any new trainable parameter.

# Two-parameter shared-entangler ansatz with a reused-parameter final mixer.
#
# Design rationale:
# - A single global RY angle ("theta_ry") is applied to every qubit, and a
#   single global RZ angle ("theta_z") is applied to every qubit. The RZ
#   layer's angle is reused as the controlled-rotation angle for two
#   short-range entangling shells (distance-1 ring and distance-2 skip-ring)
#   via CRZ. This exact 2-distinct-parameter backbone was empirically the
#   best-performing candidate so far (higher combined score than both a
#   3-parameter dedicated-entangler variant and a 3-parameter variant that
#   added a long-range IsingXX shell, which instead destabilized training).
# - A dedicated third circuit parameter for long-range coupling was tried
#   and hurt generalization (train/val/test accuracy all dropped to ~0.8),
#   confirming that parameter economy dominates for this small-data regime.
# - Instead of adding a new parameter for extra expressivity, we append a
#   final global RY layer that REUSES "theta_ry" (no new distinct parameter
#   name). This acts as a post-entanglement mixer, giving the circuit one
#   more chance to rotate the correlated state into alignment with the
#   fixed two-qubit readout observable, at zero extra parameter cost.
# - Total: 2 distinct circuit parameters (theta_ry, theta_z) plus 2 readout
#   params = 4 total.
ANSATZ_SPEC = []

# Global single-qubit layer: one shared RY angle for all 8 qubits.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": _i, "param": "theta_ry"})

# Global single-qubit layer: one shared RZ angle for all 8 qubits.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": _i, "param": "theta_z"})

# Shell 1: nearest-neighbor ring (distance 1), reuses theta_z via CRZ.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "CRZ", "wires": [_i, (_i + 1) % N_QUBITS], "param": "theta_z"})

# Shell 2: skip ring (distance 2), reuses theta_z via CRZ.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "CRZ", "wires": [_i, (_i + 2) % N_QUBITS], "param": "theta_z"})

# Final mixer: global RY layer reusing theta_ry (no new parameter), applied
# after the entangling shells to help align the resulting correlations with
# the fixed readout observable.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": _i, "param": "theta_ry"})

# Minimal-parameter, multi-shell shared-entangler ansatz with axis-mixed
# long-range shell.
#
# Design rationale:
# - A single global RY angle ("theta_ry") is applied to every qubit as the
#   local-rotation backbone.
# - A single global RZ angle ("theta_z") is applied to every qubit, and the
#   SAME angle is reused as the controlled-rotation angle across three
#   entangling shells on the 8-qubit ring: nearest-neighbor (distance 1),
#   skip (distance 2), and antipodal (distance 4). This 2-distinct-parameter
#   backbone (with all-CRZ shells) previously achieved the best combined
#   score (0.61); a variant that instead appended a reused-theta_ry final
#   mixer regressed sharply (0.55), so that mixer is dropped here in favor
#   of the proven backbone.
# - Targeted axis-mixing: the antipodal shell (distance 4) uses CRY instead
#   of CRZ, while still reusing "theta_z" as its angle (no new parameter).
#   All-CRZ shells commute with each other and with the local RZ layer, so
#   they only ever act diagonally in the Z basis and cannot rotate Bloch
#   vectors out of that basis on their own -- a residual symmetry that
#   Z-diagonal correlations alone may not resolve for the hardest samples.
#   Swapping to CRY only on the long-range links introduces a non-commuting
#   rotation exactly where the input state's longest-range correlations
#   live, which should help separate the worst validation group without
#   any additional trainable parameter.
# - The distance-3 shell remains omitted, consistent with a prior finding
#   that the fully-connected 28-edge graph dilutes the per-edge effective
#   rotation and hurts training and validation accuracy.
ANSATZ_SPEC = []

# Global single-qubit layer: one shared RY angle for all 8 qubits.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": _i, "param": "theta_ry"})

# Global single-qubit layer: one shared RZ angle for all 8 qubits.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": _i, "param": "theta_z"})

# Shell 1: nearest-neighbor ring (distance 1), reuses theta_z via CRZ.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "CRZ", "wires": [_i, (_i + 1) % N_QUBITS], "param": "theta_z"})

# Shell 2: skip ring (distance 2), reuses theta_z via CRZ.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "CRZ", "wires": [_i, (_i + 2) % N_QUBITS], "param": "theta_z"})

# Shell 3: long-range antipodal pairing (distance 4), reuses theta_z but via
# CRY instead of CRZ to break the Z-diagonal residual symmetry only on the
# longest-range links.
for _i in range(N_QUBITS // 2):
    ANSATZ_SPEC.append({"gate": "CRY", "wires": [_i, _i + N_QUBITS // 2], "param": "theta_z"})
