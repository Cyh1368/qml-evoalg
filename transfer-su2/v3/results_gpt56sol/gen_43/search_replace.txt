<DESCRIPTION>
Give all readout-aligned CRZ gates one shared parameter that is independent of the collective RY/ZZ angle. The current tying forces basis mixing, correlation evolution, and measurement-aligned phase adjustment to use the same value despite representing different generators. A dedicated phase can improve the hardest-group margin by rotating correlations specifically toward the supplied readout observable. Sharing it across every readout pair preserves symmetry and adds only one trainable scalar, limiting overfitting in the few-shot regime.
</DESCRIPTION>
