# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Aggressive parameter sharing across repeats, combined with block repetition, yields high expressivity at minimal cost.  
  • Generation 4 (“Shared-parameter CZ-RY Quantum Classifier”) and Generation 12 (current best) both use only 20 variational parameters (shared RY, a single ZZ, shared RZ per block × 6 repeats) and achieve perfect 1.00/1.00/1.00 accuracies with zero generalization gap.  
- Single “global” parametrized two-qubit coupling per block (one shared Ising-ZZ) suffices to entangle 8 qubits when embedded in a linear CZ chain.  
  • The current best program measures only one IsingZZ(zz_shared) per block (qubits 2–5), yet attains test loss ≈ 0.01, improving on earlier 0.02 losses (Gen 4) without extra parameters.  
- Simple gain/bias readout calibration on averaged Z–Z correlators stabilizes output scaling and eliminates needing dedicated readout layers.  
  • All top circuits (Generations 3, 4, 6, 12) append two trainable readout parameters and converge reliably with zero overfitting.  
- Block-based ansatz specification (ANSATZ_SPEC + apply_ansatz_block) enables safe, repeatable mutations and automated resource counting, driving rapid prototyping of efficient designs.  

## Ineffective Approaches  
- Over-parameterized ansätze with many unique parameters add little expressivity beyond a compact core.  
  • Generation 3 used 32 parameters (depth 35, gates 186) and converged in ~60 steps to loss ≈ 0.03 (efficiency ≈ 0.03), versus 20-param versions at loss ≈ 0.02–0.01 (efficiency ≈ 0.05).  
- Parity-shared CRZ layers increase implementation complexity without measurable gains.  
  • Generation 7 (38 params, alternating RY/RZ, parity-shared CRZ) matched 100% accuracy and low loss but only achieved parameter efficiency ~0.03, inferior to simpler shared-ZZ designs.  
- Extreme parameter compression can degrade convergence speed and loss.  
  • A 26-param circuit (Generation 8) reached perfect accuracy but required ~420 optimizer steps and test loss rose to ~0.04, versus ~60–90 steps in 20–32-param designs.  

## Implementation Insights  
- The validate_ansatz_spec + ordered_unique_keys pattern enforces consistent parameter indexing and early error detection, crucial for large-scale ansatz searches.  
- apply_ansatz_block’s key→offset mapping cleanly implements both per-block repetition and parameter sharing (e.g., “ry_shared” and “rz_shared” reused across 8 qubits), drastically reducing boilerplate.  
- Using qml.queuing.AnnotatedQueue to extract depth and gate_count enables “free” resource metrics tracking alongside accuracy/loss, guiding compactness trade-offs.  
- Decoupling state encoding (qml.StatePrep) from variational layers focuses optimization effort on expressivity; the current best program’s 6×(shared RY + CZ chain + ZZ + shared RZ) delivers deep entanglement without bespoke encoding gates.  

## Performance Analysis  
- Parameter count vs. test loss vs. convergence:  
  • 62–74 params: test loss ≈ 0.01, ~30 steps, efficiency ≈ 0.02 (Gen 2, 5)  
  • 20 params (Gen 4): test loss ≈ 0.02, ~60 steps, efficiency ≈ 0.05  
  • 20 params (current best): test loss ≈ 0.01, ~90 steps, efficiency ≈ 0.05  
  • 26 params: test loss ≈ 0.04, ~420 steps, efficiency ≈ 0.04  
- Depth and gate count trade-offs:  
  • Current best achieves gate_count 144 (down from 186) and intermediate depth 49, balancing expressivity (via CZ chain + ZZ) and circuit size, improving test loss while retaining perfect accuracies.  
- Convergence thresholds:  
  • Generation 4 hit 90% validation at ~60 steps; current best reached 90% at ~90 steps but attained lower final loss (0.01 vs. 0.02), showing that merging RZ into phase reductions can enhance fine-tuning at modest extra training cost.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Split the single “zz_shared” into two shared ZZ entanglers per block—“zz_chain” on wires [2,5] and “zz_cross” on wires [3,6].  
   This adds just one extra parameter per block but provides two independent two-qubit couplings, enriching the entanglement graph along orthogonal diagonals. It directly extends the proven shared‐ZZ strategy while probing whether a denser ZZ network accelerates convergence or lowers final loss.

2. Augment each block with a shared IsingXX entangler on the same wire pair(s) used by ZZ (e.g., [2,5]).  
   Adding one “xx_shared” parameter per block leverages the complementary expressivity of XX+ZZ couplings observed in mixed‐axis experiments. This mutation maintains aggressive sharing and minimal overhead yet may capture correlations the ZZ alone misses, potentially speeding up fine‐tuning.

3. Parity-split the global RY layer into “ry_even” and “ry_odd” parameters applied to even- and odd-indexed qubits respectively.  
   By replacing the single “ry_shared” with two shared angles, you double local rotational flexibility (adding one param/block) while retaining sharing across qubits. This builds on the success of parity-modulated single‐qubit gates to improve feature discrimination without a large parameter increase.

4. Introduce per-block scaling factors that multiply all rotation angles within a block: add parameters “scale_0”…“scale_5” for blocks 0–5.  
   Each block’s two single-qubit and entangler angles become angle×scale_i, giving depth-wise adaptive learning rates for the variational layers. This adds six global parameters but keeps the core 10-param block intact, offering fine control over each layer’s expressivity as training proceeds.

5. Alternate the two-qubit chain gate between CZ and CNOT across repeats (e.g., use CZ on even repeats, CNOT on odd repeats).  
   This swap does not change parameter count but diversifies the native entangling interactions, which may expose the optimizer to richer operator subspaces. It preserves the linear chain layout while testing whether mixed‐gate patterns can reduce convergence steps or further lower test loss.
