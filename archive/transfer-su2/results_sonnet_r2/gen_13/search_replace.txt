reduce_params_single_shared_rotation

<DESCRIPTION>
The current best candidate (20 params, 100% train/val/test accuracy) uses a shared RY layer, a CZ chain, one ZZ entangler, and a shared RZ layer per block (3 params/block × 6 blocks + 2 readout = 20). Since accuracy is already saturated at 1.00, further gains must come from parameter economy while preserving expressivity. I propose collapsing the RY and RZ shared layers into a single shared-parameter combination by removing the separate RZ layer and instead using a single shared RY angle plus reusing the same shared angle name for the ZZ gate (linking entangling strength to local rotation), cutting to 2 unique params per block (12 total + 2 readout = 14 params). This tests whether the task's structure permits even fewer independent parameters while maintaining the CZ backbone connectivity and one non-local ZZ interaction per block, since the seed and prior variants show that mere presence of entanglement plus one rotation type already drives perfect classification here. If this proves too aggressive, the shared angle reuse still allows the optimizer full flexibility per-block since each of the 6 repeats has independent parameter copies, preserving depth-wise expressivity while shrinking width-wise redundancy.
