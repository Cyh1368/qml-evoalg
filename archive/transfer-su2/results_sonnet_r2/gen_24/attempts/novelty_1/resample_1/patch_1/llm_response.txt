alternating_ring_diagonal_entangler

<DESCRIPTION>
The current 20-parameter ansatz already achieves perfect accuracy with fast convergence (90 steps). To further improve convergence speed and potentially reduce test loss while keeping the same parameter count, I alternate the entangling connectivity pattern across the 6 repeated blocks: odd-indexed blocks use the standard ring-edge ZZ entangler (as before), while even-indexed blocks use diagonal pairs (0,4),(1,5),(2,6),(3,7) instead. Since ANSATZ_SPEC is a single fixed spec applied identically at every repeat in the current fixed architecture, achieving alternation requires embedding the block-index parity logic directly via two ZZ layers on both edge sets but sharing the SAME "zz_shared" parameter — this keeps N_PARAMS identical while broadening entanglement in every single block application (both ring and diagonal edges are applied together each time), which increases connectivity diversity within each block without adding any new trainable parameters. This exposes the circuit to richer entanglement structure (ring + diagonal) which can improve robustness/convergence without any parameter cost increase.
