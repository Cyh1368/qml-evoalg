reduce_params_shared_ring

<DESCRIPTION>
The current spec achieves perfect accuracy already (100% train/val/test) but with 146 total parameters (24 per block x 6 blocks + 2 readout), yielding low parameter_efficiency (0.01), which is explicitly rewarded by the scoring. Since accuracy is already saturated, the main lever left is aggressive parameter reduction while preserving expressivity enough to keep the same accuracy.

Key changes:
1. Replace the per-qubit independent RY+RZ (16 params) plus per-qubit independent RZ-post (8 params) = 24 params/block, with a much more economical parametrization:
   - Single shared RY angle for all qubits (1 param) followed by single shared RZ angle for all qubits (1 param) as the "input rotation" layer - this still allows universal single-qubit rotation up to a shared angle, since after StatePrep encodes all information already in amplitudes, the classifier mostly needs to correlate/entangle then rotate to measurement basis.
   - Replace the CZ ring (fixed, no params) with a parametrized ring of IsingZZ (entangling) gates using a SINGLE shared parameter across the ring (1 param) to keep the entangling structure while drastically cutting parameter count and keeping expressivity (still 7 ZZ gates per block, just tied together).
   - Keep final RZ layer but use two shared parameters split even/odd wires (2 params) instead of 8 independent, to add a little more flexibility for measurement alignment while keeping parameter count low.

This drops per-block trainable parameters from 24 to 5 (1 RY shared + 1 RZ shared pre + 1 ZZ shared + 2 RZ post even/odd) — an ~80% cut in circuit parameters (from 144 to 30 total circuit params, 32 with readout), which should substantially boost parameter_efficiency while the added entangling ZZ gates (replacing plain CZ) should maintain or even improve expressivity/accuracy since IsingZZ has a tunable angle instead of being fixed at CZ's implicit pi rotation.
