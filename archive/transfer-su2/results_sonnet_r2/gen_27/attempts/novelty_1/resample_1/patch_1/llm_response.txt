add_xx_twist_ring

<DESCRIPTION>
Add an orthogonal one-axis-twist term by inserting IsingXX gates on the same ring edges as the existing IsingZZ entangler, reusing the same "zz_shared" parameter (renamed conceptually to a shared "twist" angle applied to both ZZ and XX). This creates a richer two-axis collective spin-squeezing-like interaction (XX+ZZ) without adding new trainable parameters, since the same angle is reused. This is inspired by one-axis-twisting/two-axis-twisting models in collective spin dynamics: combining ZZ and XX couplings generates non-linear entangling dynamics that can enhance expressivity/discriminating power per parameter, potentially improving convergence speed and final loss while keeping parameter count identical (still 20 total params). Gate count increases modestly (8 extra IsingXX gates per block, 48 total), but no new parameters are introduced, preserving parameter economy while testing whether richer entanglement structure improves loss/convergence.
