add_shared_xx_entangler

<DESCRIPTION>
The current 20-parameter ansatz (8 RY shared + 1 ZZ shared + 1 RZ shared) already achieves perfect train/val/test accuracy with low loss (0.01) and fast convergence (90 steps). To push loss even lower while keeping parameter count minimal, I add a complementary IsingXX ring entangler that shares a single new parameter "xx_shared" across the same ring edges as the existing ZZ layer. This introduces orthogonal (X-basis) entanglement in addition to the existing Z-basis (ZZ) entanglement, which can help the circuit represent correlations that pure ZZ interactions plus RY/RZ single-qubit rotations cannot capture efficiently. Since only one new parameter is added per block (6 total across repeats), this keeps the parameter count increase minimal (from 20 to 21) while potentially improving expressivity enough to reduce test_loss below the current 0.01, without harming the excellent accuracy or convergence speed already achieved.
