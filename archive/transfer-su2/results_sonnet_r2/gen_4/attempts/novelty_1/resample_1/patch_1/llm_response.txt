<DESCRIPTION>
The baseline already achieves 100% accuracy on all splits with 146 parameters, but parameter efficiency is very low (0.01), which strongly penalizes the combined score. Since the scoring rewards parameter economy heavily, I propose drastically cutting the per-block parameter count while preserving enough expressivity to entangle all qubits.

Key changes:
1. Remove the redundant pre/post RZ split - only keep one RZ layer per block instead of two (halves the single-qubit param count from 24 to 16 per block, then further reduce).
2. Replace independent RY/RZ rotations per qubit with a single shared RY parameter and single shared RZ parameter per block (parameter sharing across qubits), drastically cutting per-block parameters from 24 to 2, while keeping full connectivity via CZ entanglers.
3. Add one shared parametrized ZZ entangling gate parameter to increase entangling expressivity per block at minimal parameter cost.

This reduces per-block params from 24 to 3 (shared ry, shared rz, shared zz), giving total circuit params = 3*6=18 plus 2 readout = 20 params, versus 146 previously — a ~7x reduction — while still allowing the circuit to reach full entanglement across all 8 qubits every block via the CZ ladder and shared ZZ Ising coupling. This should preserve accuracy (since the seed already reaches 100% train/val/test accuracy, indicating the task is easy and doesn't need many independent parameters) while substantially boosting parameter_efficiency and thus the combined score.
