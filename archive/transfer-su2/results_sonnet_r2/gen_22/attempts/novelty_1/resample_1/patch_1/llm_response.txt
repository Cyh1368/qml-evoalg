add_shared_xx_twist_entangler

<DESCRIPTION>
The current best-performing 20-parameter ansatz uses a CZ ladder plus a single shared ZZ interaction on qubits (2,5) and RY/RZ shared rotations. To further improve entanglement quality while keeping parameter count minimal, I add a complementary shared IsingXX entangler across the same long-range pair-adjacent structure as the CZ ladder (ring edges), using ONE shared parameter "xx_shared". This introduces orthogonal (X-basis) entangling power alongside the existing Z-based CZ/ZZ gates, which is known to improve expressivity for classifying entangled states without breaking permutation-like parameter sharing. Cost: +1 parameter per block (6 total), bringing total params from 20 to 26, still far below the 32-param second baseline while retaining full accuracy and potentially improving convergence speed and lowering test/validation loss due to the mixed-basis coupling that captures correlations invisible to pure Z-Z probes.
