mixed_axis_shared_entangler

<DESCRIPTION>
The strongest prior variant (score 0.60) used a single shared entangling parameter "theta_ent" applied identically (as CRZ) across three connectivity shells (nearest-neighbor, skip-2, antipodal). Since apply_ansatz_block is fixed and cannot dispatch different gates per repeat, we instead diversify the *rotation axis* of the entangler across the three shells within a single block application (which is still applied identically in every repeat): CRZ on the nearest-neighbor ring, CRX on the skip-2 ring, and CRY on the antipodal pairs, all tied to the same "theta_ent" parameter. This mixes Z-, X-, and Y-type two-qubit correlations without adding any new trainable parameters (still only 3 distinct circuit params + 2 readout params = 5 total), which should let the shared angle simultaneously shape complementary correlators relevant to the unknown readout observable, improving worst-group margin and generalization while preserving the parameter economy that scored best so far. This also reverts away from the current 5-distinct-param version (which underperformed the 3-param version, 0.51 vs 0.60), restoring the higher-scoring parameter budget.
