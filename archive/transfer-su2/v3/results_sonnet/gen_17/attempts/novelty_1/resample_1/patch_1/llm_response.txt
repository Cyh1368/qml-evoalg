<DESCRIPTION>
Replace the current 5-distinct-parameter ansatz (even/odd RY, ZZ ring, antipodal CRZ, global RZ) with a minimal 3-distinct-parameter design that outperformed it in prior runs (global RY + global RZ + one shared entangling angle), but extend the entangling structure from a partial set of shells (distance 1,2,4) to the *complete* graph on 8 qubits (all pairwise distances 1,2,3,4 covering every one of the 28 edges) using a single shared IsingZZ angle.

Rationale: the earlier ablation showed that collapsing to 3 shared parameters (global RY, global RZ, one shared entangler reused across several distance shells) scored substantially higher (0.60) than the current 5-parameter even/odd design (0.52), confirming that parameter economy dominates the score here. We push this further by making the entangling layer fully connected (every qubit pair gets exactly one shared-angle interaction) instead of only three shells, which should let correlations relevant to *any* dataset-chosen readout pair be captured without adding any new trainable parameters (still exactly 3 circuit params + 2 readout params = 5 total). We switch CRZ (asymmetric, needs a specific control/target) to the symmetric IsingZZ gate for the entangler, since a fully-symmetric interaction should generalize better across permutation-like structure in the readout pairs and is consistent with the improved generalization seen when moving from asymmetric to shared symmetric operations in the prior experiment. This keeps the trainable-parameter count minimal while maximizing the diversity/robustness of correlations available to the calibrated readout, targeting worst-group margin generalization on held-out difficulty groups.
