# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Multi-scale shared entanglers with a single trainable angle  
  • The Multi-Scale Shared-Entangler Classifier (combined 0.60) outperformed all prior designs by reusing one “θ_ent” across three connectivity shells (distance 1, 2, 4). This enriched global correlations without increasing parameter count, boosting test accuracy to 0.85 and cutting the generalization gap to 0.15.  
- Extreme parameter tying across repeats and wires  
  • Tying the same two rotation angles (θ_ry, θ_rz) and one entangler angle over N_REPEATS = 3 (3 circuit parameters total) yielded perfect train accuracy (1.00) with stable validation/test (0.88/0.85). This echoes Gen 3’s success but pushes combined score from 0.52 to 0.60.  
- Minimal single-qubit rotation family  
  • Using only global RY and RZ, rather than separate per-qubit angles, maintained full Bloch-sphere coverage when interleaved with rich entanglers. The current best program’s depth-45/108-gate circuit shows that 2 shared rotation parameters suffice for strong expressivity.  
- Calibrated two-qubit correlator readout with gain/bias  
  • Consistently across high-scoring models (Gen 6: 0.60, Gen 3: 0.52), averaging fixed dataset-specific correlators followed by a trainable gain and bias stabilized margins (validation_margin ≈ 0.57) and prevented trivial parameter inflation.  

## Ineffective Approaches  
- Over-sharing with too few entangling primitives  
  • The Even-Odd Shared RY + ZZ-CRZ Ansatz (Gen 14, combined 0.35) tied one entangler across only a nearest-neighbor ZZ ring and long-range CRZ, but lacked mid-range couplings. It underfit badly (val/test 0.56) and exhibited a large gap (0.32), showing that a single shell isn’t enough.  
- Excessive symmetry without skip-distance links  
  • The Parity-Invariant Classifier (Gen 16, combined 0.34) used parity-shared RY/RX, nearest-neighbor ZZ, antipodal CRZ, and global RZ—yet still underperformed, reaching only test 0.58. Omitting skip-distance (distance 2) couplings capped expressivity and validation margins fell to 0.32.  
- Over-capacity without long-range specificity  
  • Parity-Symmetric 8-Qubit State Classifier (Gen 11, combined 0.51) added even/odd rotations (7 params) but missed the dilution effect of multi-scale sharing. Validation plateaued at 0.86 and combined score trailed the multi-scale design by 0.09.  

## Implementation Insights  
- Declarative ANSATZ_SPEC with automatic validation  
  • The current best program’s gate dictionaries (ANSATZ_SPEC) and `validate_ansatz_spec` caught spec errors early, ensuring consistency in wire indexing and gate types. This prevented wasted compute on invalid candidates.  
- Unified `apply_ansatz_block` abstraction  
  • A single loop over ANSATZ_SPEC with a `key_to_position` map streamlined the implementation of shared RY/​RZ/​CRZ layers. This pattern made it trivial to add or remove shells, directly correlating code modularity with rapid architecture trials.  
- Consistent depth/gate counting via AnnotatedQueue  
  • Extracting depth = 45 and gate_count = 108 through `AnnotatedQueue` enabled tight correlation of circuit complexity with performance, revealing the sweet spot around depth ≈ 45 for eight qubits under few-shot training.  
- Wide random initialization scale  
  • Initializing angles uniformly in [−π, π] (instead of near zero) avoided dead zones and improved ranking stability across different ansatz structures, contributing to the current best program’s zero‐std validation accuracy.  

## Performance Analysis  
- Parameter count vs. combined score  
  • Designs with ~3 distinct circuit parameters (Gen 6) achieved 0.60, outperforming those with ~5–7 parameters (Gen 3: 0.52, Gen 11: 0.51) by focusing expressivity into multi-scale entanglers rather than per-qubit rotations.  
- Gate depth sweet spot around 45 layers  
  • Shallower circuits (depth 33 in Gen 14/16) underfit (combined ≈ 0.34), while deeper ones (depth 54 in Gen 9) only reached ~0.38. The current best’s depth 45/108 gates balanced expressivity and trainability for maximal test_acc = 0.85.  
- Long-range couplings lift test accuracy  
  • Adding antipodal (distance 4) links in Gen 6 boosted test_acc by ~0.15 over ring-only designs (Gen 9: test ≈ 0.51), confirming that multi-scale connectivity directly translates to higher predictive power.  
- Parameter efficiency correlates with generalization  
  • The Multi-Scale Shared-Entangler model attained the highest parameter_efficiency = 0.17 and lowest generalization_gap = 0.15. In contrast, Gen 3’s efficiency = 0.12 and gap = 0.16, showing even slight architecture refinements yield measurable gains in per-parameter utility.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce an orthogonal‐axis entangler bank.  
   Immediately after your three CRZ “theta_ent” shells, append three IsingXX shells at distances 1, 2, and 4 (wire pairs `[(i,(i+d)%8) for i in range(8)]` with d=1,2,4), all tied to a single new param `"theta_xx"`. This tests whether adding X–X correlations in the same multi‐scale topology boosts expressivity with only one extra parameter, building directly on the weight‐sharing success of the CRZ shells.

2. Stage the global RZ phase into pre- and post-entangling layers.  
   Replace your single `"theta_rz"` RZ entries with two shared parameters: insert an RZ on every qubit with param `"theta_rz_pre"` immediately after the RY block, and another RZ with param `"theta_rz_post"` just before the first CRZ shell. This still uses one gate per qubit per stage but gives finer phase‐shaping control to see if split‐phase rotations further widen the validation margin without increasing depth.

3. Alternate Z– and X–entanglers across repeats.  
   Define two versions of `ANSATZ_SPEC`: Spec A uses your existing CRZ shells under `"theta_ent"`, Spec B swaps each CRZ for a CRX on the same wire pairs (also tied to `"theta_ent"`). In `apply_ansatz_block`, dispatch Spec A for even `block_index` and Spec B for odd, interleaving Z–Z and X–Z coupling patterns across the three repeats. This leverages mixed‐axis correlations while keeping the parameter budget identical.

4. Add a fourth “distance-3” shell into the shared entangler.  
   To your existing three shells, append eight CRZ gates coupling qubits separated by three positions (`(i,(i+3)%8)`), all reusing `"theta_ent"`. This fills in mid-long‐range links so every pair lies under path-length ≤2 in the entangling graph, strengthening connectivity without any extra parameters and directly extending the proven multi-scale paradigm.

5. Partially unshare the mid-range shell for targeted flexibility.  
   Keep the nearest-neighbor (d=1) and antipodal (d=4) CRZ shells tied to `"theta_ent"`, but assign the skip-distance (d=2) shell its own new param `"theta_ent_mid"`. This slight relaxation tests whether granting the critical mid-range links independent weight improves performance and generalization while adding just one extra circuit parameter.
