# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- Multi-Scale Entanglement Shells with Shared Angle  
  • Generation 22 “Multi-scale 8-Qubit Shared-Entangler Classifier” (combined 0.56; train 1.00/val 0.88/test 0.85; gap 0.15) demonstrated that adding a novel distance-3 shell alongside distance 1, 2, 4 CRZ links—all tied to a single θ_ent—boosts test accuracy from ~0.55 to 0.85 without increasing distinct parameters.  
  • The current best program (combined 0.60; train 1.00/val 0.88/test 0.85; gap 0.15) reuses this three-shell pattern (distances 1, 2, 4) with only three circuit parameters (θ_ry, θ_rz, θ_ent) and attains the top score.

- Full-Graph CRZ Sharing  
  • Generation 23 “Parameter-Efficient Full-Graph CRZ Ansatz” (combined 0.59; train 1.00/val 0.85/test 0.83; gap 0.17) ties θ_ent across all 28 CRZ edges in four shells plus two global rotations (θ_ry, θ_rz). This extreme sharing yields near-peak test accuracy with just two distinct ansatz parameters.

- Minimal Single-Qubit Rotation Family  
  • Both the current best and Gen 23 use only global RY and RZ (θ_ry, θ_rz) per block. This 2-parameter rotation layer, interleaved with multi-scale entanglers and repeated thrice, spans full Bloch coverage and underpins high expressivity per parameter.

- Parameter Tying Across Repeats  
  • Repeating the same ansatz block N_REPEATS = 3 with tied parameters amplifies non-linearity without enlarging the trainable space. Gen 22, Gen 23, and the current best all achieve perfect training accuracy (1.00) and zero seed-to-seed variance.

## Ineffective Approaches

- Limited Shell Diversity and Heavy Sharing  
  • “Three-Shell CRZ Ansatz 8-Qubit Classifier” (Gen 20; combined 0.34; train 0.88/val 0.55/test 0.55; gap 0.33) shared four parameters across nearest-neighbor, mid-range, and antipodal CRZs but lacked the skip-distance links and underfit critical correlations, driving overfitting.  
  • Generation 21 “Multi-Scale Shared-Entangler 8-Qubit Classifier” (combined 0.34; train 0.88/val 0.55/test 0.55; gap 0.33) similarly tied only two single-qubit and two two-qubit angles, failing to capture mid-range structure.

- Single-Angle Entangler Over-Tying  
  • “Shared-parameter 8-qubit State Classifier” (Gen 24; combined 0.34; train 0.81/val 0.54/test 0.48; gap 0.34) collapsed three shells (CRZ/CRX/CRY) into one angle. This extreme under-parameterization produced poor margins and chance-level test accuracy.

- Under-Capacity without Long-Range Links  
  • Earlier single-shell models (Gen 18/19) with only nearest-neighbor or ring entanglers achieved ~0.50 train/test, showing that omitting skip (distance 2) or antipodal (distance 4) links prevents learning nonlocal readout correlations.

## Implementation Insights

- Declarative ANSATZ_SPEC and Automated Validation  
  • All high-performers define gates in an `ANSATZ_SPEC` list validated by `validate_ansatz_spec`, which catches wire mis-indexing and unsupported gates, preventing runtime errors and enabling quick shell revisions.

- Unified apply_ansatz_block Abstraction  
  • The `apply_ansatz_block` loop maps `PARAMETER_KEYS_PER_BLOCK` to gate parameters and applies each entry, decoupling gate layout from parameter management. This made adding distance-2 and distance-4 shells trivial in Gen 22 and the current best.

- Circuit Complexity via AnnotatedQueue  
  • Using `qml.queuing.AnnotatedQueue` to extract depth (45) and gate_count (108) established a “sweet spot” complexity. Top models (current best, Gen 22) target depth ≈45, balancing expressivity and trainability.

- Wide Uniform Initialization  
  • Initializing all ansatz angles uniformly in [–π, π] (init_scale = π), combined with gain=1, bias=0 seeding, eliminated optimizer dead zones and produced deterministic validation/test metrics (std = 0.00) across seeds.

## Performance Analysis

- Combined Score Trajectory  
  • Early multi-shell/shared designs (Gen 20/21/24) stagnated at combined ≈0.34. Incorporating skip-distance and antipodal links in one shared θ_ent (Gen 22) jumped to 0.56; extending to full-graph sharing (Gen 23) reached 0.59; refining to the three-shell global CRZ pattern in the current best yielded 0.60.

- Parameter Count vs. Test Accuracy  
  • Models with 3–5 total parameters outperformed those with 4–7: the current best (5 params, 3 distinct) and Gen 22 (5 params, 3 distinct) both hit test 0.85; Gen 23 (4 params, 2 distinct) hit 0.83; over-parameterized or under-parameterized variants scored ≤0.55.

- Generalization Gap Reduction  
  • Gap shrank from 0.33 (Gen 20/21) to 0.17 (Gen 23) to 0.15 (Gen 22/current best) as shell diversity increased and parameters were efficiently shared. Rich, multi-scale entanglement combats overfitting despite perfect training.

- Depth Consistency  
  • All top programs maintain gate depth ~45. Deviating deeper (e.g., Gen 23 depth 54) yields marginal gains, underscoring that adding distinct gates must be balanced by targeted entanglement patterns rather than sheer circuit length.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce mixed-axis entanglement by appending a CRX gate for each existing CRZ link in shells 1, 2, and 4, reusing the same “theta_ent” parameter. This injects X–Z correlations alongside Z–Z couplings without increasing the distinct parameter count, building on the success of single-θ_ent multi-scale sharing.  

2. Untie the global entangler across repeats: replace the single “theta_ent” with three block-specific parameters “theta_ent_0”, “theta_ent_1”, and “theta_ent_2”, each still shared across distances 1, 2, and 4 within its block. This adds only two extra variables but tests whether per-repeat phase shifts deepen sequential correlation building.  

3. Append a final global single-qubit rotation layer after the third repeat: add RY(wires=0…7, param=“theta_ry_out”) (and optionally RZ with “theta_rz_out”) before measurement. This mixer-style adjustment can refine the Bloch vectors post-entanglement, analogous to a QAOA mixer, sharpening class separability.  

4. Enhance readout calibration granularity by assigning a separate gain and bias to each shell’s measured correlator group (distance-1, distance-2, distance-4), for a total of six calibration parameters. Per-scale margin tuning can correct shell-specific systematic shifts without altering circuit depth.  

5. Add asymmetric mid-range flexibility by splitting the distance-2 shell into two interleaved subsets (even-indexed vs. odd-indexed skip links) and tying each subset to its own “theta_ent_mid_even” and “theta_ent_mid_odd”. This one-parameter expansion probes whether directional skip-ring unsharing captures dataset anisotropies better than fully shared skip entanglers.
