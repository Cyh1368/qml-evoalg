# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- Two-Parameter Multi-Shell Shared-CRZ Ansatz (Current Best, Gen 54)  
  • Achieved combined score 0.61 (train 1.00, val 0.90, test 0.85) with only two circuit parameters (θ_ry, θ_z) + two readout params.  
  • Uses three CRZ shells at distances 1, 2, 4 on an 8-qubit ring, interleaved after global RY→RZ layers, repeated 3× with exact parameter‐tying.  
  • Depth 45, gate count 108: this precise connectivity pattern maximizes expressivity per parameter.  

- Interleaved RZ Layer + Zero-Cost Mixer (Gen 52: “Interleaved Dual-Axis Shared-Entangler Ansatz”)  
  • Combined score 0.57 (train 1.00, val 0.88, test 0.85) with four circuit parameters.  
  • Inserting an extra global RZ before multi‐distance CRZ shells and appending a reused‐RY mixer improved margin stability without new parameter keys.  

- Exact Parameter Sharing Across Repeats  
  • All top‐scoring circuits (Gen 50 and Gen 54) define ANSATZ_SPEC once and loop N_REPEATS=3 over the same parameter keys, preserving rotational symmetry.  
  • This enforces a richer gradient landscape with minimal parameters, driving convergence to perfect training accuracy in ~1 440 steps.  

- Constrained Shell Selection  
  • Focusing entanglement on distances 1, 2, 4 (and omitting distance 3 or extra long-range parameters) consistently outperformed both sparser (2-shell) and denser (4-shell) variants.  

## Ineffective Approaches

- Extreme Single‐Parameter Tying  
  • Gen 56 (“Single-Parameter Shared-Entangler Ansatz”), Gen 59, and Gen 60 all collapse to ≈50% accuracy (combined scores ∼0.40–0.45) when a lone θ is reused across global rotations and multi-axis shells.  
  • Feedback: expressivity is insufficient for any nontrivial classification, resulting in random‐guess performance despite parameter efficiency.  

- Cross-Axis Entanglers Without New Parameters (Gen 51)  
  • Introducing non-commuting CRY/CRX shells under the existing θ_ry/θ_z ties led to overfitting (train 0.88) but poor generalization (val 0.55, test 0.48; combined 0.35).  
  • Mixing generator axes without augmenting the parameter set broke the model’s ability to capture robust state correlations.  

- Symmetric ZZ Refinement with Two Parameters (Gen 57: “8-Qubit Shared-Entangler Ansatz State Classifier”)  
  • Achieved only combined 0.40 (train 0.69, val 0.56, test 0.50) with two θs and a symmetric nearest‐neighbor ZZ shell.  
  • Feedback: limited expressivity and the ZZ shell did not compensate for the overly constrained parameter space, yielding a 19% generalization gap.  

## Implementation Insights

- Declarative ANSATZ_SPEC + validate_ansatz_spec  
  • Centralizing gate definitions in a list of dicts—then running validate_ansatz_spec—catches mis‐indexed wires and unsupported gates at load time.  
  • Mapping param keys to indices ensures exact tying across repeats (see apply_ansatz_block’s key_to_position).  

- Wide Uniform Initialization & Decoupled Readout Calibration  
  • Initializing circuit angles uniformly over [−π, π] avoids dead‐zone starts; gain/bias start at (1, 0) to decouple readout from circuit training.  
  • This consistent protocol across candidates reduces ranking noise from optimizer artifacts.  

- Profiling Depth and Gate Count via qml.queuing.AnnotatedQueue  
  • Using AnnotatedQueue + tape.graph.get_depth() to confirm the “sweet spot” of depth 45/gate 108 guided shell pruning.  
  • Ensured circuits neither under‐ nor over‐utilized hardware connectivity.  

- CRZ‐Only Entanglement Backbone  
  • Reusing the same θ_z for both RZ and all controlled-Z gates (CRZ) concentrates learning capacity on phase correlations.  
  • Avoiding extra two-qubit gate types (e.g., XX, YY, CRX) kept the implementation simple and robust.  

## Performance Analysis

- Parameter Efficiency vs. Score  
  • Best two-param design (Gen 54) yields parameter efficiency 0.21 and combined score 0.61; four-param interleaved (Gen 52) achieves efficiency 0.15 and score 0.57.  
  • Single-param variants cluster at efficiency 0.17 or below but fail to exceed random accuracy, underscoring a floor on minimal parameter counts.  

- Depth/Gate Count Correlation  
  • Circuits at depth 45/gate 108 (Gen 50, 54) outperform deeper designs: Gen 52 (depth 48/gate 132) scores 0.57, while Gen 51 (depth 84) plunges to 0.35.  
  • Confirms that targeted connectivity—rather than sheer depth—drives generalization.  

- Generalization Gap Trends  
  • Two-parameter multi-shell: gap 0.15, worst-group margin 0.33.  
  • Single-parameter and symmetric variants: gaps range 0.00–0.19 but at much lower test accuracy (≤0.56), indicating underfitting dominates over overfitting.  

- Convergence Efficiency  
  • Top performers converge to validation ≥0.90 in ~1 440 steps. Less effective candidates either never reach that threshold or require substantially more epochs without matching peak accuracy.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce fixed per-shell scaling factors on the shared “theta_z.”  
   In your ANSATZ_SPEC (or in apply_ansatz_block), wrap each CRZ call so that the angle is multiplied by a hard-coded multiplier—e.g. 1.0 for distance-1, 0.8 for distance-2, and 1.2 for distance-4. This preserves the 2-parameter budget while softly breaking perfect shell symmetry, leveraging the proven benefit of static symmetry distortions to enrich expressivity without adding trainables.  

2. Break perfect repeat symmetry via per-repeat scaling offsets on “theta_z.”  
   In apply_ansatz_block, multiply theta_z by a small constant array [1.00, 0.95, 1.05][repeat_index] before each CRZ layer. This injects gentle heterogeneity across the three tied repeats—building on the strong convergence of exact parameter sharing yet diversifying layer‐wise entanglement patterns.  

3. Permute the order of the three entangling shells across repeats.  
   Use the repeat_index to choose one of three hard-coded shell orders (e.g. repeat 0: 1→2→4; repeat 1: 2→4→1; repeat 2: 4→1→2) while still reading the same theta_z. This interleaves distinct circuit pathways under identical parameters, improving gradient flow and mixing as suggested by the success of tied repeats.  

4. Append a final global RZ mixer reusing “theta_z.”  
   After your three CRZ loops in ANSATZ_SPEC, add eight {"gate":"RZ","wire":i,"param":"theta_z"} entries. Aligning the last rotation axis with the entanglement backbone tests whether a shared-parameter mixer can boost margin stability—all without inflating the parameter count.  

5. Insert a param-free CNOT ring mixer to enrich entanglement.  
   Between the global RZ layer and your first CRZ shell (or after each shell), append a layer of CNOTs connecting wire i→(i+1)%N_QUBITS. This zero-cost entangler—akin to the “zero-cost mixer” in Gen 52—adds non-commuting connectivity and can enhance expressivity and margin robustness without any new parameters.
