<DESCRIPTION>
The current low-parameter candidate (4 distinct params, pure-ZZ ring) scores far below the historical best (5 distinct params, with an extra long-range CRZ layer, score 0.52). Rather than reintroducing a heavy CRZ hop layer, this edit tests heterogeneous two-qubit entanglers as recommended: keep the even/odd RY sublattice rotations (2 params), but split the nearest-neighbor entangling ring into two tied-parameter passes — one using IsingZZ ("zz") and one using IsingXX ("xx") on the same ring topology — followed by the shared final RZ phase layer ("rz_post"). This keeps the same 5 distinct-parameter budget as the best-performing candidate while diversifying the type of correlations the circuit can build (ZZ commutes with computational-basis features, XX mixes across the X basis), which should help generalize a broader range of "hidden difficulty" validation groups instead of over-fitting to one entangling axis. Because N_REPEATS=3 already re-applies the whole block identically, sequencing ZZ-ring then XX-ring inside one block effectively realizes an A,B,A,... alternation across repeats without adding extra parameters or increasing depth beyond what a single extra ring layer costs.
