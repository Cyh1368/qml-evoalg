add_xx_ring_entangler

<DESCRIPTION>
Revert the ansatz to the higher-scoring even/odd-RY + ZZ-ring + antipodal-CRZ + global-RZ structure (prior score 0.52), which strongly outperformed the current 3-parameter ry/ent/rz variant (score 0.38). On top of that proven base, add a parallel nearest-neighbour IsingXX ring sharing a single new parameter "xx_ring", right after the ZZ ring. Mixing XX (flip-flop) correlators with the existing ZZ (phase) correlators gives the entangling layer access to a richer, more expressive two-qubit correlation subspace while costing only one extra trainable parameter (6 total instead of 5), which should improve worst-group margin/separation without harming the parameter-economy score much, and matches the explicit recommendation to test whether orthogonal entanglers boost generalization the way the long-range CRZ did.
</DESCRIPTION>
