<DESCRIPTION>
The previous 3-parameter design (independent "ry", "ent", "rz") regressed sharply (score 0.38) relative to the earlier 2-parameter "theta_ry"/"theta_z" seed that scored 0.61. That seed shared a single angle between the local RZ layer and every CRZ entangling edge across three connectivity shells (nearest-neighbor, skip-2, antipodal). Building on that stronger baseline, this edit keeps only 2 distinct trainable circuit parameters ("theta_ry" for a global RY layer, "theta_z" shared by the RZ layer and all entanglers) but diversifies the *generator type* of the entangling shells (CRZ on the nearest-neighbor ring, CRY on the skip-2 ring, CRX on the antipodal pairs) while still tying them all to the same "theta_z" angle. This increases the operator diversity/expressivity reachable per shared parameter (since CRZ, CRY, CRX rotate different Bloch-sphere axes) without adding a single extra trainable parameter, which should help separate harder validation groups (worst-group margin) while preserving the parameter-count advantage that scores well. It directly reverts the regression from 3 params back to 2, and adds a low-risk expressivity boost that costs nothing in parameter economy.
