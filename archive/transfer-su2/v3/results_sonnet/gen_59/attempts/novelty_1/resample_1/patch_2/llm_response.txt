<DESCRIPTION>
Collapse the two distinct trainable circuit parameters ("theta_ry" and "theta_z") into a single shared parameter name "theta" used for both the local RY/RZ rotations and all CRZ entangling shells. Parameter economy is explicitly the dominant scoring factor with "no point of diminishing returns," so going from 2 to 1 distinct circuit parameters (3 total trainable values with gain/bias) should improve the score even at some accuracy cost. The circuit retains its full gate structure (same three entangling shells, same interleaved RZ layer) — only the parameter name binding changes, so expressivity through gate placement, wire connectivity, and 3x repetition is preserved; only the number of independently-optimizable scalars shrinks. This also reduces train/test gap risk since fewer parameters constrain overfitting on the very small training set, aligning with the goal of robust worst-group generalization.
</DESCRIPTION>
