<DESCRIPTION>
The current readout uses a uniform average of all measured pair correlators. The prior recommendations suggest that adding learnable weights per readout pair could significantly improve performance by allowing the model to emphasize its most predictive correlators. This is especially valuable for worst-group margin (the dominant score term), as the model can learn to give more weight to features that reliably separate hard samples.

The key insight is that different readout pairs may have very different signal-to-noise ratios and predictiveness. A learnable weighted mean (with normalized weights) adds minimal overhead (~8 parameters for a typical readout) while providing a powerful calibration mechanism that adapts to the data distribution.

I will:
1. Add learnable pair weights to the parameter count (one per readout pair, normalized to sum to 1)
2. Modify `predict_batch` to compute a weighted mean instead of a uniform mean
3. Update parameter initialization to set pair weights uniformly at the start

This lightweight extension maintains circuit parameter economy while dramatically improving readout calibration and worst-group robustness.

def predict_batch(params, x_batch: np.ndarray):
    """Scalar prediction per state: weighted mean of correlators with learnable pair weights."""
    circuit_params = params[:N_CIRCUIT_PARAMS]
    gain = params[N_CIRCUIT_PARAMS]
    bias = params[N_CIRCUIT_PARAMS + 1]
    pair_weights_raw = params[N_CIRCUIT_PARAMS + 2:]  # (n_pairs,)
    
    # Normalize pair weights to sum to 1 for stable learned aggregation
    pair_weights = pair_weights_raw / pnp.sum(pnp.abs(pair_weights_raw) + 1e-8)
    
    states = pnp.array(np.asarray(x_batch, dtype=complex), requires_grad=False)
    z = pnp.stack(circuit_pair_expectations(states, circuit_params))  # (n_pairs, B)
    
    # Compute weighted mean: expand weights to broadcast over batch dimension
    weighted_z = z * pnp.expand_dims(pair_weights, axis=1)  # (n_pairs, B)
    raw = pnp.sum(weighted_z, axis=0)  # (B,)
    
    return gain * (raw - bias)
