The current program achieves a score of 0.40, which is significantly lower than the previous best (0.56). The key issues are:

1. **Over-aggressive parameter sharing**: The current design shares ALL RZ parameters across all 8 qubits (rz_final), which severely constrains expressiveness. This is a regression from prior designs that used even/odd parity sharing.

2. **Poor worst-group margin (0.16)**: The worst-group margin is the dominant scoring term. It indicates the classifier fails on the hardest samples, suggesting insufficient circuit capacity to separate difficult cases.

3. **High generalization gap (0.28)**: The large train-test gap combined with low test accuracy suggests overfitting despite low parameter count, which points to insufficient inductive bias and expressiveness.

4. **Suboptimal gate patterns**: The current design uses redundant XX gates at distance-0 and distance-2 with different parameters, but all three blocks apply identical patterns, wasting the opportunity to introduce learned diversity.

**Proposed Solution**: Implement cyclic entangler-pattern diversity as recommended. Instead of applying the SAME block 3 times, define three block variants (A, B, C) that cyclically shift the two-qubit entangler wirings while keeping all single-qubit rotation parameters tied. This achieves:

- **Preserved parameter economy**: Same total distinct parameter count (no increase in trainable parameters)
- **Enhanced expressiveness through pattern diversity**: Each repetition introduces different entanglement patterns without adding parameters
- **Better worst-group generalization**: Diverse entanglement patterns help the circuit discover more robust decision boundaries for hard samples
- **Restored RZ individuality**: Restore even/odd parity sharing for RZ (like successful prior designs) instead of global sharing

The three blocks will cycle through different XX wiring patterns:
- Block A: Original pattern (wires [0,1], [2,3], [4,5], [6,7], [0,2], [1,3], [4,6], [5,7], [0,2], [0,4], [0,6])
- Block B: Pattern shifted by +1 (modulo 8) on second wire (wires [0,2], [2,4], [4,6], [6,0], [0,3], [1,4], [4,7], [5,0], [0,3], [0,5], [0,7])
- Block C: Pattern shifted by +2 (modulo 8) on second wire

This preserves block_index-aware execution and maintains the parameter-sharing architecture while enabling learned diversity.

    Parameters are shared across repetitions: every application of the block
    reads the same values, so block_index is accepted only for API symmetry.
    """
    if SPEC_ERRORS:
        raise ValueError("; ".join(SPEC_ERRORS))

    del block_index  # parameters are tied across repeats
    key_to_position = {key: i for i, key in enumerate(PARAMETER_KEYS_PER_BLOCK)}
    for item in ANSATZ_SPEC:
        gate = str(item["gate"]).upper()
        if gate in ALLOWED_SINGLE_QUBIT_GATES:
