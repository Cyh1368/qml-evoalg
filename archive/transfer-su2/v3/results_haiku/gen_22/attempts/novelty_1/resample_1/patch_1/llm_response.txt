<DESCRIPTION>
The current program (score 0.40) shows poor generalization (gap 0.24) and worst-group margin (0.24). The prior Gen 2 program (score 0.54) achieved better worst-group margin (0.31) with heterogeneous structure but higher parameter count (12 distinct params).

Following the recommendation to break strict 3× repetition symmetry, I will implement two variant ansatz blocks (A and B) that are applied in an A–B–A sequence. This introduces structural heterogeneity across the three repetitions while maintaining ~12 distinct parameters.

**Key changes:**
1. Block A uses ZZ entanglement on pairs (0,3) and (4,7)
2. Block B swaps these to (1,4) and (5,2), plus uses YY instead of ZZ for diversity
3. Apply blocks in sequence: A→B→A

This alternation mimics the successful pattern from Gen 2 but with tighter parameter economy and more deliberate symmetry breaking. The hypothesis is that:
- Heterogeneous connectivity across layers should better separate hard samples (improving worst_group_margin)
- Reduced redundancy from varied entanglement patterns should improve generalization
- The A–B–A structure remains learnable with modest parameter sharing

The resulting circuit will have ~11–12 distinct parameters and maintain competitive depth.

    reads the same values, so block_index is accepted only for API symmetry.
    """
    if SPEC_ERRORS:
        raise ValueError("; ".join(SPEC_ERRORS))

    del block_index  # parameters are tied across repeats
    key_to_position = {key: i for i, key in enumerate(PARAMETER_KEYS_PER_BLOCK)}
    for item in ANSATZ_SPEC:
        gate = str(item["gate"]).upper()
        if gate in ALLOWED_SINGLE_QUBIT_GATES:

                qml.RZ(angle, wires=wire)
