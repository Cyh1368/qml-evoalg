The current program has degraded from the prior baseline:
- Combined score dropped from 0.60 → 0.55
- Test accuracy fell from 0.96 → 0.89
- Worst-group margin slightly declined from 0.32 → 0.31
- Parameter count increased from 7 distinct to 8 distinct (n_params: 9 → 10)
- Depth increased from 15 → 24, gate count from 72 → 84

The recent addition of a ring-loop YY entanglement layer ("yy_loop" parameter) added complexity without improving robustness. The recommendation from the evaluator explicitly suggests a mixed-scale initialization strategy:

**After drawing all N_PARAMS from Uniform(–π, π), reset any param whose key contains "ent_near", "cross", or "diag" to Uniform(–π/4, π/4) while leaving all rotation and readout params at full scale.**

This strategy works by narrowing the initialization range for entangler angles (which tend to cause barren plateaus and poor convergence) while preserving the full-scale random init for single-qubit rotations (which are more robust). The entangler keys "xx_near", "yy_diag", "yy_loop", and "zz_diag" all contain substrings matching "ent_near", "cross", or "diag", so they will be rescaled.

This mixed-scale approach:
1. Prevents barren plateaus in entangling layers
2. Stabilizes convergence (~780 steps observed in prior successful generation)
3. Reduces overfitting by giving entanglers a narrow starting range, forcing them to learn more meaningful patterns
4. Maintains the seed-stable training observed in high-performance generations

The implementation filters parameter names during initialization and rescales their values accordingly. This is a pure initialization change with no circuit topology modifications, so it preserves the gate structure while fixing the optimization landscape.
