The current program achieves a combined score of 0.49, down from 0.60 in the prior baseline. The key performance gap is:
- worst_group_margin_mean: 0.22 (vs 0.32 in baseline)
- validation_margin_mean: 0.43 (vs 0.64 in baseline)
- generalization_gap_mean: 0.15 (vs 0.04 in baseline)
- n_params: 13 (vs 9 in baseline)

The problem is clear: the current ANSATZ has too many distinct parameters (11) relative to the baseline (7), which increases overfitting without proportional gains in worst-group margin separation. The recommendation to split readout calibration by parity offers a targeted way to improve worst-group margins without increasing circuit complexity.

The strategy:
1. Keep the ANSATZ_SPEC lean (restore to ~7-8 distinct params, matching the baseline structure)
2. Add parity-specific gain/bias to the readout: 4 additional parameters split by whether the first qubit in each READOUT_PAIR is even or odd
3. This provides separate calibration for two subgroups without circuit changes

The parity split is principled because:
- It mirrors the inherent structure of the 8-qubit system (qubit indices 0,2,4,6 vs 1,3,5,7)
- Readout pairs likely exhibit different error profiles / margins based on this structure
- It allows the optimizer to independently tune gain/bias for the two groups
- The +2 parameter cost is negligible for margin improvement

def predict_batch(params, x_batch: np.ndarray):
    """Scalar prediction per state: parity-specific calibrated mean of correlators.
    
    Split readout calibration into even/odd based on the first qubit of each pair.
    """
    circuit_params = params[:N_CIRCUIT_PARAMS]
    gain_even = params[N_CIRCUIT_PARAMS]
    bias_even = params[N_CIRCUIT_PARAMS + 1]
    gain_odd = params[N_CIRCUIT_PARAMS + 2]
    bias_odd = params[N_CIRCUIT_PARAMS + 3]
    
    states = pnp.array(np.asarray(x_batch, dtype=complex), requires_grad=False)
    z = pnp.stack(circuit_pair_expectations(states, circuit_params))  # (n_pairs, B)
    
    # Identify even and odd pair indices based on first qubit parity
    even_idx = pnp.array([i for i, (a, b) in enumerate(READOUT_PAIRS) if a % 2 == 0], dtype=int)
    odd_idx = pnp.array([i for i, (a, b) in enumerate(READOUT_PAIRS) if a % 2 == 1], dtype=int)
    
    # Compute separate means for each group
    raw_even = pnp.mean(z[even_idx], axis=0) if len(even_idx) > 0 else pnp.array(0.0)
    raw_odd = pnp.mean(z[odd_idx], axis=0) if len(odd_idx) > 0 else pnp.array(0.0)
    
    # Apply separate gain/bias to each group and average
    pred_even = gain_even * (raw_even - bias_even) if len(even_idx) > 0 else pnp.array(0.0)
    pred_odd = gain_odd * (raw_odd - bias_odd) if len(odd_idx) > 0 else pnp.array(0.0)
    
    # Weighted average by group size
    n_even = float(len(even_idx))
    n_odd = float(len(odd_idx))
    n_total = n_even + n_odd
    return (n_even * pred_even + n_odd * pred_odd) / n_total if n_total > 0 else pnp.array(0.0)
