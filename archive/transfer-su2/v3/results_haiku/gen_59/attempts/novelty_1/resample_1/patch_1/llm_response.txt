<DESCRIPTION>
The current bottleneck is the worst_group_margin_mean of 0.32, which is significantly lower than the validation_margin_mean of 0.64. This indicates that hard subgroups of validation samples are not being separated robustly enough.

The recommendation proposes splitting readout calibration by parity: instead of a single gain/bias pair applied to all pair correlators, we introduce separate calibration parameters for even-indexed and odd-indexed pair positions. This allows the model to decouple sublattice biases and tighten margins within each parity subgroup independently.

Implementation:
1. Increase N_READOUT_PARAMS from 2 to 4: "gain_even", "bias_even", "gain_odd", "bias_odd"
2. Compute raw_even and raw_odd separately by filtering READOUT_PAIRS by parity
3. Combine them as: gain_even*(raw_even–bias_even) + gain_odd*(raw_odd–bias_odd)
4. Initialize the new parameters appropriately (gains=1, biases=0)

This +2-parameter tweak directly addresses the worst-group margin problem by allowing independent calibration of even and odd sublattices, which are natural geometric subdivisions in an 8-qubit system. The cost (2 extra parameters) is negligible, but the benefit for robust separation should be substantial.
</DESCRIPTION>

def predict_batch(params, x_batch: np.ndarray):
    """Scalar prediction per state: calibrated mean of the fixed correlators.
    
    Split calibration by pair index parity to decouple even/odd sublattice biases
    and improve robustness on hard validation subgroups.
    """
    circuit_params = params[:N_CIRCUIT_PARAMS]
    gain_even = params[N_CIRCUIT_PARAMS]
    bias_even = params[N_CIRCUIT_PARAMS + 1]
    gain_odd = params[N_CIRCUIT_PARAMS + 2]
    bias_odd = params[N_CIRCUIT_PARAMS + 3]
    states = pnp.array(np.asarray(x_batch, dtype=complex), requires_grad=False)
    z = pnp.stack(circuit_pair_expectations(states, circuit_params))  # (n_pairs, B)
    
    # Separate even and odd pair indices
    raw_even = pnp.mean(z[::2, :], axis=0) if len(READOUT_PAIRS) > 0 else pnp.mean(z, axis=0)
    raw_odd = pnp.mean(z[1::2, :], axis=0) if len(READOUT_PAIRS) > 1 else pnp.mean(z, axis=0)
    
    # Apply independent calibration per parity
    return gain_even * (raw_even - bias_even) + gain_odd * (raw_odd - bias_odd)
