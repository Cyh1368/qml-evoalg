# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

• One-parameter global rotation trajectory + Möbius-ladder CZ   
  – Generation 22 (Collective-Angle 8-Qubit Möbius Ansatz) ties a single “collective_angle” across all RY and RZ gates, repeats the minimal block three times, and uses fixed long-range CZ links. This yields the top combined score (0.53), test accuracy 0.74, parameter efficiency 0.25, depth 33, and only 3 tunable weights.  

• Repetition of a minimal, tied-parameter block multiplies expressivity  
  – Across Gen 20, 21, and 22, using N_REPEATS=3 with identical parameters boosts test accuracy from ≈0.65 (single pass) to 0.73–0.74 without adding parameters.  

• Wide uniform initialization in [–π, π]  
  – All high-scoring ansätze (Gen 18, 20, 22) initialize angles across the full period, avoiding barren-plateau artifacts and ensuring consistent convergence.  

• Trainable gain/bias readout calibration  
  – Every top performer stabilizes margins (Gen 22 validation_margin 0.31, worst_group_margin 0.19) by appending “gain*(mean(correlators)–bias),” preventing trivial zero-gain solutions.  

## Ineffective Approaches

• Over-tying with insufficient connectivity underfits badly  
  – Gen 24 (Shared-Angle 8-Qubit Ansatz) uses one shared RY parameter plus cyclic CZ/XX but scores only 0.39 combined (test 0.46, gap 0.23), indicating that extreme parameter tying without non-local entanglement fails to capture correlations.  

• Symmetric-only ZZ entanglers yield high train but poor generalization  
  – Gen 25 (Symmetric Möbius Ladder Ansatz) ties two parameters across RY/RZ and shared ZZ on diametric pairs. Despite train 0.94, it achieves only combined 0.47 (test 0.72, gap 0.21), showing that symmetry without parameter diversity leaves under-expressivity on validation subsets.  

• Adding more distinct parameters without richer entanglers gives diminishing returns  
  – Gen 21 (Symmetric 8-Qubit State Classifier) uses 4 parameters (2 distinct) in a Möbius ladder + CRZ readout, scoring 0.51 (test 0.73) but still gap 0.14. Extra parameters alone couldn’t close the generalization gap.  

## Implementation Insights

• Central ANSATZ_SPEC + key-to-index mapping streamlines tying  
  – The best program (Gen 22) builds `{param_key: index}` once in `apply_ansatz_block`, loops over gates, and ignores `block_index`—ensuring zero overhead for tied-parameter repeats.  

• Explicit parameter tying via `del block_index`  
  – By dropping block-specific weights, all repeats share the same array slice; this simple pattern underpins Gen 22’s 3-fold depth gain without extra parameters.  

• Circuit metadata extraction for cost/performance trade-offs  
  – Using `qml.queuing.AnnotatedQueue` + `tape.graph.get_depth()`, Gen 22 reports depth=33 and gate_count=84, enabling direct comparison to deeper designs (Gen 20 depth 55, gates 108).  

• Opaque two-qubit correlator readout + calibration  
  – Measuring Hermitian(PAIR_OBSERVABLE) on dataset pairs and averaging before gain/bias fits both global features and margins; seen in all top ansätze (Gen 16, 18, 22).  

## Performance Analysis

• Combined score spread: 0.39→0.53  
  – Gen 24 (0.39) at the low end, Gen 22 tops at 0.53. Only designs combining non-local CZ links, block repetition, and extreme parameter tying (1–3 parameters) reach >0.50.  

• Non-local Möbius CZ vs. local mixers  
  – Moving from local/hypercube entanglers (Gen 15 test 0.60) to Möbius-ladder CZ (Gen 22 test 0.74) yields an absolute +14% test gain without increasing tunable dimensions.  

• Parameter efficiency correlates with minimal distinct angles  
  – Gen 22’s efficiency 0.25 (test 0.74 / 3 params) outperforms Gen 20’s 0.15 (test 0.73 / 5 params) and Gen 21’s ≈0.18 (test 0.73 / 4 params).  

• Moderate generalization gaps unlock higher test accuracy  
  – Accepting gap≈0.14 (Gen 22) achieves test 0.74, whereas low-gap (<0.07) underfitting models stall at test≈0.50. Controlled over-expressivity benefits few-shot generalization.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Parameterize the Möbius‐ladder cross‐chords with a single shared ZZ angle  
   In ANSATZ_SPEC, replace each fixed CZ on wires [0,4], [1,5], [2,6], [3,7] with  
     `{"gate":"ZZ","wires":[i,j],"param":"cross_ent"}`  
   This preserves the proven non-local connectivity while giving the optimizer control over the strength of all four diametric links via one extra parameter—leveraging the expressivity gain of tunable entanglers without blowing up the parameter count.  

2. Append a shared nearest‐neighbor IsingXX layer after the ladder  
   Immediately following the Möbius‐ladder block in ANSATZ_SPEC, add for i in 0…7:  
     `{"gate":"XX","wires":[i,(i+1)%8],"param":"xx_nn"}`  
   One extra “xx_nn” angle strengthens local correlations (as seen in Gen 3’s shared two-qubit gates) and can lift test accuracy under a tight param budget by complementing the global non-local links.  

3. Untie the single “collective_angle” into per-block, per-axis parameters  
   Change PARAMETER_KEYS_PER_BLOCK to `["y_0","z_0","y_1","z_1","y_2","z_2"]` and in ANSATZ_SPEC tag each RY in block k with `"param":"y_k"` and each RZ with `"param":"z_k"`.  
   This trades 1 → 6 circuit parameters, allowing each of the three depth repeats to learn its own axis-specific mixer, which can boost expressivity and test accuracy while still enforcing strong within-block tying.  

4. Replace fixed nearest-neighbour CZs with a shared CRZ entangler  
   In ANSATZ_SPEC, swap each CZ on [i,i+1] with  
     `{"gate":"CRZ","wires":[i,(i+1)%8],"param":"nn_phase"}`  
   A single “nn_phase” tuning all NN phase-gates lets the circuit adjust propagation strength dynamically, combining the benefits of paired two-qubit rotations (seen in Gen 21’s CRZ readout) with the Möbius ladder’s non-local coverage.  

5. Alternate two Möbius-ladder patterns across repeats  
   Define ANSATZ_SPEC_A as the existing ladder and ANSATZ_SPEC_B as the same but with cross-chords shifted (e.g. [0,5],[1,6],[2,7],[3,4]). In apply_ansatz_block, apply A when block_index % 2==0 else B, reusing the same tied rotation parameters.  
   This injects richer non-local connectivity along depth without extra parameters, potentially capturing correlations that a single static pattern misses, as suggested by the depth-amplification benefits of block repetition.
