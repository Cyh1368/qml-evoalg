# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Extreme parameter tying of collective rotations plus a fixed, richly connected entangler.  
  • Global-Rotation Möbius-Ladder (Gen 10) uses only two distinct angles (“global_y”, “global_z”) and a parameter-free Möbius CZ network repeated three times. It achieves the top test accuracy (0.74), combined score 0.51, generalization gap 0.14, and highest parameter efficiency 0.18.  
- Low parameter count with nontrivial entanglement preserves expressivity.  
  • The 8-Qubit Repeated RY/XX ansatz (Gen 3) with five parameters and shared XX gates also reached combined 0.51, but plateaued at test 0.69. In contrast, Gen 10’s richer long-range CZ links push test accuracy higher despite fewer parameters.  
- Consistent use of trainable gain/bias calibration on averaged two-qubit correlators.  
  • All top performers (Gen 1–5, Gen 10) reuse the same `predict_batch` gain/bias pattern, stabilizing margins and avoiding trivial zero-gain solutions.  
- Full-period random initialization to escape dead zones.  
  • Möbius-Ladder and earlier models initialize angles in [−π, π], preventing early optimizer stagnation and contributing to stable convergence across seeds.  

## Ineffective Approaches  
- Over-tying with weak entanglers underfits the data.  
  • Shared-Parameter Floquet (Gen 8) ties two angles around a simple CZ ring, yielding high gap (0.24) and test 0.51—no better than random.  
  • Single-Param Kicked-Ising (Gen 7) with one circuit angle reaches only test 0.53 (combined 0.45).  
- Deep circuits without parameter diversity still plateau at chance.  
  • Shared Mixer + Periodic ZZ (Gen 6) uses four parameters in a 27-depth circuit but test remains 0.51 (combined 0.40), indicating depth alone can’t substitute for diverse rotations.  
- Untied local rotations over-parameterize and overfit.  
  • The initial all-untied RY/RZ ansatz (Gen 0) with 26 parameters and depth 20 overfits severely (train 0.88 → test 0.56; gap 0.31), achieving combined 0.29.  

## Implementation Insights  
- Centralized parameter‐key lookup for tied parameters.  
  • All successful ansätze build a `{param_name: index}` map once, then loop over `ANSATZ_SPEC`, avoiding per-repeat key overhead and ensuring correct tieing.  
- Explicit ansatz validation decouples spec errors from training.  
  • The `validate_ansatz_spec` function flags unsupported gates or malformed wires before QNode creation, preventing silent runtime failures.  
- Rich entanglement via non-local CZ links coded directly in the spec.  
  • Gen 10’s Möbius-ladder adds cross chords (0–4, 1–5, 2–6, 3–7) in addition to the ring, dramatically boosting expressivity without extra parameters.  
- Metadata extraction to balance depth vs. gate count.  
  • Using `qml.queuing.AnnotatedQueue` and `tape.graph.get_depth()` ensures the circuit remains within target depth (33) and gate-count (84), informing efficient entangler designs.  

## Performance Analysis  
- Test accuracy tracks entanglement richness more than depth or parameter count.  
  • Gen 5 (3 parameters, depth 9) reached only test 0.56, while Gen 10 (2 parameters, depth 33) hits test 0.74, showing that a well-connected fixed entangler can outweigh circuit shallowness.  
- Extreme regularization via minimal parameters reduces gap but may cap accuracy.  
  • Gen 3’s tight parameter tying achieved a low gap (0.06) but test 0.69; Gen 10 accepts a slightly larger gap (0.14) for substantially higher test accuracy.  
- Parameter efficiency (test accuracy / n_params) improves with expressivity:  
  • Gen 10 leads at 0.18, Gen 3 at 0.14, Gen 5 at 0.10, illustrating that richer entanglement boosts efficiency when paired with minimal parameters.  
- Combined score correlates with test accuracy rather than train performance.  
  • Although several tied-parameter models have similar low gaps, only those with non-local entanglement (Gen 10, Gen 3) break past test 0.69 to maximize the combined metric (0.51).

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Add a shared ZZ entangler on nearest neighbors at the end of each block  
   Extend ANSATZ_SPEC so that, after the Möbius-ladder CZs and before the RZs, you append  
     for i in range(N_QUBITS):  
       {"gate": "ZZ", "wires": [i, (i+1) % N_QUBITS], "param": "zz_nn"}  
   This injects one trainable two-qubit parameter across all nearest neighbors, leveraging the success of Gen 3’s shared XX entanglement to boost expressivity with minimal extra cost.  

2. Parameterize the Möbius-ladder cross chords with one shared angle  
   In ANSATZ_SPEC, replace the four fixed cross-ring CZ gates on wires [0,4],[1,5],[2,6],[3,7] with  
     {"gate": "ZZ", "wires": [...], "param": "cross_ent"}  
   This turns long-range entanglement itself into a tunable knob (one extra parameter) and builds directly on Gen 10’s rich connectivity to raise test accuracy without increasing gap.  

3. Semi-collective local rotations by even/odd grouping  
   Instead of two “global_y” and “global_z” keys, define “global_y_even”, “global_y_odd”, “global_z_even”, “global_z_odd” in PARAMETER_KEYS, and in ANSATZ_SPEC apply RY/RZ on even-indexed qubits with the “_even” keys and on odd-indexed qubits with the “_odd” keys.  
   This moves from 2 to 4 rotation parameters, doubling expressivity in a structured way that preserves extreme tying within each subgroup.  

4. Sweep the block repetition count around 3 to find the optimal depth  
   Refactor the definition of N_REPEATS into a mutable hyperparameter and generate variants with N_REPEATS={2,3,4} (depth≈22,33,44) while keeping the Möbius-ladder + rotation spec fixed.  
   Global insights show that depth alone doesn’t substitute for connectivity but there may be a sweet spot between under- and over-repetition that further boosts test accuracy.  

5. Inject a shared CRZ layer on the readout pairs before measurement  
   After all ansatz repeats, append into the qnode loop:  
     for (a,b) in READOUT_PAIRS: qml.CRZ(params[key_to_position["readout_crz"]], wires=[a,b])  
   This adds one controllable phase entangler directly on the correlator pairs, focusing expressivity where the fixed Hermitian measurements occur, an approach that improved margins in earlier prototypes.
