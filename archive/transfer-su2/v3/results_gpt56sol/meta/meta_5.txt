# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Collective global rotations with minimal distinct parameters.  
  • Tied-Parameter Collective Ansatz (Gen 5, “collective_basis_ansatz”) uses only three per-block parameters (RZ→RY→RZ) across all 8 qubits (plus gain/bias), achieving the top combined score 0.41.  
  • This pattern cut the generalization gap to 0.06 (versus 0.18–0.31 in earlier models) while retaining reasonable train accuracy (0.56).  
- Depth reduction via collapsing repeats into single collective layer.  
  • Gen 5’s circuit depth of 9 is substantially shallower than the 20–30 depths of earlier 3-repeat designs, improving parameter efficiency (0.10) without severely sacrificing test accuracy.  
- Early stopping and few-shot balanced sampling preserved across successful variants.  
  • All top-performing models (Gen 1–5) employ class-balanced subsampling, Adam optimization, and validation-loss early stopping, confirming these as stable scaffolds for fair comparison.  

## Ineffective Approaches  
- Fully un-tied RY/RZ chains with linear CZ entanglement (Gen 0 “initial_program”)  
  • Despite 26 parameters and depth 20, it overfits severely (train 0.88 → test 0.56; gap 0.31; combined 0.29).  
- Excessive parameter tying in specialized entanglers without depth reduction (Gen 4 “shared_floquet_ising”)  
  • Three shared parameters in repeated Ising-ZZ rings still yield a large gap (0.31) and mediocre test accuracy (0.50; combined 0.35), indicating that mere sharing in 30-depth circuits is insufficient.  
- Global-tied rotations with fixed periodic CZ ring (Gen 1 “symmetry_tied_floquet”)  
  • Tying RY, RZ, RX across all wires improved gap (0.18) but test accuracy remained low (0.51; combined 0.39), pointing to under-expressivity in entanglement variety.  

## Implementation Insights  
- Parameter key ordering and tied-lookup map simplifies repeat logic.  
  • All successful programs share the pattern: build a `PARAMETER_KEYS_PER_BLOCK` list, map keys once, then loop over `ANSATZ_SPEC` to apply gates. This avoids per-repeat key overhead.  
- Circuit metadata extraction informs depth vs. gate-count trade-off.  
  • Gen 5 leverages `qml.queuing.AnnotatedQueue` + `tape.graph.get_depth()` to confirm a shallow 9-depth construction, prioritizing depth reduction over gate count.  
- Averaged two-qubit Hermitian correlator readouts with trainable gain/bias remain a stable, low-variance measurement stage.  
  • All models reuse the same `predict_batch` pattern, isolating ansatz effects and ensuring comparability.  

## Performance Analysis  
- Combined score progression correlates inversely with parameter count and depth.  
  • Gen 0 (26 params, depth 20): 0.29 → Gen 4 (3 params, depth 30): 0.35 → Gen 2 (4 params, depth 20): 0.37 → Gen 1 (3 params, depth ?): 0.39 → Gen 5 (3 params, depth 9): 0.41.  
- Generalization gap tightly linked to expressivity vs. regularization balance.  
  • Models with moderate tying but high repeat depth (Gen 2, Gen 4) see gaps ~0.31; those with extreme tying plus shallow depth (Gen 5) drive gap down to 0.06.  
- Test accuracy plateau near chance level (~0.50–0.51) across tied-parameter models.  
  • Although Gen 5 achieves the best regularization, all minimal-param variants converge to ~0.50 test accuracy, suggesting a trade-off ceiling under the current measurement scheme.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce a single tied-parameter two-qubit entangling layer after each collective RZ→RY→RZ block. Concretely, extend ANSATZ_SPEC to append one `{"gate": "ZZ", "wires": [i, (i+1)%N_QUBITS], "param": "collective_zz"}` for every nearest-neighbor pair i, using a single new key `"collective_zz"`. This adds just one extra parameter and +1 depth per block, preserving the minimal-param philosophy while injecting controllable entanglement to boost test accuracy.  

2. Split the 8 qubits into two tied-parameter groups (e.g. even vs. odd indices) for the collective rotations. Define six parameters—`z_pre_even`, `z_pre_odd`, `y_even`, `y_odd`, `z_post_even`, `z_post_odd`—and in ANSATZ_SPEC apply RZ/RY/RZ on evens with the “_even” keys and odds with the “_odd” keys. This semi-collective pattern doubles expressivity over the current 3-param block while still collapsing repeats and controlling depth.  

3. Sweep the repetition count around the current best. Generate two new variants with N_REPEATS=2 (depth≈6) and N_REPEATS=4 (depth≈12) but keep the 3-parameter RZ→RY→RZ block unchanged. This will empirically map the sweet spot between under-expressivity (too few repeats) and over-regularization (too many shallow repeats).  

4. Interleave fixed CZ entanglement every other repeat to diversify connectivity without new params. Modify the loop in `circuit_pair_expectations` so that for odd repeats you call `qml.CZ(wires=[i,(i+1)%N_QUBITS])` over all nearest neighbors before the next collective rotation. This builds on Gen 1’s gap improvements from fixed entanglement but keeps the core 3-param, shallow-depth block intact.  

5. Target readout pairs with a single tied CRZ before measurement. After all repeats, add one `CRZ` layer across each `READOUT_PAIRS` using a new param key `"readout_crz"`. By entangling exactly the qubit pairs used in the Hermitian correlator measurement with one extra shared parameter, you focus expressivity where it directly impacts the averaged readout signal.
