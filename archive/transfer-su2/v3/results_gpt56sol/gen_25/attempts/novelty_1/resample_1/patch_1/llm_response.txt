<DESCRIPTION>
Replace the underperforming readout-graph Floquet circuit with the previously stronger symmetry-regularized Möbius-ladder structure. A single collective angle remains shared by every RY and RZ rotation, preserving parameter economy and few-shot generalization. The local ring uses fixed CZ gates, while the four diametric Möbius chords use one shared ZZ parameter. This adds only one circuit degree of freedom but allows optimization to control non-local correlation strength independently, which should improve worst-group separation without introducing wire-specific parameters or excessive training capacity.

# A one-parameter Floquet circuit built on the actual readout graph.
#
# The global RY mixer and the two noncommuting interaction sweeps share the
# same angle. Consequently the model has only one circuit degree of freedom,
# but its repeated action is not equivalent to one simple Pauli rotation.
# Reversing the ZZ sweep also avoids introducing an arbitrary preferred end
# of the supplied pair ordering.
_SHARED_PARAM = "readout_floquet_angle"

ANSATZ_SPEC = (
    [
        {"gate": "RY", "wire": wire, "param": _SHARED_PARAM}
        for wire in range(N_QUBITS)
    ]
    + [
        {
            "gate": "XX",
            "wires": [int(a), int(b)],
            "param": _SHARED_PARAM,
        }
        for a, b in READOUT_PAIRS
    ]
    + [
        {
            "gate": "ZZ",
            "wires": [int(a), int(b)],
            "param": _SHARED_PARAM,
        }
        for a, b in reversed(READOUT_PAIRS)
    ]
)
