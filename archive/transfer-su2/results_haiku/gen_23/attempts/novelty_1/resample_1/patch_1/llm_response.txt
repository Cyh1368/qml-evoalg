<DESCRIPTION>
The current program achieves perfect accuracy (1.00) with 26 parameters and fast convergence (30 steps), which is excellent. However, the recommendation suggests alternating between fixed CZ chains and parametrized ZZ entanglers across the 6 repeats to inject richer two-qubit couplings while maintaining parameter economy.

The key insight is:
- **Odd-indexed repeats (1, 3, 5)**: Use fixed nearest-neighbor CZ chain (0 parameters)
- **Even-indexed repeats (0, 2, 4)**: Use shared-parameter IsingZZ entanglers on the chain (1 parameter per block)

This approach:
1. Maintains the proven single-qubit rotations (RY on even qubits, RZ on odd qubits)
2. Alternates entanglement strategies to expose the circuit to different correlation structures
3. Reduces total parameters from 26 to approximately 20 (3 params × 6 repeats + 2 readout = 20), improving parameter efficiency
4. Leverages the fact that ZZ-based minimal ansätze achieve perfect accuracy while CZ chains provide structural stability
5. Preserves fast convergence by keeping the alternation pattern simple and deterministic

The modification requires:
- Replacing the current XX-based entanglement with a hybrid approach
- Using conditional logic in `apply_ansatz_block` to alternate between CZ (fixed) and ZZ (parametrized) based on block index
- Simplifying ANSATZ_SPEC to define only the ZZ variant, with CZ gates applied conditionally

def apply_ansatz_block(params, block_index: int) -> None:
    """Apply one candidate ansatz block from the formal ANSATZ_SPEC.
    
    Alternating entangler strategy:
    - Odd-indexed repeats (1, 3, 5): fixed CZ nearest-neighbor chain
    - Even-indexed repeats (0, 2, 4): parametrized ZZ nearest-neighbor chain
    """
    if SPEC_ERRORS:
        raise ValueError("; ".join(SPEC_ERRORS))

    offset = block_index * N_PARAMS_PER_BLOCK
    key_to_position = {key: i for i, key in enumerate(PARAMETER_KEYS_PER_BLOCK)}
    is_even_repeat = (block_index % 2 == 0)
    
    for item in ANSATZ_SPEC:
        gate = str(item["gate"]).upper()
        if gate in ALLOWED_SINGLE_QUBIT_GATES:
            angle = params[offset + key_to_position[item["param"]]]
            wire = int(item["wire"])
            if gate == "RX":
                qml.RX(angle, wires=wire)
            elif gate == "RY":
                qml.RY(angle, wires=wire)
            elif gate == "RZ":
                qml.RZ(angle, wires=wire)
        elif gate in ALLOWED_TWO_QUBIT_GATES:
            wires = [int(w) for w in item["wires"]]
            if gate == "CNOT":
                qml.CNOT(wires=wires)
            elif gate == "CZ":
                qml.CZ(wires=wires)
        elif gate in ALLOWED_PARAM_TWO_QUBIT_GATES:
            wires = [int(w) for w in item["wires"]]
            if gate == "ZZ":
                # Apply ZZ only on even-indexed repeats; apply fixed CZ on odd-indexed repeats
                if is_even_repeat:
                    angle = params[offset + key_to_position[item["param"]]]
                    qml.IsingZZ(angle, wires=wires)
                else:
                    qml.CZ(wires=wires)
            else:
                angle = params[offset + key_to_position[item["param"]]]
                if gate == "CRX":
                    qml.CRX(angle, wires=wires)
                elif gate == "CRY":
                    qml.CRY(angle, wires=wires)
                elif gate == "CRZ":
                    qml.CRZ(angle, wires=wires)
                elif gate == "XX":
                    qml.IsingXX(angle, wires=wires)
                elif gate == "YY":
                    qml.IsingYY(angle, wires=wires)
