# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Shared-parameter single-qubit rotations across even/odd qubits plus a fixed CZ chain (Generation 2) yielded 1.00/1.00/1.00 accuracies with only 26 parameters, parameter efficiency 0.04, and convergence in ~90 steps—demonstrating that aggressive parameter reuse preserves expressivity.  
- A simple trainable gain/bias layer on averaged two-qubit ZZ correlators (used in Gen 2, Gen 8, Gen 10) consistently delivered zero generalization gap and stabilized training across all top circuits.  
- Repeating a small block N_REPEATS=6 times (Gen 2, Gen 8, Gen 10) balanced expressivity and parameter economy, enabling perfect separability without overfitting.  
- Structuring ansatz blocks as even/odd shared RY rotations with uniform RZ “pre”/“post” phases (Gen 2) achieved rapid convergence and full classification power with minimal unique weights.  

## Ineffective Approaches  
- Over-pruning entangling gates to reduce depth/gate count (Generation 10) cut gates from 186→90 but slowed convergence from ~90→300 steps, indicating that simpler topology alone may starve the optimiser of rich gradients.  
- Introducing mixed parametric two-qubit gates (CRX/CRY/CRZ alongside CZ in Gen 3) inflated parameter count to 74 yet only attained a combined score of 0.87, showing that misaligned two-qubit interactions can erode efficiency.  
- Adding cross-pair IsingZZ entanglers (Gen 9’s 62 parameters, depth 30) did not improve parameter efficiency (∼0.02) despite deeper entanglement, suggesting extra interactions beyond nearest neighbors yield diminishing returns.  
- Expanding single-qubit gate axes (adding YZ layers in Gen 7) increased circuit complexity (74 parameters) without lowering validation/test loss (0.04/0.03), failing to surpass simpler XX/ZZ-based designs.  

## Implementation Insights  
- Early validation of ANSATZ_SPEC and building a param-key→index map (as in Gen 2) ensures minimal runtime overhead when applying repeated blocks.  
- Encapsulating the small ansatz in apply_ansatz_block(params, block_index) with explicit dispatch for ALLOWED_* gates preserves flexibility while avoiding code bloat.  
- Vectorizing correlator measurements via pnp.stack in predict_batch boosts throughput when evaluating multiple readout pairs.  
- Initializing output gain=1 and bias=0 decouples quantum feature learning from linear scaling, as seen in all top programs, and guarantees that the circuit focuses first on extracting meaningful correlators.  

## Performance Analysis  
- Circuits with ≤38 unique parameters consistently hit perfect accuracy and zero generalization gap; parameter efficiency rises from 0.01 (74 params)→0.026 (38 params)→0.04 (26 params).  
- Depth/gate count trade-off: the minimal-depth Gen 8 (12/60) converged in ~60 steps; the deeper Gen 2 (35/186) in ~90 steps; and the mid-depth Gen 10 (18/90) in ~300 steps—highlighting that block structure and gradient richness, not just gate count, govern convergence speed.  
- Perfect test accuracy was achieved across all designs once expressivity exceeded the dataset complexity (~26–38 params), confirming a threshold beyond which additional capacity yields diminishing returns.  
- Faster converging designs (Gen 3, Gen 7 with 74 params) required only ~30 steps but sacrificed parameter efficiency; Gen 2 strikes a balance with 26 params, perfect accuracy, and moderate convergence time.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Alternate shared‐parameter entanglers across repeats  
   In odd‐indexed repeats keep the fixed CZ chain, and in even‐indexed repeats swap each CZ for an IsingXX gate with two shared parameters (“xx_even” for pairs starting on even qubits, “xx_odd” for odd). This preserves the 4‐param/per‐block budget, injects richer two‐qubit interactions proven to speed convergence in Gen 1/3, and maintains the proven repeat‐and‐share architecture.  

2. Prepend a global RX mixing rotation in each block  
   Add a single trainable parameter “rx_global” at the very start of every block, applying RX(rx_global) to all eight qubits before the existing RY layers. Similar minimal‐overhead mixing layers have improved expressivity in hybrid ansätze without blowing up the parameter count, and should synergize with the even/odd RY+RZ pattern to furnish stronger gradients.  

3. Pairwise share block parameters to deepen stacking  
   Instead of unique parameters for all six repeats, tie blocks (0&1), (2&3), and (4&5) so you only learn three distinct parameter sets but still apply six layers. This halves the unique‐parameter budget (from 26→14) while preserving overall circuit depth, testing whether deeper, more parameter‐efficient repetition can match expressivity.  

4. Replace the fixed CZ chain with tunable IsingZZ entanglers  
   Swap out each CZ in the nearest‐neighbor chain for an IsingZZ gate and introduce two shared parameters per block (“zz_even”/“zz_odd”) to modulate coupling strength. This small shift builds on the success of parameterized two‐qubit gates in Gen 2’s minimal ansatz, potentially yielding finer control over entanglement and sharper correlator features without increasing gate count.  

5. Use group‐wise gains on readout correlators  
   Instead of a single global gain, split the measured ZZ correlators into two groups (e.g. those on even‐starting pairs vs odd‐starting pairs) and learn a separate gain for each before averaging, plus the existing bias. This adds only one extra parameter but allows the model to differentially weight the most informative correlator subsets—leveraging the zero‐gap stability of the gain/bias layer while boosting discriminative power.
