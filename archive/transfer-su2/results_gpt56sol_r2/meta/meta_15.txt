# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Two‐axis global rotation with CZ chain (Current Best Program, Generation 9):  
  • ANSATZ_SPEC ties one global_ry and one global_rz per block (N_PARAMS_PER_BLOCK=2), repeated N_REPEATS=6.  
  • Achieves perfect train/validation/test accuracy, test_loss≈0.01, depth=29, gate_count=138, convergence in ~90 steps.  
- Single‐axis global mixing with XX entanglers (Generations 15 & 18):  
  • One shared “collective_mix” or “global_ry” per block driving XX Ising interactions, N_PARAMS=8.  
  • Yields perfect accuracy, test_loss≈0.05, depth=23, gate_count=90, rapid convergence (~30 steps).  
- Fixed two‐qubit Z–Z correlator readout + gain/bias calibration (All Top‐Performers):  
  • Averaging dataset‐specified PauliZ⊗PauliZ observables and calibrating with two readout parameters stabilizes losses (~0.01–0.05) and ensures zero generalization gap.  
- Block repetition count N_REPEATS=6 across all high‐scoring programs ensures full expressivity without over-depth penalties.  

## Ineffective Approaches  
- CZ‐only entanglement blocks (Generations 3 & 4):  
  • No parameterized rotations; plateaued at ~50% accuracy (combined score ~0.64).  
- Fully unshared, per‐qubit parameterization (146 trainable angles):  
  • Although it converged in ~30 steps, it scored only 0.81 combined with extreme parameter redundancy (param_efficiency≈0.01).  
- Single‐axis global RY without a second rotation axis:  
  • Test_loss≈0.04 (Generations 1, 8, 10) vs. ~0.01 for two‐axis; omitting RZ sacrifices tighter loss minimization.  
- Increasing N_REPEATS beyond 6:  
  • No further accuracy or loss improvements, only added gates and depth, confirming N_REPEATS=6 as the sweet spot.  

## Implementation Insights  
- Declarative ANSATZ_SPEC + apply_ansatz_block abstraction:  
  • Enables swapping between one‐parameter (shared_ry_xx_mixer) and two‐parameter (global_ry/global_rz) designs without altering the training loop.  
- Ordered unique PARAMETER_KEYS_PER_BLOCK + offset indexing:  
  • Clean parameter-to-gate mapping; in the current best program, this yields 2 keys per block → 12 circuit parameters + 2 readout.  
- Early stopping with best‐weight restoration:  
  • All top performers (e.g., Generation 14/19 tie_collective_axes) used min_delta=1e-4, patience=75 to halt at optimal validation loss and preserve zero generalization gap.  
- Separation of state upload (qml.StatePrep) from ansatz application:  
  • Decouples data handling from circuit specification, simplifying block iteration and ensuring consistent readout across splits.  

## Performance Analysis  
- Loss vs. parameter count trade-off:  
  • Single‐axis (8 params): test_loss≈0.05, param_efficiency=0.12.  
  • Two‐axis (14 params): test_loss≈0.01 (4× lower), param_efficiency=0.07.  
- Convergence steps scale with N_PARAMS:  
  • 8-parameter mixers converge in ~30–60 steps; 14-parameter global_ry/global_rz takes ~90 steps.  
- Depth/gate count impact:  
  • Depth=23, gate_count=90 (single-axis RY/XX) vs. depth=29, gate_count=138 (two-axis RY/RZ + CZ) yields substantial loss reduction at modest resource cost.  
- Consistent zero generalization gap across all perfect-accuracy variants reinforces that expressivity via parameter sharing and output calibration—not sheer parameter volume—drives robust generalization.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Extend the readout layer with per‐pair weighting. Instead of averaging all PauliZ⊗PauliZ expectations uniformly, introduce one trainable weight w_i for each readout pair and compute raw = ∑_i w_i · z_i. Initialize all w_i=1/√N_pairs and include them in N_READOUT_PARAMS. This builds on the proven benefit of gain/bias calibration by letting the circuit learn which correlators are most informative, potentially lowering test_loss without increasing circuit depth.

2. Generalize CZ links into fSim-style entanglers. In ANSATZ_SPEC replace each CZ gate on wires [i,i+1] with two controlled-rotations: a CRZ(ϕ_zz) followed by a CRX(ϕ_xx), sharing one ϕ_zz and one ϕ_xx per block. This 4-parameter entangling block retains the successful linear topology while giving the circuit richer pairwise interactions, informed by the strong performance of tunable entanglers in previous generations.

3. Probe next-nearest-neighbor correlations. Augment ANSATZ_SPEC by adding CZ gates on wires [i, i+2] for i=0…5 in each block (no new parameters). By injecting modest non-nearest-neighbor entanglement you test whether broader connectivity further reduces loss, analogously to the stable generalization seen when readout measured only nearest-neighbor ZZ correlators.

4. Parallelize the CZ chain into two commuting layers. Replace the sequential CZ list with two sublayers per block: first apply CZ on even links ([0,1],[2,3],[4,5],[6,7]) then on odd links ([1,2],[3,4],[5,6]). Because disjoint CZs commute, this reordering preserves connectivity but can halve the circuit depth, potentially accelerating convergence while maintaining perfect accuracy.

5. Enrich single‐qubit mixing with a global RX axis. Augment each block’s ANSATZ_SPEC by inserting R X(global_rx) on every qubit before the existing RY and RZ calls, introducing one extra parameter per block. This three-axis rotation per block explores the full SU(2) on each qubit, extending the two-axis success of Gen 9 and trading one parameter per block for potentially tighter loss minimization.
