# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Collective, symmetry-tied rotations with a linear CZ chain  
  • Generation 9 “Global-RY/RZ CZ 8-Qubit Classifier” and Generation 5 “Symmetric Hardware-efficient 8-qubit Classifier” both use two global rotation parameters per block (global_ry, global_rz) interleaved with a 7-link CZ chain, repeated 6×. They achieve perfect train/validation/test accuracy (1.00), zero generalization gap, low test loss (~0.01), and parameter efficiency 0.07 with only 14 total parameters.  
- Single‐axis global sharing for extreme compression  
  • Generation 1 “Permutation-Symmetric 8-Qubit Classifier” (and its cousins Generation 8 and 10) tie a single RY parameter per layer across all 8 qubits (8 circuit params + 2 readout), reach perfect accuracy, zero gap, test loss ~0.04, and parameter efficiency 0.12 using just 10 parameters, converging in ~60 steps.  
- Fixed two-qubit Z–Z correlator readout plus trainable gain/bias  
  • Every top‐performing variant combines averaged dataset-specified ZZ measurements with a 2-parameter linear calibration. This consistently stabilizes training, yields low loss, and preserves zero generalization gap.  
- Block repetition count N_REPEATS=6  
  • Across all five perfect‐accuracy programs (Gen 1, 5, 8, 9, 10), repeating the small rotation + CZ block six times achieved full expressivity without overdepth or wasted gates.

## Ineffective Approaches  
- CZ-only entanglement blocks (no parameterized rotations)  
  • Generation 3 and 4 CZ-only classifiers, despite higher “parameter efficiency” (≈0.25), plateaued at ~50% accuracy (combined score 0.64). The absence of any tunable rotations left no capacity to distinguish the classes.  
- Over-parameterization without sharing  
  • The fully per-qubit ansatz (146 trainable angles) hit 100% accuracy in ~30 steps but scored only 0.81 combined (parameter efficiency 0.01). Vast capacity not only wasted resources but also slowed per-parameter learning.  
- Removing RZ while keeping two parameters per block  
  • Programs that omitted one rotation axis (e.g., only global RY + CZ) traded off slightly higher test loss (~0.04) versus the two-axis variants’ ~0.01, indicating the need for at least two orthogonal rotation parameters for tighter loss minimization.  
- Excess depth beyond 6 repeats  
  • Increasing repeats/depth above 6 did not improve accuracy or lower loss further, but did add gates and runtime, confirming N_REPEATS=6 as a sweet spot.

## Implementation Insights  
- Modular ANSATZ_SPEC + apply_ansatz_block abstraction  
  • The use of a declarative spec list and a single `apply_ansatz_block` function enabled rapid swapping between one- and two-parameter global sharing (e.g., Generation 1 vs 9) without touching the training loop.  
- Ordered parameter keys for clean indexing  
  • Building `PARAMETER_KEYS_PER_BLOCK = ["global_ry","global_rz"]` and computing offsets per repeat yields an N_PARAMS=14 implementation that’s easy to audit, as seen in the current best program (Gen 9).  
- Consistent training pipeline with Pennylane QNode/Adam/backprop  
  • Uniform use of Pennylane’s autograd QNode, Adam optimizer, mini-batch L2 loss, early stopping (min_delta=1e-4, patience=75), and best-weight restoration produced robust convergence across all successful variants.  
- Separation of data upload and circuit dynamics  
  • Loading full 8-qubit states via `qml.StatePrep` once per upload decoupled dataset handling from ansatz design, simplifying both readout logic and block specification.

## Performance Analysis  
- Parameter efficiency vs. test loss trade-off  
  • Single-axis global RY designs: N_PARAMS=10, param_efficiency=0.12, test_loss≈0.04.  
  • Two-axis global RY/RZ designs: N_PARAMS=14, param_efficiency=0.07, test_loss≈0.01.  
  → Adding a second rotation axis halves loss at the cost of modest parameter overhead.  
- Convergence steps scale with N_PARAMS  
  • 8-param programs converged in ~60 steps; 14-param programs in ~90 steps; fully-parametrized in ~30 steps but with no efficiency gains.  
- Depth/gate count vs. loss  
  • Depth=23, gate_count=90 (single-axis RY) yields loss ~0.04.  
  • Depth=29, gate_count=138 (two-axis RY/RZ) yields loss ~0.01.  
  → Six extra layers of RZ rotations deliver a ~4× reduction in loss.  
- Consistent zero generalization gap across all top performers  
  • Every perfect-accuracy variant, regardless of parameter count, maintained a generalization gap of 0.00, underscoring that expressivity and calibration choices—not sheer depth or parameter count—drive robust generalization.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Implement hybrid hierarchical sharing of rotation angles. In each block, share a single “global_rz” parameter across all six repeats but allocate a distinct “block_ry_i” for RY in repeat i (i=0…5), giving 1 + 6 = 7 parameters per upload. This probes the trade-off between the low loss of two-axis global sharing and the expressivity of per-block tuning—building on the best program’s use of shared RZ for stability while injecting block-level RY flexibility.  

2. Replace fixed CZ entanglers with tunable controlled-phase (CRZ) gates. Swap each CZ in the chain with CRZ(ϕ, wires=[i,i+1]) and share one “phi_ent” per block, so each block learns its own entangling phase instead of a hard π. By making the entanglement strength learnable, you maintain the linear nearest-neighbor topology that succeeded in Gen 9 while giving the circuit the ability to adapt its correlation depth to the data.  

3. Introduce a mid-circuit data re-upload. After the third ansatz block, call `qml.StatePrep` again on the same input state before continuing with the remaining three repeats. Data re-uploading has been shown to boost expressivity in low-parameter circuits at marginal gate cost, and here it could further reduce loss without increasing the number of trainable angles.  

4. Parameterize block angles via a low-dimensional polynomial schedule. Rather than storing six independent RY/RZ per-axis per-block, define two base parameters each for RY and RZ—(a_ry, b_ry) and (a_rz, b_rz)—and compute block_i angle = a + b · (i/(N_REPEATS−1)). This four-parameter scheme tests whether smoothly varying angles across repeats can match or beat the 14-parameter two-axis design, leveraging the observed smooth convergence behavior of global-shared rotations.  

5. Apply sublattice-specific global rotations. Divide qubits into even (0,2,4,6) and odd (1,3,5,7) sets and in each block use four shared parameters—“ry_even,” “ry_odd,” “rz_even,” and “rz_odd”—instead of fully global axes. This intermediate symmetry retains much of the parameter efficiency of global sharing (4 vs 14 per block total) while granting finer control, directly extending the successful symmetry-tied rotation pattern with a moderate increase in expressivity.
