# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Two-axis global rotation per block (one “global_ry” and one “global_rz”), repeated N_REPEATS = 6  
  • Current Best Program (seed) & Generation 9 both achieved perfect (1.00) accuracy and the lowest test_loss≈0.01, converging in ~90 steps on a depth-29, 138-gate circuit (parameter efficiency 0.07).  
- Single-axis collective-angle ansatz (one parameter driving both RY/RZ per block), N_REPEATS = 6  
  • Generations 22, 23, 24, 27, and 30 each hit 1.00 accuracy with test_loss≈0.02–0.04, converging in ~60 steps, using only 8 parameters (efficiency 0.12).  
- Fixed two-qubit Z–Z correlator measurements + trainable gain/bias calibration  
  • Present in all top performers—stabilizes losses (~0.01–0.05), ensures zero generalization gap.  
- Block repetition count of 6  
  • Consistently provided enough expressivity without unnecessarily increasing depth or gate count.  

## Ineffective Approaches  
- CZ-only entanglement blocks without parameterized rotations (Generations 3 & 4)  
  • Plateaued at ~50% accuracy (combined score≈0.64).  
- Fully unshared per-qubit parameterization (146 trainable angles)  
  • Converged in ~30 steps but scored only ~0.81 accuracy with very poor parameter efficiency (~0.01).  
- Single-axis global RY without a second rotation axis (Generations 1, 8, 10)  
  • Achieved perfect accuracy but test_loss≈0.04–0.05 vs. ~0.01 for two-axis designs—omitting RZ sacrifices tighter loss minimization.  
- Increasing N_REPEATS beyond 6  
  • No further gains in accuracy or loss; only increased depth and gate counts.  

## Implementation Insights  
- Declarative ANSATZ_SPEC + apply_ansatz_block abstraction  
  • Enabled swapping between one-parameter (shared single-axis) and two-parameter (global_ry/global_rz) designs without touching the training loop.  
- Ordered unique PARAMETER_KEYS_PER_BLOCK + offset indexing  
  • E.g., current best program’s PARAMETER_KEYS_PER_BLOCK=['global_ry','global_rz'] yields clean mapping: 2 keys × 6 repeats = 12 circuit parameters, plus 2 readout.  
- Pennylane autograd QNode + AdamOptimizer + early stopping with best-weight restoration  
  • Delivered robust convergence (zero generalization gap) and allowed stopping as soon as validation_loss plateaued (min_delta=1e-4, patience=75).  
- Separation of data upload (qml.StatePrep) from ansatz blocks  
  • Simplified code structure, ensured consistent state preparation across train/validation/test splits.  

## Performance Analysis  
- Two-axis vs. single-axis trade-off  
  • Two-axis (current best & Gen 9): test_loss≈0.01, efficiency 0.07, convergence ~90 steps  
  • Single-axis (Gens 22, 23, 24, 27, 30): test_loss≈0.02–0.04, efficiency 0.12, convergence ~60 steps  
- Depth and gate counts were constant (29, 138) across top ansatz variants  
  • Isolates parameterization (number and type of shared rotations) as the primary performance driver.  
- Zero generalization gap across all high-scoring shared-parameter designs  
  • Confirms that expressivity via parameter sharing and calibrated readout—rather than sheer parameter volume—drives robust generalization.  
- Convergence steps scale with N_PARAMS  
  • 8-parameter collective/single-axis designs converge ~60 steps; 14-parameter two-axis designs take ~90 steps in exchange for tighter loss minimization.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Hybrid single-/two-axis block schedule  
   Split the 6 repeats into two phases: use a single shared angle “θ” per block (driving both RY/RZ) for the first 3 repeats, then switch to the two-parameter (global_ry, global_rz) blocks for the last 3 repeats. This leverages the ~60-step convergence of single-axis designs early on while still exploiting two-axis blocks’ tighter loss minimization in the back half.  

2. Parameterized ZZ entanglers  
   In each block’s ANSATZ_SPEC, replace every CZ gate with a trainable IsingZZ(angle) gate, sharing one “global_zz” parameter per block. This adds just one extra circuit parameter per block to enrich pairwise correlations (mirroring successful fSim-style entanglers) without increasing circuit depth, and could further lower test_loss.  

3. Per-pair readout weighting  
   Extend N_READOUT_PARAMS by introducing a trainable weight w_i for each measured ZZ correlator (initialize w_i=1/√N_pairs). In predict_batch(), compute raw = ∑_i w_i·z_i instead of the simple mean. Building on the proven gain/bias calibration, this lets the model learn which correlators carry the strongest signal and may tighten the loss.  

4. Shared-axis variation to boost efficiency  
   Modify ANSATZ_SPEC so that all RZ rotations share a single global parameter “global_rz” across every block, while retaining block-specific “global_ry” values. This reduces one parameter per block (total params = 6 + 6 readout) and tests whether a truly global Z-axis correction suffices for tight loss, improving parameter efficiency.  

5. Alternating rotation order for richer expressivity  
   Within apply_ansatz_block(), for even-indexed repeats apply RY(global_ry) then RZ(global_rz), but for odd repeats swap the order (RZ then RY). This keeps the same two-axis, two-param-per-block budget while exploring a broader class of local unitaries, potentially uncovering lower-loss configurations without changing depth or gate count.
