# Resuming frontier run at phase transitions

phase transition: a jump in the best-so-far evolution score

As we discussed a while ago in this repo, one research question we want to answer is whether other models in the ensemble can reach some high score when the model that initially made the discovery is removed. In this case, I found that in all three of the frontier runs, it is GPT that made the crucial discoveries. However, I would like to know whether this is actually because the other two models are bad. Such a claim cannot be immediately verified because ShinkaEvolve chooses models randomly. So the two other models may have the capability to make the discovery, but it's just that the random selection of the models gave the opportunity to ChatGPT. 

Therefore, I want you to design ShinkaEvolve runs that answer this question. If we look at or_frontier, which reached 50 generations, There are many jumps in the score. In other words, the phase transitions happen at generation 3, 5, 9, 14, and 22. Except for the very last one, all of these are discoveries made by ChatGPT. Thus, you should design ShinkaEvolve runs that continue in its evolution from generations 2, 4, 8, 13, and 21. However, in these new runs, you should not include GPT 5.6 Sol extra high, which initially made the discoveries. The hypothesis is that the remaining models are able to recover this phase transition, although perhaps at a slower pace. If they are not able to identify these phase transitions, then we can say that scientific discovery, and in particular identifying symmetries, could be a useful model benchmark. Otherwise, if they are actually to validate our hypothesis, then that means there isn't that big of a difference between the model capabilities, although apparently it does seem like there is.
