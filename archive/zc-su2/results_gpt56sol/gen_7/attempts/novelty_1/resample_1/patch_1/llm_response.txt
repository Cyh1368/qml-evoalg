<DESCRIPTION>
This design compresses the successful rotation-and-entanglement pattern into a single collective trainable mode. All eight RY gates share one parameter, reducing the ansatz contribution from two parameters per repetition to one while imposing a strong symmetry prior that should improve few-shot generalization.

The CZ chain is retained for reliable global connectivity, but its commuting gates are reordered into even-edge and odd-edge matchings. This edge-colored schedule implements the same chain entangler while exposing greater parallelism and potentially reducing compiled depth. The result preserves the proven gate family and connectivity while improving parameter economy and removing the unnecessary even/odd rotational distinction.
</DESCRIPTION>

"""Collective, symmetry-constrained quantum ansatz.

Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved. The input encoding,
readout, training loop, and metric computation remain fixed in the backend.
"""

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}
ALLOWED_ISING_GATES = {"XX", "YY", "ZZ"}


# EVOLVE-BLOCK-START
ANSATZ_SPEC = [
    # One collective trainable mode across the full register.
    {"gate": "RY", "wire": 0, "param": "collective_ry"},
    {"gate": "RY", "wire": 1, "param": "collective_ry"},
    {"gate": "RY", "wire": 2, "param": "collective_ry"},
    {"gate": "RY", "wire": 3, "param": "collective_ry"},
    {"gate": "RY", "wire": 4, "param": "collective_ry"},
    {"gate": "RY", "wire": 5, "param": "collective_ry"},
    {"gate": "RY", "wire": 6, "param": "collective_ry"},
    {"gate": "RY", "wire": 7, "param": "collective_ry"},

    # Edge-colored CZ chain: identical connectivity with parallel matchings.
    {"gate": "CZ", "wires": [0, 1]},
    {"gate": "CZ", "wires": [2, 3]},
    {"gate": "CZ", "wires": [4, 5]},
    {"gate": "CZ", "wires": [6, 7]},

    {"gate": "CZ", "wires": [1, 2]},
    {"gate": "CZ", "wires": [3, 4]},
    {"gate": "CZ", "wires": [5, 6]},
]
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
