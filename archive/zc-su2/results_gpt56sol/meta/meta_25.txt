# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns
- Global shared‐rotation + single CZ layer ansatz  
  • “Collective‐Mode RY‐CZ Ansatz” (Gen 16, tied_collective_phase) and Gen 19’s “single_matching_entangler” both use eight repeated RY gates, one layer of parallel CZ on adjacent pairs, and achieve combined score 0.80, perfect train/validation/test accuracy, zero generalization gap, and converge in ~60 steps.  
- Phase echo via tied RZ adds expressivity without extra parameters  
  • The current best program appends eight RZ gates all tied to the same `collective_mode` parameter (“phase echo”), retaining 8 parameters and boosting phase flexibility while preserving combined score 0.80 and parameter efficiency 0.12.  
- Disjoint adjacent‐pair CZ entanglement at minimal depth  
  • A single CZ layer with wires [0,1],[2,3],[4,5],[6,7] suffices for full‐register entanglement. This pattern yields rapid convergence (60 steps) and zero overfitting, matching deeper chain/ring designs in accuracy at substantially lower depth.

## Ineffective Approaches
- Pure shared‐RY with no entanglement  
  • Gen 21’s “Collective RY Ansatz on 8 Qubits” (single shared RY, depth 6) scores 0.45 combined and only 52% test accuracy—under-expressive without entangling gates.  
- Over-shared ring entanglement  
  • Gen 15’s “Shared-RY Ring Entanglement” uses one RY + two CZ ring layers but scores 0.0 due to excessive parameter tying and under-expressivity.  
- Dual-axis/shared-XX over-parameterization  
  • Gen 22 (“dual_axis_collective”) and Gen 24 (“parallel_cz_shared_xx”) employ 14 parameters (RX+RY or RY+XX) with depth 18, achieving perfect accuracy but combined score only 0.72 and parameter efficiency 0.07—no accuracy gain despite extra parameters.

## Implementation Insights
- Repeat gate dictionaries for collective modes  
  • Eight entries of `{"gate":"RY","wire":i,"param":"collective_mode"}` (and similarly for RZ) define one trainable angle across all qubits, maximizing expressivity per parameter.  
- Strict spec compliance: use `"wire"` vs. `"wires"` correctly  
  • All high-scoring ansätze (Gen 16, Gen 19) adhere to `"wire"` for single-qubit gates and `"wires"` for two-qubit gates; misnaming (Gen 17) caused spec parsing failures.  
- Single CZ matching layer for minimal‐depth entanglement  
  • Four dictionaries of `{"gate":"CZ","wires":[i,i+1]}` yield depth 12 (or 18 with added RZ) yet secure zero generalization gap.  
- Phase‐echo RZ layering without new parameters  
  • Tying RZ rotations to `collective_mode` doubles phase degrees of freedom (“shared_ry_cz_echo” pattern) with no parameter count increase, preserving convergence speed and score.

## Performance Analysis
- Eight parameters → top combined score 0.80  
  • Both Gen 16 and Gen 19 reach 0.80 using exactly 8 trainable angles; increasing to 14 parameters (Gen 22/24) lowers combined score to 0.72 despite identical accuracy.  
- Depth/gate count expansion does not harm convergence  
  • Adding the RZ echo in Gen 16 raises depth from 12→18 and gates from 72→120 but leaves convergence (~60 steps), accuracy, and combined score unchanged—parameter count and entanglement topology are primary.  
- Parameter efficiency ≈0.12 correlates with top score  
  • Ansätze with reported parameter efficiency 0.12 (8 params) consistently hit 0.80 combined; models with efficiency ≤0.07 plateau at 0.72 or below.  
- Single CZ layer suffices vs. multi‐layer chain/ring  
  • Chain/ring CZ patterns require depth 18–30 and 90–168 gates for the same perfect accuracy but take 90–210 steps; single matching entangler hits identical results faster and with fewer resources.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Stack a second RY–CZ–RZ echo block with no new parameters. After the existing RZ layer, append another eight `{"gate":"RY","wire":i,"param":"collective_mode"}` entries, the four parallel CZ matchings, and eight `{"gate":"RZ","wire":i,"param":"collective_mode"}`. This deepens the ansatz while preserving n_params=8 and tests whether two minimal blocks accelerate convergence below ∼60 steps.

2. Insert a shifted CZ matching layer for fuller connectivity. Immediately after the current CZs (and before the RZ echo), add four fixed CZs on wires [1,2], [3,4], [5,6], [7,0]. This two-edge-colored entangler maintains depth-2 coupling, retains parameter efficiency ≈0.12, and may reduce training steps by covering inter-block correlations.

3. Replace each fixed CZ with a single shared-parameter CRZ entangler. Change each `{"gate":"CZ","wires":[i,j]}` to `{"gate":"CRZ","wires":[i,j],"param":"crz_shared"}`, introducing exactly one extra angle. This probes whether a tunable entangling phase boosts expressivity beyond fixed CZs while only marginally increasing n_params to 9.

4. Prepend a global shared RX rotation for dual-axis control. Before the existing RY block, add eight `{"gate":"RX","wire":i,"param":"collective_rx"}` entries. This one additional parameter gives the optimizer access to two rotation axes (RX+RY) in the same collective fashion, potentially improving loss landscapes without diluting parameter efficiency.

5. Split the collective RY/RZ mode into two half-register parameters. Replace `collective_mode` on qubits 0–3 with `collective_mode_A` and on qubits 4–7 with `collective_mode_B`. This raises n_params from 1 to 2 for both RY and RZ echoes (total n_params=10) but preserves the CZ topology, testing whether a slight increase in expressivity yields a higher combined score.
