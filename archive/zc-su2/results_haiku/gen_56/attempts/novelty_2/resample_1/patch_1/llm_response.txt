<DESCRIPTION>
The current program uses 20 parameters with shared XX gates, achieving 0.68 score. Prior successful attempts achieved 0.72 with only 14 parameters using simpler CZ chains and RY/RZ rotations.

The key insight from prior metrics is that:
1. Fewer parameters (14 vs 20) achieved better scores (0.72 vs 0.68)
2. CZ chains were more parameter-efficient than XX chains
3. The problem achieves perfect accuracy with minimal parameters, suggesting it benefits from sparsity and controlled expressivity

This new approach hybridizes entanglement strategies:
- Block 1: Uses a CZ chain (fixed, non-parametrized) for stable, economical entanglement
- Block 2: Uses CRZ gates with a single shared parameter for adaptive, parameterized entanglement
- Single-qubit rotations: Alternates between RY and RZ with shared parameters for better expressivity with fewer params
- Reduced parameter footprint: Only 3 parameters (ry_shared, rz_shared, phi_crz) vs 20 in current approach

This design:
1. Recovers the parameter efficiency of the best prior solution (14 params) by using CZ + CRZ chains
2. Adds controlled expressivity through CRZ in the second block without parameter explosion
3. Uses alternating single-qubit rotations to maximize expressivity per parameter
4. Should converge faster (prior convergence was ~90 steps with 14 params) due to reduced parameter count
