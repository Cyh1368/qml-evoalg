The prior programs achieved perfect accuracy with 2 parameters (ry_shared, rz_shared) using RY–RZ sandwiches with fixed CZ entanglement. The current program adds XX gates (3 parameters), increasing parameter count and reducing parameter efficiency from 0.07 to 0.05 while maintaining the same accuracy.

Key insight from prior analysis: The recommendation suggests that a global RX initialization layer can diversify initial state sampling and improve convergence. Combined with the observation that the simplest 2-parameter approach (prior program #2) achieved excellent performance with minimal depth, I propose a novel strategy that:

1. **Prepends a shared RX layer** for initialization (adding 1 parameter: rx_shared)
2. **Alternates between two complementary entanglement patterns** within a single ansatz block:
   - First half uses a chain of CZ gates (fixed, no parameters)
   - Second half uses a chain of XX gates with a distinct parameter (xx_alt)
3. **Maintains tight parameter sharing** across all rotation layers to keep n_params low
4. **Uses asymmetric coupling** to break symmetries that might limit expressiveness while staying parameter-efficient

This design draws inspiration from:
- The RX initialization recommendation (global kickstart)
- The parameter-efficient prior program (2 params achieving 0.72 score)
- The current program's insight that Ising gates can enhance expressiveness
- Novel alternation strategy to combine both fixed and parametric entanglement without quadrupling parameters

The goal is to recover the parameter efficiency (back toward 0.07) while potentially improving accuracy through the RX initialization and dual entanglement strategy, thus improving the combined score beyond 0.68.
