# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Two-Block CZ-Sandwich with Global Sharing  
  • Seed Program (“two-block CZ-sandwich”, 14 params, depth 65, 372 gates) achieves combined score 0.72—+0.04 over all 20-param designs—by repeating  
    [global RY × 8 → global RZ × 8 → linear CZ chain → global RZ × 8] twice.  
  • Replicating identical entangling blocks at fixed parameter count inflates gate-per-parameter ratio (372 gates/14 params ≈ 26.6) and drives expressivity.  
- Linear CZ Chain Topology  
  • The seed’s nearest-neighbor CZ chain yields perfect 1.00 accuracy, zero gap, and convergence in ~90 steps, outperforming ring-CZ or CRZ ladders (which plateau at 0.68 score).  
- Aggressive Parameter Sharing  
  • Collapsing 16 RY and 32 RZ rotations into just ry_shared and rz_shared maximizes parameter efficiency (0.07) and unlocks the top combined score.  
- Block Replication Over Parameter Diversification  
  • Doubling block depth at constant 2 shared parameters (versus adding distinct per-qubit angles) yields a net +0.04 score improvement, confirming that gate-depth per parameter is more critical than raw parameter count for this task.

## Ineffective Approaches  
- Overparameterized Per-Wire Rotations  
  • 8-qubit three-layer Ising ansatz (194 params, depth 66) scores only 0.61 despite perfect accuracy—parameter efficiency 0.01—highlighting diminishing returns past minimal global parameters.  
  • Shared-Parameter CZ Chain Ansätze (20 params, depth 41–65) uniformly cap at 0.68 combined score; adding more free parameters beyond the seed’s 14 fails to boost expressivity.  
- Entangler Substitution Without Block Replication  
  • CRZ-based shared entangler (Gen 33) converges fastest (~60 steps) but still scores 0.68—no gain over CZ chain—underscoring that two-qubit gate choice alone is insufficient without deep block repetition.  
- Underparameterization of Single Shared Layers  
  • Two-Block CZ-RY-RZ Ansatz in Gen 41 using only one shared RY and one shared RZ per block fails entirely (score 0.00), demonstrating a lower bound on parameter-sharing before expressivity collapses.

## Implementation Insights  
- RY→RZ→CZ-Chain→RZ Sandwich Template  
  • The pattern of global RY on all qubits, followed by global RZ, a linear CZ chain, then another global RZ, forms a highly expressive motif when repeated.  
- Gate-to-Parameter Ratio Drives Score  
  • Seed: 372 gates/14 params → PE 0.07 → score 0.72; 20-param designs: ~192–372 gates → PE 0.05 → score 0.68; 194-param Ising: 194 gates → PE 0.01 → score 0.61.  
- Parameter Tie-Back for Generalization  
  • Reusing “ry_shared” and “rz_shared” across both blocks maintains zero generalization gap while deepening the circuit, showing tied parameters can regularize and enrich landscape navigation.  
- Block Duplication vs. Parameter Expansion  
  • The seed’s two identical entangling blocks double circuit depth without increasing parameter count, achieving higher expressivity than simply adding unique parameters per layer.

## Performance Analysis  
- Combined Score Trends  
  • Seed (14 params) → 0.72; all 20-param CZ/CRZ/RX-augmented chains → 0.68; 194-param Ising → 0.61; minimal-param single-block → 0.00.  
- Parameter Efficiency Correlation  
  • Score increases track with PE: 0.07 (seed) > 0.05 (20-param designs) > 0.01 (Ising), confirming gate-per-parameter ratio is a strong predictor of generalization performance.  
- Convergence vs. Entangler Type  
  • While CRZ-shared ansatz converges fastest (~60 steps), it matches CZ chain’s 0.68 score only when paired with two-block repetition; the seed CZ design balances 90-step convergence with best expressivity.  
- Depth-Driven Expressivity  
  • Doubling block count (seed: 65 depth) yields +0.04 score over single-block variants (depth 35–41), despite identical parameter budgets, underscoring that deeper circuits at fixed parameters unlock richer hypothesis classes.
