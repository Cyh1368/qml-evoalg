# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- CZ-Sandwich Blocks with Global Sharing  
  • Repeating a minimal “sandwich” block of shared-parameter RY → RZ → CZ-chain → RZ twice (Seed program, Gen 13/23) drives the combined score to 0.72 with only 14 parameters, perfect accuracy, zero gap, and parameter efficiency 0.07.  
  • The Seed program’s two-block design outperforms shallow single-block XX-based circuits (Gen 19/22: 20 params, score 0.68) by +0.04 score, demonstrating that deeper CZ layering at fixed parameter count boosts expressivity.  

- Aggressive Global Parameter Reuse  
  • Collapsing all single-qubit rotations into two scalars (ry_shared, rz_shared) consistently yields top scores (0.72) across Gen 13, Gen 23, Gen 24.  
  • The ring-CZ variant (Gen 24) confirms robustness of full sharing: same 14 params, score 0.72 despite slightly different entanglement topology.  

- CZ vs. XX Entanglers  
  • Substituting nearest-neighbor XX gates for CZ (Gen 19/22) holds depth/gate count constant but drops the score from 0.72→0.68, confirming CZ-chain is more expressive per parameter in this task.  

## Ineffective Approaches

- Under-Parameterized Two-Layer Rotations  
  • Circuits using only 2 global rotation params (rx_shared, rz_shared) with CZ chain (Gen 16) failed entirely (score 0.00), showing that two parameters cannot span the required hypothesis space.  

- XX-Based Entanglement Blocks  
  • Shared-Parameter RY-RZ-XX ansatz (Gen 19/22) with 20 params, depth 35, 186 gates converges faster (60 steps) but scores only 0.68—0.04 below CZ-sandwich designs—indicating XX alone underfits without more parameters.  

- High-Depth, Low-Gate CZ Variants with Slow Convergence  
  • Ring CZ design (Gen 24) matches 0.72 score with 14 params but takes 150 steps to converge—~60% slower than the Seed’s two-block chain (90 steps)—suggesting linear CZ chains favor faster optimization.  

## Implementation Insights

- Block Template and Parameter Reuse  
  • Seed program EVOLVE-BLOCK is a direct instantiation of the “sandwich” template:  
    1. 8× RY(ry_shared)  
    2. 8× RZ(rz_shared)  
    3. CZ chain across [0–1],…,[6–7]  
    4. 8× RZ(rz_shared)  
  Repeating this block twice with the same param names quadruples layer depth without increasing parameter count.  

- Gate-Level Economy  
  • By reusing “ry_shared” and “rz_shared” across all 32 single-qubit rotations in each block (64 total), the Seed circuit attains maximum parameter efficiency (14 params over 372 gates) and perfect generalization.  

- Depth vs. Parameter Trade-off  
  • Seed’s depth 65/gate count 372 vs. RY-RZ-XX’s depth 35/186: doubling depth at fixed params yields +0.04 score. This underscores that expressivity gains arise from additional CZ layers rather than extra parameters.  

## Performance Analysis

- Parameter Count vs. Combined Score  
  • 20 params (Gen 19/22) → score 0.68; 14 params (Gen 13/23/24) → score 0.72. Fewer parameters + deeper CZ blocks deliver the highest combined score.  

- Convergence Steps vs. Entanglement Topology  
  • Linear CZ chain: Seed (2 blocks) converges in ~90 steps.  
  • Ring CZ: Gen 24 converges in ~150 steps despite same param count and score, showing that linear chains yield more favorable optimization landscapes.  

- Entangler Effectiveness  
  • CZ-chain circuits consistently hit perfect 1.00/1.00/1.00 accuracy with zero gap; XX-chain designs plateau at 0.68 despite similar depths, confirming a ~6-point advantage for CZ in this classification task.  

- Gate Count Impact  
  • Shallow XX-based (186 gates) vs. deep CZ-based (372 gates): doubling gate count at fixed parameters is an acceptable cost for a +0.04 score improvement and robust generalization.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Split the shared Z-rotation into pre- and post-entanglement phases.  Replace each `{"gate":"RZ",…,"param":"rz_shared"}` before the CZ chain with `param:"rz_pre"` and each one after with `param:"rz_post"`.  This raises n_params from 2→3, gives the optimizer independent control over pre- vs. post-CZ phase shifts, and is directly informed by the proven sandwich template’s need for flexible layer-wise tuning.  

2. Upgrade the CZ chain to tunable CRZ gates.  Substitute each `{"gate":"CZ","wires":[i,i+1]}` with `{"gate":"CRZ","wires":[i,i+1],"param":"phi_shared"}` (one new parameter shared across all entanglers).  This preserves the linear ladder topology that drove fast convergence while letting the circuit learn entangling angles, building on the success of global parameter reuse.  

3. Give each sandwich block its own rotation pair.  Instead of one `ry_shared`/`rz_shared`, define `ry_1`,`rz_1` for block 1 and `ry_2`,`rz_2` for block 2 (n_params→4).  This block-specific sharing retains parameter economy within each layer but allows the two deep CZ-sandwiches to specialize differently, potentially accelerating convergence or squeezing out extra score gains.  

4. Test a triple-stacked CZ-sandwich.  Append a third copy of the RY→RZ→CZ-chain→RZ template at the end, reusing the existing `ry_shared` and `rz_shared` (n_params still 2, depth→≈100, gate_count→≈560).  Given that doubling depth yielded +0.04, further deepening without new parameters probes whether even richer CZ layering can surpass the 0.72 ceiling.  

5. Prepend a global X-axis rotation layer.  Insert eight `{"gate":"RX","wire":i,"param":"rx_shared"}` gates on all qubits before the first RY layer (introducing a third parameter).  This cross-axis augmentation explores whether adding a shared RX before the proven Y/Z sandwich can improve expressivity-per-parameter while keeping the same linear CZ backbone.
