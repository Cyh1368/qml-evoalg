butterfly_hypercube_ansatz

<DESCRIPTION>
A fundamentally different entangling topology: instead of a dense ring + skip-connections (which needs O(n) two-qubit gates per parametrized "shell" and stacks up to depth 75 with 174 gates), this design uses a **butterfly / hypercube network** — the same topology used in FFT and hypercube interconnects to achieve full all-to-all information mixing in only log2(N)=3 stages. For N=8 qubits, three entangling stages at distances 1, 2, and 4 connect every qubit to every other qubit's "basin" with only 4 parallel two-qubit gates per stage (12 total gates per round), instead of 8-20 gates per shared-parameter ring layer used previously.

Key structural ideas:
1. Single global RY rotation (1 param) prepares all qubits identically before entangling — cheap and symmetric.
2. Entangling is done via a butterfly network at hop distances {1,2,4}, alternating ZZ and XX interactions (using orthogonal couplings, motivated by the recommendation that XX complements ZZ-only designs) — but crucially ALL entangling gates share a single parameter name "ent", keeping trainable-parameter count minimal while giving full connectivity in far fewer physical gates and shallower depth than the ring+skip-shell approach.
3. A shared global RZ phase layer (1 param) sits between two butterfly rounds, and the entangling round is repeated with swapped gate types (ZZ<->XX) for extra mixing without adding new parameters.
4. A final RY layer reuses the very first parameter name, closing the ansatz symmetrically.

This achieves the same full-connectivity guarantee as the previous ring-based design (every qubit pair is coupled through some path) but with dramatically fewer total gates (48 vs 174) and much shallower depth (~9 layers vs 75), while keeping only 3 distinct trainable parameters — directly targeting the scoring priorities of parameter economy, convergence speed, and robust worst-group margin via richer orthogonal (ZZ+XX) coupling types.
