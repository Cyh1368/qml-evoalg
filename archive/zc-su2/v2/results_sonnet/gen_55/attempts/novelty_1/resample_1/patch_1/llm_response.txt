<DESCRIPTION>
Builds on the best-performing prior seed (single global-phase/entangling parameter "theta" shared across all RZ and ZZ gates, plus one RY pre-rotation parameter "ry_a" — 2 distinct trainable parameters total). The key addition, following the recommendation, is a shell of long-range **directional** CRZ gates on opposite-qubit pairs ([0,4],[1,5],[2,6],[3,7]), inserted between the ZZ entangling shells and the backward CNOT ladder. Critically, these CRZ gates **reuse the existing "theta" parameter** rather than introducing a new parameter name, so the distinct-parameter count stays at 2 (the absolute floor achieved so far while keeping a rich enough circuit to separate hard validation groups). CRZ is asymmetric (control/target), unlike the symmetric ZZ gates already present, so it contributes genuinely new expressive directional correlations across the hypercube's opposite-corner links without any parameter-count cost. This targets the worst-group margin (the dominant score term) while preserving parameter economy, which the scoring rule says always dominates.

Design rationale:
- Keep RY pre-rotation layer fully shared under "ry_a" (as in the two best seeds).
- Keep the global phase RZ layers before/after entangling, shared under "theta".
- Keep the full nearest-neighbor + opposite + skip-2 ZZ shells, all under "theta", exactly as the 0.73-scoring seed (it had the best score so far).
- Add a new CRZ shell on the 4 opposite-qubit pairs (hypercube long diagonals), still under "theta", placed right after the ZZ shells and right before the backward CNOT ladder — directly implementing the given recommendation but avoiding a new parameter name.
- Keep fixed CNOT ladders (forward/backward) untouched — they add mixing with zero parameter cost.

This should either match or improve the worst-group margin (directional phase kicks on long-range pairs can sharpen decision boundaries for hard subgroups) while keeping n_distinct_params minimal (2), which the scoring function rewards unconditionally.
