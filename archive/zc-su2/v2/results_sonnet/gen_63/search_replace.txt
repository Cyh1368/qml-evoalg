<DESCRIPTION>
Add a directional CRZ layer on the nearest-neighbor ring (wires [0,1],[1,2],...,[7,0]) sharing the existing "theta" parameter, inserted right before the final RZ sandwich layer. Unlike the symmetric ZZ couplers already present, CRZ is control/target asymmetric, so this introduces new directional phase correlations across the same connectivity without adding any new trainable parameter name (still n_distinct_params=2). This is expected to strengthen entangling expressivity and improve worst-group margin/separation while keeping parameter economy maximal, mirroring the successful RZ/ZZ fusion pattern already used in this ansatz.
</DESCRIPTION>
