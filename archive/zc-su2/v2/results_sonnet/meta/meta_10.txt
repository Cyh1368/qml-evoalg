# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns

- Two-group single-qubit parameter sharing around a ZZ-ring entangler  
  • Generation 8 (Shared-Parameter Ring Ansatz, score 0.69) defines RY and RZ rotations in two symmetric groups (wires 0–3 vs 4–7) with distinct parameters {ry_a, ry_b, rz_a, rz_b}. This yields perfect train/valid/test accuracy, zero generalization gap, and a high validation margin (0.73) using only 5 distinct parameters.  
- Sandwiching entangling blocks with pre- and post-RZ layers  
  • Wrapping the fully shared ZZ ring with RZ_pre and RZ_post (reusing rz_a/rz_b) boosts phase flexibility and worst-group margin. Seen in Generation 8 (margin 0.36) and earlier in the Shared-Parameter ZZ-Ring Ansatz (score 0.62, margin 0.36).  
- Fully shared ring-topology WW (Ising-type) entanglers  
  • A single “zz_ring” parameter controlling all ring edges concentrates entanglement expressivity into a low-dimensional subspace. Generation 8, Generation 2 (8-Qubit Ring CRZ RY-RZ Ansatz, score 0.58), and Generation 9 (Ring-Entangled Pauli Ansatz, score 0.64) all validate zero or minimal generalization gaps with this pattern.  
- Minimal, backend-delegated ANSATZ_SPEC  
  • Evolving only a compact ansatz description (ANSATZ_SPEC) and outsourcing encoding/training accelerates iteration. Both the top-scoring Generation 8 and earlier high scorers share this structure, converging in ~60 steps.

## Ineffective Approaches

- Over-collapsing pre/post-RZ parameters  
  • The “share_rz_pre_post_params” patch on the RY-RZ CZ Ansatz collapsed all RZs into one set of parameters and scored 0.0—distinct phase angles per layer proved critical.  
- Single-parameter controlled-phase (CRZ) entanglers  
  • The Single-Layer RY-CRZ-RZ Ansatz used one shared CRZ for all neighbor pairs and failed entirely (score 0.0), indicating under-expressive entanglement.  
- Linear CZ chains without parameterized weights  
  • CZ-Chain Ansätze topped out at ~0.61 combined score, with nonzero gaps (~0.01) and lower margins (~0.69), underscoring the need for richer Ising-type parameterization.  
- Excessive parameter reduction harming margins  
  • Generation 10’s aggressive sharing (10 parameters, score 0.65) achieved zero gap but only a 0.35 worst-group margin, showing that beyond a point, further sharing can erode robustness.

## Implementation Insights

- Explicit parameter naming enforces symmetry and reduces scope  
  • In Generation 8’s ANSATZ_SPEC, naming four shared rotation parameters (“ry_a”, “ry_b”, “rz_a”, “rz_b”) plus “zz_ring” yields only 5 distinct trainables yet preserves full classification power.  
- Alternating RY → RZ → ZZ → RZ blocks  
  • This recurring motif (also in Generation 2, Generation 4) balances single-qubit flexibility with entangling depth, controlling both expressivity and trainability.  
- Reusing pre-entangling RZ parameters post-entangling  
  • The practice of reapplying rz_a/rz_b in both pre- and post-layers slashes distinct parameter counts without sacrificing margin, as evidenced by Generation 8’s 0.73 validation margin.  
- Decoupling ansatz spec from backend logic  
  • Passing a self-contained ANSATZ_SPEC to `run_experiment` isolates circuit design from data encoding and optimization, simplifying code and enabling rapid patch iterations.

## Performance Analysis

- Combined score progression  
  • Full unshared RY–RZ + CZ chain: ~0.60  
  • CZ-Chain with partial RZ sharing: 0.61  
  • Shared-Parameter ZZ-Ring (Generation 2): 0.62  
  • Partitioned Shared-CRZ Ansatz (Generation 4): 0.65  
  • Ring-Entangled Pauli Ansatz (Generation 9): 0.64  
  • Shared-Parameter Ring Ansatz (Generation 10): 0.65

- Parameter efficiency correlates with peak performance  
  • Efficiency increased from 0.04 (full unshared) → 0.07 (ZZ-Ring) → 0.11 (Partitioned CRZ) → **0.14 (Gen 8)** in lockstep with score gains.  
- Generalization and margin trade-offs  
  • Only the fully shared ZZ-ring designs (Generations 2, 8, 9, 10) achieved zero generalization gap. Generation 8 led the pack with the highest validation (0.73) and worst-group (0.36) margins.  
- Convergence consistency  
  • Top shared-parameter circuits consistently converge in ~60 steps, balancing rapid training with robust decision boundaries.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Introduce a second “sandwich” block of RY→RZ_pre→ZZ_ring→RZ_post using the same shared parameters.  Duplicate the existing four-layer motif immediately after the current RZ_post layer—reusing ry_a/ry_b, rz_a/​rz_b, and zz_ring—to probe whether modestly increased depth tightens decision boundaries without inflating the distinct parameter count.  Top shared-parameter circuits consistently converge in ~60 steps, so this extension is likely to train stably.  

2. Split the single zz_ring into two shared parameters “zz_even” and “zz_odd.”  Assign zz_even to edges (0–1, 2–3, 4–5, 6–7) and zz_odd to edges (1–2, 3–4, 5–6, 7–0).  This retains the ring topology while doubling entanglement flexibility from 1→2 parameters—a pattern that has improved margins in prior generations.  

3. Interleave a fully shared XX ring immediately after the ZZ gates.  For each cyclic neighbor pair [0,1], [1,2], …, [7,0], insert XX with a single new parameter “xx_ring.”  Mixing orthogonal Ising interactions taps a richer entanglement subspace and has shown promise in boosting generalization margins.  

4. Append a global RZ layer at the very end with one shared parameter “rz_global.”  Apply RZ(rz_global) on all eight qubits after the final RZ_post_g* rotations to introduce a global phase adjustment.  Minimal overhead global rotations have improved classification surfaces in other ansätze and can fine-tune the decision boundary.  

5. Increase phase granularity by decoupling pre- and post-entangling RZ parameters.  Replace “rz_a”/“rz_b” with four parameters—“rz_pre_a,” “rz_pre_b,” “rz_post_a,” and “rz_post_b”—so that pre- and post- layers each have independent angles for both qubit groups.  Prior experiments show that distinct phase angles per layer boost expressivity, and this change tests whether added phase flexibility raises worst-group margins.
