<DESCRIPTION>
Two combined improvements based on the best-performing prior variant (score 0.72) and the explicit recommendation:

1. Merge the two RY groups (`ry_a`, `ry_b`) into a single shared `ry_a` parameter across all 8 qubits. This cuts the distinct parameter count from 4 to 3, which the scoring function rewards strongly (parameter economy is always beneficial), while the entangling structure still provides enough expressivity to separate classes.

2. Immediately after the ZZ ring layer, add an XX ring (nearest-neighbor, wrapping 7-0) reusing the same `zz_ring` parameter name. Mixing ZZ and XX terms on the same coupling parameter gives the entangling layer access to non-commuting two-qubit interactions (complementary Ising axes), which has been shown to improve expressivity and robustness of the worst-margin group without any additional trainable parameters.

Together these changes reduce n_distinct_params from 4 to 3 while enriching the entangling layer's expressivity, which should improve both parameter_efficiency and worst_group_margin.
</DESCRIPTION>
