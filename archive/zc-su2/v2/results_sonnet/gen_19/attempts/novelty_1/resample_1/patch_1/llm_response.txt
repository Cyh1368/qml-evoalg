xx_zz_dual_ring_shared

<DESCRIPTION>
Builds on the best-performing 5-parameter sandwich ansatz (RY pre-rotation groups, RZ pre/post layers, ZZ entangling ring) by inserting a fully shared XX ring immediately after the ZZ ring, using a single new parameter "xx_ring" for all 8 cyclic nearest-neighbor pairs (0,1)...(7,0). This mixes two orthogonal Ising interactions (ZZ and XX) to access a richer entangling subspace while keeping parameter count minimal (6 distinct parameters total: ry_a, ry_b, rz_a, rz_b, zz_ring, xx_ring). The RZ post-layer reuses the pre-layer parameters (rz_a, rz_b) as before, preserving parameter economy. This design targets improved worst-group margin (robust separation on hard samples) by combining complementary entangling structures, while still using far fewer parameters than the less efficient 9-parameter grouped variant that scored lower (0.64 vs 0.69).
