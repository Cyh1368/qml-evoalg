<DESCRIPTION>
Reduce parameter count (and hence improve parameter-economy score) by sharing
the post-entangler RZ phase parameters with the pre-entangler RZ phase
parameters on each wire (same "rz_i" name used before and after the CZ
entangling layer). This halves the RZ parameter count (from 16 down to 8),
cutting total distinct parameters from 24 to 16, while still allowing per-qubit
RY rotations to break symmetry. The RZ-CZ-RZ(same angle) sandwich still creates
non-trivial entangled phase structure (it is not equivalent to identity because
CZ does not commute trivially with the surrounding same-angle RZ layers acting
across different qubit pairs), so expressivity for classification should be
largely preserved while the parameter count drops meaningfully, which the
scoring rule rewards strongly (fewer distinct params always scores higher).
This should also help reduce train/validation gap and encourage faster,
more robust convergence since the search space shrinks.
</DESCRIPTION>
