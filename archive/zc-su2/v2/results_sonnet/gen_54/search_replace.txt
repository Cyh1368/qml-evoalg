<DESCRIPTION>
Two coordinated changes to push toward the higher-scoring 3-distinct-parameter regime while deepening the entangling structure (per the recommendation to repeat the ZZ block under a shared parameter):

1. Merge the `ry_a`/`ry_b` split into a single shared `ry_a` parameter across all 8 qubits, reducing distinct trainable parameters from 4 to 3 (matching the configuration that previously scored 0.72, which strongly rewards parameter economy).
2. Add a "skip-2" connectivity shell (0-2,1-3,2-4,3-5,4-6,5-7,6-0,7-1) and then repeat the entire three-shell ZZ block (ring + opposite + skip-2) a second time, all reusing the single `zz_ring` parameter. This increases entangling depth/expressivity at zero extra parameter cost, which the notes indicate previously yielded a modest score lift, aiming to better separate the hardest validation group (worst-group margin) while keeping n_distinct_params at 3.
