This candidate is a crossover between the two highest-scoring seeds: the "CNOT-ladder + shared global RZ + shared ZZ-ring" ansatz (score 0.70, 4 distinct params) and the "two-block sandwich with shared RY/RZ/ZZ" ansatz (score 0.69, 5 distinct params). Both top performers show that reducing the number of *distinct* trainable parameter names is the dominant driver of score, while still keeping enough entangling structure (rings, ladders) to guarantee good worst-group margin.

Design choices:
- Kept the exact 4-distinct-parameter skeleton of the best scoring seed: `ry_a`/`ry_b` for a two-group RY pre-rotation, a single shared `rz_p` for all RZ layers, and a single shared `zz_ring` parameter for all pairwise ZZ entangling interactions.
- Retained the zero-cost forward/backward CNOT ladders from the best seed, which add connectivity and non-linearity without introducing new trainable parameters, and provide a "sandwich" structure (RZ before and after entangling) shown to help both seeds converge to accuracy 1.0.
- Added extra long-range ZZ couplings (0-4, 1-5, 2-6, 3-7) that reuse the very same `zz_ring` parameter. This crosses the ring topology with the pattern seen in the smaller seed's odd/even-edge decomposition, increasing the connectivity graph (helpful for separating the *hardest* groups per the task's robust-separation objective) while adding literally zero new distinct parameters or extra param count beyond the proven-best structure.
- Avoided doubling the whole block (as the 5-param seed did), since the backend already repeats the block automatically; instead, expressivity is increased purely through more no-cost/no-new-param gates (extra CNOTs and long-range ZZ reusing `zz_ring`), directly targeting the "parameter economy always wins" evolution rule while trying to boost worst-group margin via richer connectivity.

Net effect: same distinct parameter count as the best-performing seed (4), moderate increase in gate count/depth for richer entanglement, and a topology that mixes nearest-neighbor ring + long-range cross entanglement + bidirectional CNOT ladders, which should help worst-group separation without paying any parameter-count penalty.
