<DESCRIPTION>
The current approach uses mostly single-qubit rotations with fixed two-qubit CRZ gates. Analysis of prior successful programs shows that:

1. Parametrized Ising gates (XX, YY, ZZ) significantly outperformed fixed gates in the second prior program (score 0.65 vs baseline).
2. Strategic parameter sharing (even/odd qubits) combined with multiple entanglement layers improved worst_group_margin and generalization.
3. The recommendation to add RX rotations adds rotational diversity cheaply.

This new approach combines:
- **RX pre-layer** (shared across all qubits) for rotational diversity (+1 param)
- **Parametrized Ising gates** instead of fixed CRZ, using strategic sharing to keep parameter count low
- **Structured entanglement**: nearest-neighbor (XX), offset (YY), and long-range (ZZ) with different shared parameters
- **Post-entanglement rotations** (RY and RZ) for classical-to-quantum feature processing
- **Parameter economy**: Only 8-9 distinct parameters despite rich expressivity

This approach should:
- Improve worst_group_margin by richer entanglement patterns
- Maintain or reduce parameter count while increasing expressivity
- Accelerate convergence through better feature space mapping
- Better separate hard-to-classify samples through multi-scale entanglement
