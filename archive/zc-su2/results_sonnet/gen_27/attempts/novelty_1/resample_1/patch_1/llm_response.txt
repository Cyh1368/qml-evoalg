<NAME>
single_param_dual_ring_entangler

<DESCRIPTION>
Builds on the highest-scoring seed (single shared rotation parameter for both pre- and post-entanglement layers, giving only 1 unique trainable parameter) and enriches the fixed entangling structure with a zero-parameter "dual-ring" topology: a nearest-neighbor CZ ring plus a skip-2 CZ ring layered on top. This adds non-local connectivity (each qubit now entangles with its immediate neighbor and its second neighbor) without increasing the parameter count, aiming to improve expressivity/generalization and potentially speed up convergence while preserving the extreme parameter economy (n_params stays minimal) that drove the best prior score.
</DESCRIPTION>

"""Seed program. Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved.

Everything else about the task, that is how inputs are encoded, how the circuit
is measured, how training works and how metrics are computed, is fixed and lives
in a module that is not reproduced here. No information about the data is
available in this file.
"""

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}
ALLOWED_ISING_GATES = {"XX", "YY", "ZZ"}


# EVOLVE-BLOCK-START
ANSATZ_SPEC = []

# 1. Pre-entanglement RY layer: ALL 8 qubits share a SINGLE trainable
#    parameter "p_shared". This is the most extreme collapse of rotation
#    parameters — a single scalar drives every qubit's initial rotation.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": wire, "param": "p_shared"})

# 2a. Fixed nearest-neighbor CZ ring (closed chain), zero trainable
#     parameters. Every qubit entangles with its immediate neighbours.
for i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [i, (i + 1) % N_QUBITS]})

# 2b. Fixed "skip-2" CZ ring layered on top of the nearest-neighbor ring,
#     still zero extra trainable parameters. This adds non-local
#     entangling loops (qubit i with qubit i+2) that were shown to help
#     expressivity/generalization at no parameter cost, forming a dual-
#     ring topology while keeping the total unique-parameter count at 1.
for i in range(0, N_QUBITS, 2):
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [i, (i + 2) % N_QUBITS]})

# 3. Post-entanglement RZ layer reusing the SAME single parameter name
#    "p_shared" as step 1 (different axis, so the single scalar still
#    drives a non-trivial entangled transformation), keeping the total
#    unique-parameter count per block at exactly 1.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": wire, "param": "p_shared"})
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
