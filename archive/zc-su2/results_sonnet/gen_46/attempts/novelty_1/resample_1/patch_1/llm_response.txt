<DESCRIPTION>
The 3-unique-parameter design (p_g0, p_g1, xx_ent) regressed the combined score to 0.68 from the 0.80 achieved by the single-shared-parameter seed designs, primarily because parameter efficiency dropped (n_params went from 8 to 20). This suggests that increasing distinct parameter names hurts the score more than it helps accuracy, since accuracy was already saturated at 1.00 in all variants.

Following the recommendation, I revert to the parameter-economical single-shared-scalar structure of the best-performing seed, but introduce a second shared parameter "theta2" dedicated to the long-range entangling CRZ gates (distinct from the rotation-layer parameter "theta1"). This gives the entangling layer independent tunable strength from the local rotations while keeping the total unique-parameter count per block at just 2 (versus 8 total with 8 repetitions), which should preserve the high parameter-efficiency and convergence speed of the seed while potentially improving expressivity enough to reduce validation/test loss further or improve robustness on harder splits.

Structure:
1. RX layer on all 8 qubits, shared "theta1".
2. RY layer on all 8 qubits, shared "theta1" (same param, different axis -> effectively a 2D rotation from one scalar).
3. Fixed nearest-neighbor CZ ring (zero param cost) for local entanglement.
4. Antipodal CRZ entangler using new shared "theta2" (independent trainable long-range interaction strength).
5. RZ layer on all 8 qubits, shared "theta1", closing the block.

This keeps depth/gate-count similar to the 0.80-scoring seeds while adding exactly one extra trainable scalar per block repetition, testing whether decoupling entangler strength from local rotation angle helps push past the 0.80 ceiling.

ANSATZ_SPEC = []

# 0. Pre-entanglement rotation layer, axis RX: ALL 8 qubits share the SAME
#    single trainable parameter "theta1".
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RX", "wire": wire, "param": "theta1"})

# 1. Pre-entanglement rotation layer, axis RY, reusing the SAME "theta1".
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": wire, "param": "theta1"})

# 2. Fixed nearest-neighbor CZ ring (closed chain), zero trainable
#    parameters, giving local connectivity across the whole register.
for i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [i, (i + 1) % N_QUBITS]})

# 3. Parametrized long-range entangler on antipodal pairs (distance 4 on
#    the 8-cycle), using a SECOND shared parameter "theta2", independent
#    from the rotation-layer parameter "theta1". This decouples local
#    rotation strength from long-range entangling strength while keeping
#    the total unique-parameter count per block at exactly 2.
for i in range(N_QUBITS // 2):
    ANSATZ_SPEC.append(
        {"gate": "CRZ", "wires": [i, i + N_QUBITS // 2], "param": "theta2"}
    )

# 4. Post-entanglement rotation layer, axis RZ, reusing the SAME "theta1"
#    parameter, keeping the total unique parameter count per block at
#    exactly 2 ("theta1", "theta2").
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": wire, "param": "theta1"})
