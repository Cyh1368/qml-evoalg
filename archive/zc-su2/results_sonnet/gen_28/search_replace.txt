Building on the current single-shared-parameter design (all rotations reuse "theta"), I add a third rotation axis (RX) before the existing RY layer, still reusing the same "theta" parameter. This creates a full RX-RY-CZ-entangle-RZ pattern per qubit, all driven by one scalar angle, giving richer single-qubit rotations (covering all three Pauli axes) without increasing the parameter count at all. Since RX and RY don't commute, inserting an RX layer before RY (with no entangling gate between them) changes the effective single-qubit unitary in a nontrivial way, potentially improving trainability/convergence speed and accuracy stability while keeping n_params=8, preserving the strong parameter economy that has been driving score improvements in previous generations.
