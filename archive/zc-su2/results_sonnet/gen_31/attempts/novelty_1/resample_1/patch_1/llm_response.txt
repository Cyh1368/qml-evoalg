single_theta_mixed_entangle

<DESCRIPTION>
Builds on the best-performing prior design (a single shared trainable parameter "theta" driving RX/RY/RZ layers) but pushes parameter economy and expressivity further. Instead of using only fixed CZ gates for entanglement, the ring entangler now alternates CNOT and CZ gates (as recommended) to diversify the entangling structure without adding parameters. Additionally, the long-range "diameter" connections are upgraded from parameter-free CZ gates to CRZ gates that reuse the same shared "theta" parameter, injecting extra trainable expressivity into the entangling layer at zero additional parameter cost. This keeps n_params at the theoretical minimum (1 per block repetition) while giving the circuit richer, parameter-coupled long-range correlations, aiming to match or exceed the top score (0.80) with even better parameter efficiency and generalization.

"""Seed program. Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved.

Everything else about the task, that is how inputs are encoded, how the circuit
is measured, how training works and how metrics are computed, is fixed and lives
in a module that is not reproduced here. No information about the data is
available in this file.
"""

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}
ALLOWED_ISING_GATES = {"XX", "YY", "ZZ"}


# EVOLVE-BLOCK-START
ANSATZ_SPEC = []

# 1. Pre-entanglement rotation layer: ALL 8 qubits share a SINGLE trainable
#    parameter "theta" on the RX axis. This is the minimal possible
#    parametrization while still touching every qubit.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RX", "wire": wire, "param": "theta"})

# 2. Mid rotation layer: same shared "theta" parameter but on the RY axis,
#    giving each qubit a richer single-qubit rotation (two non-commuting
#    axes) before entanglement, still at zero extra parameter cost.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": wire, "param": "theta"})

# 3. Nearest-neighbor entangling ring, alternating CNOT and CZ gates
#    (instead of a uniform CZ ring) to diversify the entangling structure
#    without introducing any new trainable parameters. This perturbs the
#    entanglement pattern relative to a pure-CZ ring while keeping the
#    same connectivity graph (an 8-cycle).
for i in range(N_QUBITS):
    gate = "CNOT" if i % 2 == 0 else "CZ"
    ANSATZ_SPEC.append({"gate": gate, "wires": [i, (i + 1) % N_QUBITS]})

# 4. Long-range "diameter" entangling layer connecting each qubit to its
#    antipodal partner (distance 4 on the 8-cycle). Instead of a fixed,
#    parameter-free CZ, we use CRZ gates that REUSE the same shared
#    "theta" parameter. This injects extra trainable expressivity into
#    the long-range entangling structure at ZERO additional parameter
#    cost, coupling rotation and entanglement strength together.
for i in range(N_QUBITS // 2):
    ANSATZ_SPEC.append(
        {"gate": "CRZ", "wires": [i, i + N_QUBITS // 2], "param": "theta"}
    )

# 5. Post-entanglement rotation layer: reuse the SAME "theta" parameter
#    (different axis, RZ), so the entire block contributes only ONE
#    unique trainable parameter in total, maximizing parameter economy.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": wire, "param": "theta"})
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
