<DESCRIPTION>
This design crosses the two 0.80-scoring seeds that both used a *single* shared trainable parameter "theta" per block repetition (maximal parameter economy, n_params=8 total across 8 reps). The first seed used a fixed CNOT/CZ ring plus a parametrized antipodal CRZ layer (depth 72, converges in 60 steps); the second seed used an XX/CZ alternating ring plus extra skip-2 and antipodal CZ shortcuts (depth 96, but converges much faster in 30 steps thanks to the non-commuting parametrized XX interaction placed directly in the entangling ring).

The crossover keeps the fast-converging ingredient (the alternating parametrized-XX/fixed-CZ nearest-neighbor ring, reusing "theta") since that was the decisive factor separating 30-step vs 60-step convergence between the two equally-accurate seeds. It drops the extra zero-parameter skip-2 sub-ring (2b) from the second seed, since the antipodal shortcuts (2c) already provide long-range connectivity, and the skip-2 ring only added depth/gate-count without changing convergence speed or accuracy. The result should retain the 30-step convergence advantage while being shallower and having fewer gates than either 0.80 seed, improving the "PARAMETER ECONOMY" / gate-count / depth aspects of the score without sacrificing the perfect train/val/test accuracy both seeds already achieve with only 1 trainable parameter per repetition.

Structure per block repetition (single shared parameter "theta"):
1. RX on all 8 qubits (shared theta) — non-commuting pre-rotation axis 1.
2. RY on all 8 qubits (shared theta) — non-commuting pre-rotation axis 2.
3. Nearest-neighbor ring, alternating: even links get a parametrized XX(theta) interaction, odd links get a fixed, zero-parameter CZ. This is the key ingredient tied to fast (30-step) convergence.
4. Fixed, zero-parameter antipodal shortcuts (distance-4 on the 8-cycle) for long-range connectivity, kept lightweight (only 4 gates) instead of adding a second skip-2 sub-ring.
5. RZ on all 8 qubits (shared theta) — post-entanglement rotation, reusing the same single parameter to keep the unique-parameter count at exactly 1 per block.

This keeps n_params identical to both parents (1 unique name x 8 repetitions = 8 total), but removes 8 redundant CZ gates (the skip-2 sub-ring) per repetition, reducing depth/gate-count relative to the faster-converging parent while preserving its structural advantage.

"""Seed program. Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved.

Everything else about the task, that is how inputs are encoded, how the circuit
is measured, how training works and how metrics are computed, is fixed and lives
in a module that is not reproduced here. No information about the data is
available in this file.
"""

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}
ALLOWED_ISING_GATES = {"XX", "YY", "ZZ"}


# EVOLVE-BLOCK-START
ANSATZ_SPEC = []

# 0. Pre-entanglement rotation layer, axis RX: ALL 8 qubits share the SAME
#    single trainable parameter "theta". Combined with the RY layer below
#    (different, non-commuting axis, no entangler in between) this gives a
#    richer per-qubit rotation while keeping only ONE trainable parameter
#    for the entire block.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RX", "wire": wire, "param": "theta"})

# 1. Pre-entanglement rotation layer, axis RY, reusing the SAME "theta".
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": wire, "param": "theta"})

# 2. Nearest-neighbor ring, alternating between a parametrized XX
#    interaction (reusing the SAME shared "theta" parameter, no new
#    trainable name introduced) and a fixed, zero-parameter CZ gate. This
#    non-commuting tunable interaction directly inside the entangling
#    ring is the key ingredient behind the fastest observed convergence
#    (30 steps) among prior single-parameter, perfect-accuracy designs.
for i in range(N_QUBITS):
    a, b = i, (i + 1) % N_QUBITS
    if i % 2 == 0:
        ANSATZ_SPEC.append({"gate": "XX", "wires": [a, b], "param": "theta"})
    else:
        ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})

# 3. Fixed, zero-parameter antipodal shortcuts (distance-4 on the
#    8-cycle) for long-range connectivity. Kept lightweight (only 4
#    gates, no extra skip-2 sub-ring) to minimize depth/gate-count while
#    preserving global connectivity across the register.
for i in range(N_QUBITS // 2):
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [i, i + N_QUBITS // 2]})

# 4. Post-entanglement rotation layer, axis RZ, reusing the SAME "theta"
#    parameter, keeping the total unique parameter count per block at
#    exactly 1.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": wire, "param": "theta"})
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
