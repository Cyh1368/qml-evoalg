Building on the two prior 0.80‑scoring designs (single shared parameter "theta" reused across every rotation and entangling gate in the block, giving n_params = number of repetitions), the current 26‑parameter multi‑group design regressed the score to 0.66 purely due to parameter bloat (parameter_efficiency dropped 3×). This version reverts to the proven single‑shared‑parameter (theta) design that achieved perfect train/val/test accuracy with maximal parameter economy, and applies the suggested improvement of turning the previously fixed, zero‑parameter skip‑2 sub‑ring (CZ between qubits 2 apart) into a **trainable** CRY interaction — but critically reuses the *same* "theta" parameter instead of introducing a new parameter name. This adds extra non‑commuting expressivity to the entangling structure (potentially improving convergence speed and robustness on tiny training sets) while keeping the total trainable-parameter count identical to the best-scoring prior candidates (n_params = number of block repetitions, i.e. maximal economy, no increase in parameter_efficiency penalty).

Key configuration:
- Single shared trainable parameter "theta" for ALL single-qubit rotations (RX, RY, RZ) and ALL parametrized two-qubit interactions (XX ring gates + new CRY skip-2 gates).
- Alternating fixed CZ / trainable XX(theta) nearest-neighbor ring for local entanglement (as in the fastest-converging prior variant).
- Skip-2 sub-ring (distance-2 connections 0-2,2-4,4-6,6-0) upgraded from fixed CZ to trainable CRY(theta), injecting extra non-commuting long-range coupling without any new parameter.
- Fixed, zero-parameter antipodal CZ shortcuts (distance-4) preserved for global connectivity at no parameter cost.
- Overall this keeps n_params minimal (matches the 0.80-scoring baseline) while increasing circuit expressivity/entanglement depth, aiming to push accuracy/convergence-speed metrics further while maintaining top parameter efficiency.

"""Seed program. Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved.

Everything else about the task, that is how inputs are encoded, how the circuit
is measured, how training works and how metrics are computed, is fixed and lives
in a module that is not reproduced here. No information about the data is
available in this file.

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}
ALLOWED_ISING_GATES = {"XX", "YY", "ZZ"}


# EVOLVE-BLOCK-START
ANSATZ_SPEC = []

# 0. Pre-entanglement rotation layer, axis RX: ALL 8 qubits share the SAME
#    single trainable parameter "theta". Combined with the RY layer below
#    (different, non-commuting axis, no entangler in between) this gives a
#    richer per-qubit rotation while keeping only ONE trainable parameter
#    for the entire block. This single-shared-parameter design is what
#    drove the best combined score (0.80) among prior candidates, thanks
#    to maximal parameter economy.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RX", "wire": wire, "param": "theta"})

# 1. Pre-entanglement rotation layer, axis RY, reusing the SAME "theta".
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": wire, "param": "theta"})

# 2a. Nearest-neighbor ring, alternating between a fixed CZ and a
#     parametrized XX interaction that REUSES the same shared "theta"
#     parameter. This injects one extra, non-commuting, tunable
#     entangling interaction WITHOUT introducing any new trainable
#     parameter name, preserving the parameter-economy advantage while
#     adding expressivity.
for i in range(N_QUBITS):
    a, b = i, (i + 1) % N_QUBITS
    if i % 2 == 0:
        ANSATZ_SPEC.append({"gate": "XX", "wires": [a, b], "param": "theta"})
    else:
        ANSATZ_SPEC.append({"gate": "CZ", "wires": [a, b]})

# 2b. Skip-2 sub-ring linking every other qubit (0-2, 2-4, 4-6, 6-0), now
#     upgraded from a fixed zero-parameter CZ to a TRAINABLE CRY
#     interaction that reuses the SAME shared "theta" parameter. This
#     boosts local/mid-range expressivity (per the observed benefit of
#     turning fixed sub-rings into trainable ones) without adding any new
#     trainable parameter name, so the total unique-parameter count per
#     block stays at exactly 1.
for i in range(0, N_QUBITS, 2):
    ANSATZ_SPEC.append({"gate": "CRY", "wires": [i, (i + 2) % N_QUBITS], "param": "theta"})

# 2c. Fixed, zero-parameter antipodal shortcuts (distance-4 on the
#     8-cycle) for long-range connectivity, kept parameter-free to avoid
#     inflating the trainable-parameter count.
for i in range(N_QUBITS // 2):
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [i, i + N_QUBITS // 2]})

# 3. Post-entanglement rotation layer, axis RZ, reusing the SAME "theta"
#    parameter, keeping the total unique parameter count per block at
#    exactly 1.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": wire, "param": "theta"})
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
