remove_redundant_rz_pre_layer
</NAME>

<DESCRIPTION>
Since CZ is a diagonal gate, it commutes with any RZ rotation. In the current ansatz, an RZ layer is applied both before ("rz_pre_*") and after ("rz_post_*") the CZ entangling ladder on every wire. Because RZ and CZ are all diagonal in the computational basis, the two RZ layers on the same wire simply compose into a single effective RZ rotation (the CZ in between doesn't change this), regardless of parameter values. This means the "rz_pre" layer adds zero expressive power beyond what "rz_post" already provides — it's pure parameter redundancy that hurts parameter economy without helping accuracy. Removing it cuts 8 parameters per repetition (48 total across the 6 repetitions), roughly halving the RZ-related parameter count while preserving the full reachable unitary set, which should substantially improve the parameter-economy component of the score without harming accuracy.
</DESCRIPTION>
