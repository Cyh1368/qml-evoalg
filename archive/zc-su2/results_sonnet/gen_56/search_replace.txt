decouple_entangler_param

<DESCRIPTION>
Introduce a second shared parameter for the entangling layer, decoupling it from the single-qubit rotation angle. Currently the CRZ long-range entangling layer reuses the same "theta" parameter as the RX/RY/RZ rotation layers, forcing rotation angle and entanglement strength to be tied together. By giving the CRZ layer its own shared parameter "theta_e" (still shared across all 8 wires, so only +1 trainable parameter total, n_params=2), the circuit gains an independent degree of freedom to tune entanglement strength separately from single-qubit rotation angle. This should help push past the apparent single-parameter expressivity ceiling (score plateaued at 0.80) while keeping the parameter count essentially minimal (2 total), preserving strong parameter efficiency and likely improving validation/test loss without hurting accuracy or convergence speed.
</DESCRIPTION>
