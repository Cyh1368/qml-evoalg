param_sharing_reduction
</NAME>

<DESCRIPTION>
The current ansatz uses 24 independent parameters per repetition (8 RY + 8 RZ-pre + 8 RZ-post), giving 146 total trainable parameters while already achieving perfect train/val/test accuracy. Since the score is dominated by parameter economy, we can cut the parameter count roughly 3x by (1) sharing the RZ-pre and RZ-post rotation on each wire under a single parameter (turning the pattern into RZ(θ)-CZ-RZ(θ), which still provides nontrivial phase entangling structure) and (2) pairing adjacent wires to share the same RY rotation parameter (wires 0-1, 2-3, 4-5, 6-7). This reduces the per-repetition parameter count from 24 to 8, while preserving the same circuit depth/connectivity (same gate count and entangling structure), which should preserve expressivity/accuracy reasonably well but substantially boost parameter efficiency and reduce the risk of overfitting on very few training examples.
</DESCRIPTION>
