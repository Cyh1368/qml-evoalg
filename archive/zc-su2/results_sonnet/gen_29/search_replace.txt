<DESCRIPTION>
Simplify the rotation layer to use a single shared parameter "theta" for all pre- and post-entanglement rotations (matching the best-performing prior seed with n_params=8, score=0.80), and additionally inject a single shared-parameter CRZ layer on disjoint qubit pairs after the CZ ring, as recommended. This adds only one extra trainable parameter ("phi") per block repetition while giving the ansatz a tunable, parametrized two-qubit interaction strength beyond the fixed CZ entangler, which should improve expressivity/generalization without significantly increasing parameter count. Reducing rotation parameters from 4 groups to a single shared theta cuts parameter count roughly in half compared to the current program, directly improving parameter economy, while the added CRZ layer compensates for the lost per-qubit rotation flexibility via controlled entanglement tuning.
