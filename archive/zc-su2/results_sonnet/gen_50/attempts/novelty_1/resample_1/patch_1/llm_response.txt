lean_shared_theta_dualring

<DESCRIPTION>
Both prior 0.80-scoring seeds used a single block-shared parameter name ("p_shared"/"theta") reused across every rotation and entangling gate, keeping n_params at the architecture minimum (one independent copy per block repetition). The current 20-parameter variant (3 unique names: p_g0, p_g1, xx_ent) dropped the score to 0.68 purely from parameter-economy loss, even though accuracy stayed perfect — confirming that unique-parameter count, not accuracy, is the main lever available to improve the score further given accuracy is already saturated at 1.0.

This version keeps the proven single-shared-parameter design (n_params = minimum architecture floor, same as both 0.80 seeds) but tightens the circuit: it uses three rotation axes (RX, RY, RZ) all bound to one shared name "theta" for maximal non-commuting single-qubit expressivity per parameter, combined with a leaner entangling backbone — a nearest-neighbor CZ ring plus a sparse 4-edge "antipodal" CZ set (instead of a denser dual-ring + antipodal combo) — and a single shared-parameter CRZ layer at offset 2 for a parametrized non-local interaction. This reduces total gate count and depth relative to both prior 0.80 seeds while preserving the same non-commuting 3-axis-rotation + fixed-entangle + parametrized-entangle structure that gave perfect train/val/test accuracy, aiming to improve convergence speed and/or loss without paying any parameter-count penalty.

```python
"""Seed program. Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved.

Everything else about the task, that is how inputs are encoded, how the circuit
is measured, how training works and how metrics are computed, is fixed and lives
in a module that is not reproduced here. No information about the data is
available in this file.
"""

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}
ALLOWED_ISING_GATES = {"XX", "YY", "ZZ"}


# EVOLVE-BLOCK-START
ANSATZ_SPEC = []

# 0. Pre-entanglement two-axis rotation: ALL 8 qubits share a SINGLE
#    trainable parameter "theta" for the RX axis. Zero extra parameter
#    cost relative to a single-axis design.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RX", "wire": wire, "param": "theta"})

# 1. Second axis (RY), reusing the SAME shared parameter "theta". Since RX
#    and RY do not commute, this still yields a genuinely 2D single-qubit
#    rotation from one scalar angle.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": wire, "param": "theta"})

# 2. Fixed, parameter-free entangling backbone, deliberately kept sparse to
#    reduce depth/gate-count relative to prior 0.80-scoring designs:
#    (a) nearest-neighbor CZ ring (wrap-around) -> degree 2 connectivity;
#    (b) a sparse 4-edge "antipodal" CZ set (only half the qubits pair with
#        their diametrically opposite partner) -> adds long-range mixing at
#        minimal extra gate cost.
for i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [i, (i + 1) % N_QUBITS]})
for i in range(N_QUBITS // 2):
    ANSATZ_SPEC.append({"gate": "CZ", "wires": [i, i + N_QUBITS // 2]})

# 3. A single shallow parametrized entangling layer (CRZ) at offset 2,
#    reusing the SAME shared "theta" parameter. This injects a
#    non-commuting, parametrized long-range interaction without adding any
#    new trainable parameter, while keeping the entangling layer shallow
#    (only N_QUBITS extra gates).
for i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "CRZ", "wires": [i, (i + 2) % N_QUBITS], "param": "theta"})

# 4. Post-entanglement rotation reusing the SAME single shared parameter
#    "theta" (third axis, RZ), completing an all-three-axis single-qubit
#    rotation basis built from exactly one trainable angle per block
#    repetition, matching the minimal parameter floor of the architecture.
for wire in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RZ", "wire": wire, "param": "theta"})
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
```
