The current implementation suffers from a large generalization gap (0.10) and suboptimal worst-group margin (0.37). The prior best program achieved 0.59 score with tighter margins, suggesting that finer parameter control and better entanglement patterns are key.

This new approach implements:
1. **Parity-split RZ layers**: Instead of using a single `rz_post` parameter for all qubits, split it into `rz_post_even` (qubits 0,2,4,6) and `rz_post_odd` (qubits 1,3,5,7), giving independent phase control while adding only one parameter.
2. **Reduced initial RZ layer**: Use parameter sharing on `rz_pre` to maintain consistency.
3. **Optimized entanglement**: Carefully select two-qubit interactions that maximize information sharing without over-parameterization. Include controlled rotations (CRX) which offer more expressive power than Ising gates for certain patterns.
4. **Simpler mid-layer control**: Remove the explicit middle RY block to reduce depth and parameter count, focusing on the most effective layers.

This approach trades minimal parameter overhead for significantly better phase control refinement, which historical data shows reduces the generalization gap and improves robustness on hard samples (worst-group margin).
