# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Two-parameter RY parity sharing with global RZ pre/post layers  
  • Current Best Program (Combined 0.58, train 1.00/val 0.97/test 0.96, gap 0.04) uses “ry_0”/“ry_1” on even/odd qubits plus shared “rz_pre”/“rz_post,” replicating the pattern from Generation 16 (Combined 0.55) and Generation 13 (Combined 0.55).  
- Diversified XX/YY/ZZ entanglers with cross-block links  
  • Defining six distinct entangler parameters on wires [0,1], [2,3], [4,5], [6,7], [1,4], [3,6] in the Current Best Program boosted test accuracy to 0.96, outperforming Generation 20 (shared entanglers, test 0.89) despite equal combined scores.  
- Balanced total vs. distinct parameters at moderate depth  
  • Optimal configurations cluster at n_params≈12, n_distinct≈10, depth≈15, gate_count≈90. The Current Best (12 / 10 / 15 / 90) achieves param_efficiency 0.08 and the smallest generalization gap.  
- Explicit per-gate parameter naming  
  • Listing each gate with its own “param” field (e.g., “xx_01,” “yy_23”) affords fine-grained expressivity without overfitting, a technique central to the highest-performing circuits.  

## Ineffective Approaches  
- Excessive depth and gate count without more distinct parameters  
  • Gen23 (depth 22, gates 108, n_distinct 10) achieved perfect training but test 0.85 and gap 0.15; Gen20 (depth 18, gates 114, n_distinct 8) hit test 0.89/gap 0.11 despite ideal train.  
- Over-reusing entangler parameters  
  • Generation 20’s four distinct Ising params (shared across multiple pairs) capped test at 0.89; Generation 21’s seven distinct entanglers only reached test 0.75/gap 0.18.  
- Sparse entanglement patterns  
  • Generation 24 (nearest-neighbor only, 11 distinct params) saw poor combined 0.36 and train 0.69, showing that omitting cross-block links severely limits expressivity.  
- Over-sharing single-qubit rotations/entanglers  
  • Parameter efficiencies below ~0.07 (e.g., Gen23’s 0.07) correlate with higher gaps and lower margins, indicating diminishing returns from excessive reuse.  

## Implementation Insights  
- Loop-based RY parity assignment  
  • “for w in range(8): param = f'ry_{w%2}'” implements two-parameter alternation compactly.  
- Shared RZ pre/post layers  
  • Repeating “rz_pre” and “rz_post” across all wires provides global phase control with just two parameters.  
- Explicit entangler listing in ANSATZ_SPEC  
  • Enumerating each XX/YY/ZZ gate with its own “param” name (e.g., {"gate":"XX","wires":[0,1],"param":"xx_01"}) ensures distinct controllable interaction strengths.  
- Shallow yet expressive circuit depth  
  • Trimming depth from 18 to 15 layers, while preserving full XX/YY/ZZ plus cross-links, reduced the generalization gap from >0.10 (in deeper variants) to 0.04.  

## Performance Analysis  
- Current Best vs. other high-sharing designs  
  • Although Generation 20 and the Current Best both combine to 0.58, the Current Best’s shallower, more diversified ansatz improves test accuracy by 7 points (0.96 vs. 0.89) and halves the gap (0.04 vs. 0.11).  
- Impact of entangler diversity  
  • Increasing distinct XX/YY/ZZ params from 4 (Gen20) to 6 (Current Best) raises combined score while reducing overfitting.  
- Param_efficiency sweet spot ≈ 0.08  
  • Circuits at this efficiency (Current Best, Gen16, Gen13) cluster at combined 0.55–0.58; efficiencies ≥ 0.09 or ≤ 0.07 see diminished generalization.  
- Depth/gate count trade-off  
  • Depth 15/gate 90 achieves the best balance; deeper (≥ 18) or shallower (< 15) circuits underperform in test accuracy or margin despite similar training convergence.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Insert a mid-circuit parity-swapped RY+shared RZ layer. After the existing XX/YY/ZZ block (and before the rz_post), apply RY gates with parameters alternating ry_1 on even wires [0,2,4,6] and ry_0 on odd wires [1,3,5,7], then a single RZ(rz_mid) on all eight qubits. This mirrors the proven two-parameter parity motif while reversing it mid-circuit and adds just one new distinct parameter, boosting expressivity within the n_distinct≤12 sweet spot.  

2. Add a single-parameter long-range CRZ entangler layer. Immediately before rz_post, append CRZ(crz_diag) gates on the four diagonal pairs [(0,5),(1,6),(2,7),(3,4)] using one shared parameter crz_diag. Global cross-block phase couplings like these have shown strong test-accuracy gains per parameter in diversified entangler schemes.  

3. Enrich the Ising graph with two new distinct ZZ links. In the main entangler block, append ZZ gates on wires [0,3] (zz_03) and [4,7] (zz_47), each with its own parameter. Prior generations demonstrated that adding well-chosen cross-block ZZ links up to n_distinct≈12 raises combined scores without overfitting at depth≈15.  

4. Diversify the two-qubit gate family via controlled rotations. Replace XX([6,7],xx_67) with CRX([6,7],crx_67) and YY([1,4],yy_14) with CRY([1,4],cry_14), leaving their positions unchanged. Introducing CRX/CRY alongside Ising couplings tests whether heterogeneous interaction types can further reduce the generalization gap.  

5. Split the final shared RZ into parity-based parameters. Instead of a single rz_post on all wires, use rz_post_even on even qubits [0,2,4,6] and rz_post_odd on odd qubits [1,3,5,7]. This parity-split echoes the RY alternation scheme, adds only one extra parameter, and refines post-entanglement phase control proven to aid generalization.
