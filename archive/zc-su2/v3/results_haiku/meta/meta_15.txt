# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Alternating two RY parameters on even/odd qubits plus shared pre-/post-RZ layers  
  • Best Program (Combined 0.58) uses “ry_0” on qubits [0,2,4,6], “ry_1” on [1,3,5,7] and uniform “rz_pre”/“rz_post” on all qubits, yielding train 1.00/val 0.97/test 0.96 with gap 0.04.  
  • Generation 13 (“Shared-Parameter 8-Qubit Ising Ansatz,” Combined 0.55) follows the same RY+RZ pattern, achieving train 1.00/val 0.92/test 0.88 with gap 0.12.  
- Diversified Ising entanglement on nearest-neighbor and cross pairs with distinct parameters  
  • Best Program interleaves XX/YY/ZZ on [0,1],[2,3],[4,5],[6,7] plus cross-block [1,4],[3,6] (six distinct entangler parameters), boosting combined from 0.47 (Generation 7) to 0.58.  
- Limiting distinct parameters to ~10 while maintaining ~12 total gates  
  • Best Program’s 12 total parameters but only 10 distinct strikes the balance between expressivity and regularization—mirroring its stable convergence at ~150 steps.  
- Circuit depth ~15 and gate count ~90  
  • Both the Best Program and Generation 13 used depth=15, gate_count=90, hitting the “sweet spot” for capacity without overfitting, compared to Generation 10’s deeper (18) and larger (114) circuit that underperformed (Combined 0.39).  

## Ineffective Approaches  
- Heavy entangler parameter sharing  
  • Generation 12 (Combined 0.29, gap 0.42) and Generation 10 (Combined 0.39, gap 0.21) reused parameters across multiple XX/YY/ZZ gates, causing either under- or over-fitting and low test accuracy (0.52 and 0.66).  
- Restricting to nearest-neighbor XX only  
  • Generation 14 (“Layered RY-RZ-XX Ansatz,” Combined 0.43) and earlier shared-parameter Ising variants (Combined ≤ 0.44) lacked YY/ZZ and cross-block links, capping test accuracy at ~0.67–0.87.  
- Increasing depth/gate count without proportional distinct parameters  
  • Generation 10’s 18-depth, 114-gate circuit with only 11 distinct parameters achieved worse performance (Combined 0.39) than the 15-depth, 90-gate Best Program (Combined 0.58).  

## Implementation Insights  
- Explicit parameter naming in ANSATZ_SPEC  
  • Defining each entangling gate as {"gate":"XX","wires":[i,j],"param":"xx_i j"} (and similarly for YY/ZZ) supports fine-grained expressivity.  
- Two-parameter RY alternation  
  • Code snippet:  
    {"gate":"RY","wire":w,"param": f"ry_{w%2}" } for w in 0…7  
  yields maximal per-qubit heterogeneity with minimal parameters.  
- Uniform RZ blocks  
  • Pre- and post-entanglement layers use:  
    {"gate":"RZ","wire":w,"param":"rz_pre"}  
    …  
    {"gate":"RZ","wire":w,"param":"rz_post"}  
  ensuring consistent phase adjustment across all qubits.  
- Balance of total vs. distinct parameters  
  • Best Program’s n_params=12, n_distinct=10 demonstrates how one can reuse two RZ and two RY parameters but keep each entangler unique, optimizing parameter efficiency (0.08).  

## Performance Analysis  
- Combined scores trend  
  • Best Program: 0.58 > Gen13: 0.55 > Gen7: 0.47 > Gen14: 0.43 > Gen10: 0.39 > Gen12: 0.29  
- Test accuracy vs. generalization gap  
  • Best Program test 0.96/gap 0.04 sharply outperforms Gen13’s test 0.88/gap 0.12 and Gen7’s test 0.79/gap 0.21.  
- Parameter efficiency correlation  
  • Optimal test performance aligns with param_efficiency≈0.08 (Best Program). Designs with higher efficiency (>0.10 in Gen7) or lower (<0.05 in Gen12/10) underperformed.  
- Depth and gate count sweet-spot  
  • Both Best Program and Gen13 (depth=15, gate_count=90) outperform deeper (depth=18) or shallower variants, confirming earlier observations that ~15 layers and ~90 gates best balance expressivity and overfitting.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Insert a mid-circuit alternating RY layer before the final rz_post. After the existing XX/YY/ZZ block and before the rz_post gates, apply  
   • RY(ry_0) on qubits [0,2,4,6] and RY(ry_1) on [1,3,5,7], re-using the same ry_0/ry_1 parameters.  
   Evidence: Doubling the proven two-parameter heterogeneity mid-circuit can boost expressivity without increasing distinct parameters, as seen in top performers’ alternating-RY patterns.

2. Duplicate the Ising entangler block with parameter reuse. Immediately after the first XX([0,1], [6,7]) / YY([2,3], [1,4]) / ZZ([4,5], [3,6]) layer and before rz_post, append an identical sequence of XX, YY, ZZ gates on the same wires, re-using xx_01, xx_67, yy_23, yy_14, zz_45, zz_36. This preserves n_distinct_params=10 while intensifying correlations, leveraging the “sweet-spot” depth≈15 that drove the Best Program’s success.

3. Probe diagonal controlled-phase links with shared CRZ. Between the entangler block(s) and rz_post, insert two CRZ gates on wires [0,4] and [2,6] using a single new parameter crz_cross. This one-parameter addition tests long-range phase control—an approach grounded in the Best Program’s efficient use of a small number of high-value cross-block couplings.

4. Explore moderate two-qubit parameter tying. Replace xx_01 and xx_67 with a shared parameter xx_nn, and tie yy_23 and yy_14 to yy_shared, while keeping zz_45 and zz_36 distinct. Reducing distinct entangler variables from six to four (plus the existing RY/RZ) probes whether slight regularization can further tighten generalization without losing the full XX/YY/ZZ gate set.

5. Introduce an alternating RZ pre-block for phase heterogeneity. Instead of uniform rz_pre, apply rz_pre_even on qubits [0,2,4,6] and rz_pre_odd on [1,3,5,7], adding one new distinct parameter (n_distinct_params→11). This mirrors the success of two-parameter RY alternation in the phase domain and stays within the empirically optimal 10–12 distinct-parameter range.
