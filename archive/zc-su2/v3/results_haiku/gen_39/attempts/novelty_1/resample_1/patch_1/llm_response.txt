The current program has degraded performance compared to prior versions (score 0.56 vs 0.58). Key issues:
1. **Worse worst_group_margin (0.32 vs 0.28 in prior)**: The robust separation on hard samples is suffering
2. **Higher convergence step (480 vs 150)**: The ansatz is harder to train
3. **Larger gate count (114 vs 90)**: Added complexity without benefit (extra RY layer after entangling)

The prior programs achieved better generalization with simpler structure. The current approach adds post-entanglement RY gates that duplicate the pre-entanglement RY layer, increasing depth and convergence time without improving separation.

**New strategy**: Return to the cleaner structure of the best prior program (score 0.58) but apply the parity-split refinement ONLY to the final RZ block. This:
- Splits `rz_post` into `rz_post_even` [0,2,4,6] and `rz_post_odd` [1,3,5,7], adding only ONE extra parameter
- Eliminates the redundant post-entanglement RY layer, reducing depth from 18 to 15 and gate count to ~90
- Maintains the proven parity-based parameter sharing that helped in prior runs
- Keeps parameter count at 11 distinct parameters (9 from entangling + rz_pre + 2 post RZ splits)
- Should converge faster and improve worst_group_margin through better phase control granularity
