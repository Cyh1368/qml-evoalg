<DESCRIPTION>
This design draws inspiration from the successful prior programs' parameter efficiency and the recommendation to use parity-split phase control. The key insights are:

1. **Parity-split final RZ layer**: Split `rz_post` into separate parameters for even (0,2,4,6) and odd (1,3,5,7) qubits, mirroring the parity structure already present in the RY initialization layer. This adds one extra parameter but provides finer phase control that historically reduces the generalization gap.

2. **Learned entanglement pattern**: Rather than blindly reusing the entanglement from prior runs, I use a more structured approach with controlled two-qubit gates (CRX/CRY) strategically placed to enhance expressiveness without dramatically increasing parameters.

3. **Selective parameter sharing**: Maintain parameter economy by sharing within logical groups (even/odd parity for RY and final RZ), but differentiate the two-qubit interactions to capture more subtle correlations needed for robust separation on hard samples.

4. **RZ middle layer consolidation**: Keep `rz_mid` unified across all qubits as a global phase modulator between initialization and entanglement, which is simpler than the current approach.

The current program achieves worse worst_group_margin (0.24 vs prior 0.31) due to over-aggressive parameter sharing that sacrifices expressiveness for economy. This variant restores expressiveness in the critical final phase control while maintaining overall parameter efficiency by keeping the two-qubit gate structure lean.
