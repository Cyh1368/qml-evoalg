<DESCRIPTION>
Insert a complementary shared-angle rotation layer between the antipodal CZ links and the local brickwork. Because CZ gates mutually commute, merely reordering the existing entanglers does not create a meaningfully different unitary. The intermediate RX/RY layer makes the global-first ordering operationally distinct, allowing antipodal correlations to be remixed before local propagation. All rotations reuse the existing parameter, preserving the single-distinct-parameter regularization that favors small-data generalization.
</DESCRIPTION>
