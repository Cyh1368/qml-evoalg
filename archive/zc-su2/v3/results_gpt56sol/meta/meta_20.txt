# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Two-parameter parity mixers with multi-scale CZ entanglement (nearest-neighbor brickwork, staggered links, antipodal long-range) deliver top performance.  Both the current best program (ANSATZ_SPEC above) and the Parity-Mixed CZ Brickwork Ansatz (Gen 17) achieved a combined score of 0.48 with train/val/test = 0.94/0.78/0.75 and a generalization gap of 0.19.  
- Minimal distinct parameters (n_distinct=2: “ry_even”/“ry_odd” over 8 qubits) yield high parameter efficiency (0.19) without sacrificing expressivity.  This pattern matches the Even-Odd RY Ansatz (Gen 6) and the current best program.  
- Depth-limited circuits (depth = 12, gate_count = 60) outperform deeper designs (depth ≈ 33–36).  The current best program’s 12-layer structure outscored Alternating RY + global RZ + CZ Mesh (Gen 12, score 0.44, gap 0.28) and other depth-33 circuits.  
- Omitting any RZ rotation layers reduces both depth and gate count.  The top designs (current best, Gen 6, Gen 17) exclude RZ gates entirely, whereas circuits with global RZ (Gen 12) underperform despite extra parameters.  

## Ineffective Approaches  
- Over-tying parameters leads to under-expressivity: the fourfold shared RY Ansatz with ring CZ links (Gen 20) scored only 0.39 (train/test ≈ 0.57–0.69), with low parameter efficiency (0.09) and modest margins.  
- Simply deepening the circuit without targeted connectivity hurts generalization: Gen 12’s depth = 33 design (Alternating RY + global RZ + CZ mesh) reached 0.44 but suffered a large gap (0.28).  
- Ansätze with unresolved code issues fail outright: the 8-Qubit Ring CRZ-CZ Ansatz (Gen 18) scored 0.0 due to diff markers and syntax errors, demonstrating that correctness is a prerequisite for performance.  
- Heavy sharing without multi-scale entanglement yields chance-level results: the Parity-Shared Ring and Antipodal Ansatz (Gen 23) scored 0.41 with uniform 50% accuracy, indicating that an inductive bias alone cannot replace expressivity.  

## Implementation Insights  
- Define ANSATZ_SPEC as an explicit list of gate dictionaries: first list all RY mixer entries per wire, then group CZ entries by connectivity scale.  E.g., the current best program’s 8 RY entries followed by 12 CZ entries.  
- Use a simple loop or inline conditional to assign parity parameters:  
    for i in range(N_QUBITS):  
        param = "ry_even" if i % 2 == 0 else "ry_odd"  
        ANSATZ_SPEC.append({"gate":"RY","wire":i,"param":param})  
- Structure CZ layers in blocks—nearest-neighbor brickwork, staggered nearest neighbors, and antipodal pairs—to distribute entanglement without adding parameters.  
- Forego single-qubit RZ rotations unless they demonstrably close an expressivity gap; removing RZ layers in top designs cut depth from ~33 to 12, boosting parameter efficiency and test accuracy.  

## Performance Analysis  
- Top combined scores (0.48) cluster around the parity-RY + multi-scale CZ pattern: current best program, Even-Odd RY Ansatz (Gen 6), and Parity-Mixed CZ Brickwork Ansatz (Gen 17).  
- Parameter efficiency (n_distinct_params/depth) tracks with score: 0.19 efficiency for top designs vs. 0.09–0.14 for lower-scoring circuits.  
- Generalization gaps are smallest (~0.19) for concise depth-12 designs; deeper circuits exhibit gaps of 0.28–0.37.  
- Gate counts around 60 yield peak performance; increasing gates and depth beyond this point (e.g., 84–108 gates, depth > 30) correlates with overfitting and score degradation.
