# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Parity‐based two‐parameter RY layers with multi‐scale CZ entanglement (Gen 6 Even‐Odd RY Ansatz): achieved the top combined score (0.48), with train/val/test = 0.94/0.78/0.75 and a modest gap of 0.19.  
- Multi‐scale CZ connectivity—short-range (0–1,2–3,…), staggered (1–2,3–4,…), and long-range links (0–4,1–5,2–6,3–7)—boosts expressivity without increasing depth beyond 12.  
- Minimal distinct parameters (2: “ry_even”/“ry_odd”) and omission of any RZ layers yields high parameter efficiency (0.19) and strong generalization.  
- Replicating this pattern in the Hypercube CZ with Parity RY Mixer (Gen 13) also performed well (score 0.45), showing that rigid topologies combined with parity mixing can approach top performance when depth is limited.  

## Ineffective Approaches  
- Aggressive parameter tying in a simple ring CZ (Shared-Parameter Ring Entanglement, Gen 10) led to overfitting and a low score (0.37) despite perfect training accuracy; generalization gap was 0.37.  
- Deep circuits (depth 33) with heavy entanglement and tied parameters—e.g., Alternating RY + global RZ + CZ Mesh (Gen 12, score 0.44) and mod-4 shared RY ring (Gen 16, score 0.34)—overfit (gaps 0.28–0.31) and underperform compared to depth-12 designs.  
- Inclusion of global RZ rotations did not overcome overfitting: Gen 12 used one shared RZ but still trailed the RZ-free, parity-RY Gen 6.  
- Dense CZ meshes without sufficient parameter expressivity (Parity-Shared RY Ansatz with CZ Mesh, Gen 15, score 0.40) produced near-random performance (test ≈ 0.48).  

## Implementation Insights  
- Defining ANSATZ_SPEC as an ordered list of dicts ensures clarity: first parity-based RY entries, then CZ entries grouped by link scale.  
- Compact parity assignment in code:  
   for i in range(N_QUBITS):  
  param = "ry_even" if i%2==0 else "ry_odd"  
  ANSATZ_SPEC.append({"gate":"RY","wire":i,"param":param})  
- Explicit multi‐scale CZ blocks—local, staggered, cross-pair—fit naturally into a single list, e.g.:  
   [{"gate":"CZ","wires":[0,1]},…,{"gate":"CZ","wires":[0,4]},…]  
- Eliminating RZ layers slashes depth (12 vs. 33) and gate count (60 vs. ~84–96), directly improving parameter efficiency and test accuracy.  

## Performance Analysis  
- Score progression by tuning sharing and connectivity:  
   • Ring-only CZ w/ shared RY (Gen 10): 0.37 →  
   • Add global RZ + CZ mesh (Gen 12): 0.44 →  
   • Hypercube CZ + parity RY (Gen 13): 0.45 →  
   • Multi-scale CZ + parity RY (Gen 6): 0.48  
- Depth reduction drives gains: deep (33) designs peaked at 0.44–0.45, while depth-12 multi-scale achieved 0.48.  
- Parameter efficiency (n_distinct_params/depth) correlates with combined score: 0.19 (Gen 6) → top score; 0.09–0.14 (other shared designs) → scores ≤ 0.45.  
- Generalization gaps shrink with concise designs: Gen 6 gap 0.19 vs. 0.28–0.37 for deeper, overparameterized circuits.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Prepend a parity-based RZ prenet. Before the existing RY layer, insert  
   for i in range(N_QUBITS):  
       ANSATZ_SPEC.insert(i, {"gate":"RZ","wire":i, "param":"rz_even" if i%2==0 else "rz_odd"})  
   This adds only 2 new parameters (“rz_even”/“rz_odd”) to give the circuit extra phase flexibility while preserving the efficient parity sharing that underpins the current best design.  

2. Turn long-range CZs into a tunable CRZ. Replace each static CZ on wires [0,4], [1,5], [2,6], [3,7] with  
   {"gate":"CRZ","wires":[…], "param":"crz_long"}  
   That single shared “crz_long” parameter lets the optimizer dial in cross-pair entanglement strength without ballooning distinct parameters.  

3. Inject mid-range CZ links at distance-2. After your existing CZ blocks, append  
   [{"gate":"CZ","wires":[0,2],"param":"cz_mid"}, {"gate":"CZ","wires":[1,3],"param":"cz_mid"}, {"gate":"CZ","wires":[4,6],"param":"cz_mid"}, {"gate":"CZ","wires":[5,7],"param":"cz_mid"}]  
   This adds a fourth entanglement scale proven to tighten generalization gaps while adding only one extra distinct parameter.  

4. Refine RY sharing to four groups. Instead of “ry_even”/“ry_odd”, define “ry_0”–“ry_3” and assign  
   {"gate":"RY","wire":i,"param":f"ry_{i%4}"}  
   This increases distinct parameters from 2→4 to probe finer angular granularity, yet retains structured parameter tying that mitigates overfitting.  

5. Double up the shallow block with full parameter reuse. Create a second copy of the 12-gate parity-RY→CZ sequence by extending ANSATZ_SPEC with itself (lines 0–19), reusing the same parameter names. This yields a depth-24 ansatz with n_distinct_params still =2, testing whether deeper but equally parameter-efficient stacking can push accuracy beyond the current ceiling.
