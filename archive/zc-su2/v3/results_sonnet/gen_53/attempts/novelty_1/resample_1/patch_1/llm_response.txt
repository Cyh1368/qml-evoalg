<NAME>
ising_parity_ansatz

<DESCRIPTION>
A fundamentally different entangling strategy: instead of fixed CNOT chains combined with local rotations, this ansatz relies entirely on continuous, physically-motivated ZZ Ising couplings for entanglement, interleaved with parity-broken single-qubit rotations. The key idea is that CNOT-based entanglers are "all-or-nothing" (either fully applied or not), which can make the optimization landscape brittle and prone to overfitting on tiny training sets. ZZ(θ) gates instead provide a continuously tunable entangling strength that can be dialed to exactly the amount of correlation needed for the hardest/worst-case validation group, which should improve worst-group margin and reduce the train/validation gap.

Structure:
1. Parity-broken RY layer: RY(ry_a) on even qubits, RY(ry_b) on odd qubits — breaks the leading-order symmetry so information from different feature subsets is encoded distinctly, using only 2 parameters.
2. A shared ring of ZZ(zz_g) Ising couplings across nearest-neighbor pairs on all 8 qubits — cheap, local entangling structure with a single shared coupling strength.
3. A single shared RZ(rz_c) rotation on all qubits — a global phase-mixing operation with 1 parameter.
4. A shared long-range ZZ(zz_h) coupling layer connecting qubits 4 apart (0-4,1-5,2-6,3-7) — creates long-range correlations necessary for global features, again just 1 parameter.
5. Final shared RY(ry_d) on all qubits — a single closing readout-rotation parameter.

Total: only 6 distinct trainable parameters, no CNOT/CRZ combinatorial layers, and every entangling operation is a smoothly tunable Ising coupling. This should generalize better from a small training set because the entangling strength itself is learned rather than being a fixed discrete operation, giving the optimizer more direct control over how much correlation is injected for the hardest examples.
