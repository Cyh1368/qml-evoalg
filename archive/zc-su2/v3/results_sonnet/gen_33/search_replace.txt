dual_generator_entangler_shared_param

<DESCRIPTION>
The current ansatz uses a single CRZ ring (phase-type entangler) shared under the parameter "ent". Drawing on the insight from the first seed program that pairing a phase-type generator (CRZ) with an amplitude-type generator (CRX) under the SAME shared parameter substantially boosts expressivity-per-parameter without adding any new trainable parameters, I add a second ring of CRX gates on the same qubit pairs, reusing the "ent" parameter. This keeps n_distinct_params at 3 (no cost increase) while giving the entangling layer two independent rotation generators driven by one angle, which should improve separation on hard validation groups (worst-group margin) and robustness, since the circuit can now express both amplitude and phase correlations from a single scalar without extra parameter overhead.
</DESCRIPTION>
