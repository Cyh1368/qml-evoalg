# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Global shared rotations + cheap two-qubit entangler:  
  • The current best ansatz (score 0.41) uses five distinct, globally shared parameters—RX(a), RY(b), RZ(c), CRZ(d), RY(e)—across all 8 qubits. This matches the “Shared-rotation entangling-ring” pattern and yields a tiny generalization gap (0.03) compared to >0.16 in other designs.  
- Dual-ring CNOT connectivity with offset layer:  
  • Two fixed CNOT rings (8-gate ring plus a 4-gate offset ring on [1–2,3–4,5–6,7–0]) in the best program double connectivity without extra parameters, pushing validation accuracy to 0.58. Earlier single-ring or linear chain designs (Alternating RY-CNOT-RZ, score 0.38) had larger gaps (0.20).  
- Disjoint-pair shared CRZ entanglers for expressivity at low cost:  
  • Four CRZ(d) gates on disjoint pairs in the top program inject non-Clifford entanglement with only one extra parameter. Compared to fixed CZ rings (Parity-Shared Ring Entangler, score 0.34, gap 0.27), this yields better train/validation balance.  
- Increased depth under parameter constraints:  
  • The best circuit depth (42) is higher than many under-performing shallow variants (e.g., Even-Odd RY with Shared CRZ, depth 45, score 0.37), allowing richer state exploration while keeping only five distinct parameters.

## Ineffective Approaches  
- Linear or simple CNOT chains without diverse entanglers:  
  • The Alternating RY-CNOT-RZ ansatz (score 0.38) used forward/reverse chains but only five parameters and no parametrized two-qubit gates, yielding underfitting (val 0.63 → test 0.61) and a 0.20 gap.  
- Over-shared parameters with insufficient connectivity:  
  • Shared-Parameter Ring Entangler variants (Gen 7 score 0.39, gap 0.17; Gen 9 score 0.36, gap 0.16) kept only 3–5 parameters but relied on fixed long-range CNOT patterns. They underfit validation (0.56–0.53) despite heavy sharing.  
- Single-layer or parity-restricted entanglement:  
  • Parity-Shared Ring Entangler (score 0.34) and Even-Odd RY with Shared CRZ (score 0.37) reused minimal parameters in parity schemes, leading to overfitting (gaps 0.19–0.27) or narrow decision margins (worst-group margin 0.01).  
- Excessive gate count without parameter diversity:  
  • Designs with very high gate counts (e.g., 162 gates in Gen 7) but only 5 distinct parameters failed to improve accuracy over the compact 144-gate best program, showing that more gates alone don’t compensate for low expressivity.

## Implementation Insights  
- Explicit per-wire shared rotation declarations:  
  • Although verbose, listing RX(a), RY(b), RZ(c), RY(e) on each wire in ANSATZ_SPEC ensures correct global sharing. This pattern is central to the top-scoring program.  
- Staggered entangler layers via manual wire lists:  
  • Hard-coding two CNOT rings—first around [0→1→…→7→0], then offset on [1–2,3–4,5–6,7–0]—maximizes qubit mixing. The split into 8 and 4 gates keeps depth moderate (42).  
- Disjoint parametrized two-qubit gates for low-overhead expressivity:  
  • Placing four CRZ(d) gates on non-overlapping qubit pairs injects parameterized entanglement without inflating circuit depth or gate count excessively.  
- Balance of depth and parameter count:  
  • The best ansatz’s 42 layers (rotations + entanglers) strike the right trade-off: deep enough for expressivity, yet limited to five distinct parameters to prevent overfitting.

## Performance Analysis  
- Combined score trend:  
  • From Parity-Shared Ring (0.34) → Alternating RY-CNOT-RZ (0.38) → Shared-Parameter Ring (0.39) → Best program (0.41). Each step added richer entanglement or cheap parametrized gates.  
- Generalization gap reduction:  
  • Gaps fell from 0.27 (Parity-Shared) → 0.20 (Alternating RY-CNOT-RZ) → 0.17 (Shared-Parameter Ring) → 0.03 (best program) as circuits combined parameter sharing with diverse entanglers.  
- Validation accuracy vs. depth:  
  • Best validation accuracy (0.58 at depth 42) surpassed shallower (45–54) and deeper (63) variants, suggesting an optimal depth window for this task.  
- Parameter efficiency steady around 0.07–0.09:  
  • Despite varying gate counts (96–162) and depths, efficiency (n_params/gate_count) remained low. The top design leveraged this by focusing on parameter quality (global sharing + CRZ) over sheer parameter quantity.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Duplicate the entire shared‐rotation + entangler block to double circuit depth under the same five parameters {a,b,c,d,e}. Concretely, append a second instance of  
   – RX(a)→RY(b)→CNOT ring→RZ(c)→CRZ(d)→offset CNOT ring→RY(e)  
   using identical “a,b,c,d,e” symbols. Evidence: the best program leveraged a 42‐layer depth to maximize expressivity; doubling this without new parameters tests if deeper coverage further boosts validation accuracy without overfitting.  
2. Introduce a second cheap parametrized two‐qubit layer via CRX on the same disjoint pairs, sharing a new parameter “f.” For example, after the offset CNOT ring insert:  
   – CRX(f) on [0,1], [2,3], [4,5], [6,7].  
   Rationale: augmenting phase entanglement (CRZ) with rotation‐axis entanglement (CRX) has high expressivity per parameter and should reduce generalization gap further.  
3. Prepend a global Ising‐type ZZ entangler layer across opposite‐qubit pairs using one shared parameter “g.” For instance, at the very top add:  
   – ZZ(g) on wires [0,4], [1,5], [2,6], [3,7].  
   This long‐range disjoint entanglement cheaply seeds global correlations before the RX(a) block, building on evidence that parameterized two‐qubit gates on disjoint pairs improve train/validation balance.  
4. Refine the CRZ entangler granularity by splitting “d” into two shared parameters “d1” and “d2.” Use CRZ(d1) on pairs [0,1] & [4,5] and CRZ(d2) on [2,3] & [6,7]. This raises n_distinct_params to 6, allowing nuanced phase entanglement across the circuit while still keeping parameter count low, to test if finer‐grained sharing outperforms a single global CRZ.  
5. Replace the second fixed offset CNOT ring with a “skip‐2” ring to boost non‐nearest‐neighbor mixing. Specifically swap the offset layer for fixed CNOTs on [0→2],[2→4],[4→6],[6→0] and [1→3],[3→5],[5→7],[7→1]. Evidence: richer entangling topologies drove successive score improvements, and a skip‐2 pattern may further enhance mixing without adding parameters.
