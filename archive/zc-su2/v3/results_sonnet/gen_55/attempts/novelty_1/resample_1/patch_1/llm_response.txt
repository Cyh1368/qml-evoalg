add_crx_amplitude_mixing

<DESCRIPTION>
The current ansatz uses CRZ for entanglement, which is diagonal in the computational basis and only imparts phase information—amplitude (probability) mixing between the entangled pair comes solely from the surrounding CNOT layers. Adding a parallel CRX layer sharing a single new parameter right after the existing CRZ block introduces genuine amplitude mixing conditioned on the control qubit, complementing the phase-only CRZ gates. This increases expressivity in a targeted, low-cost way (+1 parameter, +4 gates, +1 depth) which should help separate harder groups without significantly increasing overfitting risk, since it's a single shared parameter reused across 4 disjoint pairs (same pattern as the existing "ent" CRZ layer that already generalizes reasonably well, per validation_margin_mean 0.20).
