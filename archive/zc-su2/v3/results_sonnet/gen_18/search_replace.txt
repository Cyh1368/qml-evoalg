<DESCRIPTION>
The current spec uses 8 independent RY parameters (one per qubit) plus a single shared CRZ entangling parameter, yielding 11 distinct parameters and severe overfitting (train 0.94 vs val 0.72, gap 0.24). The two higher-scoring seed programs both used far fewer distinct parameters (4-5) with aggressive sharing of single-qubit rotations across all qubits, which generalized better and scored higher (0.39-0.41) despite lower train accuracy.

This edit (1) collapses the 8 per-qubit RY parameters into a single shared "ry0" parameter (mirroring the successful seed-1 pattern), drastically cutting parameter count and combating overfitting, and (2) splits the single shared "ent" CRZ parameter into two parameters ("ent1" for even-indexed edges, "ent2" for odd-indexed edges) to retain some entangling expressivity/granularity at low added cost, similar to the recommended CRZ granularity refinement. Net distinct parameter count drops from 11 to 5, matching the best-performing seed's parameter budget while keeping the RZ pre/post structure intact for phase flexibility.
</DESCRIPTION>
