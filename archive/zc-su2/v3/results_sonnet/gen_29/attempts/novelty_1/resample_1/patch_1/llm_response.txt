merge_shared_params_reduce_count

<DESCRIPTION>
Following the principle that fewer distinct trainable parameters strictly improves the score, this edit collapses the two alternating entangling parameters ("ent1"/"ent2") into a single shared parameter "ent", and collapses the pre- and post-entangling RZ layers ("rz_pre"/"rz_post") into a single shared parameter "rz". This reduces the distinct parameter count from 5 to 3 while keeping the same gate structure, depth, and connectivity (RY ring, RZ layers, CRZ ring, skip-2 CNOT mixing, RZ layer), which previously already generalized well (near-zero gap). Sharing the RZ pre/post parameters imposes a symmetry constraint that acts as a regularizer, and sharing the CRZ ring parameter across all 7 ring edges gives a single global entangling strength, both of which should reduce overfitting risk on the small training set while preserving expressivity through the fixed skip-2 CNOT mixing layer.
</DESCRIPTION>
