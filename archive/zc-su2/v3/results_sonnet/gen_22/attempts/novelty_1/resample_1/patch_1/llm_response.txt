zz_seeded_ring_entangler

<DESCRIPTION>
Redesigned the ansatz to open with a long-range, parameter-shared ZZ entangling layer across antipodal qubit pairs ([0,4],[1,5],[2,6],[3,7]) before any single-qubit rotations, seeding global correlations early as recommended. Following this, a shared two-axis single-qubit rotation (RX then RY, same parameter) locally reshapes each qubit's state, then a fixed CNOT backbone chain spreads local entanglement, followed by a shared-parameter CRZ ring (including the wrap-around edge) for uniform, order-independent coupling. Finally, a shared RY layer (reusing the same parameter as the opening ZZ layer, at zero extra parameter cost) mixes amplitudes before readout. This structure keeps only 3 distinct trainable parameter names (down from previous designs' 4-5), while combining long-range, local, and ring entanglement patterns intended to boost worst-group margin and reduce the train-test gap, in line with the parameter-economy and robust-separation priorities.

```python
"""Seed program. Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved.

Everything else about the task, that is how inputs are encoded, how the circuit
is measured, how training works and how metrics are computed, is fixed and lives
in a module that is not reproduced here. No information about the data is
available in this file.
"""

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}
ALLOWED_ISING_GATES = {"XX", "YY", "ZZ"}


# EVOLVE-BLOCK-START
ANSATZ_SPEC = []

# --- Stage 0: long-range entanglement seed ---------------------------------
# A single shared parameter "a" drives a disjoint ZZ layer between antipodal
# qubit pairs. This gives the circuit global correlations *before* any local
# rotations are applied, so subsequent local structure operates on an
# already-entangled state rather than having to build long-range structure
# itself. Using one shared parameter keeps the cost at zero extra params.
_ANTIPODAL_PAIRS = [(0, 4), (1, 5), (2, 6), (3, 7)]
for _q1, _q2 in _ANTIPODAL_PAIRS:
    ANSATZ_SPEC.append({"gate": "ZZ", "wires": [_q1, _q2], "param": "a"})

# --- Stage 1: shared two-axis single-qubit rotation -------------------------
# Same scalar parameter "b" reused for both RX and RY on every qubit. This
# gives each qubit a richer local unitary (rotation about two axes) without
# increasing the parameter count.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RX", "wire": _i, "param": "b"})
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": _i, "param": "b"})

# --- Stage 2: fixed local entangling backbone -------------------------------
# Parameter-free nearest-neighbor CNOT chain to spread the local rotation
# information across the register.
for _i in range(N_QUBITS - 1):
    ANSATZ_SPEC.append({"gate": "CNOT", "wires": [_i, _i + 1]})

# --- Stage 3: parametrized ring entangler -----------------------------------
# Shared parameter "c" drives a full ring of CRZ gates (including the
# wrap-around edge 7->0), giving uniform, order-independent entangling
# strength around the whole register.
for _i in range(N_QUBITS):
    _j = (_i + 1) % N_QUBITS
    ANSATZ_SPEC.append({"gate": "CRZ", "wires": [_i, _j], "param": "c"})

# --- Stage 4: final shared rotation, reusing "a" ----------------------------
# Reusing the same parameter as the opening ZZ layer costs nothing extra and
# lets the trained value serve a dual role: seeding long-range entanglement
# early and reshaping local amplitudes right before readout.
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": _i, "param": "a"})
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
```
