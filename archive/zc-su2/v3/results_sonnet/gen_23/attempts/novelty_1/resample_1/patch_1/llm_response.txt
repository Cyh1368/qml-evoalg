zz_preamble_dual_generator_ring

<DESCRIPTION>
Restructured the ansatz into four clearly modular stages to seed long-range correlations before local processing, matching the recommendation to prepend a global ZZ entangling layer on opposite-qubit pairs. Stage 1 applies a single shared-parameter ZZ(g) layer on the four "antipodal" pairs [0,4],[1,5],[2,6],[3,7], establishing long-range entanglement structure before any local rotation touches the state. Stage 2 applies a shared two-axis rotation (RX then RY, same parameter "a") on every qubit, giving a richer single-qubit unitary at no extra parameter cost. Stage 3 is a fixed parameter-free nearest-neighbor CNOT chain (forward direction) to spread the antipodal correlations locally. Stage 4 is a dual-generator ring entangler (CRZ ring followed by CRX ring, sharing parameter "b") that mixes phase and amplitude information around the full ring including the wrap-around edge. A final shared RY(c) rotation prepares the state for readout. This keeps the distinct trainable parameter count minimal (only 4: g, a, b, c) while combining long-range pre-entanglement, two-axis local rotations, and dual-generator ring mixing—structural ingredients that individually improved margin or reduced train/validation gap in prior runs—into one coherent, low-parameter design intended to boost worst-group margin and generalization simultaneously.

"""Seed program. Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved.

Everything else about the task, that is how inputs are encoded, how the circuit
is measured, how training works and how metrics are computed, is fixed and lives
in a module that is not reproduced here. No information about the data is
available in this file.
"""

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}
ALLOWED_ISING_GATES = {"XX", "YY", "ZZ"}


# EVOLVE-BLOCK-START
ANSATZ_SPEC = []

# ---------------------------------------------------------------------------
# Stage 1: Global long-range entangling preamble.
# A single shared parameter "g" drives ZZ interactions across the four
# antipodal (opposite) qubit pairs. This seeds long-range correlations
# across the register *before* any local rotation is applied, so the
# subsequent local processing acts on an already globally-correlated
# state. Costs only 1 trainable parameter.
# ---------------------------------------------------------------------------
_ANTIPODAL_PAIRS = [(0, 4), (1, 5), (2, 6), (3, 7)]
for _a, _b in _ANTIPODAL_PAIRS:
    ANSATZ_SPEC.append({"gate": "ZZ", "wires": [_a, _b], "param": "g"})

# ---------------------------------------------------------------------------
# Stage 2: Shared two-axis local rotation.
# RX and RY on every qubit reuse the SAME parameter "a", producing a richer
# effective single-qubit unitary than either rotation alone, without any
# extra parameter cost.
# ---------------------------------------------------------------------------
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RX", "wire": _i, "param": "a"})
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": _i, "param": "a"})

# ---------------------------------------------------------------------------
# Stage 3: Fixed (parameter-free) nearest-neighbor entangling chain.
# Spreads the antipodal correlations seeded in Stage 1 locally across the
# chain, at zero parameter cost.
# ---------------------------------------------------------------------------
for _i in range(N_QUBITS - 1):
    ANSATZ_SPEC.append({"gate": "CNOT", "wires": [_i, _i + 1]})

# ---------------------------------------------------------------------------
# Stage 4: Dual-generator ring entangler.
# A full ring of CRZ gates (phase-type generator) followed by a full ring of
# CRX gates (amplitude-type generator), both sharing the SAME parameter
# "b". This increases expressivity-per-parameter substantially without
# growing the parameter count, and includes the wrap-around edge (7 -> 0)
# for full-ring connectivity.
# ---------------------------------------------------------------------------
for _i in range(N_QUBITS):
    _j = (_i + 1) % N_QUBITS
    ANSATZ_SPEC.append({"gate": "CRZ", "wires": [_i, _j], "param": "b"})
for _i in range(N_QUBITS):
    _j = (_i + 1) % N_QUBITS
    ANSATZ_SPEC.append({"gate": "CRX", "wires": [_i, _j], "param": "b"})

# ---------------------------------------------------------------------------
# Stage 5: Final shared rotation before readout.
# ---------------------------------------------------------------------------
for _i in range(N_QUBITS):
    ANSATZ_SPEC.append({"gate": "RY", "wire": _i, "param": "c"})
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
