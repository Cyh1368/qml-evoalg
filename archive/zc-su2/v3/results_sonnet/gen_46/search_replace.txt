<DESCRIPTION>
The final global RY(ry_c) layer currently applies the same shared parameter to all 8 qubits, collapsing the even/odd sub-lattice information created by the preceding entangling layers into a single symmetric rotation. Since the best-performing prior variant benefited from parity-differentiated rotations (ry_a/ry_b, rz_a/rz_b), we apply the same principle to the final readout rotation: split it into ry_c_even (qubits 0,2,4,6) and ry_c_odd (qubits 1,3,5,7). This adds only one extra distinct parameter (4→5... actually current has 4 distinct, this makes 5) while allowing the classifier to set independent decision thresholds for the two parity classes that were entangled asymmetrically by the skip-2 CNOT rings (which only connect same-parity qubits). This should improve worst-group margin without meaningfully hurting parameter economy or generalization.
</DESCRIPTION>
