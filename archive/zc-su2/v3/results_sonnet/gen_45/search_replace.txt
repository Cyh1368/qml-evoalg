phase_entangling_rings_shared_h

<DESCRIPTION>
The current low-parameter ansatz (3 distinct params) achieves a low score (0.39) despite fewer parameters, largely because the fixed CNOT rings provide no trainable phase structure and the model under-fits the harder validation groups. The best-performing prior variant (0.42) used more distinct parameters but had a stronger entangling structure. To recover expressive entangling capability while keeping the parameter count as low as possible, we replace both fixed CNOT rings with parameterized CRZ ("controlled phase") gates on the same wire connectivity, sharing a single new parameter "h" across all of them. This turns the previously untrainable entangling rings into a single extra trainable phase parameter, giving the optimizer a lever to tune inter-qubit correlation strength without adding coherent bit-flip noise sensitivity from CNOTs, and only costs 1 extra distinct parameter (4 total), which should still register as parameter-efficient while substantially improving worst-group margin and generalization.
</DESCRIPTION>
