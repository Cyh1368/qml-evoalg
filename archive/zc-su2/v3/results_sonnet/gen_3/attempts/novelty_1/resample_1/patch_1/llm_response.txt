param_efficient_shared_ansatz

<DESCRIPTION>
The original ansatz used 24 distinct trainable parameters (one independent
rotation per qubit for RY, RZ-pre and RZ-post), which is expensive in
parameter count and clearly overfits: train accuracy 0.88 vs validation 0.63
(gap 0.31), and the worst-group margin is tiny (0.03), meaning the classifier
barely separates the hardest samples.

Since parameter economy is scored aggressively (fewer distinct parameter
names always scores higher, with no diminishing returns) and the training set
is tiny (so overfitting to per-qubit idiosyncrasies hurts held-out
performance), the redesign aggressively shares parameters across qubits while
keeping enough structural expressivity via fixed entangling gates and
repeated application of the block (the harness applies the same ansatz
multiple times with the same parameters, so depth/expressivity still grows
even though the parameter count stays low).

New design (5 distinct parameters total):
1. RX(a) applied to every qubit — one shared global parameter, acts as a
   coarse global rotation of the input-encoded state.
2. RY(b) applied to every qubit — second global rotation, orthogonal axis.
3. A fixed CNOT ring across all 8 qubits (no parameters) to entangle
   neighboring qubits and mix information for correlation-based features.
4. RZ(c) applied to every qubit — third shared global parameter, breaks
   any remaining symmetry along phase axis.
5. CRZ(d) on two disjoint sets of neighboring pairs (0,1),(2,3),(4,5),(6,7)
   sharing one parameter "d" — cheap parametrized entangling structure that
   lets pairs communicate a tunable amount without blowing up parameter count.
6. A second fixed CNOT ring (offset) further mixes qubits so information
   from the CRZ step spreads.
7. Final RY(e) applied to every qubit — a last shared rotation before
   readout, giving the circuit one more degree of freedom to shape the
   output distribution.

This yields only 5 distinct trainable parameters, drastically reducing
parameter count from 24, which should substantially improve parameter
efficiency, generalization gap and stability across repeated applications of
the block, while the fixed entangling gates preserve enough expressive power
to separate difficult samples (helped by the fact that ansatz is applied
multiple times with the SAME shared parameters, effectively deepening the
circuit without adding trainable degrees of freedom).
