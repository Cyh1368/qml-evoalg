add_shared_entangling_crz

<DESCRIPTION>
The current candidate has no parametrized two-qubit gate at all, which the prior two seed variants (both of which scored higher, 0.40-0.41) did have via a single shared CRZ entangling layer across disjoint pairs. Adding a light-weight, single-shared-parameter CRZ layer between the two CNOT rings introduces genuine entangling non-Clifford correlations (needed to separate hard groups) while adding only one extra distinct trainable parameter (6 total, matching the best-performing seed's parameter count). This should improve worst-group margin and reduce the current large train/val gap by giving the circuit a cheap way to encode pairwise correlations instead of relying purely on the alternating RY/RZ + CNOT-ring structure that appears to be overfitting (train 0.81 vs val 0.63).

</DESCRIPTION>
