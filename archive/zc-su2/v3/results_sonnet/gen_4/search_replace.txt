reduce_params_shared_entangling_ansatz

<DESCRIPTION>
The current ansatz uses 24 distinct trainable parameters (one RY + two RZ per qubit, all independent), which likely overfits on the small training set (train acc 0.88 vs val/test acc 0.63/0.56 — a large generalization gap) and is penalized heavily for parameter count.

I propose a redesign that drastically cuts the parameter count via aggressive weight-sharing across qubits (even/odd grouping), while still providing multi-layer entanglement (a forward CNOT chain then a backward CNOT chain) to preserve expressivity for correlating information across all 8 qubits. This uses only 5 distinct parameters total (down from 24), which should:
1. Directly boost parameter_efficiency score component.
2. Reduce the train-test generalization gap by strongly constraining the hypothesis class (parameter sharing acts as a powerful inductive-bias regularizer, well-suited to very small training sets).
3. Preserve entangling structure (bidirectional CNOT chains) so the circuit can still build up correlated features across qubits despite fewer free parameters.

This aligns with the stated scoring priorities: fewer distinct params always scores higher, and reducing the train-test gap is rewarded.
</DESCRIPTION>
