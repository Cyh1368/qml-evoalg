# Rewind Experiment Design

- Search space problem: rewind to just before a discovery, then run forward only 1–2 steps, 10–20 times
  - No need to remove the model that originally made the discovery; the whole process is probabilistic
  - Outcome: observed probability and std dev for each model to make that discovery at that stage
- Sharp jumps or discontinuities (≥20% of max score) in the historical best-score graph trigger a rewind analysis
- Rewind removes the compounding advantage of frontier models, giving weaker models the same starting conditions
  - Proposed test: cut a frontier run just before a discovery, then run all three ensembles forward to see if weaker models can recreate it
  - Reveals whether the cutoff is a hard capability gate or a probabilistic difference
- Frontier model advantage compounds step over step; weaker models propagate noise into subsequent nodes
  - Tree width expands exponentially in the binary symmetric case, diluting signal-to-noise for weaker models
  - Also a function of round-robin heuristics, node selection, and tree depth: harder tasks likely widen the frontier lead further

# Classifying Progress vs. Mistakes

- Evolution accumulates both progress and mistakes; these compound over long runs
- Score alone is insufficient: a failed run (score 0) could still have identified the correct symmetry
  - A node can start from a correct insight but fail due to a minor coding error
  - Binary progress/mistake classification is too coarse; multiple things change per node
- Two verification approaches:
  - Stated symmetry: regex search on patch notes (good baseline); could also prompt the ensemble to explicitly list symmetries identified
  - Implemented symmetry: symbolic check on the resulting circuit
- Possible multi-level labeling per node:
  1. Implemented some symmetry
  2. Implemented symmetry across all 8 qubits
  3. Achieved full S8-invariant symmetry
- Two experimental paths going forward:
  1. Controlled rewind experiment
  2. Observe model behavior over long runs (but setups are not directly comparable: different rewind points yield different histories)
