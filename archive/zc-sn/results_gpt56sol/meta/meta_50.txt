# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Three‐layer QAOA‐style entanglement plus final parity‐shared RX mixer  
  • Generation 37 (“final_rx_mixer”, Combined 0.89) stacked even‐bond CZ, odd‐bond CZ, full‐chain CZ, each sandwiched by parity‐tied RZ layers, then ended with an RX mixer (“rx_final_even/odd”).  
  • This 3-entangler + mixer motif lifted the combined score from ~0.87 (e.g. Generation 45 at 0.86) to 0.89 without overfitting (gap = 0.05).  
- Consistent even/odd parameter sharing across all phases and mixer  
  • Parity‐shared RZ layers (“rz_even_pre/post_*”, “rz_odd_pre/post_*”, “rz2_pre/post_*”) balanced expressivity and kept n_params at 134 (efficiency = 0.01).  
  • The same pattern for “rx_final_even/odd” transformed learned phases into populations more effectively than fully independent RX (e.g. Generation 39 lacked it, Combined 0.87).  
- Hardware-native gate set with clear block structure  
  • Restricting to RY/RZ/CZ/RX and using an explicit ANSATZ_SPEC block enabled the compiler to optimize repeated patterns, yielding zero metric variance (std = 0.00).  
  • The clear sequence of RY → (RZ–CZ–RZ)×3 → RX converged in ~540 steps, comparable to or faster than shallower designs (e.g. Brickwork converged in ~390 steps but scored 0.86).  

## Ineffective Approaches  
- Over-entangling without a noncommuting mixer  
  • Layered two-block CZ sandwiches (e.g. Generation 43 “mirror_tied_phase_chain”, depth 132, gates 408) plateaued at 0.87 and lacked the RX final mixer.  
  • Purely dual CZ matchings (e.g. “dual_phase_chain”, 0.77) underperformed despite high depth (123) and gate count (408).  
- Long-range or chord entanglement patterns  
  • Generation 38’s over-dense chords (390 gates, depth 129) dropped to 0.77 combined, showing that more connectivity alone harms noise resilience.  
- Excessive per-qubit post-entanglement RZ layers  
  • Brickwork and Ring CZ variants achieved only 0.86 with 105–120 depth and ~276–312 gates but did not match the 0.89 peak, indicating diminishing returns from extra single-qubit phases without a final mixer.  

## Implementation Insights  
- ANSATZ_SPEC block with descriptive, suffix-based names  
  • Using names like “rz_even_pre_even” and “rx_final_odd” makes parity‐sharing explicit and reduces binding/debug errors.  
  • The single-block specification helps backends collapse identical gates, keeping the gate count tractable even at depth 159.  
- Parity-tied parameters ensure balanced capacity  
  • Even/odd tying halves independent parameters per layer, preserving parameter efficiency (0.01) while retaining layer‐wise flexibility.  
- Final noncommuting mixer unlocks phase-to-population conversion  
  • The “RX” mixer with parity-shared parameters concludes the ansatz effectively, as seen by the jump to 0.89 combined, compared to similar designs without it.  

## Performance Analysis  
- Combined score uplift tied to 3-block CZ + RX mixer  
  • Generation 37’s 0.89 vs. Generation 45’s 0.86 and earlier seeds’ ≤ 0.87 confirms the third entangler block plus final RX mixer is the critical differentiator.  
- Depth and gate-count trade-off remains favorable  
  • Though depth increased to 159 and gates to 558, convergence (540 steps) stayed competitive with shallower circuits (e.g. ring entangled at 510 steps).  
- Stable generalization and zero variance  
  • Train/validation/test accuracies of 0.93/0.93/0.88 with std = 0.00 reflect both expressivity and robust training, outperforming all other 0.86–0.87-level ansätze.  
- Parameter efficiency plateau  
  • Top performers all exhibit efficiency ≈ 0.01, indicating that layering strategy—not parameter count—drives gains beyond the 0.86 threshold.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Insert a secondary mid‐circuit parity-shared RY mixer between the second and third CZ-sandwich blocks.  Immediately after the `rz_odd_post_even/odd` gates and before the `rz2_pre_even/odd` layer, add  
    • RY(ry_mid_even) on qubits 0,2,4,6 and RY(ry_mid_odd) on 1,3,5,7.  
   Evidence: the p=2 style interleaving of non-commuting mixers (RX) boosted nonlinearity; testing an orthogonal mixer axis (RY) may further enrich the reachable state manifold and speed convergence.  

2. Replace the entire second CZ entangler block with parameterized CRZ gates (parity-shared) instead of hard CZs.  Concretely, swap each `{"gate":"CZ","wires":[i,j]}` in the odd‐bond section for  
    • `{"gate":"CRZ","wires":[i,j],"param":"crz_odd"`} on (1–2,3–4,5–6,7–0), using two shared parameters `crz_odd_even` (for even-indexed edges) and `crz_odd_odd`.  
   Evidence: commuting CRZs can enrich entangling phases at zero extra depth and builds on Gen 28’s success sharpening correlations with CRZ.  

3. Augment the ansatz with a sparse next-nearest-neighbor CZ layer after the first CZ sandwich.  After the existing even-bond pre/post RZs and CZs, insert CZ gates on pairs (0,2),(1,3),(2,4),(3,5),(4,6),(5,7) with no additional single-qubit phases.  
   Evidence: a low-density “diagonal” entangler may capture medium-range correlations without the over-dense chords that Gen 38 showed to be harmful.  

4. Tie the pre-phase RZ parameters across all three entangler blocks into a single shared pair, and likewise tie all post-phase RZs.  That is, set  
    • `rz_even_pre_even = rz_odd_pre_even = rz2_pre_even = rz_pre_even` (and similarly for the odd indices), and  
    • `rz_even_post_even = rz_odd_post_even = rz2_post_even = rz_post_even`, etc.  
   Evidence: the top performers plateau at efficiency ≈0.01; further parameter sharing tests if the same expressive capacity can be retained with fewer independent angles.  

5. Append a second final mixer stage in a different axis: after the existing parity-shared RX(“rx_final_even/odd”), immediately apply RY(“ry_final_even”) on 0,2,4,6 and RY(“ry_final_odd”) on 1,3,5,7.  
   Evidence: a two-axis mixer (RX→RY) could more thoroughly convert learned phases into populations and is a natural p=2 extension of the successful final non-commuting mixer motif.
