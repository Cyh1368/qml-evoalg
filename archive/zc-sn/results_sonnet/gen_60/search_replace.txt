<DESCRIPTION>
Enhance two-qubit axis diversity in the ring entangler layer: currently all ring edges use CRZ with alternating shared parameters (crz_ring_even/crz_ring_odd). We change the odd edges to use CRY instead of CRZ, keeping crz_ring_even on even edges and introducing cry_ring_odd on odd edges. Mixing rotation axes (Z and Y) in the entangling layer increases the expressivity of the circuit's effective unitary group coverage without adding any extra gates, depth, or parameters (same count, just relabeled param name and gate type). This mirrors the successful skip-2/skip-3 mixed-axis pattern already used elsewhere in the ansatz (CRZ/CRY alternation), and prior generations (seed variant 2) showed accuracy gains from axis mixing in the skip-connections; applying the same principle to the ring layer should further improve expressivity and validation accuracy at zero extra cost.
</DESCRIPTION>

def _ring_crz(n, even_param="crz_ring_even", odd_param="crz_ring_odd"):
    """Nearest-neighbor ring entanglement with alternating shared strength."""
    gates = []
    for i in range(n):
        j = (i + 1) % n
        param = even_param if i % 2 == 0 else odd_param
        gates.append({"gate": "CRZ", "wires": [i, j], "param": param})
    return gates
