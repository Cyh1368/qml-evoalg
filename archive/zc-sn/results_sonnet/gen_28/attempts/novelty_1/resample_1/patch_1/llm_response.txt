ry_crz_ring_rx_tied_skip

<DESCRIPTION>
The previous experiment showed that the RY + alternating-shared CRZ-ring + RX + shared-skip-CRZ architecture (score 0.87) clearly outperforms the RY/RZ-sandwich design currently in the file (score 0.81). I therefore replace the current ANSATZ_SPEC with a design built on that stronger architecture, and additionally apply the recommended symmetric parameter-tying trick to the RX layer (tying `rx_i` with `rx_{7-i}`) to cut the RX parameter count in half (8→4) while keeping full per-qubit RY expressivity and the proven alternating-shared CRZ ring plus single shared long-range CRZ skip connections. This keeps the well-performing entangling topology, reduces parameter count for better parameter efficiency and generalization, and should recover (and hopefully exceed) the 0.87 score while using fewer parameters than the original 0.87 design.
