parametrized_ring_plus_skip_entanglement

<DESCRIPTION>
The best-performing prior ansatz (score 0.87) used *parametrized* CRZ ring entanglers (with two shared "even/odd" parameters) followed by an additional sparse skip-2 CRZ layer with a single shared parameter. The current program instead uses fixed (non-trainable) CZ gates for its ring entangler and has no skip-2 layer, which likely limits its ability to learn the right entangling strength and long-range correlations, contributing to its lower score (0.85) despite having more total parameters spent on local RZ layers.

This edit swaps the fixed CZ ring for a trainable CRZ ring (using two shared parameters "crz_ring_even"/"crz_ring_odd" to keep parameter count modest with an alternating strength pattern), keeps the existing RZ_pre/RZ_post single-qubit layers for local expressivity, and appends a lightweight skip-2 CRZ layer with one shared parameter ("crz_skip") for long-range mixing, mirroring the structure that empirically achieved the best combined score. This only adds 3 extra parameters while replacing the non-trainable CZ ring with a trainable one, and should improve validation accuracy and reduce the train-test gap by letting the model learn entangling strengths rather than fixing them to maximal (CZ) values.

Argumentation: Trainable ring entanglement strength was shown effective in earlier variants (CRZ ring + skip layer, score 0.87), and adding a controllable long-range skip connection increases expressivity for capturing global correlations at very low parameter cost (single shared parameter), consistent with parameter-efficiency goals.
