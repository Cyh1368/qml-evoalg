alternating_skip_ring_ansatz

<DESCRIPTION>
Reverting to the best-performing base structure (RY layer → alternating-strength ring CRZ entangler → full RX layer → skip-2 CRZ entangler) which previously achieved the highest combined score (0.87), and additionally applying the recommended mutation: splitting the single shared `crz_skip` parameter into two alternating parameters `crz_skip_even`/`crz_skip_odd` for the skip-2 connections. This mirrors the proven alternating-sharing pattern used successfully in the ring layer, giving the long-range entangler more expressivity (2 degrees of freedom instead of 1) while still keeping parameter count low and preserving the implicit regularization benefit of shared parameters. This should improve validation accuracy and reduce the train-test gap relative to both the fully-shared skip layer and the current CZ+long-range variant that scored lower (0.81).

</DESCRIPTION>
