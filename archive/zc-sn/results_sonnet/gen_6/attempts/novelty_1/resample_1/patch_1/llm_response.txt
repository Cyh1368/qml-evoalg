ring_entangled_shared_ansatz

<DESCRIPTION>
The seed ansatz used many independent single-qubit RY/RZ rotations (24 free angles per layer) combined with a simple linear CZ ladder, giving high parameter count but only nearest-neighbor, unweighted entanglement. This new design keeps the idea of alternating single-qubit rotation layers and entangling layers, but replaces the fixed, parameter-free CZ ladder with *parametrized* ring and long-range entangling gates whose rotation angles are **shared** across all pairs in a layer. This dramatically cuts the number of trainable parameters devoted to entanglement (from 0 informative params in CZ to a handful of shared angles) while giving the entangler an actual learnable strength, which should improve expressivity per parameter and reduce overfitting.

Key ideas combined from the context programs and extended:
1. Keep two blocks of individually-parametrized single-qubit rotations (RY then RZ then RY) to preserve local expressivity, similar to the seed's RY/RZ pattern.
2. Replace the fixed CZ ladder with a *ring* of CRZ gates (qubit i -> qubit i+1 mod 8) using a **single shared parameter** for the whole ring — this gives a rotation-angle-controlled uniform entangling strength that the optimizer can tune, instead of a fixed CZ.
3. Add a fixed-topology CNOT ring (no parameters) to mix information further without adding parameter count, ensuring full connectivity across all 8 qubits.
4. Add a long-range CRX layer connecting qubits (i, i+4) — i.e., opposite corners of the ring — again using a single shared parameter, to capture global correlations cheaply.
5. This yields far fewer parameters devoted to entanglement (2 shared angles total) versus the seed's 24 pure single-qubit parameters and 0 informative two-qubit parameters, improving parameter efficiency while adding genuinely tunable multi-qubit correlation structure that should help validation/test generalization.

This is a fundamentally different strategy than the seed: instead of "all single qubit rotations parametrized, entanglement fixed," we use "moderate single-qubit parametrization + cheap but tunable shared-parameter entanglers with full ring and long-range coverage," aiming for a better accuracy/parameter tradeoff and smaller train-test gap.
