<NAME>
tie_symmetric_rz_params
</NAME>

<DESCRIPTION>
Reduce parameter count and improve generalization by tying the pre- and post-entangling RZ rotation parameters across symmetric qubit pairs (0,7), (1,6), (2,5), (3,4). Instead of 8 independent rz_pre and 8 independent rz_post parameters, we now use only 4 shared rz_pre and 4 shared rz_post parameters, each applied to a mirror-symmetric pair of qubits. This halves the RZ parameter count (16 → 8) while preserving the same gate structure and depth, which should reduce overfitting (smaller train-test gap) similar to the gains seen with the shared long-range CRZ entangler, without sacrificing expressivity since the ring topology already treats qubits symmetrically.
</DESCRIPTION>
