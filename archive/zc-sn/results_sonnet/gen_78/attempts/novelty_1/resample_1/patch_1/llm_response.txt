modular_skip_diam_ansatz

<DESCRIPTION>
This crossover merges the clean, modular layer-construction style of the second seed (functions for RY/RX layers, ring entanglement, skip entanglement, diameter entanglement) with the axis-diversified skip-connection trick from the current program (alternating CRZ/CRY on the skip-2 layer instead of a single-axis CRZ). The skip-3 layer from the pure modular version is dropped to cut gate count/depth (which should help convergence speed, similar to the current program's faster convergence at step 150) while keeping the single-parameter antipodal "diameter" CRZ layer for cheap global mixing (which contributed to the modular version's better validation/test loss of 0.31/0.34). The block is still duplicated with fully shared parameter names to double effective depth without inflating the parameter count, following the pattern that worked well in both parents. This combination aims to capture the best of both: fast convergence, low generalization gap, and strong validation/test loss with an efficient parameter budget.

Concretely, one block is:
1. RY layer (8 independent params) — expressivity.
2. Ring CRZ, alternating shared params (2 params) — local nearest-neighbor mixing.
3. RX layer (8 independent params) — second rotation axis.
4. Skip-2 entanglement alternating CRZ/CRY (2 params) — mid-range mixing with axis diversity, cheaper and more expressive than a single-axis skip layer.
5. Diameter (distance-4) CRZ, single shared param — cheap global mixing across the whole register.

This block is applied twice with fully shared parameter names, giving depth without added parameter cost.

"""Seed program. Only ANSATZ_SPEC inside the EVOLVE-BLOCK is evolved.

Everything else about the task, that is how inputs are encoded, how the circuit
is measured, how training works and how metrics are computed, is fixed and lives
in a module that is not reproduced here. No information about the data is
available in this file.
"""

from _backend import run_experiment as _run

N_QUBITS = 8
ALLOWED_SINGLE_QUBIT_GATES = {"RX", "RY", "RZ"}
ALLOWED_TWO_QUBIT_GATES = {"CNOT", "CZ"}
ALLOWED_PARAM_TWO_QUBIT_GATES = {"CRX", "CRY", "CRZ"}


# EVOLVE-BLOCK-START
def _ry_layer(qubits, prefix="ry"):
    """Per-qubit RY rotations, one trainable parameter each."""
    return [{"gate": "RY", "wire": q, "param": f"{prefix}_{q}"} for q in qubits]


def _rx_layer(qubits, prefix="rx"):
    """Per-qubit RX rotations, one trainable parameter each."""
    return [{"gate": "RX", "wire": q, "param": f"{prefix}_{q}"} for q in qubits]


def _ring_crz(n, even_param="crz_ring_even", odd_param="crz_ring_odd"):
    """Nearest-neighbor ring entanglement with alternating shared strength."""
    gates = []
    for i in range(n):
        j = (i + 1) % n
        param = even_param if i % 2 == 0 else odd_param
        gates.append({"gate": "CRZ", "wires": [i, j], "param": param})
    return gates


def _skip_mixed(n, step=2, even_param="crz_skip_even", odd_param="cry_skip_odd"):
    """Sparse skip-`step` entanglement that alternates rotation axis
    (CRZ / CRY) between even and odd source qubits. This gives extra
    expressivity per parameter compared to a single-axis skip layer,
    at no additional parameter cost (still just two shared params)."""
    gates = []
    for i in range(n):
        j = (i + step) % n
        if i % 2 == 0:
            gates.append({"gate": "CRZ", "wires": [i, j], "param": even_param})
        else:
            gates.append({"gate": "CRY", "wires": [i, j], "param": odd_param})
    return gates


def _diameter_crz(n, param="crz_diam"):
    """Antipodal (distance n/2) entanglement with a single shared parameter,
    providing cheap global mixing across the whole register without
    inflating the parameter count."""
    half = n // 2
    return [{"gate": "CRZ", "wires": [i, i + half], "param": param} for i in range(half)]


def _build_block(n=N_QUBITS):
    """Compose one full ansatz block from modular layers:
      1. Per-qubit RY rotations (expressivity).
      2. Ring CRZ entanglement, alternating shared strength (local mixing).
      3. Per-qubit RX rotations (second rotation axis, more expressivity).
      4. Skip-2 entanglement, alternating CRZ/CRY shared params (mid-range
         mixing with axis diversity at low parameter cost).
      5. Diameter CRZ entanglement, single shared parameter (cheap global
         mixing across the whole register).

    Compared to a full modular design that also includes a skip-3 layer,
    this trims one entangling layer to reduce circuit depth/gate count,
    aiming for faster convergence while retaining both mid-range and
    global connectivity.
    """
    block = []
    block += _ry_layer(range(n))
    block += _ring_crz(n)
    block += _rx_layer(range(n))
    block += _skip_mixed(n, step=2)
    block += _diameter_crz(n)
    return block


_BLOCK = _build_block(N_QUBITS)

# Apply the block twice, reusing identical parameter names across both
# copies. This deepens the circuit (more expressive power, more entangling
# layers) while keeping the parameter count unchanged compared to a single
# copy -- the same regularizing "shared depth" trick that drove earlier
# generations' accuracy gains, combined with a lean but diverse
# entanglement topology (ring, axis-mixed skip-2, and single-parameter
# diameter) that balances expressivity, parameter efficiency and
# convergence speed.
ANSATZ_SPEC = _BLOCK + _BLOCK
# EVOLVE-BLOCK-END


def run_experiment(**kwargs):
    return _run(ANSATZ_SPEC, **kwargs)
