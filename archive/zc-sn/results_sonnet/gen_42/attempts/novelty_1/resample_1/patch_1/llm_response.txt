alternating_skip2_crz_split

<DESCRIPTION>
The current "crz_skip" layer uses a single shared parameter across all 6 skip-2 edges (0-2,1-3,2-4,3-5,4-6,5-7), which limits expressivity for this long-range connectivity layer. Following the proven alternating-parameter pattern already successfully used in the ring layer (crz_ring_even/odd), I split the skip-2 layer into two alternating shared parameters: "crz_skip_even" for edges [0,2],[2,4],[4,6] and "crz_skip_odd" for edges [1,3],[3,5],[5,7]. This adds only 1 extra parameter (from 1 to 2) while doubling the trainable degrees of freedom in this connectivity pattern, allowing even and odd qubit chains to learn independent long-range correlations. This mirrors the ring layer's structure and should improve the model's capacity to capture skip-connectivity patterns without significantly increasing parameter count or depth, consistent with prior generations (Gen31/33/37) that benefited from this alternating design.
