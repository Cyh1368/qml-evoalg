diameter_tied_ansatz

<DESCRIPTION>
Builds on the previous best-performing tied-duplication ansatz (0.89 score) by adding a diameter-distance entangling layer (distance-4 CRZ connections with a single shared parameter) after the existing skip-2 layer. This introduces long-range (opposite-qubit) correlations that were previously missing, while keeping parameter growth minimal (only 1 new shared parameter per block). The full block — RY pre-rotation, alternating-shared ring CRZ, RX rotation, shared skip-2 CRZ, and now shared diameter CRZ — is then duplicated with fully tied parameter names (as in the best prior candidate), doubling effective depth without increasing parameter count beyond the single extra diameter parameter. This tests whether adding a genuinely all-to-all-reachable connectivity pattern (ring + skip-2 + skip-4 gives every qubit pair reachable within 2 hops) improves validation accuracy and reduces the generalization gap relative to the 0.89 baseline, while still using very few unique parameters (20 per block) for efficient training and fast convergence.
</DESCRIPTION>
