# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Parameter sharing in single-qubit rotation layers across even/odd qubit pairs (labels “ry_a”/“ry_b” and “rz_pre_*/rz_post_*”) doubled parameter efficiency to 0.02 and drove the top combined score of 0.87 with only a 0.01 generalization gap (Current Best Program).  
- Bidirectional CZ chains (a forward 0–7 chain immediately followed by its reverse) enriched entanglement without adding trainable parameters, yielding robust generalization (gap 0.01) and matching the highest score versus single-direction chains (e.g., Shared-Rotation Linear Chain: gap 0.09, score 0.84).  
- Splitting RZ rotations into pre- and post-entanglement blocks preserved expressivity with only 38 parameters, mirroring the low-param/high-expressivity trend seen in the Shared RY/RZ Sparse Skip-Link Ansatz (38 params, score 0.86, gap 0.02).  
- Compact, shared-parameter designs converged faster: the best shared-parameter CZ ansatz reached stable accuracy in ~180 steps versus ~570–750 steps for deep, fully independent or CRX/CRZ-heavy circuits (Alternating-CRX: 570 steps; RY-RZ-CZ independent: 750 steps).  

## Ineffective Approaches  
- Fully independent rotation layers with high parameter counts (164–158 params) produced low parameter efficiency (0.01) and never exceeded combined scores of 0.84–0.78 (8-Qubit Layered RY-RZ: 0.78, gap 0.02; Alternating-CRX: 0.84, gap 0.08).  
- Incorporating parametrized two-qubit gates (CRX, CRY, CRZ) inflated circuit depth and gate count without clear accuracy gains, and often increased overfitting (e.g., RY-RZ-CRZ ansatz: gap 0.12, score 0.84; Layered RY/RZ+CRY: gap 0.07, score 0.86).  
- Dense entangling patterns followed by heavy, untied rotation layers (Shared-Rotation Linear Chain Ansatz) failed to improve scores (0.84) and suffered larger gaps (0.09) despite mid-range parameter counts (134).  
- Deep circuits (>99 depth) without parameter tying consistently under-utilized parameters (efficiency 0.01) and required more training steps, underscoring diminishing returns from brute-force depth increases.  

## Implementation Insights  
- Using a JSON-style ANSATZ_SPEC with shared parameter labels (e.g., “ry_a”/“ry_b”, “rz_pre_a”/“rz_pre_b”, “rz_post_a”/“rz_post_b”) provides a minimal, readable mechanism for enforcing pairwise parameter tying across multiple gates.  
- Leveraging native, unparameterized CZ gates in a forward/reverse chain attains full qubit connectivity and strong entanglement at zero additional parameter cost, outperforming CRX/CRY/CRZ-based schemes.  
- The clear separation of “pre-entanglement” and “post-entanglement” single-qubit rotation layers—each with shared parameters—maximizes expressivity per parameter and stabilizes convergence.  
- Encapsulating only the ANSATZ_SPEC in the evolve block (with all training/measurement logic fixed) allows rapid iterative refinement of circuit patterns without re-implementing backend details.  

## Performance Analysis  
- The Current Best Program (shared-parameter bidirectional CZ ansatz) ties the top combined score of 0.87 but doubles parameter efficiency to 0.02 (versus 0.01 in the similarly scored Shared-Parameter Star-Topology Ansatz) and cuts the generalization gap to 0.01 (from 0.05).  
- Circuits with parameter efficiency ≥0.02 (Current Best; Sparse Skip-Link Ansatz) consistently achieve combined scores ≥0.86 and generalization gaps ≤0.02, while all designs with efficiency 0.01 cap out at scores ≤0.86 with gaps ≥0.07.  
- Convergence speed anti-correlates with free-parameter count: the best tied-parameter designs converge in ~180 steps, whereas fully independent or CR-gate-heavy circuits require 4–5× more optimization steps.  
- Although the best ansatz has the greatest depth (154) and gate count (312), its superior parameter efficiency and minimal overfitting produce the highest net performance, validating the trade-off of moderate hardware cost for maximal algorithmic gain.

# META RECOMMENDATIONS

The following are actionable recommendations for the next program generations:

1. Merge the pre- and post-entanglement RZ layers into a single shared parameter per group.  Replace both “rz_pre_a”/“rz_post_a” with “rz_a” (and likewise “rz_b”), so each qubit still receives two RZ rotations but they share the same angle.  This halves n_params (≈20 total), doubles parameter efficiency, and directly tests whether the symmetry of tied pre/post RZ alone can sustain a 0.87 score with an even smaller overfitting gap.  

2. Append a global, all-qubit RX rotation after the final RZ layer using a single new parameter “rx_global”.  Drawing on the success of minimal shared rotations in RY/RZ, this lone RX gate per qubit can enhance Hilbert-space mixing at almost zero overhead.  If it boosts validation accuracy without harming generalization, you’ve gained expressivity with only one extra parameter.  

3. Insert a CZ “star” fan-out centered on qubit 3 between the forward and reverse chains: add unparameterized CZs from qubit 3 to each of the others—and in the reverse chain, from each back to 3.  This zero-parameter entangling motif broadens connectivity in the spirit of skip-link and bidirectional chains, potentially tightening the generalization gap without inflating depth or parameter count.  

4. After the post-entanglement RZ block, add a second shared RY layer with an orthogonal grouping: assign qubits [0,2,4,6]→“ry_c” and [1,3,5,7]→“ry_d”.  You introduce only 2 new parameters but capture rotation modes that the original even/odd pairing misses.  This extension of the mirror-symmetric RY structure should preserve fast convergence while enriching local expressivity.  

5. Replace the unparameterized CZs in the reverse chain with a tied CRZ gate “crz_rev”.  Swap each reverse-direction CZ for CRZ(wires, param=“crz_rev”), so all seven edges share one trainable phase.  This lightweight two-qubit parameterization tests whether a single global entangling angle can outperform fixed CZs, adhering to the low-overfitting benefits of shared parameters.
