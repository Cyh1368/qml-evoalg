<DESCRIPTION>
The current program (score 0.90, 68 params) has added too many parameters and gates, increasing depth and complexity without meaningful accuracy gains. The best prior performer (score 0.91, 50 params) used alternating CRZ in the reverse chain with only 2 parameters (crz_rev_a, crz_rev_b), achieving better efficiency.

Key insight: The current program's cross-talk CRY layer (4 params) and mid-circuit RX (1 shared param) add 40% more parameters than the optimal prior design while validation accuracy remains at 0.92. The prior program's strength was parameter efficiency (50 params vs 68) combined with strategic parameter sharing.

New approach:
1. Return to the efficient reverse-chain CRZ alternation (crz_rev_a, crz_rev_b) proven to work well
2. Add lightly parametrized forward entanglement: replace alternating CZ gates in the forward chain with CRZ using a single shared "crz_fwd" parameter on links [1,2], [3,4], [5,6], keeping CZ on [0,1], [2,3], [4,5], [6,7]
3. Eliminate the cross-talk CRY layer and mid-circuit RX layer entirely
4. Reduce post-entanglement RZ to just one pair-shared parameter
5. Target: ~48-50 params with improved expressivity from bidirectional parametrized gates

This hybrid approach:
- Adds minimal trainable parameters (crz_fwd alone)
- Probes whether weak forward gate tuning improves learning
- Maintains the proven efficient reverse chain structure
- Reduces depth and gate count vs current program
- Should improve parameter efficiency while maintaining or improving accuracy
