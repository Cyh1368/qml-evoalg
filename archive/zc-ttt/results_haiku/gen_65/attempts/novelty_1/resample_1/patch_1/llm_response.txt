<DESCRIPTION>
This novel approach draws inspiration from the successful parameter sharing strategies observed in prior programs (particularly the global `rz_phase` parameter and shared `crx_shared` gates), but applies a fundamentally different hierarchical structure.

Key insights from context programs:
1. Shared parameters (like `rz_phase`) reduce overfitting and parameter count while maintaining expressivity
2. The second program achieved better validation accuracy (0.68) with more parameters but better generalization
3. Mixed gate types (CRX, CRY, CRZ) provide better expressivity than uniform gates
4. Three-qubit interactions (ZZZ, CCRZ) enhance learning capacity

Novel approach:
- **Hierarchical CRZ tying**: Instead of individual CRZ parameters, group symmetric qubit pairs into shared parameter families. This reduces parameters while preserving expressivity through structured sharing.
- **Strategic CCRZ placement**: Replace one ZZZ gate with CCRZ to leverage double-control expressivity, which can capture more complex correlations with fewer parameters.
- **Dual-phase RZ strategy**: Use separate `rz_pre` and `rz_post` phases to allow the circuit to learn distinct pre- and post-entanglement coherence adjustments, improving generalization.
- **Reduced output layer**: Share some output RY parameters to reduce overfitting while maintaining sufficient degrees of freedom.
- **Optimized gate density**: Carefully balance parametrized vs. fixed gates to achieve better parameter efficiency without sacrificing expressivity.

This design aims to achieve higher validation accuracy (target: 0.70+) with controlled parameter growth, reducing the generalization gap below 0.06.
