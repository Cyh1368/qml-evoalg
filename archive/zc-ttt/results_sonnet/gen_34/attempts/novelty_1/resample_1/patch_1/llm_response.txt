<DESCRIPTION>
Collapse all four CRZ gates incident on qubit 0 (edges [0,2], [0,3], [0,7], [0,8]) into a single shared parameter `crz_hub0`. Currently these use three distinct params (crz_0, crz_1, crz_2 twice), giving qubit 0's hub asymmetric treatment relative to other qubits' more heavily shared entangling structure. Sharing a single rotation angle across all edges from qubit 0 imposes a symmetry prior (qubit 0 interacts identically with its neighbors), reducing parameter count from 162 to 159 while preserving depth and gate count. This tests whether stronger symmetry-driven parameter reduction on the highest-degree hub qubit improves generalization (smaller train-val gap) without sacrificing expressivity, following the pattern that already gave gains when moving from fully independent CRZ params (score 0.61) to partial sharing (score 0.63).
</DESCRIPTION>
