add_rx_layer_full_rotation

<DESCRIPTION>
The current ansatz applies only RY then RZ rotations per qubit before entangling, which does not span the full single-qubit rotation group (missing an X-axis component). Adding an RX layer prior to the RY layer turns each qubit's local unitary into an RX‑RY‑RZ product, which is capable of representing an arbitrary single-qubit rotation (up to global phase). This should increase the model's expressive power and help address the current underfitting symptom (train accuracy only 0.57), without an excessive parameter increase (adds 9 parameters per block instantiation). The three-layer single qubit rotation combined with the existing entangling CZ pattern should give the circuit more capacity to fit the data while keeping the well-tested entangling topology unchanged.

Argumentation: Since generalization gap is small (0.07) but overall accuracy is quite low (train ~0.57, val ~0.55, test ~0.49), the model appears to be underfitting rather than overfitting. Adding expressivity to the single-qubit rotation stage is a natural way to increase capacity without changing the entangling qubit-pair topology (which is architecturally fixed by hardware constraints), and is a standard technique in variational circuit design (using a universal single-qubit rotation decomposition RX-RY-RZ instead of just RY-RZ).
</DESCRIPTION>
