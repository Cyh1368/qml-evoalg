crz_dual_sublayer_reorder

<DESCRIPTION>
The best-performing seed used a monolithic 12-gate CRZ entangling block (depth 41, combined score 0.63), while a variant that replaced half the CRZ gates with fixed CZ gates lost expressivity and regressed to 0.59. This version keeps the full parametrized CRZ block (restoring accuracy) but restructures it into two explicit sub-layers as recommended: sub-layer A = {(0,2),(0,3),(0,7),(0,8),(1,3),(2,4)} and sub-layer B = {(1,8),(2,6),(3,5),(4,8),(5,7),(6,7)}, while preserving all original parameter-sharing (crz_2 shared between 0–7/0–8, crz_3 shared between 1–3/1–8, crz_4 shared between 2–4/2–6). This reordering groups gates by shared-qubit dependency more tightly within each half, aiming to shave circuit depth (targeting ~39 instead of 41) without changing the parameter count (162) or gate count (207), while keeping the same expressive entangling structure that gave the best combined score so far.
