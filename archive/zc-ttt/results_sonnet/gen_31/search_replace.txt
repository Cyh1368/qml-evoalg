Additionally, it implements the suggested extreme hub-edge sharing: all four CRZ gates incident on qubit 0 ([0,2],[0,3],[0,7],[0,8]) now share a single parameter `crz_hub0` instead of using two separate parameters (`crz_0`, `crz_1`, `crz_2` reused twice). This reduces two-qubit parameter count from 4 to 1 for qubit-0's edges, testing whether stronger symmetry-driven parameter sharing (treating qubit 0 as a symmetric hub controller) improves generalization further while keeping circuit depth and gate count unchanged. The remaining CRZ sharing pattern (crz_3 for [1,3]/[1,8], crz_4 for [2,4]/[2,6]) is kept as in the best prior version, since it already demonstrated improved validation accuracy (0.72) and reduced overfitting gap (0.09) relative to the no-sharing seed.
