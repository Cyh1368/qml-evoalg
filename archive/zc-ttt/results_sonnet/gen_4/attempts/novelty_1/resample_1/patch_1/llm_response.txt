parametrized_entanglers_reuse_params

<DESCRIPTION>
The seed circuit uses fixed (non-trainable) CZ gates for all entangling interactions, which limits the model's ability to learn correlations between qubits — this likely explains the relatively low train accuracy (0.57) despite a sizable parameter count (162). I replace the fixed CZ two-qubit gates with parametrized CRZ gates, reusing the already-existing "rz_pre_<control>" rotation parameters as the controlled-rotation angle for each entangling edge. This makes every two-qubit interaction trainable and lets the optimizer learn how strongly qubits should be entangled, increasing expressivity and potentially improving fit quality, while keeping the total parameter count exactly the same (162) since no new parameter names are introduced — sharing the "rz_pre_x" params between the local RZ rotation and the entangling CRZ gate. This should improve train/validation accuracy without increasing overfitting risk from added parameters.
</DESCRIPTION>
