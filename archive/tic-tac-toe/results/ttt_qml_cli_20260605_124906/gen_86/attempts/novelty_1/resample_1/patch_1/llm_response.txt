The key insight from the recommendation is to alternate the rotation axis across repeats within the same ansatz block application. This injects complementary entanglement correlations (X-axis in one repeat, Y-axis in another) without adding parameters—we reuse the same shared parameter for both axes.

**Strategy:**

2. In `apply_ansatz_block`, branch on `repeat_index` (0 or 1):

   - Odd repeat (repeat_index=1): Use CRY on ring edges with the same shared "crx_ring" parameter
3. This provides axis diversity at zero parameter cost, building on the proven single-shared-parameter ring approach

**Expected benefit:**
- Richer entanglement structure through complementary rotation axes
- No parameter overhead (reuse the same parameter name across different gate types)

def apply_ansatz_block(params, block_index: int) -> None:
    """Apply one candidate ansatz block from the formal ANSATZ_SPEC.
    
    Special handling: ring entanglement axis alternates between repeats.
    - Even repeat_index (0): use CRX on ring edges
    - Odd repeat_index (1): use CRY on ring edges
    This provides axis diversity without additional parameters.
    """
    if SPEC_ERRORS:
        raise ValueError("; ".join(SPEC_ERRORS))

    upload_index = block_index // N_REPEATS
    repeat_index = block_index % N_REPEATS
    offset = block_index * N_PARAMS_PER_BLOCK
    key_to_position = {key: i for i, key in enumerate(PARAMETER_KEYS_PER_BLOCK)}
    
    # Determine which gate axis to use for ring on this repeat
    ring_gate_type = "CRX" if repeat_index == 0 else "CRY"
    
    for item in ANSATZ_SPEC:
        gate = str(item["gate"]).upper()
        if gate in ALLOWED_SINGLE_QUBIT_GATES:
            angle = params[offset + key_to_position[item["param"]]]
            wire = int(item["wire"])
            if gate == "RX":
                qml.RX(angle, wires=wire)
            elif gate == "RY":
                qml.RY(angle, wires=wire)
            elif gate == "RZ":
                qml.RZ(angle, wires=wire)
        elif gate in ALLOWED_TWO_QUBIT_GATES:
            wires = [int(w) for w in item["wires"]]
            if gate == "CNOT":
                qml.CNOT(wires=wires)
            elif gate == "CZ":
                qml.CZ(wires=wires)
        elif gate in ALLOWED_PARAM_TWO_QUBIT_GATES:
            angle = params[offset + key_to_position[item["param"]]]
            wires = [int(w) for w in item["wires"]]
            
            # Alternate ring axis based on repeat_index
            if gate == "CRX" and item["param"] == "crx_ring":
                if ring_gate_type == "CRX":
                    qml.CRX(angle, wires=wires)
                else:
                    qml.CRY(angle, wires=wires)
            elif gate == "CRY":
                qml.CRY(angle, wires=wires)
            elif gate == "CRZ":
                qml.CRZ(angle, wires=wires)
