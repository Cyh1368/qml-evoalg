<DESCRIPTION>Introduce a base RY parameter per group (corner/edge/center) and add per-upload delta parameters for the three uploads, so each upload can slightly adjust the shared RY rotations. This increases expressivity while keeping the same overall structure. The apply block remains generic; the extra delta parameters are simply additional RY gates with the same wires, summing their angles (since rotations around the same axis commute). This should improve validation/test performance by enabling upload-specific modulation of the RY layer without changing the training loop or feature map.</DESCRIPTION>
