per_upload_crx_ring_deltas

<DESCRIPTION>
Introduce per-upload deltas to the ring entanglement by replacing the perimeter CZ gates with a pair of CRX gates per edge: a shared base CRX gate and a per-block delta CRX gate. This leverages additive gate composition (CRX(base) followed by CRX(delta) on the same wires yields a net rotation of base + delta) to provide modest but expressive per-upload flexibility without exploding parameter count. The base parameter (crx_ring_base) is shared across all blocks, while crx_ring_delta provides upload-specific adjustments. This changes only ANSATZ_SPEC and increases N_PARAMS_PER_BLOCK by 2 (crx_ring_base and crx_ring_delta), scaling N_PARAMS accordingly. The approach follows the suggested delta-parameter technique for improved expressivity with controlled parameter growth.
</DESCRIPTION>
