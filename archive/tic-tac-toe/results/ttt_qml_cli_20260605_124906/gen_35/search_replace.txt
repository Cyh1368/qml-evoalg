<DESCRIPTION>
Introduce a secondary hub entanglement layer by adding CRZ entangling gates from the center qubit to each edge qubit. This augments the expressivity around the center-edge couplings with a single shared parameter per hub-edge pair, which can improve information propagation and potentially boost validation/test performance without drastically increasing depth. The change appends four CRZ gates after the existing per-edge CRX hub-edge gates, using a new parameter key crz_hub_edge.
</DESCRIPTION>
