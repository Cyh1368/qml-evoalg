<DESCRIPTION>
Introduce a more expressive ring entanglement by replacing the CZ ring with a ring of CRX gates that share a single parameter across all edges. This aligns with the higher-performing prior setup that uses a ring of CRX with a shared parameter, reducing per-block parameter count while increasing expressivity, which can improve validation/test performance and potentially close the train-test gap.
