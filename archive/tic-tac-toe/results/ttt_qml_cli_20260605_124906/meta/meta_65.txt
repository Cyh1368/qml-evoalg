# GLOBAL INSIGHTS SCRATCHPAD

The following are global insights about optimization approaches and their effectiveness:

## Successful Algorithmic Patterns  
- Five-layer hierarchical ansatz with symmetry-aware rotations and two levels of parameterized entanglement (pre-RZ → RY → CRX ring → CRY hub → post-RZ), repeated 3 × 2 times, achieves the top combined score of 0.60 (train 0.57, val 0.65, test 0.50) in the **Seed Program**.  
- Single shared CRX parameter for all outer-ring entangling gates concentrates entangling power efficiently; splitting the ring into multiple parameters (e.g., Gen 73 in prior work) consistently undercut combined score by ≈0.10, whereas the seed’s one-parameter ring preserves expressivity.  
- Single shared CRY parameter for center-to-edge (hub) entanglement maintains rich connectivity without inflating the parameter budget—key to boosting validation accuracy to 0.65 in the seed.  
- Four-fold rotational symmetry grouping into three parameter keys per rotation layer (corner/edge/center) keeps the total at 66 parameters and depth at 70, striking the optimal expressivity–compactness balance.  

## Ineffective Approaches  
- Over-aggressive parameter sharing across both rotation and entanglement layers (Programs Gen 81, 82, 83) yielded compact circuits (60–66 params) but underfitted, scoring only 0.43–0.44 combined with narrow generalization gaps (0.15–0.17).  
- Introducing non-parametric two-qubit gates (e.g., adding CZ to the ring/hub motif in Gen 85’s “ring_hub_crx_plus_cz”) reduced combined score to 0.45, indicating that fixed CZ entanglers dilute the learning capacity of parameterized CRX/CRY.  
- Simply increasing circuit depth or gate count without enriching parameter diversity (Gen 84 depth 132, 333 gates) only raised combined score to 0.48, far below the seed’s 0.60, reinforcing that depth alone does not compensate for under-expressive ansatz design.  
- Fragmenting ring entanglement into multiple parameters or over-sharing rotation layers led to stagnant low training accuracy (≈0.33–0.37), signaling insufficient capacity to model tic-tac-toe win/draw patterns.  

## Implementation Insights  
- Mapping parameter keys to positions once per ansatz block (`key_to_position = {…}`) keeps the hot loop in `apply_ansatz_block` at O(1) lookup per gate, minimizing Python overhead during repeated block invocations.  
- Validating `ANSATZ_SPEC` upfront via `validate_ansatz_spec` prevents wasted training on malformed circuits (seed SPEC_ERRORS = [] vs. earlier gens aborting).  
- Extracting `QuantumScript` from a `qml.queuing.AnnotatedQueue` permits precise measurement of depth (70) and gate count (261), enabling consistent tracking of the empirically optimal sweet spot.  
- Isolating all candidate changes inside `ANSATZ_SPEC` while keeping data-loading, feature map, and training loop fixed ensures fair, focused comparisons—demonstrated by the seed’s repeatable 0.60 combined score with zero std deviation.  

## Performance Analysis  
- The seed’s combined score of 0.60 outpaces all evaluated variants (next best: Gen 84 at 0.48), demonstrating a clear performance gap (≈0.12).  
- Circuits with similar depth (70) but fewer parameters (60 in Gen 81) scored ~0.44, underscoring that the seed’s exact 66-parameter design is critical for expressivity.  
- Underfitting variants display small generalization gaps (0.03–0.17) alongside low test accuracy (0.32–0.50), whereas the seed balances capacity and regularization with a gap of 0.07 and test accuracy of 0.50.  
- Validation accuracy correlates strongly with combined score: only the seed exceeds 0.60 combined by attaining val 0.65; all other designs plateau at val 0.44–0.47, reinforcing the importance of the seed’s specific ansatz structure.

The following are actionable recommendations for the next program generations:

1. Interleave ring–hub–ring within each ansatz block  
   In `_build_hierarchical_ansatz_spec`, split the eight perimeter CRX gates into two groups of four (e.g. wires 0→1,1→2,2→3,3→4 then 4→5,5→6,6→7,7→0) and insert the four CRY hub gates between them. This “ring–hub–ring” ordering uses exactly the same `"crx_ring"` and `"cry_hub_edge"` parameters and keeps the block depth ≈35, but it enriches entanglement mixing at zero extra parameter cost—building on the seed’s proven two-level structure.  

2. Alternate entanglement axis on the ring edges  
   Modify the ring layer in the spec so that you alternate between CRX and CRY on the eight outer edges, e.g.  
     • CRX on (0,1), CRY on (1,2), CRX on (2,3), CRY on (3,4), …  
   All eight gates still draw from the single `"crx_ring"` key. By mixing two-qubit rotation axes around the perimeter, you diversify nonlocal correlations without changing the 66-parameter budget—leveraging the seed’s success with one shared ring angle.  

3. Inject long-range opposite-edge entanglement for free  
   After the hub layer in each block, append two extra CRX gates on opposite edge pairs `{1→5, 3→7}`, both using the existing `"crx_ring"` parameter. These new “cross-board” links introduce additional long-range connectivity that the seed lacked, yet cost zero new parameters and add minimal depth, potentially capturing diagonal win/draw patterns more efficiently.  

4. Add a mid-block, symmetry-shared RY layer  
   Merge `"rz_pre_edge"`/`"rz_post_edge"` into a single `"rz_edge"` (and similarly merge corner keys), freeing two parameter slots. Then, between the seed’s RY and ring layers, insert:  
     • `{"gate":"RY","wire":i,"param":"ry_mid_corner"}` for corners i∈{0,2,4,6}  
     • `{"gate":"RY","wire":i,"param":"ry_mid_edge"}` for edges i∈{1,3,5,7}  
     • `{"gate":"RY","wire":8,"param":"ry_mid_center"}`  
   This extra three-key rotation layer tunes superpositions immediately before entanglement, building on the proven power of symmetry-shared rotations while holding Nₚₐᵣₐₘ=66.  

5. Swap entanglement order on alternating repeats  
   In `apply_ansatz_block`, branch on `repeat_index`: for even repeats apply the standard “pre-RZ → RY → ring → hub → post-RZ” ordering, but for odd repeats swap the ring and hub steps so it becomes “pre-RZ → RY → hub → ring → post-RZ.” This reorder mixes the two-qubit interactions in a new way at zero parameter cost, exploiting the block structure’s modularity to potentially improve expressivity.
