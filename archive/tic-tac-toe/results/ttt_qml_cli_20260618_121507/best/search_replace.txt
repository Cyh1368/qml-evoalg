<DESCRIPTION>
The current bidirectional CRY layer increased depth and parameters but reduced validation/test accuracy, likely because it over-rotates population amplitudes and disrupts the useful endpoint-to-midpoint line features. This edit keeps the extra entangling capacity but changes that second outer-ring layer to orbit-shared CRZ gates aligned with the same tic-tac-toe line segments as the successful CRY layer. CRZ adds conditional phase/parity information, which later RX/RY readout mixers can convert into Z evidence, while avoiding the stronger amplitude scrambling of reverse CRY. Parameter count remains the same as the current candidate, but the inductive bias is closer to line/parity detection.
