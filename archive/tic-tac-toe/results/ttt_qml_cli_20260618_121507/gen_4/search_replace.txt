<DESCRIPTION>
Replace the heavily parameter-shared CRY-only line block with a more sign-sensitive hardware-efficient/line-compressor hybrid. The fixed RX feature map stores player sign primarily in the Y quadrature; adding trainable RZ followed by RY lets the circuit rotate that sign information into Z readout. Independent per-wire RX/RZ/RY input rotations improve expressivity compared with the current orbit-shared decoder, while keeping post-readout rotations orbit-shared for regularization. Fixed CNOT line-compressor motifs target tic-tac-toe line midpoints and the center using only allowed grid adjacencies, creating stronger non-parametric nonlinear/parity features than small-initialized controlled rotations. Shared CRY gates then softly route midpoint evidence into the measurement groups for cross/circle/draw without excessive parameters.
</DESCRIPTION>
