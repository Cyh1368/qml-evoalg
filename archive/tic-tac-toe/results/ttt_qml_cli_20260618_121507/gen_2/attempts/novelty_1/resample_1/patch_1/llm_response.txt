The fixed training configuration uses Adam with learning_rate=0.03, 100 epochs, 30 steps/epoch, batch_size=15, l=3 data re-uploading, and p=2 ansatz repetitions. The original block used 27 independent parameters per block, giving 162 total trainable parameters, with a generic EfficientSU2-style CZ mesh.

This proposal changes only the EVOLVE-BLOCK. The new ansatz uses tic-tac-toe structure directly: shared corner/edge/center RX and RY rotations decode the signed RX feature map while reducing overfitting; CRY gates aggregate adjacent pairs along legal winning-line segments; center-to-edge CRY gates help route diagonal and center-line information through the allowed grid connectivity; final shared RY/RX readout rotations improve measurement alignment for the fixed [cross, circle, draw] observables. Parameter sharing reduces the model to 90 total parameters while preserving symmetry and using entanglement more task-specifically than the seed CZ-only mesh.
