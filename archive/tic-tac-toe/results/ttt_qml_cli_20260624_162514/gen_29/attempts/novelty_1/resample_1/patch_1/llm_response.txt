<DESCRIPTION>
Refine the ansatz to improve generalization and reduce circuit depth. Changes:
- Replace parametrized CRX-heavy entangling (which drove up depth and gate count) with a compact fixed CZ entangling pattern (symmetric reduced ring + two hub links). This lowers depth and regularizes the model.
- Split the shared RX mixing parameter into rx_corner and rx_edge (keeping rx_center) so corners and edges can be mixed differently while keeping parameter growth minimal (one extra RX param).
- Add a small final RY output layer (shared periphery vs center) to sharpen readout decision boundaries without a large parameter increase.

These edits aim to reduce overfitting (lower capacity / depth) while giving the model targeted local flexibility (corner vs edge RX), improving validation/test accuracy and parameter efficiency.
</DESCRIPTION>
