add_fixed_cz_entangling_between_crz_and_zzz
</NAME>

<DESCRIPTION>
Introduce fixed CZ entangling gates on every allowed grid edge immediately after the shared CRZ layer. The CZs add deterministic entanglement and cross-talk without increasing the number of trainable parameters, giving the subsequent three-qubit ZZZ/CCRZ motifs richer correlated inputs to act on. This aims to improve expressivity and accelerate learning while preserving parameter efficiency and respecting connectivity constraints.

The replacement only modifies ANSATZ_SPEC (inside the allowed EVOLVE block) and keeps all existing parameter keys unchanged so N_PARAMS is the same. CZ gates are placed on each GRID_EDGE, inserted between the CRZ layer and the ZZZ motifs.
</DESCRIPTION>
