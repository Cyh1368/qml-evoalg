add_shared_crz_and_zzz_motifs
</NAME>

<DESCRIPTION>
Introduce two motif-inspired modifications to the ansatz block to improve learning of tic-tac-toe structure while keeping parameter growth modest:

1. Replace the fixed CZ entanglers with a shared-parameter CRZ ("crz_edge") on every allowed grid edge. This makes the entangling strength trainable but parameter-efficient because all edges reuse the same parameter within a block.
2. Add collective three-qubit ZZZ rotations on the eight winning lines using a single shared parameter ("zzz_shared") per block. These explicitly target the triple correlations that define win conditions, again using sharing to keep the parameter count low.

Both motifs are repeated per block (and still receive independent copies across uploads/repeats), so the circuit can adapt entanglement strength and emphasize winning-line correlations while only modestly increasing N_PARAMS. The change respects connectivity and gate vocabulary constraints.
</DESCRIPTION>
