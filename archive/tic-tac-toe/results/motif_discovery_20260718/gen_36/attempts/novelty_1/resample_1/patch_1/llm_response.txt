<DESCRIPTION>
Replace the current ansatz block with a compact, symmetry-aware motif architecture that proved effective in earlier experiments.

Changes:
- Split the three-qubit ZZZ motif into separate row/column/diagonal parameters so the circuit can learn distinct responses for different geometric winning patterns.
- Keep symmetry-grouped local rotations (pre/post RZ and RY) to reduce parameter count while respecting board symmetries.
- Retain a CZ lattice backbone for stable entanglement propagation.
- Add a shared CRZ for center-edge couplings and a CCRZ on diagonals to provide targeted center/diagonal modulation.
- The design uses 14 unique parameter keys per block (14 * 3 uploads * 2 repeats = 84 total parameters), balancing expressivity and parameter efficiency.

Rationale:
Splitting the ZZZ motifs by geometric class encourages the circuit to develop distinct detectors for win-lines (rows, columns, diagonals). The CZ backbone ensures good entanglement spread; targeted controlled-phase gates (CRZ/CCRZ) give the network tunable interactions that focus on center-mediated and diagonal features. Grouped single-qubit rotations reduce redundant parameters while preserving symmetry priors. This configuration previously improved validation/test metrics relative to the current block.
